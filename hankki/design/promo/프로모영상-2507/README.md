## 다시 뽑는 법
```
cd <scripts가 있는 작업폴더>
npm i ffmpeg-static playwright-core   # ffmpeg 없는 환경이면 ffmpeg-static 필요
node promo_build.mjs                  # promo.html 생성(자산 base64 인라인)
node promo_render.mjs                 # Playwright 녹화 → ffmpeg mp4(9:16) 인코딩 → 검수 프레임
# 스토어용 16:9(세로 원본 가운데 + 양옆 블러):
ffmpeg -i 한끼-프로모-2507.mp4 -filter_complex \
 "[0:v]scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080,boxblur=28:2,eq=brightness=-0.20:saturation=0.82[bg];[0:v]scale=-2:1080[fg];[bg][fg]overlay=(W-w)/2:(H-h)/2[v]" \
 -map "[v]" -r 30 -c:v libx264 -preset slow -crf 16 -pix_fmt yuv420p -movflags +faststart 한끼-프로모-2507-스토어-16x9.mp4
```
- `promo_build.mjs` = 6장면 애니 HTML(타임라인). 자산 경로는 `src/assets/stickers/photo`·`design/promo/fonts`·`docs/stickers/곰펭-에피소드-2507` 기준.
- `promo_render.mjs` = 1080×1920 녹화 + 검은화면 자동트림 + mp4 인코딩(crf 15). (이미지 디코드 후 `__go`로 애니 시작)
  - ⚠️ **버그 픽스(2026-07-26)**: blackdetect 로그는 **stderr**로 나오는데 예전엔 execFileSync(stdout)로 읽어 파싱이 항상 실패 → 트림이 기본값이라 **검은 리드인이 남았음**. 이제 `execSync(...2>&1)`로 읽고 검은구간 끝난 뒤부터 사용.
