# 🎬 한끼 프로모 영상 (2026-07-24)

레꾸 꾸미기 과정 영상 [#24] — **스토어 프로모(유튜브 링크) + 인스타 릴스 겸용.**

## 스펙
- `한끼-프로모-2507.mp4` — **세로 9:16 (1080×1920) · ~30.5초 · H.264/yuv420p · 30fps · 무음**
- Play 프로모 영상 규격 충족(30~120초, 9:16/16:9 허용). 인스타 릴스도 그대로 OK.

| ~5-11s | **꾸미기** (②레꾸) | 큰 카드 **연어 포케볼**(fe_06) + **곰펭 콩콩 점프**(앱 hk-kong 모션) + 스티커 하나씩(펭·곰·포스트잇·✨·🌸) + 트레이(곰·펭·떡볶이·아보카도스무디 fe_15) |

## 원칙 (창업자 확정)
- **훅(0~7초)이 승부처** — 드라마틱하고 임팩트 있게, 너무 빠르지 않게.
- **최신 자산만** — 곰펭=물결 gp_*, 음식=예시전용 **fe_ 아이콘**(범용 fy_ ❌), 상표안전 큐레이션명.
- **곰펭 모션 = 앱 실제 모션 그대로**(styles.css): 콩콩(hk-kong)·통통(hk-tongtong)·살랑/인사(hk-sway).
- 무음 — 인스타 올릴 때 트렌드 음원 얹기. 스토어는 유튜브에 비공개(일부공개) 업로드 후 링크.

## 다시 뽑는 법
```
cd <scripts가 있는 작업폴더>
npm i ffmpeg-static playwright-core   # ffmpeg 없는 환경이면 ffmpeg-static 필요
node promo_build.mjs                  # promo.html 생성(자산 base64 인라인)
node promo_render.mjs                 # Playwright 녹화 → ffmpeg mp4 인코딩 → 검수 프레임
```
- `promo_build.mjs` = 6장면 애니 HTML(타임라인). 자산 경로는 `src/assets/stickers/photo`·`design/promo/fonts`·`docs/stickers/곰펭-에피소드-2507` 기준.
- `promo_render.mjs` = 1080×1920 녹화 + 검은화면 자동트림 + mp4 인코딩. (이미지 디코드 완료 후 `__go` 신호로 애니 시작 → 타이밍 오프셋 0)
