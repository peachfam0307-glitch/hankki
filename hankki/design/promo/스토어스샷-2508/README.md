## ⭐ 왜 다시 뽑았나 — **음식 아이콘이 옛 그림이었다**

v5(2026-08-22) 의 **02번 「레시피가 쌓이면 나만의 요리책」** 장에 깔린 음식 아이콘이
전부 **옛 카와이 일러스트**였다. 그 뒤에 창업자 실사 컷으로 세 번 갈아끼웠다 —
**v11.32(106컷) · v11.44(119컷) · v11.49(6컷 ＋ 픽커 재편)**.
즉 **스토어에 올라간 그림이 지금 앱과 다른 세대**였다.

⛔ 뿌리는 2026-07-31 에 적어둔 그것과 같다 —
*"스샷을 앱 밖에서 따로 그려서 앱이 바뀌어도 안 따라온다."*
✅ 이번 판은 **앱을 실제로 띄워 찍은 화면**을 쓴다(`scripts/_shot-스토어용화면-0822.mjs`).

## 🔁 다시 뽑는 법 (앱이 바뀌면 이 두 줄)

```
node scripts/_shot-스토어용화면-0822.mjs     # 앱을 띄워 화면 8장 캡처
node scripts/_판-스토어시안-0822.mjs         # 그 위에 헤드라인을 얹어 스토어 8장
```
→ `/tmp/.../scratchpad/스토어시안/` 에 나오면 **이 폴더로 복사**한다.
⛔ scratchpad 는 세션과 함께 날아간다 — 저장소에 두는 이유다(규칙 20).
