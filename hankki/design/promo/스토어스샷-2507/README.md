## 📐 규격이 이미 맞았다

`Onboarding.jsx:59` = *"1080×1920 스테이지를 화면에 맞춰 통째로 축소 **(스샷 디자인 픽셀 그대로)**"*
`Stage` 는 `zoom: scale` 로 «보여주기만» 축소한다 — 원본은 **1080×1920**.
`fit()` = `min(innerWidth/1080, innerHeight*0.82/1920)` → **뷰포트 1080×2342 면 scale ≈ 1**.
＋`deviceScaleFactor: 2` = **2160×3840** 출력.

## ⛔⛔ 만들며 두 번 틀렸다 — 둘 다 규칙 18 ⓘ(검사가 무엇을 보는지)

   ✅ 애초에 **숨길 필요가 없었다** — 스테이지 «요소만» 찍으면 바깥 버튼은 안 들어간다.

   ✅ 안쪽에만 있는 **`zoom`** 으로 갈랐다.
   ⭐ **「DOM 에 스테이지 20장」을 찍어둔 줄이 이걸 잡았다** — 개수를 출력하는 게 값을 했다.
