# ⛔ 여기는 「지금 안 쓰는 것」만 모아둔 곳

**여기 있는 파일로 판단하지 마라.** 지우지 않고 남겨둔 건 기록 때문이지, 쓰라고 둔 게 아니다.

## 지금 쓰는 것
- 낱장 8장 → `../renders-v3/`
- 그리는 스크립트 → `../scripts/store_v3.mjs`

## 왜 옮겼나 (2026-07-31)
옛 8장이 **폴더 맨 위**에, 새 8장이 **`renders-v3/` 안**에 **같은 이름**으로 있었다.
그래서 「저장소에 있는 것 = 스토어에 올라간 것」이라고 잘못 판단했다.
실제로는 스토어의 ④가 이미 218종 판으로 교체돼 있었는데 저장소엔 7/24 판이 있었다.

창업자: *"너 옛날꺼 보고있는거 같은데"*, *"비교해봐 이게 마지막 에셋에 올라간 거야"*

문구를 되살릴 때도 옛 스크립트(`scripts/store_new2.mjs`)를 집어서
**폐기하기로 한 마트·제품 브랜드명을 도로 넣었다.**

📌 **내가 조심하면 될 일이 아니라 폴더가 그렇게 생겨서 난 일이었다.** 그래서 격리했다.

## 이제 어떻게 막히나
- 이 폴더의 파일을 열려고 하면 **훅이 막는다** (`.claude/hooks/latest-guard.sh`)
  → 위 「지금 쓰는 것」을 먼저 읽으면 그때 열린다.
- 옛 세대가 다시 밖으로 나오면 `npm run smoke` 가 **실패**한다
  (`scripts/latest-map.mjs --check` — 같은 이름이 두 곳에 있으면 걸린다)

## ⚠️ 저장소가 모르는 것
**Play Console에 «지금» 올라가 있는 8장은 저장소로 알 수 없다.**
바꾸기 전에 반드시 창업자에게 실물을 확인할 것.
