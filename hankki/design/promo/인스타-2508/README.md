### ⭐ 인스타는 「게시물」과 「프로필 격자」가 다르다 — 여기서 갈린다

- **게시물 본문(피드에서 스크롤할 때)** — 1:1 · 4:5 · 3:4 **전부 그대로 나온다.** 안 잘린다.
- **프로필 격자(내 계정에 쌓이는 썸네일)** — **비율에 상관없이 전부 3:4 로 잘린다.**

우리 영상은 애들이 화면 끝에 붙어 있어서(§3 참조) 이게 크게 다르다:

| | 격자에서 잘리는 폭 | 무엇이 잘리나 |
|---|---|---|
| 1:1 | 1080 → 810 = **좌우 135px씩(25%)** | **카롱 몸통 절반 · 뾰미 꼬리와 귀** |
| 4:5 | 1080 → 1012 = 좌우 34px씩(6%) | 카롱 팔 끝 살짝 |
| 3:4 | 자를 게 없다 | — |

👉 눈으로 볼 것 = **`격자-비교.png`** (세 판을 실제로 3:4 로 잘라 나란히 놓은 것)

## 3. ⛔ 여기서 두 번 틀렸다 — 다음에 또 하지 말 것

### ⓐ 소리를 버렸다
첫 판을 만들 때 ffmpeg 에 `-an` 을 넣어 **오디오 트랙을 통째로 날렸다.**
창업자 *"원래 소리가 안나?"* 로 잡혔다.
👉 **원본에 소리가 있는지 «먼저 재고» 시작한다** — `ffmpeg -i 원본 -af volumedetect -f null /dev/null`
　 무음이면 `mean_volume` 이 -91dB 근처, 진짜 소리면 -17dB 같은 값이 나온다.

### ⓑ 세로로 만들었더니 애들이 작아졌다
창업자 *"세로로 하니까 애들이 잘 안보인다 ㅠ"*
원본이 **가로 16:9** 라, 세로 1080×1920 의 폭에 맞추면 높이가 **608px** — 화면의 **32%** 뿐이다.
👉 **가로 원본을 세로 틀에 넣으면 «무조건» 작아진다.** 틀을 정할 때 이걸 먼저 계산한다.

```
애들이 차지하는 비율 = 608 ÷ 틀 높이
   9:16(1920) → 32%      4:5(1350) → 45%      1:1(1080) → 56%
```

### 좌우를 잘라 키울 수 없는 이유 — **픽셀로 쟀다**
| 프레임 | 그림 범위 | 왼 여백 | 오른 여백 |
|---|---|---|---|
| 0.3초 | x=16~1243 | 16px | 36px |
| 2.5초 | x=0~1279 | **0px** | **0px** |
| 5.0초 | x=54~1198 | 54px | 81px |
| 7.5초 | x=0~1246 | **0px** | 33px |
| 9.5초 | x=20~1243 | 20px | 36px |

왼쪽 **카롱**, 오른쪽 **뾰미**가 화면 끝에 붙어 있다 → **좌우를 자르면 애들이 잘린다.**
👉 확대·크롭으로는 못 키운다. **틀의 세로를 줄이는 것만이 답이다.**

## 5. 합치는 명령 (4:5 기준)

```bash
FF=/usr/local/lib/python3.11/dist-packages/imageio_ffmpeg/binaries/ffmpeg-linux-x86_64-v7.0.2

# 본편 — 크림 바탕 위에 영상, 그 위에 투명 오버레이. 소리는 원본 그대로 ＋ 끝 0.8초 페이드아웃
"$FF" -f lavfi -i "color=c=0xF2E9D8:s=1080x1350:r=24:d=10" -i 원본.mp4 -loop 1 -i f45.png \
  -filter_complex "[1:v]scale=1080:608[v];[0:v][v]overlay=0:371[bg];[bg][2:v]overlay=0:0,format=yuv420p[out];[1:a]afade=t=out:st=9.2:d=0.8[a]" \
  -map "[out]" -map "[a]" -t 10 -c:v libx264 -preset medium -crf 19 -c:a aac -b:a 128k body45.mp4

# 아웃트로 — 3초, 0.45초 페이드인. ⚠️무음 트랙을 «넣어야» concat 이 된다
"$FF" -loop 1 -i o45.png -f lavfi -i "anullsrc=r=48000:cl=stereo" \
  -filter_complex "[0:v]fade=t=in:st=0:d=0.45,format=yuv420p[out]" \
  -map "[out]" -map 1:a -t 3 -r 24 -c:v libx264 -preset medium -crf 19 -c:a aac -b:a 128k outro45.mp4

printf "file 'body45.mp4'\nfile 'outro45.mp4'\n" > cat.txt
"$FF" -f concat -safe 0 -i cat.txt -c copy 한끼-인스타-4대5.mp4
```

**영상 y좌표** = (틀 높이 − 608) ÷ 2 → 4:5 는 **371**, 3:4 는 **416**, 1:1 은 **236**, 9:16 은 **676**.
