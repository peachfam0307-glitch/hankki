## ⛔⛔ 오늘 값을 치르고 배운 것 넷

**⑴ 밝은 그림 위에 «빛나는 흰 별»은 안 보인다**
🔢 뾰미 시안에서 반짝임 놓을 자리들의 바탕 밝기 = **187~198 / 255**. 흰빛이 더할 수 있는 건 60 남짓뿐이다.
✅ 답 = **테두리 있는 별**(갈색 선 ＋ 크림 속). 테두리는 어두워서 바탕이 아무리 밝아도 읽히고,
   시안이 「선으로 그린 그림」이라 **화풍도 맞는다**. 후광만 깔아 보는 건 「따뜻해졌다」 정도였고 «반짝»이 아니었다.

**⑵ 늘려 채우기는 「늘리는 방향으로 무늬가 없을 때」만 통한다**
릴스 끝판 CTA 를 안전지대로 올리려고 325px 들어올리고 아래를 «맨 아랫줄 8줄»로 늘려 채웠는데,
그 줄이 하필 **세로 줄무늬 선반**이라 화면 아래 5분의 1이 통째로 뭉갠 줄무늬가 됐다.
📮 창업자 = *"마지막 꾸며버림 아래 뭉개진거 그대로 나와. 이거 그대로 올려도 된다고?"*
⛔ 그리고 내가 *"열어서 확인했다 · 티 안 남"* 이라고 **적어놓고** 보냈다 — 작게 보고 판정한 것이다(규칙 13).

**⑶ 스티커 자리는 「규칙」이 아니라 「그 장에 어디가 비었나」가 정한다**
여덟 장을 같은 자리(카드 아래 모서리, 좌우 번갈아)에 기계적으로 박았더니 여섯은 통하고 둘은 빽빽한 데 처박혔다.
📮 창업자 = *"공간이 있는게 붙여야 하는데 애들이 다 좁은데 들어가있어"*

**⑷ ⭐제일 큰 것 — 문제를 하나씩 «더해서» 풀면 원본에서 멀어진다**
스샷 릴스를 세 판 헛돌았다. 그 순서가 정확히 이랬다 —

## ⚠️ 다음에 이 릴스를 다시 뽑을 때 조심할 것

- **창업자가 준 원본 녹화는 받는 즉시 안전한 자리로 옮긴다.** 차돌짬뽕 49.22초 원본이 `/tmp` 에서 사라져
  이미 만든 릴스에서 몸통을 떼어 써야 했다(`BODY_READY=1` · 한 세대 더 인코딩된다).
- **`ffmpeg -i` 는 출력 파일이 없으면 항상 exit 1** — `set -e` ＋ `pipefail` 이라 보고 줄에서 통째로 죽는다.
- **`zoompan` 의 `d` 는 「입력 한 장을 몇 장으로 늘릴까」** — `d=120` 을 줬더니 2초가 **1분 58초**가 됐다. `d=1`.
- **필터의 `fps=60` 만으로는 60fps 가 안 나온다** — 출력에 `-r 60` 을 직접 박아야 한다.
- **판 안 파이썬 블록에 백틱·달러중괄호 금지**(규칙 24) — 오늘 `_판-스샷인스타` 에서 «두 번» 죽었다. 낫표「」로.
- **bash 변수 이름은 ASCII**(규칙 24).
