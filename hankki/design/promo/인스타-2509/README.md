## ⚠️ 함정 기록

· `-ss` 를 `-i` **앞**에 두면 키프레임으로 어긋난다 → 경계 작업은 `-i` **뒤**에
· `color` 소스 위에 오려낸 조각을 얹을 때 **`setpts=PTS-STARTPTS`** 를 안 주면 첫 프레임이 **빈 화면**으로 나온다
· 조각을 따로 굽고 `-c copy` 로 이으면 **이음매에서 한 프레임이 깨진다** → **한 번에** 굽는다
· `concat` 필터는 크기·SAR·픽셀형식이 **전부 같아야** 한다 → 조각마다 `format=yuv420p,setsar=1`
· 원본 **24.82초부터** 공유 시트가 옆으로 밀려나며 화면이 찢어진다 → 그 전에 끊는다
· 이 ffmpeg 빌드엔 **`drawtext` 필터가 없다**
· 애니메이션은 CSS 로 두지 말고 **`setFrame(t)` 로 프레임마다 계산**한다 — 헤드리스에서 박자가 흔들린다
