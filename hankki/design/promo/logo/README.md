## 컨셉 (탐색 결과)

곰곰 셰프(마스코트)를 워드마크 "한끼"에 녹이는 방향으로 탐색. 후보 여럿 만들고
창업자 피드백으로 좁힘.

### ✅ 유력안 — 곰 = ㅎ
- **곰 얼굴이 "한"의 ㅎ 을 대체**, 셰프모자가 위로 뻗어 ㅎ 윗획 역할.
- 아래에 **HANKKI** 를 얹어 가독성 보강(곰이 ㅎ 대체 → 한끼가 애매하면 HANKKI가 잡아줌).
- 크기: **M (곰 W130)** 확정. 모자 테두리: **연한 브라운(#a5825f)** — ㅎ 글자처럼 붙어 보이게.
- 미리보기: `previews/logo-곰ㅎ-2색.png`, `previews/곰ㅎ-귀수정+확대.png`

### 앱 아이콘(홈화면) — 곰 마크만 + 아래 '한끼' 라벨 (유튜브식)
- 작은 아이콘에선 HANKKI가 안 보이니 **곰 얼굴만 타일에**, '한끼'는 OS 라벨로.
- 미리보기: `previews/앱아이콘-곰만-타일.png`

### 색 (2벌)
- **① 밝은 크림 + 브라운** — 앱 배경 크림톤과 통일(추천, 앱 아이콘용).
- **② 클레이 브라운 + 크림** — 홈화면에서 눈에 띔(대표그래픽·스플래시·모집카드 포인트용).

### 보류 아이디어 — 냄비 = ㅎ + 곰이 끼의 ㅣ 위
- 르쿠르제풍 냄비를 ㅎ 자리에(꼭지=ㅗ, 뚜껑=가로획, 동그란 몸통=동그라미),
  곰은 작게 "끼"의 ㅣ 위에 앉힘. "요리" 정체성이 직관적이나 곰 존재감↓·다소 정제된(대기업) 느낌.
- 미리보기: `previews/냄비ㅎ+곰ㅣ위.png`

## 🔧 다듬을 것 (다음에)
- **곰=ㅎ 좌우대칭**: 곰의 오른쪽 귀가 "ㅏ" 획과 붙어 비대칭으로 보임. 곰을 살짝 줄이거나
  ㅎ↔ㅏ 간격/배치 조정 필요.
- 최종 아이콘 세트 굽기: 192·512·maskable·apple-touch(작은 건 HANKKI 빼고 곰만).
- 온보딩/대표그래픽/스플래시에 로고 통일 반영.

## 왜 픽셀 검출?
폰트 글자 위에 마스코트를 눈대중 좌표로 얹으니 계속 어긋남. → 캔버스에 "한끼"를 그린 뒤
"한"의 ㅎ 카운터(구멍)를 flood-fill로 찾아 그 중심에 곰 얼굴중심을 맞춤. 재현 가능·정확.
