## 3. 🙋‍♀️ 우리(창업자·남편)를 숫자에서 빼기

### ⛔ 구글이 안내하는 IP 방식은 우리한테 «안 맞는다»

「내부 트래픽 정의」 화면은 설명 그대로 **「IP 주소를 정의합니다」** 다.
창업자 폰은 **모바일 데이터(KT)** 라 IP 가 계속 바뀌고, 집 와이파이도 대개 유동 IP 다.
며칠 뒤 딴 IP 가 되면 **조용히 안 걸러진다** — 조용히 실패하는 장치는 없는 장치다.

### ⭐ 그래서 「그 기기가 누구인가」로 가른다 — 두 조각이 맞물린다

```
① 앱 (v12.91)                         ② 콘솔 필터
   우리 기기면 딱지를 붙여 보낸다   →    딱지 붙은 것을 뺀다
   traffic_type: 'internal'             「traffic_type 가 internal 과
                                          정확하게 일치하는 이벤트를 제외」
```

**① 앱 쪽** — `src/stats.js` 가 `localStorage` 의 **`hankki:founder`**(운영자 열쇠)를 보고 정한다.
　 새로 만들지 않았다 — AI 무제한에 쓰던 열쇠가 **이미** 있었다(`ocr.js` · `nudges.js`).
　 🔢 실물 확인(브라우저에서 config 를 읽었다):
```
🙂 보통 유저   → {"anonymize_ip":true,"send_page_view":false}
🙋‍♀️ 열쇠 있음  → {"anonymize_ip":true,"send_page_view":false,"traffic_type":"internal"}
```

**② 콘솔 쪽** — `⚙ 관리 → 데이터 수집 및 수정 → 데이터 필터 → 「Internal Traffic」`
　 · 필터 유형 = **내부 트래픽** · 필터 연산 = **제외**
　 · 매개변수 `traffic_type` = `internal`
　 · **필터 상태 = 「사용중」** ← 2026-09-09 08:1x 창업자가 켰다(캡처로 확인)

　 ⛔ **켜기 전 기본값은 「테스트」였다** — 테스트는 **표시만 하고 실제로는 안 뺀다.**

### ⚠️ 알고 있을 것

- **24~36시간** 지나야 반영된다
- **이미 쌓인 것은 안 지워진다** — 앞으로 것만 걸러진다(9/8 밤 활성 사용자 4 는 그대로 남는다)
- ✅ **남편 폰도 끝났다** (2026-09-09 08:2x · 창업자 = *"남편것도 했어"* · 앱이 정상으로 떴다)
  방법 = 그 폰 크롬에서 `?founder=<열쇠>` 를 한 번 연다
  ⭐ **TWA(우리 앱)는 크롬과 저장소를 함께 쓴다** → 크롬에서 넣으면 앱도 읽는다
  ⚠️ 단 **기본 브라우저가 크롬일 때** — 삼성 인터넷이 기본이면 거기서 열어야 한다
  🔑 열쇠 값은 **저장소에 없다**(비밀이라 맞다). Cloudflare 워커 환경변수에 있다.

## 5. 🙅‍♀️ 흔한 오해 — 창업자가 물어서 확인한 것들

### ❓ *"내가 여러 번 들어가면 여러 명처럼 보이나?"*
**아니다.** 같은 폰·같은 앱으로 100번 열어도 **1명**이다. 폰에 저장된 임의의 번호로 묶인다.
**세션수·이벤트 수는 늘고, 활성 사용자는 안 는다.**

⚠️ **여러 명으로 «세어지는» 경우** = 기기가 다를 때(폰/패드/PC) · 시크릿 모드 · 앱 데이터 지우기.
⛔ **[정정]** 한때 *"앱과 브라우저는 저장소가 달라 2명일 수 있다"* 고 말했는데 **과장이었다** —
　 **TWA 는 같은 주소면 크롬과 저장소를 공유한다.**

### ❓ *"그 필터가 나만 빠지는 건 줄 어떻게 알아? 나만 설정하지도 않았는데"*
⭐ **날카로운 질문이었고, 이 질문 덕에 필터 조건을 실제로 열어 봤다.**
**콘솔은 「누가 나인지」 모른다.** 가르는 것은 **폰**이다 — 우리 폰에만 열쇠가 있어 딱지가 붙고,
콘솔 필터는 「딱지 붙은 것 빼기」라는 규칙일 뿐이다. 두 조각이 맞물려야 돌아간다.

### ❓ *"개발자 계정만 빼기를 안 해도 되나?"*
**「개발자 계정」이라는 개념이 통계엔 없다.** GA 콘솔에 로그인한 것과, 그 폰이 앱을 쓰는 것은
완전히 별개다(9/8 밤 활성 사용자 4 에 창업자가 그대로 들어가 있던 것이 그 증거다).
게다가 **우리 앱은 계정 정보를 통계에 아예 안 보낸다** — 계정 기준 제외는 애초에 불가능하다.
⭐ **기기 기준이 오히려 낫다** — 앱에서 로그아웃해도, 계정을 바꿔도 계속 빠진다.
