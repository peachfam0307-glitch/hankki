[캐릭터: 꼬르곰 — 맨날 배고픈 순둥이 아기곰 셰프]

   — 기쁘면 붕 뜨고, 슬프면 축 처지고, 당황하면 삐뚤어짐.
   (모자를 늘리거나 고무처럼 변형하진 말고, 위치·각도만 바꿈)
② 나무 숟가락: 기본적으로 손에 쥐고 있음.
   단, 두 손 제스처가 필요한 컷(박수·하트·만세 등)에선 앞치마 주머니에 꽂거나 옆에 둠.
③ 크림색 미니 앞치마(가는 스트라이프·앞주머니·작은 리본)

■ 입 (상황별 스위치)
- 먹는/배고픈 컷에서만: 살짝 벌어진 입 + 혀 조금, 침은 아주 가끔 한 방울(욕망 표현)
- 그 외 감정·인사 컷: 평범하고 담백한 입(그 컷 감정에 맞게)

■ 그림체 (카톡 인기 이모티콘 감성)
- 얇고 균일한 연속선(연한 브라운). 손으로 슥 그린 살짝의 손맛은 OK, 단 선이 뚝뚝 끊기면 안 됨
- 100% 플랫 컬러. 음영·그라데이션·입체감 없음
- 여백 많고 단순하게. 소품·배경 최소, 이펙트는 한 컷에 1종류
- 흰 배경, 정사각형, 글자 없음

■ 분위기
- "하찮은데 웃긴" 톤: 본인은 진지한데 어딘가 허술해서 웃김. 능청스럽고 뻔뻔하게
- 표정보다 포즈·모자·숟가락이 감정을 말하게

■ 하지 말 것
- 3등신 / 붉은 진갈색 / 눈 반짝이 여러 개 / 굵은 검정 외곽선 / 음영
- 라인프렌즈 브라운·리락쿠마·곰돌이 푸와 비슷하게

[포즈] ← 이 줄만 아래 32컷 리스트에서 갈아끼우기

## B. 🐧 펭펭이 기본 프롬프트 (복붙)

```
초귀여운 카카오톡 이모티콘 캐릭터를 그려줘. 아래 설정을 그대로 지켜줘.

[캐릭터: 펭펭이 — 시크한 패셔니스타 아기펭귄]

■ 비율
- 2등신, 곰보다 날씬한 세로 계란형 실루엣(뚱뚱한 공 모양 금지)
- 날개·발은 짧고 뭉툭, 몸통은 길쭉·시크하게

■ 얼굴
- 눈: 반쯤 감긴 심드렁한 눈("그래서?" 느낌). 활짝 웃지 않고, 눈썹만 살짝 움직여 감정 표현
- 귀여운 일자 단발(앞머리가 일자로 딱 떨어져 얼굴을 감쌈)
- 부리: 작은 주황 삼각형 / 볼터치: 아주 연하게

■ 색 (은은하고 따뜻한 톤 — 채도 너무 낮지 않게)
- 몸: 은은한 블루그레이, 배는 흰색, 부리·발은 주황

■ 시그니처 (패션 = 펭펭이의 정체성)
- 블랙 베레모를 삐딱하게(위에 꼭지)
- 귀여운 트렌치코트(베이지~연카멜) — 시그니처 (가죽자켓 아님, 건달 느낌 나서 뺌)
- 슬림한 검정 선글라스는 필요한 컷에서만(썬글 쓸 땐 반쯤 감긴 눈이 위로 빼꼼)
- 팔짱 자주, 머리 옆에 점 세 개 "…"

■ 표현
- 무표정·리액션 최소. 감정은 말·표정보다 행동으로(눈썹 까딱, 베레 만지기, 폰 먼저 보기)

■ 그림체 (곰과 동일)
- 얇고 균일한 연속선(연한 차콜). 살짝 손맛 OK, 끊김은 금지
- 100% 플랫, 음영·그라데이션 없음. 여백 많이. 흰 배경, 정사각형, 글자 없음

■ 분위기
- "하찮은데 시크한" 톤: 패션은 완벽한데 리액션이 영혼 없어서 웃김. 능청스럽고 뻔뻔하게

■ 하지 말 것
- 왕눈·활짝 웃음 / 크고 동그란 안경(범생이) / 굵은 검정 외곽선 / 음영
- 펭수·뽀로로와 비슷하게

[포즈] ← 이 줄만 아래 32컷 리스트에서 갈아끼우기
팔짱 끼고 고개 살짝 기울여 심드렁하게 쳐다보는 모습, 머리 옆에 점 세 개
```

[크기 관계 — 꼭 지킬 것]

- "하찮은데 웃긴" 톤. 표정보다 포즈·소품이 감정을 말하게

[하지 말 것]
- 둘 크기 비슷하게 X / 음영 X / 굵은 검정선 X / 라인프렌즈·펭수·뽀로로 비슷하게 X

[포즈] ← 이 줄만 케미 6컷(아래 27~32번)에서 갈아끼우기
곰이 하트뿅 돌진해 안기려 하고, 작은 펭이 한 날개로 곰 이마를 밀어 막는 모습. 곰은 초롱초롱, 펭은 무표정

## E. 📱 사용법 (중요)
1. **새 대화 열지 말고 같은 대화에서 계속.** 첫 그림 잘 나오면 "이 캐릭터 그대로, 이번엔 ○○하는 모습".
2. 잘 나온 **기준 그림 저장 → 새 컷마다 첨부** + "이 그림이랑 똑같은 캐릭터로".
3. **글자 절대 넣지 마** — AI가 한글 깨뜨림. 대사·자막은 나중에 얹음. 포즈·표정으로만 의미 전달.
4. **수정은 한 번에 하나씩**: "모자 더 붕 뜨게" / "선 더 얇게" / "침 빼줘".
5. **콤비컷은 규칙 C 꼭 붙이기**(펭을 작게 안 하면 크기 똑같이 나옴).
6. 잘 나온 것 클로드에게 전송 → 판정 + 세트 밸런스 점검 + 최종 자막.
