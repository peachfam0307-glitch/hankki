# Play Console 스토어 이미지(아이콘·그래픽) 교체법 — 삽질 포함 ✅ 완료기록

> 2026-07-17 스토어 등록정보의 아이콘·그래픽을 곰곰이로 교체하며 "저장 버튼이 어디에도 없어서" 한참 헤맴.
> 결론: **스토어 등록정보엔 눈에 띄는 "저장" 버튼이 없고, 저장은 "게시 개요"에서 "검토 제출"로 완료된다.**

---

## ⚡ TL;DR — 다음에 이미지 바꿀 때 (PC)
1. Play Console → 한끼 앱 → 왼쪽 **`사용자 늘리기` → `앱 정보` → `기본 스토어 등록정보`**
2. "기본 스토어 등록정보" 줄 오른쪽 **`수정 →`** 클릭
3. `그래픽` 섹션에서 **앱 아이콘 / 그래픽 이미지** 각각 **`애셋 추가`** → 컴퓨터에서 파일 선택
   - 아이콘 = `public/icons/icon-512-v6.png` (512×512)
   - 그래픽 = `design/promo/renders/스토어-그래픽-곰돌이.png` (1024×500)
4. 왼쪽 메뉴 **`게시 개요`** 로 이동 → **`검토를 위해 변경사항 N개 제출`**(파란 버튼) 클릭 → 끝.
   - 빠른 검사(최대 14분) 후 자동으로 검토 제출됨. 등록정보 변경은 보통 몇 시간~하루 검토.

---

## ⚠️ 헤맨 지점 3가지 (이거 모르면 또 헤맴)
1. **"저장" 버튼이 페이지 맨 아래에 없다.** 화면을 아무리 내려도(스크린샷·XR 동영상 칸까지) 저장 버튼이 안 보인다.
   → Play Console 규칙: **실제 변경사항이 있을 때만** 저장 UI가 뜬다. 그런데 스토어 등록정보는 애셋을 추가하면 그 자체가 "변경 대기" 상태로 잡히고, **최종 저장/제출은 `게시 개요`에서** 한다.
2. **"페이지에서 나가시겠습니까? 저장하지 않은 변경사항은 삭제됩니다" 창**이 뜨면 = 아직 미저장.
   → ⚠️ 빨간 **`나가기 및 삭제` 누르지 말 것**(변경 날아감). **`머무르기`** 누르고 위 4번(게시 개요 제출)으로.
3. 저장 버튼 찾을 때 **`Ctrl` + `-`(축소)** 로 화면 줄이면 숨은 버튼이 보이기도 한다(이번엔 축소해도 없었음 → 게시 개요가 정답이었음).

---

## 최종 확인법
- 게시 개요에 **`검토 중인 변경사항`** 으로 "앱 아이콘 변경 / 그래픽 이미지 변경" 2건 뜨면 = 제출 성공.
- 스토어 반영은 검토 통과 후(몇 시간~하루). 앱 기능엔 영향 없음.

---

## 교훈 (일반화)
- **콘솔에서 "저장이 안 돼" 싶으면 = 실제로는 별도 "제출/게시" 단계가 따로 있는 경우가 많다.** 저장 버튼만 찾지 말고 게시/검토 개요를 확인.
- 메뉴 경로는 자주 바뀜 → 안내 전 최신 확인(2026: "성장"→"사용자 늘리기", 중간이 "앱 정보").
