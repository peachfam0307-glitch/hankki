### 문제 ① 문구가 앱과 다르다

### 문제 ② ⛔ **유니코드 이모지가 박혀 있다** (우리 규칙 위반)
렌더 스크립트를 스캔해보니 스샷 소스에 이모지가 **20종**:

### 문제 ③ 🐛 **이모지 하나가 깨져 렌더됐다**
①히어로 포스트잇의 `오늘 한 끼 완성! 🍳` 에서 **프라이팬이 돋보기 모양으로 나온다.**

📌 **셋 다 같은 뿌리** — 스샷을 **앱 밖에서 따로 그렸기 때문**이다. 앱이 바뀌어도 안 따라온다.

`title === ''` 는 «절대» 참이 될 수 없다** → 직접 고른 아이콘이 항상 버려지고 제목 자동추천으로 덮인다.
제목을 같이 고친 경우도 같다. **아이콘만 바꾸면 유지된다** — 그래서 될 때와 안 될 때가 갈렸다.

📌 뿌리 = v8.58 에 「제목 바뀌면 아이콘 다시 추천」을 넣으면서
**「유저가 직접 고른 것」과 「자동으로 붙은 것」을 구분하지 않았다.**
→ 고칠 방향 = **직접 골랐다는 표시를 남긴다**(자동으로 붙은 것만 다시 추천).

⚠️ 재현을 시도했지만 **앱이 건드리기 전엔 `hankki:v1` 에 아무것도 안 쓴다**(첫 렌더로는 저장 안 됨)
→ **고치기 전에 UI 를 실제로 눌러 재현하고, 고친 뒤 다시 재현으로 확인할 것**(규칙 7).

`migrateBasics` 맨 앞에 `if (v >= BASICS_VERSION) return …` 가드가 있어 **버전이 오를 때만 돈다.**
