## 4. ⚠️ 아이폰은 «푸시하면 바뀌지 않는다» — 안드로이드와 다르다

📌 **이걸 헷갈리면 사고가 난다.**

| | 안드로이드(Play · TWA) | 아이폰(App Store · Capacitor) |
|---|---|---|
| 앱 화면 | **웹을 고치면 바로 바뀐다**(심사 없음) | ⛔ **빌드에 «구워 넣는다»** (`"webDir": "../hankki/dist"`) |
| 고치려면 | 푸시 = 배포 | **다시 굽고 → 다시 올리고 → 다시 심사** |

⛔ 그러니 **아이폰 쪽 고침은 「다음 빌드」에 실린다.** 오늘 고친 것(빈 접시·브리또 두 편)은
   **안드로이드엔 곧 나가지만 아이폰엔 다음 빌드 때** 들어간다.
