## 3. 🏗 설계 — 3층

### 층1 · 담는 그릇 = `docs/계측-일별-YYYY-MM.json` (기계가 읽는다)
하루 = 한 덩어리. 사람·기기·화면 15·행동 34·워커·쿠팡·유지·**비고(그날 우리 기기로 열었나)**.
⛔ **빈 칸은 `0` 이 아니라 `null`(모름)** — 「안 받았다」와 「0이었다」는 다른 값이다.
🔢 하루 ≈ 1.5KB → 30일 45KB. **달마다 파일을 가른다**(`9월-지켜보기` 가 이미 89,413 B 라 Markdown 에 다 쓰면 같은 길을 간다).

### 층2 · 읽는 도구 = `scripts/계측-보고.mjs`
| 명령 | 무엇 |
|---|---|
| `--넣기 <날짜>` | 그날 값을 JSON 에 넣는다. **검산** = 화면별 조회 합 ≠ 개요 총 조회수면 **죽는다**(캡처가 잘렸다는 뜻) |
| `--하루 <날짜>` | 그날 한 장 ＋ **전날과 견줘 바뀐 것만** |
| `--추세 7` | 이레 흐름 — 늘었나 줄었나 |
| `--달 2026-09` | 월 보고서 Markdown 을 **만들어 준다** ⛔손으로 안 쓴다(손으로 쓰면 낡는다) |
⭐ 나누기 전에 **`계측-잣대.mjs` 를 스스로 부른다** — 공정 구간 밖 값으로는 비율을 안 낸다.

### 층3 · 판단으로 잇는 고리 = `docs/계측-기대치.json`
흐름마다 「이 정도면 정상」을 **미리** 적어 두고, 벗어나면 🔴 로 뜬다.

| 잣대 | 지금 | 벗어나면 |
|---|---|---|
| 징검다리 건넘% | 87~90% | **< 80%** 🔴 광고 → 설치가 샌다 |
| `brag_shared` | 0 이 며칠째 | **3일 연속 0** 🔴 자랑 길 의심 |
| 새 사용자 | 33→22→14→12 | **3일 연속 내리막** 🔴 (⛔광고비를 같이 봐야 갈린다) |
| `home` 머문 시간 | 9초 | **< 5초** 🟡 홈이 문 노릇도 못 한다 |
| 가져오기 저장률 | ⏳ 9/20 에 첫 깨끗한 값 | 기준을 그때 정한다 |
⛔ **표본이 작으면 경보를 안 낸다** — `n < 30` 이면 비율을 아예 안 말한다.

## 4. 🔁 다각도 검토 셋 (절대원칙 33 · 관문 통과본)

**1차 · 사람** — 창업자가 바쁜 날엔 5장 중 2장만 준다 → 빈 칸을 0 으로 세면 「유저가 안 했다」가 된다.
　→ ⓐ빈 칸 `null` ⓑ**매일은 「바뀐 것 3줄」만**, 전체는 주 1회, 깊은 판단은 월 1회 ⓒ새 세션이 모르니 **브리핑에 「어제 칸이 비었다」** 한 줄.

**2차 · 사고** — ⓐ내가 숫자를 잘못 옮긴다 → **검산**(합이 안 맞으면 죽는다) ⓑ캡처가 「1-50 of 95」로 잘린 판이다(2026-08-04 와 같은 사고) → **행 수를 같이** ⓒ오염 기간을 안 보고 나눈다 → **잣대 자동 호출** ⓓ같은 날을 두 번 넣어 덮는다 → **안 덮고 경고** ⓔ우리 기기가 섞인다 → **비고 칸**.

**3차 · 규모·시간** — 화면 15 ＋ 행동 34 = 하루 49줄. 유저가 100명이든 1만명이든 **이 수는 안 늘어난다**(화면 수가 고정이라). 늘어나는 건 날짜뿐 → 달별 파일. 1년 = 12파일 × 45KB.
