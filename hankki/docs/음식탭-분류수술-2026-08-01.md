뭔가 중구난방이야. 확인 후 완벽 수정. **분류자체가 좀 이상한듯해.**"*

→ **셋 다 사실이었다.** 눈으로 훑지 않고 코드에서 직접 세서 확인했다(`_diag.mjs`·`_diag2.mjs`).

## 2️⃣ 뿌리 원인 두 가지

### ⓐ 그림 세대가 겹쳐 있다 — 31쌍
같은 요리를 **다른 시트에서 또 그렸는데 둘 다 픽커에 올렸다.**

| 겹치는 세대 | 쌍 |
|---|---|
| `fi_j*` ↔ `fi_isk*` (일식) | 우동·라멘·장어덮밥·타코야키·미소국 **5쌍** |
| `fy_y*` ↔ `fy_yng*` (양식) | 햄버거·샌드위치·오므라이스·스테이크 **4쌍** |
| `fh_k*` ↔ `fh_hnc/htj/hnb*` (한식) | 불고기·돌솥비빔밥·순두부·미역국·삼계탕·갈비탕·잡채·계란말이 **8쌍** |
| `fb_b*` ↔ `fb_bun*` (분식) | 김밥·라면·떡볶이·순대 **4쌍** |
| `fj_c*` ↔ `fj_jsk*` (중식) | 볶음밥·마파두부 **2쌍** |
| `fe_*` ↔ 기존 | 오징어볶음·리조또·브런치·피자·만두 등 |

📌 **그래서 스크롤하면 똑같은 게 계속 나온다. 그게 「중구난방」의 정체다.**

### ⓑ 분류 축이 «섞여» 있다 — 그래서 중복이 «필연»이다
지금 그룹은 두 가지 다른 기준이 한 줄에 섞여 있다.

- **나라 축** — 한식 · 양식 · 중식 · 일식 · 태국·베트남
- **성격 축** — 조리법 · 해산물·장 · 반찬·나물 · 분식·간식 · 빵·음료

**연어롤은 일식이면서 해산물이다. 떡볶이는 한식이면서 분식이다.**
→ 축이 섞이면 **한 요리가 두 집에 살 수밖에 없다.** 손으로 아무리 정리해도 다시 어긋난다.

⭐ **그래서 「어느 칸에 넣을까」가 아니라 「축을 하나로 세운다」가 답이다.**

## 3️⃣ 수술 원칙

1. ⭐ **한 컷은 한 집에만 산다** — 중복 0. (검사로 못 박아 다시 안 생기게)
2. ⛔ **파일은 안 지운다** — 픽커에서 내리기만. *이미 그걸로 저장한 표지가 깨지면 안 된다*
   (`kf_c_`·`sf_` 때와 같은 방식)
3. 🎨 **둘 중 남길 하나는 그림을 보고 고른다** — 이름으로 고르지 않는다
4. 🤖 **게이트를 만든다** — `npm run smoke` 가 중복을 세서 **다시 생기면 배포가 막히게**
