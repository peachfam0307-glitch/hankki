## 📱 위젯·바로가기 — 2026-08-13 조사 끝 · **일단 안 한다**(창업자 판정)

> 📮 창업자 *"우리앱을 혹시위젯으로 넣을 수 있어??"* · *"우리 냉장고 담기리스트를 위젯에 추가하면 바로 쓸 수 있으니까"*
> → 조사 뒤 *"복잡하면 다음에 하자. 혹시나 뭘 또 건드려서.. 또 버그많아지면 피곤"* → **되돌렸다.**
> ⭐ 다음에 다시 알아보지 않게 결론만 남긴다.

**⛔ 진짜 위젯(홈 화면에 목록이 «보이는» 것) = 못 만든다. 우리만이 아니다.**
- PWA 는 홈 화면 위젯 표준이 **아예 없다** — iOS·안드로이드 둘 다([Progressier](https://intercom.help/progressier/en/articles/12814946-can-a-pwa-create-home-screen-widgets))
- 네이티브 앱(삼성노트·구글킵)은 되는 게 맞다. **웹으로 만든 앱이 전부 안 되는 것.**
- TWA 껍데기에 위젯 코드를 넣어도 **데이터를 못 읽는다** — 우리 데이터는 브라우저 localStorage, 위젯은 안드로이드 쪽. 서버가 0이라 가져올 데도 없다.
- 길이 있긴 하다 = ⒜WebView 껍데기로 교체(크롬 엔진을 버린다·구글이 단순 웹뷰를 반려하기도) ⒝서버 두기(비용＋데이터 보안 재신고). **둘 다 앱을 다시 만드는 수준.**

**✅ 되는 것 = 「앱 바로가기」**(홈 아이콘 길게 누르면 뜨는 메뉴 · 최대 4개 · 아이콘 96px＋)
- 매니페스트 `shortcuts` → **bubblewrap 이 읽어 안드로이드 바로가기로 만들어 준다**([web.dev](https://web.dev/articles/app-shortcuts))
- ⚠️ **「바로 열림」이지 「바로 보임」이 아니다** — 목록 내용은 안 보인다

**⛔ 「매니페스트 몇 줄」이 아니었다 — 내가 처음에 그렇게 말했고 틀렸다.** 실제로 필요한 것:
1. **`App.jsx` 가 주소(`?t=…`)로 탭을 열 줄 알아야 한다** ← 탭 초기화 = 앱 «모든» 진입에 걸리는 자리
2. 아이콘 4개(96px 이상) 3. 매니페스트 `shortcuts` 4. **웹 배포 → 그 뒤 bubblewrap 이 다시 읽어야 AAB 에 들어간다**
- ⭐ 냉장고만은 쉽다 — `ShopScreen` 이 이미 `sessionStorage['hankki:shopView']` 를 읽으므로 **그 값만 넣어 주면 새 배선 0줄**이다.
- ⏰ **다시 볼 때 = 재심사 통과 뒤 · AAB 를 어차피 굽는 판에.** 순서로는 결제(#54)보다도 뒤.
