# 🔍 경쟁 지형 + 맘카페 침투 (리서치) · 2026-07-19

> 창업자 요청 리서치. ⚠️ **사실(경쟁·채널) = 저장 / 전략 제안 = 창업자 ㄱㄱ 대기.**

## 1. 😱 냉정한 경쟁 현실 — "레시피 정리 앱"은 이미 레드오션
- **대형(검색형)**: 만개의레시피(2012, 1000만·20만 레시피) · 해먹(2015, 350만) · 우리의식탁(200만, AI 재료추천 + 푸드커뮤니티 '샵스타일' 오픈).
- ⚠️ **"SNS 레시피 저장 + AI 정리 + 장보기" = 2024~25년에 쏟아진 신생앱 다수와 정면 중복:**
  - **요리로그**(저장·AI정리·장보기·기록, 유튜브·인스타·블로그 링크 저장) · **요리조리**(기록장·요리모드·타이머·AI 자동 레시피·태그) · **냠냠**(레시피북·프리미엄 구독) · **Recify / 레시피오 / 요리GO**(SNS 영상→AI 요리책 정리 + 장보기) · **해먹으리**(AI 영상→레시피, 재료비·칼로리 자동, 판교 창조허브·글로벌 목표).
- **→ 한끼의 "흩어진 레시피 한곳에 + AI 가져오기"는 더 이상 차별점 아님.** 오히려 한끼는 이 기능 경쟁엔 **늦었고**(AI 가져오기 아직 미구현), 일부는 자본·팀도 있음.

## 2. 🕳️ 그래서 진짜 빈틈 (아무도 안 하는 것 = 우리 무기)
경쟁앱 공통 = AI 정리 · 커뮤니티 · SNS 연동 · 장보기(쿠팡). **아무도 안 하는 것:**
- **감정 캐릭터 IP(꼬르곰·펭펭)** — 어른용 캐릭터 레시피앱 = 없음(캐릭터 사례는 어린이용 Kiddoz뿐).
- **다꾸 감성 꾸미기(표지 데코)** — 없음.
- **자랑 공유 카드** — 없음(SNS "연동"은 있어도 "내가 꾸민 카드 자랑"은 없음).
- **18년 주부 큐레이션(주부의 장바구니)** — 없음.
- **감정·위로 포지셔닝** — 전부 "도구/검색", 감정 공간은 없음.
- **→ 결론: 감정·캐릭터·꾸미기·큐레이션 = "차별화 옵션"이 아니라 한끼가 존재할 유일한 이유.**

## 3. ⚠️ 전략 제안 (창업자 ㄱㄱ 대기)
- **포지셔닝 전환**: "레시피 정리 앱"으로 홍보 ❌(경쟁앱과 똑같아 묻힘) → **"요리하는 나를 위로·기록 + 내 레시피북 예쁘게 꾸미고 자랑"**으로.
- **"흩어진 레시피 한곳에" 태그라인 = 모두가 쓰는 말** → 차별 문구로 교체 검토(스토어·온보딩).
- **AI 가져오기 = 이제 필수기능(table stakes), 킬러 아님** → 언젠가 맞춰야 하지만 여기 올인 금지. 킬러 = 아무도 없는 것(캐릭터·꾸미기·공유·큐레이션).

## 4. 📣 맘카페 침투 플레이북 (우리 획득 채널)
- **맘카페 주 이용자 = 20후~40초 여성 = 우리 타겟과 정확히 일치.** (네이버/다음, 지역 '○○맘카페' + 요리·살림 카페)
- **생명 = 진정성.** 광고티 나면 삭제·역효과(당근 동네생활 삭제 전례와 동일 리스크). "18년차 주부가 만든 앱" 스토리 + 진짜 후기.
- **형태**: "제가 쓰는 레시피 정리+꾸미기 앱" **공유 톤**(홍보 아님) + **예쁜 카드 이미지 첨부**(그게 바이럴 훅). 도배 금지, 카페별 정책 확인.
- **체험단 라이트**: 무료라 부담 0 — "몇 분 써보고 한 줄 후기".
- **역할 분담**: 카페별 톤 맞춘 글 + 카드 이미지 = **클로드 제작.** 창업자는 붙여넣기·판단만(영업 안 해도 됨).

## 🔄 2차 확인 (2026-07-19) — AI 무료화 + 트래션
- **AI 가져오기 = 무료가 대세.** 요리조리 **무료 전환**, 해먹으리·레시피오도 사실상 무료("공유만 누르면 AI 정리"). → **AI로 돈 벌 생각 접기(table stakes).** 우리 수익 = 커머스(쿠팡)+꾸미기가 맞음.
- **트래션 = 아무도 독점 못 함.** 신생앱 ~10개 난립(요리로그·요리조리·냠냠·Recify·레시피오·요리GO·레시픽·Recipesoup·해먹으리…), 공개 다운로드 순위·수치 없음(=대박 난 곳 없음). 해먹으리가 가장 활발(스레드·판교 지원)이나 검증 전.
- ⚠️ **Recipesoup = "AI 감성 레시피 다이어리('왜 만들었는지'·'그날의 감정' 기록)"** — 감정 기록 각을 이미 하는 앱 등장. → "감정 무주공산"은 더 좁혀짐. **진짜 우리만 = 캐릭터 IP(꼬르곰·펭펭) + 다꾸 꾸미기 + 자랑 카드 + 18년 큐레이션.**
- **함의**: 무난·me-too로 가면 10개 틈에 묻힘. 유일한 차별 = 아무도 없는 캐릭터·꾸미기·자랑·큐레이션 + **창업자 진짜 취향·안목.**
