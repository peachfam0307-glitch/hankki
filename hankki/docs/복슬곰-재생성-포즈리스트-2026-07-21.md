## 🐻 곰(복슬 꼬르곰) 단독 포즈 리스트

### ⭐ 히어로/대표 — **1컷/장** (최고화질 · 로고·홈·스토어)
- **H1. 대표샷**: 국자 들고 정면 방긋 (기본 마스코트)
- **H2. 로고용**: 냄비 안고 정면 (상표 결합상표용 · 옵션)

### 😊 감정 스티커 — **4컷/장** (2×2)
- **장A**: ①와아~(만세 신남) ②하트 뿅(너무 좋아) ③엄지척(최고야곰) ④뿌듯(맛있게 만들었곰)
- **장B**: ①하트눈(반함) ②눈물 그렁(서럽곰 ㅠㅠ) ③놀람(어?!) ④쿨쿨(냠냠 먹고 꿀잠)

### 🍳 요리 스티커 — **4컷/장** (2×2)
- **장C**: ①냄비 젓기(보글보글) ②팬 흔들기(요리조리 착착) ③오므라이스 짜잔 ④반죽/케이크 데코
- **장D**: ①계량컵 재기 ②도마 썰기 ③오븐 꺼내기 ④설거지(거품)

### 🏠 일상 스티커 — **4컷/장** (2×2)
- **장E**: ①장바구니 들고(장보러 왔곰) ②도시락 배달(배달이곰) ③레시피북 뒤적(어디갔지) ④두 손 만세(오늘도 성공이곰)

→ 곰 단독 = 히어로 1컷×(1~2) + 4컷×5장 = **약 22컷**

## 🐻🐧 콤비(복슬곰 + 펭펭) 포즈 리스트 — **1컷/장** (둘이 크게, 6장)
> 대비 포인트: **곰=감정 활짝 / 펭=옆에서 무표정 시크.**
1. **[대표]** 곰이 요리 접시 들고 자랑 + 펭이 옆에서 무심하게 포크로 냠
2. **[애정]** 곰이 두 손 하트 뿅 + 펭은 무표정으로 옆에
3. **[해냈다]** 곰 두 손 만세 신남 + 펭 엄지척(무심)
4. **[하이파이브]** 곰·펭 손바닥 마주침 (곰 활짝, 펭 무표정)
5. **[나란히]** 둘이 앉아 같이 먹기 (곰 행복, 펭 오물오물 무심)
6. **[다정]** 곰이 펭 어깨 살짝 감싸고 정면 (곰 웃음, 펭 시크)

## 📋 GPT 복붙 프롬프트 (포즈만 갈아끼우면 됨)

### 🐻 복슬곰 개별 — 4컷 한 장 (첨부: 위 복슬곰 시트 B)
```
첨부한 "복실곱슬 곰곰이" 그대로 그려줘 — 곱슬·복슬복슬한 구름결 털, 이마 앞 곱슬 한 덩어리(시그니처),
동그란 눈 + 'ㅇ' 입, 인형처럼 말랑·두툼한 몸, 도톰한 셰프모자, 프릴 앞치마(냄비 로고 주머니). 크림~브라운 톤.
순백색(#FFFFFF) 배경에 2x2로 4컷, 각 캐릭터 아주 크게·서로 안 겹치게 넉넉한 간격.
그림자·글자·번호 없이 전신, 굵고 끊김 없는 검은 외곽선. 포즈:
1) 두 손 만세 "와아~" (신남)
2) 두 손 하트 뿅 (너무 좋아)
3) 엄지척 (최고야곰)
4) 냄비 안고 뿌듯 (맛있게 만들었곰)
```
> 장B·C·D·E는 위 포즈 4줄만 갈아끼워 4장 더.

### 🐻🐧 콤비 — 1컷 한 장 (첨부: 복슬곰 + 기존 펭펭)
```
첨부한 복슬곰(곱슬 털·셰프모자·프릴앞치마) + 펭펭(트렌치코트·베레·끝 안으로 말리는 단발 보브 C컬, 무표정 시크) 콤비.
곰=표정 풍부·신남 / 펭=무표정 시크. 같은 화풍, 굵은 검은 외곽선.
순백색(#FFFFFF) 배경, 한 장에 1컷만 크게(둘이 함께라 최대한 크게), 그림자·글자·번호 없이 전신.
[포즈] 곰이 요리 접시를 들고 자랑, 펭이 옆에서 무심하게 포크로 먹음.
```
> 콤비 6장 따로 생성(포즈만 교체).

### 🐻 복슬곰 히어로 1컷 (로고·홈·스토어용, 최고화질)
```
"복실곱슬 곰곰이"를 순백 배경 1컷으로 아주 크게(고해상). 국자 들고 정면 방긋,
곱슬 구름결 털·이마 앞 곱슬·'ㅇ' 입·셰프모자·프릴앞치마(냄비로고). 굵은 외곽선, 그림자·글자 없이 전신.
```
