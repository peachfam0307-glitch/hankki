## 2. 장치 다섯 — 구멍마다 하나

### 장치 A · 앱이 «버전»을 실어 보낸다 → 구멍 ②
**무엇** — `stats.js` 가 보내는 모든 `page_view` 에 `app_version: APP_VERSION` 한 칸을 싣는다(웹 gtag ＋ 아이폰 직접 보내기 둘 다 · `ep.app_version`).
**왜 이게 뿌리인가** — 「버그 있던 버전」을 GA4 보고서에서 **통째로 뺄 수 있다.** 오늘 같은 날엔 「v13.50 이상만」으로 찍으면 끝이다. 날짜로 자르는 건 배포 시각을 사람이 기억해야 하지만, 버전은 숫자가 스스로 안다.
**창업자 몫 1회** — GA4 → 관리 → 맞춤 정의 → 맞춤 측정기준 「app_version」 등록 (⛔등록 «뒤» 데이터부터 보인다 · 지난 건 안 붙는다).
**⛔ 앱 코드 수정 = 배포 필요.** 창업자 「배포해」 뒤.
**재현판** — 웹·아이폰 두 길 다 `app_version` 이 실려 나가나 6칸.

### 장치 B · 계측 잣대 도구 → 구멍 ①②⑤
**무엇** — `scripts/계측-잣대.mjs --부터 9/10 --까지 9/16 --이벤트 recipe_saved,import_photo`
출력 =
```
recipe_saved   심은 날 2026-09-10 (git log -S 자동)   오염: 9/13~9/15 09:56 (자르기 안내 안 뜸)
import_photo   심은 날 2026-09-10                       오염: 같음
⇒ 공정한 공통 구간 = 2026-09-15 09:56 ~ 2026-09-16      ⛔ 그 밖의 값으로 비율을 말하지 않는다
```
**심은 날** = `git log -S` 로 도구가 «스스로» 센다. 손으로 안 적는다.
**오염 기간** = 아래 장치 C 의 장부를 읽는다.
**훅** — 창업자가 「애널리틱스·개요·이름·클래스」 캡처를 줄 때 `UserPromptSubmit` 훅이 *"⛔ 나누기 «전»에 계측-잣대를 돌려라"* 를 띄운다(막지 않고 띄운다 — 규칙 26 한계).

### 장치 C · 오염 장부 → 구멍 ②(날짜) · ⑥(뜻 바뀜)
**무엇** — `docs/계측-오염장부.md` 한 장. 줄 하나 = 「흐름 · 깨진 시각 · 고친 시각 · 고친 커밋 · 무엇이 깨졌나」.
```
| 가져오기 | 2026-09-13 | 2026-09-15 09:56 | 4ee4b70e3 | 자르기 안내가 한 번도 안 뜸 |
| AI 다듬기 | 2026-09-01 | 2026-09-13 | (편차의정체) | 8000 토큰이 120초를 넘어 빈손 |
```
＋ **뜻이 바뀐 날**도 적는다(예: `cook_done` 정의 변경) — 같은 이름인데 다른 것을 재면 그것도 오염이다.
**누가 적나** — `/릴리즈` 스킬에 한 줄 추가: *"이 배포가 «흐름»을 고쳤나? 고쳤으면 장부에 적어라."* ⛔규칙만 적으면 안 지켜지니 → `check-오염장부.mjs`: 커밋 메시지에 「고침·버그·구멍·안 뜨던」이 있는데 장부가 그대로면 **빨간불**.

### 장치 D · 토큰 상한 게이트 → 구멍 ④ (설계 관문 통과 09-16 22:4x)
**무엇** — `scripts/check-tokenbudget.mjs`: 저장소의 `VISION_MAX_TOKENS`(`ocr-proxy/worker-tidy.js:564`)와 앱 대기(`src/tidy.js:117-118` = 5000×24)를 둘 다 읽어, **실측 기준선(2000 토큰 ↔ 120,000ms · 2026-09-13 창업자 실물)** 보다 비율이 나쁘면 배포를 막는다.
· 이름을 못 찾으면 죽는다(조용히 통과 금지) · 숫자가 아니면 죽는다
· 메시지 = 「토큰을 올리려면 앱 대기도 같이 올려라」＋ 두 파일 줄 번호
· ⛔ **저장소만 지킨다.** 서버에서 직접 바꾸는 건 못 막는다(규칙 36) — 메시지에 그렇게 적는다.
**앱 코드 수정 없음** — 오늘 밤 바로 만들 수 있다.

### 장치 E · 창업자 기기 제외 → 구멍 ③
**다른 세션이 이미 설계 관문을 통과해 진행 중**(`_repro-내부기기-0916.mjs` · 「내부 기기는 통계 «안 보냄»」 · 창업자 답 대기). ⛔ 여기서 중복으로 만들지 않는다.
＋ 창업자 몫 = GA4 「내부 트래픽」 필터 「활성」(무조건 · 2026-09-16 확정).
＋ 아이폰 = 「버전 일곱 번 탭」(⏳`login_apple` 3 이 되면 · 아이폰 세션).

## 3. 다섯을 겹치면 왜 «다시는» 안 나나

```
오늘 사고 = 오염된 기간(②) 의 창업자 포함(③) 숫자를, 심은 날 다른 이벤트끼리(①) 나눠서(⑤) 말했다.

A 가 있었으면 → 「v13.50 미만」을 보고서에서 뺐다               (②)
B 가 있었으면 → 도구가 「공정 구간 = 9/15 09:56~」라고 먼저 말했다   (①②⑤)
C 가 있었으면 → 9/13~9/15 가 오염이라고 «저장소»가 알고 있었다      (②)
D 가 있었으면 → 토큰이 되돌아가는 순간 배포가 막혔다               (④)
E 가 있었으면 → 창업자 테스트가 애초에 안 섞였다                 (③)
```
⭐ **하나로는 안 된다.** 다섯이 «다른 구멍»이라 다섯 다 있어야 한다.
