## ▶️ 시트가 더 오면 (한 줄씩)
```bash
cd /home/user/hankki/hankki
D=docs/stickers/재료아이콘-창업자-2026-08-12
cp <업로드파일> "$D/원본시트/시트N.png"
python3 tools/cut.py "$D/원본시트/시트N.png" "$D/낱개" "sN_" --diecut 6 --join 30
python3 tools/contact.py "$D"/낱개/sN_*.png --out /tmp/재료-sN.png   # ← 열어서 «눈으로» 이름 짝짓기
```
- ⛔ **컷 수가 16이 아니면 멈춘다** — 한 칸 안에서 떨어진 조각(고추 세 개 등)이 따로 잘린 것이다.
  `--join 30` 으로 묶는다(칸 간격 ≈313px 보다 훨씬 작아 옆 칸이 안 딸려온다).
- ⛔⛔ **파일 올라온 순서 ≠ 창업자가 보낸 순서.** 2026-08-12 에 실제로 2번↔3번이 뒤바뀌어 있었다.
  크기로 짐작하지 말고 **컨택트시트를 열어서** 확인한다(규칙 18).
- ⛔ 이름은 짐작이 아니다 — 판을 보고 하나씩 짝지어 `이름표.json` 에 적는다.
- `--diecut 6` = 긴변(1254~1536)의 0.5% = 표준 두께(CLAUDE.md 핀).
