# 🍱 음식 아이콘 — 창업자 2026-08-11 (48컷)

> 창업자 *"내가 한끼찾아보면서 새로 받았어. 이걸로 바꿔주면 되고"*

## 왜 받았나
36편 판정판(https://claude.ai/code/artifact/b33e4a55-a4db-4f24-8f4e-57d527ffcf89)에서
**⛔사진 없음 2 · 🔁겹침 9 · 🕸넓은 낱말 6** 이 나왔고, 창업자가 그 자리를 메우려고 새로 뽑았다.

⭐ **다만 36편 전용이 아니다** — 48컷 중 «이름이 딱 맞는» 편은 7개고,
나머지 41컷은 **아이콘 라이브러리를 통째로 넓히는 컷**이다(계란장·충무김밥·딸기라떼·봉골레파스타 등).

## 이름을 어떻게 붙였나 — ⛔짐작 아님
`scripts/_이름표-아이콘48-0811.py` 가 **시트 격자 칸 «아래»에 인쇄된 라벨을 잘라
잘린 컷 옆에 붙였다.** 그 확인표(`_검수/이름표-확인.png`)를 눈으로 읽어 옮겼다.

⛔ 2026-08-04 에 컨택트시트에서 **칸을 밀려 읽어** 엉뚱한 컷을 고른 적이 있다(규칙 18).
그래서 «내 눈»이 아니라 «기계»가 짝을 짓게 했다.

⚠️ 처음엔 라벨 띠를 칸의 아래 **22%** 로 잡았다가 **아랫줄 라벨이 잘려** 안 읽혔다 —
아래 칸은 시트 밑 여백이 좁아 라벨이 칸 «안»에서 더 위에 앉는다. **34% 로 넓혀** 다시 뽑았다.
