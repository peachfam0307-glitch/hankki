```bash
# 투명 프레임 3장 — 이미 오려져 있다. 칸으로만 나눈다(흰 테 두르지 않는다)

# 흰 배경 6장 — 얇은 선을 지키려고 흰 테 2px(긴변 ~300px 의 0.7%)
python3 tools/cut.py <시트.png> <낼폴더> ??? --diecut 2

# ⚠️ 도장장식·손그림장식은 위 명령이면 8컷·16컷으로 «틀리게» 나온다
#    (얇은 선·떨어진 조각이 버려지거나 쪼개진다) → 칸으로 묶고 문턱을 낮춘다
python3 tools/cut.py <시트.png> <낼폴더> ??? --diecut 2 --grid 4x3 --min 200 --drop 0
```

⚠️ **`--min 8000`(기본)이 얇은 선을 버린다** — 도장 시트의 점선·햇살·물감 점이 그래서 사라졌다.
⚠️ **`--drop 0.12`(기본)이 떨어진 조각을 뗀다** — 하트 셋·물감 점 셋이 그래서 쪼개졌다.
📌 **개수가 12가 아니면 무조건 다시 자른다.** 「대충 맞겠지」로 넘어가면 그게 그대로 앱에 들어간다.
