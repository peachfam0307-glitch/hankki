# 🗄 앱에 «이미 들어간» 이미지 (2026-08-15)

📮 창업자 2026-08-15
> *"이미지들중 옛컷들 ＋ **반영완료된 이미지들.** 반영완료 문서들 다 보관소로 이동."*
> *"**지금 앱에 반영된거** 얘기하는거야."* · *"**할 것은 건드리면 안되고.**"*

## ⭐ 판정 기준 = 「그 컷이 `src/assets` 안에 있나」

창업자 말 그대로다 — **앱에 들어간 것**이 반영완료다.
⚠️ 날짜로 잠겨 있어도(9/1·10/1 공개 예정) **앱 소스엔 이미 있으면 반영완료**다.
반대로 **아직 앱에 안 들어간 컷이 「할 것」**이고, 그건 손대지 않았다.

## 🔬 어떻게 쟀나 — 이름이 아니라 «그림 내용»으로

⛔⛔ **처음엔 파일 «이름»으로 맞춰봤는데 통째로 틀렸다.**
문서 컷과 앱 키는 이름이 달라서(`물결-021-01` → `gp_gomhi`)
**앱 정본인 `곰펭-물결-신규-2507` 이 「4% 반영」으로 나왔다.**
📌 규칙 18 그대로 — **「없다」가 아니라 «내 확인 방식이 안 되는 것»이었다.**

✅ 그래서 **그림 내용(md5)** 으로 맞췄다. 이건 못 속인다.

⛔⛔ **＋ `asset-map.mjs` 의 「🗃 문서 폴더 재고 (아직 앱에 안 들어간 낱개)」 표도 믿으면 안 된다.**
제목은 「안 들어간 것」인데 **코드는 앱에 있는 걸 안 빼고 그냥 다 센다**(`asset-map.mjs:121~139`).
이 표로 판정했으면 **반영된 것을 「할 것」으로 잘못 봤을 것**이다.
