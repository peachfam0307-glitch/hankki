## 왜 이 넷이 「기본템」인가

- 🎨 **색이 뮤트 뉴트럴**(베이지·세이지·더스티블루·라벤더) → 우리 종이 다섯 색
  (아이보리·하늘·분홍·세이지·크라프트) **어디에도 안 부딪힌다**
- 🗓 **계절이 없다** → 사철. 9월이 와도 순서가 안 밀린다
- 🖊 **얇은 갈색 외곽선 ＋ 종이 질감** → 기존 `dl_`(굵은 검정＋쨍한 파스텔)과 **겹치지 않는다**
  (겹침 대조판으로 확인 — 겹치는 컷 0)
- 😊 **감정·표정 씰은 우리한테 아예 없던 종류**다. 일기에 「오늘 기분」을 찍는 도장

## 📔 일기 «전용»

`STICKER_GROUPS` 에 **`only: 'diary'`** ＋ **`diary: true`** 를 붙인다.
- `only: 'diary'` = 레시피 꾸미기 서랍엔 **아예 안 나온다**(창업자 지시)
- `diary: true` = 일기 꾸미기의 **「일꾸」 칸**에 들어간다

## ✂️ 자를 때 — ⛔ 이걸 안 지키면 얼굴이 사라진다

```bash
python3 tools/cut.py <시트> <폴더> <접두어> --diecut 2 --drop 0
#   코너·띠 시트만 추가:  --join 45 --min 300
```

⭐⭐ **`--drop 0` 이 핵심이다.** 기본값(0.12)으로 자르면 **표정 씰 12컷 중 3컷의 얼굴이 통째로 사라진다** —
눈·볼터치·입은 테두리와 «떨어진» 조각이라 본체의 12% 미만으로 잡혀 잔챙이로 지워지고,
남은 테두리만 링으로 보여 **「구멍 뚫린 도장」** 이 된다(창업자 *"구멍뚫린거 난리났어 지지직~"*).

⛔ **`--join`(15·25·40)·`--diecut` 을 아무리 만져도 안 고쳐진다.** 셋 다 해보고서야 찾았다.
📌 **증상은 「구멍」인데 원인은 「조각 버리기」였다 — 같은 증상이라고 같은 손잡이가 아니다.**

🔒 이제 `cut.py` 가 **자르는 자리에서 잡는다** — 「속이 빈 고리」면 경고하고 `--drop 0` 을 안내한다.
   (옛 옵션으로 돌려 그 3컷만 잡고 나머지 45컷엔 조용한 것까지 확인했다)
