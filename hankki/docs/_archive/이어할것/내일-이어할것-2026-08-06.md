## 4️⃣ 🧠 오늘 배운 것 — 내일도 밟기 쉬운 것들

- **자를 땐 «꺼낼 길»을 같이 단다** — 자르는 조건과 더보기 조건이 어긋나면 물건이 «사라진다»
- **개수를 줄일 땐 «무엇을 세는지»를 본다** — 제품과 줄은 다른 단위다
- **기본값을 신호로 읽지 말 것** — `source: 'manual'` 은 「직접 썼다」가 아니라 기본값이다
- ⭐**기능을 바꾸면 「바깥에 한 말」도 같이 바꾼다** — 방침·데이터 보안 신고·스토어 표시는 **코드를 안 따라온다**
- **빈 값·반쪽을 넘기는 건 안 넘기는 것보다 나쁘다** — 빈 `fontEmbedCSS` = 「글꼴 심지 마」
- **JSX 주석은 «자식» 자리에서만** — `=> (` 바로 뒤에 넣으면 빌드가 깨진다(두 번 밟았다)
- **`npm run smoke` 는 빌드를 안 한다** — 버전만 올리고 안 구우면 dist 가 낡는다(오늘 가드가 실제로 막아줬다)
- ⛔**`subst.py --new` 안의 `\n` 은 «글자»로 박힌다** — 여러 줄을 넣을 땐 `--new-file` 이나 Write 를 쓸 것 (오늘 실제로 당했다)
