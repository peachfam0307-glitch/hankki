> 🗄 **보관소 — 창업자가 지시할 때만 연다.** (절대원칙 2026-08-13)

# 🖼 아이콘 대조 검수판은 «저장소에 안 담기로» 했다 (창업자 판정 2026-08-15)

## 📮 무슨 일이었나

2026-08-14 에 음식 아이콘 「그림 ↔ 이름표」를 전수 판독하면서 대조판 **48장(90MB)** 을 뽑았다.
보관소를 정리하며 이걸 저장소에 담을지 물었고, **창업자 판정 = 「안 담는다」.**

## ⭐ 왜 안 담아도 괜찮나 — «판정 결과»는 이미 저장돼 있다

**판은 «판정하는 도구»였지 «판정 결과»가 아니다.** 결과는 따로 남아 있다:

| 남아 있는 것 | 무엇 |
|---|---|
| `docs/stickers/아이콘-이름표-창업자.json` | 창업자가 준 «무슨 그림인가» 이름표 |
| `scripts/icon-checked.json` | 어느 컷을 «언제 봤나» 판독 기록 |
| `scripts/check-iconlabels.mjs` | 판독 기록 없는 컷이 픽커에 새로 들어오면 **배포를 막는다** |

⭐ 그러니 **잃은 것이 없다.** 판만 없앴고, 판이 만들어 낸 답은 셋 다 코드·데이터로 살아 있다.

## 🔁 다시 만드는 법 (도구는 저장소에 있다)

```
python3 hankki/tools/icon-labels.py --new                 # 아직 판독 기록이 없는 컷만
python3 hankki/tools/icon-labels.py fe_97 fe_113          # 골라서
python3 hankki/tools/icon-labels.py --zoom fe_97 fe_111   # 3배 · 나란히 (판정용)
```

⚠️ **판정이 갈리면 `--zoom` 3배로 본다.** 작게 보면 틀린다 —
2026-08-05 에 콩나물무침을 300px 로 보고 「면」이라 판정한 적이 있다(규칙 18).

## ⛔ 「지우지 않는다」와 어긋나지 않는다

창업자 보존원칙(*"삭제 금지 = 보존"*)이 지키는 것은 **창업자가 준 것과 다시 못 만드는 것**이다.
이 판은 **우리 도구가 우리 자산으로 다시 뽑아내는 생성물**이고,
공개 저장소라 한 번 담으면 **90MB 가 히스토리에 영구히 남아** 되돌리기 어렵다.
📌 그래서 이번만은 «담지 않는 쪽»이 보존원칙에 어긋나지 않는다 — 그리고 그건 **창업자가 직접 정했다.**
