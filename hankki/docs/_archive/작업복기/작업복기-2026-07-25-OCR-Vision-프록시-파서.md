# 작업복기 2026-07-25 — OCR 근본해결(Google Vision 프록시) + 파서 정확도

## 한 줄 요약
"예전엔 잘됐는데 갑자기 이상해진" OCR을 **근본 진단 → Google Vision 프록시로 대체 → 파서 6종 수정**으로 해결. v8.43(Vision 연동)·v8.44(파서) 배포.

## 1. 진단 — 근본 원인은 파서 아니라 OCR 엔진
- 증상: 사용자 작성 레시피(사진 OCR)가 잘림·외계어·재료에 순서 섞임. "예전엔 잘됐는데 갑자기."
- 파서 재현 결과: **파서는 웬만하면 잘 나눔.** 문제는 텍스트 자체가 쓰레기로 들어오는 것.
- 범인: `ocr.js`가 **1순위로 폰 내장 `TextDetector`**(한국어 정확)를 쓰는데, 이건 **크롬 표준이 아니라 실험 플래그 뒤에 숨은 불안정 API.** 크롬 업데이트로 기본 비활성 → **조용히 tesseract(한글 약함)로 폴백** → "갑자기 이상해짐." 즉 좋은 길이 막혀 약한 길로 떨어진 것.

## 2. 결정 — 클라우드 OCR (창업자 비용 우려 대응)
- 리서치: OCR.space(2.5만/월 무료·한글약함) · Azure(5천) · **Google Vision(1천/월 무료·정확도 최상·$300크레딧)** · 네이버클로바(한글특화).
- 추천·확정: **Google Vision** (인쇄체 한글 최상 + 세팅 쉬움 + 활주로 안전). 손글씨 주력이면 클로바.
- 창업자 결정: **무료 5회/월 + 990원에 25장 팩**을 오픈 때 함께(유료 유도). 원가 ≈2원/건, 마진 95%. → 유저 늘수록 프리미엄 매출이 원가를 덮음(구조적으로 마이너스 불가).

## 3. 구축 — 요새(fortress) 프록시
- 창업자가 직접(안내 따라): 구글 프로젝트·Vision API·키(Vision 전용 제한)·$300체험·예산경보 ₩1,000 / Cloudflare 무료계정·Worker `hankki-ocr`·KV `hankki-ocr-kv`·Secret 2개.
- 코드·보안은 클로드: `ocr-proxy/worker.js` = **6중 방어벽**(전역 월900[=비용$0 보장]·일120·유저5·IP분당6·오리진체크·구글예산). 상세 = `ocr-proxy/README.md`.
- 앱 연동: `src/ocr.js`에 `ocrViaProxy()` — **Vision 1순위**, 실패(오프라인·한도·오류) 시 기존 파이프라인으로 **조용히 폴백**(더 나빠질 일 없음). 기기 uid(localStorage `hankki:did`)로 유저당 카운트.
- ⭐ **provider 락인 아님**: worker.js의 Vision 호출부만 바꾸면 클로바 등으로 교체, 앱·보안·KV 재사용.
- 검증: 작업환경 네트워크 정책이 workers.dev 아웃바운드를 막아 직접 테스트 불가 → 창업자 폰 실테스트로 확인. **황태장아찌·전복솥밥 등 한글 완벽 인식 확인("우와ㅋ").**

## 4. 파서 정확도 6종 수정 (v8.44) — 실레시피 6개 재현·검증
Vision이 깨끗한 텍스트를 주자 남은 건 분류 정확도. `src/parseRecipe.js`:
1. **`푼` 제거**(STEP_VERB) — 제일 흔한 단위 **`스푼`**에 걸려 "…3스푼" 재료가 순서로 오분류되던 최대 버그.
2. **팁 문구→메모** — "15일 숙성시키면 더 맛있으니까"처럼 기간 숫자만 있는 팁이 재료로 새던 것(QTY·불릿·조리문장 아니고 TIP_CUE면 메모).
3. **레시피 배너 스킵** — "맛보장 양념 레시피!" 같은 장식 배너 제거.
4. **끝괄호 주석 분류 제외** — "멸치액젓 2스푼 (저는…꿀팁!)"의 핵심 '멸치액젓 2스푼'=재료로(괄호가 !로 끝나도 순서 오인 안 함).
5. **조리동사 추가** — `두르·둘러·자르·잘라·구운`. "팬에 기름 약간 두르고"·붙은 "1대파는 자르고"를 순서로 인식.
- ❌ **FIX E(✅마커→메모) 폐기**: 목살스테이크가 ✅를 재료·순서 전부에 불릿처럼 써서 회귀 발생 → 제거. 팁은 기존 TIP_CUE로 처리(더 안전).
- 검증 6종: 황태장아찌·충무김밥·전복솥밥·목살조림·목살스테이크 = 재료/순서/메모 제자리 + 제육볶음 회귀가드 통과. 재현 하네스 = scratchpad `parse_repro.mjs`.

## 5. 남은 것 (다음 패스)
- **파서 어려운 케이스**: 긴 순서가 줄바꿈으로 잘려 첫 줄(verb 없고 "20분·조금만" 수량어만)이 재료로 새는 것(우삼겹묵쌈솥밥). = 분류 전 줄 병합이 필요한 큰 수술 → 별도 설계. (지금도 앱 에디터 드래그로 보정 가능·초안 안내 있음)
- 자잘: "재료:"·"양념" 라벨 접두어 잔존, 전복 ✅팁 일부 순서로.
- **결제(990원 팩)** = 포트원/토스 + KV 크레딧 원장. 무료 5회부터 먼저.
- (기존) 펭 배경패치 4종·여름 시즌카드.
