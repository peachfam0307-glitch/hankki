## 3. 말을 한 곳으로 모았다 — `src/안내말.js`

까닭 10가지 × 안내 × 열쇠를 **한 곳**에서 만든다. 화면은 그 말을 실어 나르기만 한다.

| 무슨 일 | 창에 뜨는 말 | 열쇠 |
|---|---|---|
| 잘 읽힘 | AI가 더 다듬는 중 → **다 됐어요 · 레시피에 올라갔어요** | 1개 |
| 글자 안 보임 | 밝은 곳에서 다시 찍어 주세요 · **열쇠 안 썼어요** | 0 |
| 같은 사진 | 전에 읽은 사진이에요 · 그대로 채웠어요 | 0 |
| AI 잠깐 안 됨 | 조금 뒤에 다시 해 주세요 | 0 |
| 이번 달 다 씀 | **열쇠를 다 썼어요 · 다음 달에 다시 채워져요** | 0 |
| 연결 끊김 | 잠시 뒤에 다시 — ⛔**열쇠 얘기를 안 한다**(모르니까) | 모름 |

### 창업자가 고른 말
- *"열쇠를 깎는다? 표현이 별로인데"* → 열쇠는 **쓰는** 것이다 → **「열쇠 안 썼어요」** 하나로 통일
- *"0개 남았어요가 무료랑은 안맞는 말이잖아"* → 0 은 「남은 수」가 아니라 **다른 사건**이다
  → 「무료」를 빼서 **유료를 켜도 안 고친다**
- *"알겠어요 빼고 닫기"* → 창 단추는 **「닫기」** 하나

⭐ 「N개 남았어요」를 짓던 **네 곳(KeyBadge·App·Inbox·Editor)을 한 곳으로** 모았다.

## 6. 배운 것

1. **글자 검사가 초록불이어도 앱은 죽어 있을 수 있다.** 브라우저로 켜 보는 검사가 마지막 잣대다.
2. **한 값에 두 뜻을 담으면 반드시 어긋난다** (`tidyFail` = 시작 표시 ＋ 실패 표시).
3. **떠 있는데 못 보면 안 뜬 것과 같다** — 자리가 곧 기능이다.
4. **검사판이 「이름 목록」을 글자 그대로 맞추면 낡는다** — 뜻을 재게 바꿨다.
5. 디스크가 이 세션에 **세 번 되감겼다.** 원격에 계속 밀어둬서 하나도 안 잃었다.
