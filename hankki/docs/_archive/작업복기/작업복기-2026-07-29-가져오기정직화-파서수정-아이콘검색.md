### 나중에 되는지 (창업자가 특히 궁금해한 것)
- **유튜브 = 나중에 됨.** 조건 = **서버 + YouTube Data API 키**(`videos.list`로 영상 설명 정식 수신).
  ⚠️ 단, **설명란에 레시피를 적어둔 영상만.** 말로만 하는 영상은 자막이 필요한데
  자막은 제3자 접근이 제한적 → **서버를 붙여도 절반만 해결.**
- **인스타 = 사실상 안 됨.** 남의 게시물 캡션은 공식 API로 못 가져옴(본인 계정만).
  **서버를 붙여도 안 된다. 캡처가 유일한 답.**
- ⚠️ 이 컨테이너는 외부망이 막혀 있어 **유튜브·API를 직접 찔러보진 못했다.**
  "읽으면 영어 동의문이 온다"는 우리 코드 동작으로 재현 확인한 사실이고,
  API 조건은 지식 기준 → **서버 붙일 때 실제로 한 번 찍어봐야 확정.**

## 3. 파서 버그 4건 (전부 실제 재현으로 확인)

1. **순서 한 줄이 통째로 사라짐** — `① 양념장 재료를 모두 섞어둔다`
   → sanitize가 `①`을 지운 뒤 '양념장'으로 시작 → **섹션 헤더로 오인 → continue로 소실.**
   블로그 레시피는 양념장 만들기가 1번인 경우가 많아 자주 터졌을 것.
   ⚠️ **함정**: 고치려고 `STEP_VERB`(조리 동사)로 걸렀더니 **`조리 순서`·`조리법` 헤더가 깨졌다**
   (동사 목록에 '조리'가 있음). → `DECLARATIVE`(서술형 종결)로 판단하도록 변경. 테스트 ⑥이 잡음.
2. **제목 잘림/빈칸** — `소고기 미역국 황금레시피` → `…황금`.
   낱말 경계 없이 '레시피'를 뗌. 고치니 이번엔 "짧고 레시피로 끝나는 줄=배너" 규칙에 걸려 **제목이 통째로 사라짐.**
   → 배너는 *제목을 이미 잡았거나 느낌표·물결이 붙은* 경우만 버리고, 꼬리는 `cleanTitleTail`로 정리.
3. **분량 없는 재료가 메모로 샘** — `다진마늘`, `대파` → **장보기 목록에서 통째로 빠짐.**
4. **줄글형 = 재료 0개** — `스파게티면 200g, 토마토홀 1캔, …` 한 줄이 통째로 순서에.
   → 조각 대부분에 분량이 붙었을 때만 쉼표 분해(조리 문장 쉼표는 안 건드림) + 한 문단을 문장 단위 순서로.

### 영수증
재현해보니 **이미 잘 동작.** 품목 4개 추출(무항생제란·닭가슴살·대파·우유),
종량제봉투·합계·카드결제·사업자번호 제외, `고주장`→`고추장` 교정까지 확인. **손대지 않고 회귀 테스트로만 고정.**

## 7. 미정리(예전 Inbox) — 입구 복구

창업자: "Inbox는 없앴어. 불필요하다고 해서. 다시 넣어야 하면 버튼 만들어야 해." → "이건 네가 알아서 해."

**문제**: 미정리 레시피는 오늘의 추천(`status!=='unsorted'`)·레시피 탭(`status==='sorted'`)에서 빠지고,
홈 '최근 저장'에도 **최신 4개 안에 있을 때만** 보인다. 밀려나면 설정 깊숙이 들어가야만 찾을 수 있었다.
→ **홈 검색창 아래 "정리 안 한 레시피 N개" 칩. N=0이면 렌더 안 함**(평소 화면은 그대로).
→ `TabTips` 낡은 안내("우측 상단 아이콘=공유받은 레시피") 정정 — 그 자리는 이제 설정.
