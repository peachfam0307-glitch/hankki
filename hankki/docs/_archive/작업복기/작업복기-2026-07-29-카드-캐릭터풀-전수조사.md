## 4. 새 도구 — `tools/cut-diecut.py`

창업자 아이디어: **"배경있는건 띠부씰처럼 배경 따라 대충 부드럽게 잘라쓰면 되지"**

배경을 지우려 하면 하늘·모래·간판이 캐릭터와 이어져 그림이 부서진다.
그래서 **지우는 대신 배경째 실루엣을 둥글게 다듬고 흰 테두리**를 두른다 → '판'이 아니라 '스티커'로 읽힌다.

```
① 테두리에 닿은 흰 배경만 플러드필 (안쪽 흰색은 외곽선이 지켜줌)
② closing → fill_holes → 블러 후 임계값   ← "대충 부드럽게"의 핵심
③ 실루엣을 border px 부풀려 흰 테두리 + 원본을 위에 얹기
```

`python3 tools/cut-diecut.py <입력> <출력> --r 22 --border 20`

⚠️ 카드 히어로(600px)엔 **쓰지 않는다.** 그 크기로 키우면 네모가 카드의 1/3을 먹어
예전에 지적받은 "카드 속 카드처럼 겉돈다"로 되돌아간다. 띠부씰은 **작게 쓰거나 꾸미기 스티커**로.

## 5. 컷 도구 관련 배운 것

`slice_grid`의 `keep_frac`은 **가장 큰 덩어리 대비 비율**이라, 하트·반짝임·김 같은 위성 조각은
`min_area`를 낮춰도 계속 버려진다(`max(min_area, biggest * keep_frac)`).
콤비장면은 `min_area=260, keep_frac=0.0005`로 잘라야 하트·반짝임·김이 살아남았다.
→ **위성 조각이 중요한 컷은 `keep_frac`을 0에 가깝게.**
