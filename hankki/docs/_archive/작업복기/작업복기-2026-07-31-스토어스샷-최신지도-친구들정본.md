📌 **안 걸리는 검사는 없는 것과 같다.** 만들었으면 걸리는 것부터 보여야 한다.

## 2. ⭐⭐ 최신 지도 — 「옛 것 보고 판단하는 사고」를 장치로 막았다

> 창업자: *"최근 건 왜 먼저 안보고 계속 옛날꺼보는거야 뭐든 일하기전에 최근 문서보기로 한거아니었어?"*
> *"이것도 시스템 좀 만들어봐. 규칙만 만들면 뭐해 안지키는데."*
> *"모든 걸 다 그렇게 만들어줘. 어떤 문서든 관련된 최신문서 미리 읽고 시작하도록"*

### 진짜 원인은 「내 부주의」가 아니라 폴더 구조였다
옛 스샷 8장이 **폴더 맨 위**에, 새 8장이 **`renders-v3/` 안**에 **같은 이름**으로 있었다.
문구를 되살릴 때도 옛 스크립트(`store_new2.mjs`)를 집어 **폐기한 마트·제품 브랜드명을 도로 넣었다.**

### 만든 것 (문서가 아니라 **장치**)
| 무엇 | 언제 작동 | 안 지키면 |
|---|---|---|
| `scripts/latest-map.mjs` | 날짜 붙은 문서에서 **주제별 최신을 코드가 고른다** | — (손 관리 아니라 안 낡음) |
| `docs/최신-지도.md` | 코드가 못 고르는 것만 **핀**. 「저장소 밖」 명시 | — |
| `.claude/hooks/latest-guard.sh` · `UserPromptSubmit` | 창업자 말에서 주제를 뽑아 **최신 문서를 먼저 들이민다** | — |
| 같은 훅 · `PreToolUse(Read/Edit/Write)` | **옛 문서·`_구판/` 파일을 열면 차단** | **파일이 안 열린다** |
| 같은 훅 · `SessionStart` | 세션 열릴 때 주제별 최신을 깔아둔다 | — |
| `npm run smoke` 에 `--check` | 핀이 낡았거나 **옛 세대가 되살아나면** | **배포가 막힌다** |

⭐ **막기만 하면 일을 못 한다** → **「최신을 먼저 읽으면 옛것도 열린다」**.
역사를 봐야 할 때가 진짜 있으니, 순서만 강제한다. 읽은 기록은 `.git/hankki-최신읽음.json`(커밋 안 됨).

⚠️ **아바타는 목 아래 장식을 안 넣는다** — 나머지 4인 전부 머리만이다(꼬비 리본·뾰미 선글라스는 머리 **위**).
첫 판엔 리본이 있어 잘라내려 했는데 1050px 컷으로는 윗부분이 남았고, 창업자가 **리본 없는 판을 다시 그려줬다.**
⛔ 단체컷에서 머리를 오려 쓰지 말 것 — 머리가 200px라 아바타 485px로 **2.4배** 늘어나 톱니(자르기 원칙 ⓶).

### 「꼬르곰」 글자가 그림에 물린 것 — 숫자가 아니라 구조로 고침
새 정본이 세로로 조금 길어져(**비율 1.25 → 1.22**) 이름줄 첫 칸이 그림 칸 아래에 물렸다.
좌표를 다시 맞추면 **그림이 또 바뀔 때 또 어긋난다.**
→ 그림 칸과 이름줄을 **한 세로 흐름(flex column)** 에 넣었다. 줄은 남은 높이를 똑같이 나눠 갖고(`flex:1 1 0`),
얼굴 크기도 줄 높이의 %다. **친구가 늘어도, 그림이 커져도 구조적으로 겹칠 수 없다.**

`_ob5.mjs` 에 「단체 그림이 첫 이름줄을 덮으면 실패」 검사 추가 —
일부러 겹치게 만들어 **41px 덮음으로 잡히는 것까지** 확인.

### 앱에서 안 쓰는 것
`src/assets/cast/bu_*.png`(상반신 5컷)은 **어디서도 import 되지 않는다**(단체컷만 씀).
그래서 상반신 펭펭이 옛 머리인 채여도 앱엔 영향 없다. 쓸 때 다시 뽑을 것.
