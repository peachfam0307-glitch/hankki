### 만든 것

- **드래그** = 인스타 문법. 프레임 안에서 사진이 손가락을 따라온다.
- **«탭 = 바꾸기»와 가르는 문턱 6px** ＋ 드래그 뒤 따라오는 click 을 삼킨다(안 그러면 끌 때마다 파일창).

### 1. 💾 `wip-snap.sh` — 자동 스냅샷 (PostToolUse · 5분마다)

안 커밋된 워킹트리를 **원격 브랜치 `wip/auto`** 에 담는다.
브랜치·인덱스 무손상(임시 인덱스 → `commit-tree`) · 배포 안 돌림 · 규칙 13 안 어김 · 출력 0.

**만들며 두 번 틀렸고 둘 다 「돌려 봐서」 잡았다:**
1. **통째로 백그라운드로 던졌더니 아무것도 안 남았다**(훅이 끝나며 자식이 죽음) ＋ `.git/wip-index.lock` 이 남아 **그 뒤 전부를 막았다** → ref 만들기는 **동기**로, 임시 인덱스는 **저장소 밖(`/tmp`)** 으로.
2. **`refs/wip/*` 는 403** — 이 환경 git 자격이 «브랜치가 아닌 ref»를 막는다(hold 브랜치 삭제가 안 되던 것과 같은 이유) → **브랜치 `wip/auto`** 로. ⭐푸시해 보고 **run 번호가 그대로인 것까지 확인**(규칙 9 안전).

`repo-guard` 에 **「스냅샷에 지금 없는 파일 N개가 있다」** 안내를 이어 붙였다. 회귀 상황을 흉내 내 실제로 뜨는 것도 확인했다(433개).

### 2. 🪤 `check-mistakes.mjs` ⑧ — 「옛 함정 사전」 (배포 게이트)

첫 항목 = **`page.reload()` ＋ `addInitScript`**.
reload 때 `addInitScript` 가 처음 상태를 다시 심어 **저장값을 «검사 자신»이 지운다** → 앱이 멀쩡한데 「안 남는다」로 나오고, 그 거짓 실패를 좇게 된다.

⛔⛔ **2026-08-06 에 `_shot-diary.mjs` 안에 경고를 적어뒀는데 오늘 또 밟았다.**
경고가 **그 파일 안에만** 있었기 때문이다 — 새 파일을 쓸 땐 옛 파일을 안 본다.
⭐ **그래서 파일 «바깥»에서 본다.** 규칙 12 확인 = 일부러 함정 넣은 파일로 걸리고, 지우면 통과.

⛔ **두 번 밟은 것만** 사전에 넣는다 — 시끄러운 게이트는 죽은 게이트다.

## 📌 오늘 배운 것

1. ⭐⭐ **「알려주는 것」과 「지켜주는 것」은 다르다.** `repo-guard` 는 알렸는데도 30분을 잃었고, 경고 주석은 알렸는데도 또 밟았다. **알림은 이미 잃은 뒤에 온다.**
2. **경고는 「그 파일 안」이 아니라 «바깥»에 둔다.** 새 파일을 쓸 땐 옛 파일을 안 본다.
3. **검증 «전»에 먼저 커밋한다.** 회귀는 예고 없이 온다 — 검증하다 잃으면 검증도 무의미하다.
4. **「안 된다」의 이유를 재고 나서 처방한다.** 403은 내 코드가 아니라 권한이었고, 「저장이 안 남는다」는 앱이 아니라 검사였다. 안 쟀으면 둘 다 엉뚱한 걸 고쳤다.
5. **원인을 단정하기 전에 `reflog`·`uptime` 을 본다.** 「컨테이너 재시작」이라 말하려다 재보니 **디스크가 어제 것**이라는 더 정확한 그림이 나왔다.
