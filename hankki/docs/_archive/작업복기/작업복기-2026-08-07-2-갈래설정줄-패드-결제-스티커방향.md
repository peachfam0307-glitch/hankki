## 1️⃣ 📱 창업자 폰 제보 넷 — 전부 «하나의 뿌리»였다

창업자 원문(사진 3장과 함께):
> *"1.2.3.4,6,7번까지 되고 **5번은 없어(어딨는지 못찾음)** 소프트잇아니고 **스티커에도 포스트잇(줄눈,그런선택지가 나와)**
> **일꾸아래 스크롤 먹통, 스크롤해도 안올라가**, 그리고 **위에 설정(색, 무늬 모양)부분이 너무 길어**
> 이거 접는거나 잠깐 숨기기나 그런게 필요햐."*

### 🔬 재현으로 잰 값 (창업자 폰과 같은 360×780)

| | 고치기 전 | 고친 뒤 | 접으면 |
|---|---:|---:|---:|
| 컨텍스트 바 | **200px · 다섯 줄** | **80px · 두 줄** | **42px** |
| 서랍 | 164 | 284 | 322 |
| **서랍 스크롤 칸** | **53** | **173** | **211** |
| 굴려야 할 거리 | 292 (데코 탭 1832) | 172 | 134 |
| 갈래 옆 밀림 | — | **0** (칩 합 302 / 칸 305) | 0 |
| 「움직임」 단추 | ⛔ 없음 | ✅ 있음 | ✅ |

⭐⭐ **⑶과 ⑷가 «같은 하나»였다.** 창업자는 「스크롤 먹통」과 「설정이 길다」를 따로 말했는데,
설정 다섯 줄이 200px 를 먹어 **서랍 스크롤 칸이 53px** 로 눌린 것이 원인이었다.
**53px 은 손가락보다 얇다** — 기술적으론 굴러가지만(0→292) 사람 손으론 위 탭 줄·아래 손잡이에 닿는다.
📌 **「먹통」이 정확한 말이었다.**

### ⑴ 「5번이 없어」 — 뿌리 = `FRIEND_IDS` 로 좁힌 것

`selIsBuddy = (type==='sticker' && FRIEND_IDS.has(key)) || type==='text'`
→ **친구들 탭 스티커 또는 직접 쓴 글자**에만 두 단추가 떴다.

⛔ **그런데 일기 서랍엔 친구들 탭이 «아예 없다»** — 실측 탭 = **마테 · 데코 · 글자 셋뿐.**
즉 **일꾸에서는 직접 쓴 글자 말고 두 단추를 띄울 길이 없었다.**

✅ 고침 = **스티커(전부) · 글자 · 포스트잇 · 글 상자 · 사진**에 붙인다.
근거 = 모션은 `hk-m-*` CSS 클래스, 효과는 위에 겹치는 파티클이라 **밑이 무엇이든 얹힌다.**
**막고 있던 건 코드지 그림이 아니었다.**

⚠️ `DecorLayer` 쪽도 같이 고쳐야 했다 — `note`·`photo` 는 모션 클래스를 감쌀 자리가 없었고,
`StickerFx` 는 `FRIEND_IDS.has(it.key) &&` 로 막혀 있었다.
📌 **모션 클래스는 «감싼 span» 에 준다** — 바깥 상자에 주면 `rotate`·`scaleX` 가 덮여 기울기·뒤집기가 날아간다(v9.03 함정).

### ⑵ 「스티커에도 포스트잇 줄눈이」 — **죽은 단추였다**

글 상자(`note` ＋ `art`)를 고르면 **색·무늬·모양** 줄이 떴는데,
`DecorLayer.jsx:424` 가 `if (it.art) return <ArtBox …>` 로 통째로 빠져서
**눌러도 아무 일이 안 났다.**

✅ 고침 = `selPlainNote` 로 갈라 **글 상자엔 그 갈래가 아예 안 생긴다.** 실측 죽은 단추 **0**.

### ⑶⑷ 갈래 방식 — **새로 만든 게 아니다**

같은 날 낮에 창업자가 *"효과단추는 네가 아이디어낸게 좋은 것 같아"* 라고 통과시킨
**「움직임 ／ 효과」 갈래 단추를 설정 전체로 넓혔을 뿐이다.**

- 갈래 줄 = 순서 · 색 · 글씨 · 무늬 · 모양 · 움직임 · 효과 (종류마다 있는 것만)
- 칩 줄 = **고른 갈래 하나만**
- **같은 갈래를 다시 누르면 접힌다** ＝ 창업자가 말한 「잠깐 숨기기」가 «누르던 자리 그대로»
- 오른쪽 ∧ 단추로도 접힌다

## 7️⃣ ⭐ 오늘 밤 배운 것

1. **따로 온 제보 두 개가 하나일 수 있다.** 「길다」와 「안 굴러간다」가 같은 원인이었다.
2. **화면을 바꾸면 검사도 같이 봐야 한다.** 검사가 옛 화면을 보고 「고장」이라 거짓말했다.
3. **「내 탓인가」는 되돌려서 가른다.** `git stash` 로 옛 코드에 돌려 두 검사의 성격을 갈랐다.
4. **같은 실수를 고치면서 또 낼 수 있다.** 밀림을 없애러 가서 갈래 줄을 또 밀리게 만들었다 — **재서** 잡았다.
5. **「없다」고 말하기 전에 센다.** 자료가 만들라는 것의 절반이 이미 있었다.
6. **검사가 「낡았다」고 해도 검사가 틀렸을 수 있다.** 넷 중 셋이 거짓이었다.
