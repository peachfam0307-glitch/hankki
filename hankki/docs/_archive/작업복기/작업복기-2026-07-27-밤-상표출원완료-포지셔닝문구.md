- 【등록대상(지정상품)】 — 유사군 `G390802`(소프트웨어) 필터 적용 확인 → 전자출판물(G5206) 함정 회피 확인 → 처음 3개 → 창업자가 "10개까지 무료면 더 넣자" → **5개로 확장**(데이터베이스관리앱·이미지파일처리·이미지문서스캔·데이터문서캡처저장·데이터처리) → "인공지능 텍스트→이미지 생성"만 제외(우리 앱과 반대 기능이라)
- **접수완료 확인** → **46,000원 납부 완료** 확인
- 창업자 "지정상품 5개 우리 앱이랑 맞는 거 맞냐, 반려될까 걱정" → 5개 전부 실제 앱 기능과 매칭됨을 표로 설명 + 반려는 지정상품 부적합보다 미납·형식누락이 주원인인데 그건 이미 해결됐다고 안심시킴
