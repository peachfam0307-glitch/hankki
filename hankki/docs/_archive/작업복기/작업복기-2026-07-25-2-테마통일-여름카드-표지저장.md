## 4. 🖼 카드 표지 저장 (v8.50) + 균형 수정 (v8.51)
- **아이디어(창업자)**: "카드 나온거 저장돼? 내 레시피에 꾸미기 대신에. 돌려서 저장해도 예쁠듯."
- **구현**: `Card`에 `cover` prop(CTA 숨김) + 화면밖 `coverRef` 카드. 모달 "🖼 이 카드를 내 레시피 표지로" 버튼 → `toJpeg` 캡처 → `onSaveCover` prop → `RecipeDetailScreen`이 `updateRecipe(id,{thumb:'photo',image})`. 재뽑기로 스타일 골라 저장 = "가챠 표지꾸미기"(홀로·팝·폴꾸·다이어리·여름 다 됨).
- **캡처 함정(중요)**: `html-to-image`가 웹폰트 CSS를 fetch하는데 **dev 프록시선 폰트fetch 타임아웃으로 ~10초** 걸림(테스트 환경 한정). **프로덕션 같은출처는 ~300ms**(기존 공유 기능이 증거). skipFonts 폴백 넣어 견고화. e2e 폴링은 이걸 감안해 넉넉히.
- **검증**: Playwright e2e(레시피→공유→랜덤카드뽑기→표지저장→`thumb:'photo'`·img 237KB 확인).
- **균형 수정(v8.51)**: 창업자 실기기 제보 "표지 저장하니 위쪽으로 올라간 것 같아". 원인 = cover가 CTA를 없애 카드 아래가 빔 + 썸네일은 **정사각(aspect-ratio:1·object-fit:cover)이라 카드 가운데 크롭** → 콘텐츠가 상단에 몰림. 수정 = cover 모드일 때만 곰펭·제목·태그 아래로(중앙정렬) — holo/pop 캐릭터 230→300·제목 775→945, pola 제목 880→985. 공유 카드(비-cover)는 그대로. 정사각 크롭 시뮬로 검증(꽉 참).
