## 5️⃣ 🐛 찾은 버그 셋 (앱 코드는 안 고쳤다 — 규칙 13)

### ⓐ 요리 기록이 「직접 고른 아이콘」을 무시한다
`MyRecipesScreen.jsx:328` — 저장된 `recipe.icon` 을 안 보고 **제목으로 다시 추측한다.**
📌 **v9.77 에서 표지에 고친 것(`iconPicked`)과 같은 버그.** 달력 칸에 아이콘을 띄우려면 **어차피 이 값이 필요하다.**

### ⓑ 🔤 글씨체 두 종이 「반쪽」이다
| | |
|---|---|
| 꾸미기 글씨체(`TEXT_FONTS`) | **6종** — 귀염체·펜글씨·통통체·또박체·**임팩트**·**라운드** |
| 앱에 파일로 실린 것 | **4종**(`src/assets/fonts/` = **1.7MB**) |
| 임팩트·라운드 | ⚠️**구글 폰트 링크로만**(`index.html:45`) — **로컬 파일 없음** |
| 캡처용 꾸러미(`fontEmbed.js:32`) | **4종 고정** — 둘이 **빠짐** |

⛔ ⒜**오프라인이면 그 둘이 안 나온다**(PWA인데) ⒝**공유 카드 캡처 때 꾸러미에 안 담긴다** → **v9.66 사고와 같은 자리**
⚠️ **⒝는 재현 안 했다** — 「꾸러미에 없다」까지가 확인된 것.

### ⓒ 📦 woff2 가 precache 에서 안 걸러진다
`vite.config.js:39` = `globIgnores: ['assets/**/*.png', 'assets/**/*.webp']` — **woff2 가 빠져 있다.**
- 첫 다운로드 **4.1MB / 상한 8MB** 중 **폰트가 1.7MB = 41%**
- 한글 woff2 하나 = **284~601KB** → ⛔**10개 더 = ＋4.2MB → 8.3MB → 배포가 막힌다**
- ✅ **해법은 이미 푼 문제** — 8/5에 스티커 PNG로 215MB→4.1MB 한 그 방법(CacheFirst)을 폰트에 그대로.
  ⭐ **다꾸 폰트는 고른 사람만 쓴다 — 스티커와 성질이 같다.** 그러면 **20개도 넣을 수 있다.**
