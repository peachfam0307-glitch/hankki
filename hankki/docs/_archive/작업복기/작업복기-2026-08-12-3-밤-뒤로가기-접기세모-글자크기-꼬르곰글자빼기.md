## 3️⃣ 🔙 뒤로가기 먹통 — 「물음창이 자기 자리가 없었다」

창업자 = *"뒤로가기 안됨(꾸미기 닫힘안돼) 저장하고 나가기 그거 선택하는거 눌림.. 급짜증난다ㅠ"*

### 🔎 구조

```
openModal(close) → 히스토리 칸 1개 push + 층 등록
popstate        → 맨 위 층을 «빼고» close() 호출
```

⛔ 꾸미기의 close 는 **곧장 안 닫고 「저장하지 않고 나갈까요?」를 먼저 묻는다.**
→ **판은 그대로인데 층과 히스토리 칸이 사라진다**
→ 다음 뒤로가기가 갈 곳을 잃어 **먹통**이 되거나, 판보다 «아래» 칸을 먹어 **꾸민 게 날아간다.**

### ⛔ 첫 처방이 안 통했다

`close()` 가 `false` 를 돌려주면 층을 남기고 `trap()` 으로 칸을 되채우게 했다.
**재현이 잡았다** — 「계속 꾸미기」 뒤 뒤로가기에 *"시트도 없이 그냥 닫혔다"*.
**크롬이 popstate 안에서 만든 칸을 «터치 없이 만든 것»이라 건너뛴다.**

### ✅ 그래서 «묻는 것»을 없앴다

**뒤로가기 = 저장하고 닫기.** 잃는 게 없으니 물을 이유도 없다.
⛔ 「취소」 단추는 그대로 «버리고 나가기» — **뒤로가기와 취소는 유저가 다른 뜻으로 누른다.**
하나로 묶었던 게 애초에 잘못이었다.

🧪 재현 8/8(레시피·일기 둘 다) — ①안 바꾸면 바로 닫힘 ②묻지 말고 저장하고 닫힘 ③꾸민 게 저장돼 있음 ④취소는 그대로 물음

## 5️⃣ 🔠 글자 크기 — 세 판 만에 맞췄다 (⭐오늘 제일 값진 배움)

### 판1 (낮) — 배율을 «상자»에 걸었다
창업자 = *"글자가 커지면서 상자가 커지면 그게 무슨의미가 있어.. **스티커는 그대로고 글자크기만 커져야지.**"*
📌 맞다 — 상자째 커지면 **손잡이로 키우는 것과 똑같아진다.** 「크기」 갈래가 있을 이유가 없어진다.

### 판2 — 배율을 «한도(max)»에 넣었다
`autoCqw(text, 13 * 배율, …)`. 짧은 글은 한도까지 커지고 긴 글은 안 넘으니 완벽해 보였다.

⛔⛔ **창업자가 정확히 잡았다** — *"보통보다 크게가 살짝 더 작아져"*

🔎 `autoCqw` 는 **0.25 씩 내려가며** 맞는 값을 찾는다. 한 줄 글자 수 `per = floor(폭 / r)` 이
**계단식으로 뚝뚝 떨어진다** → **시작점이 바뀌면 «다른 계단»에 걸려**
큰 한도에서 내려온 값이 오히려 더 작아질 수 있다.

### ✅ 판3 — 계산은 「보통」으로 한 번, 결과에 «곱한다»

```js
const noteCqw = autoCqw(text, 14, …) * textSizeV(it.tz)
```

**곱셈이라 순서가 뒤집힐 수 없다.**

| 단 | 글자 |
|---|---:|
| 작게 0.82 | 12.2px |
| 보통 1.0 | 14.9px |
| 크게 1.28 | 19.1px |
| **아주 크게 1.6** | **23.9px** |

＋ 「크게」 이상이면 **안 자른다**(`overflow: visible`).
📌 옛 제보 *"글씨체가 커지는데 상자는 그대로라 글씨가 잘려"* 의 답은
**「상자 키우기」가 아니라 「안 자르기」**였다. 반년쯤 돌아왔다.

## 9️⃣ 📌 오늘 밤 배운 것

1. **「넣었다」 ≠ 「보인다」** — 소스에 있어도 단추로 안 보이면 없는 것이다.
2. **글자로 아이콘을 만들면 크기를 못 잡는다** — `▾` 13px 의 실제 삼각형은 7px. 도형은 SVG.
3. **계산의 «시작점»을 바꾸면 결과 순서가 뒤집힐 수 있다** — 계단식 함수에선 곱셈이 안전하다.
4. **뒤로가기와 취소는 다른 뜻이다** — 하나로 묶으면 둘 다 나빠진다.
5. **1px 차이가 「없다」를 만든다** — 꼬르곰 277px vs 굴칸 276px.
6. **창업자 말의 «대상»을 내가 정하지 말 것** — 「접기」는 그룹이 아니라 탭 줄이었다.

⭐⭐ 다섯 다 **창업자가 폰에서 보고 잡았다.** 내 숫자 검사는 전부 초록불이었다.
📌 규칙 21(보여주기 전 실물 확인)을 지켰어도 **「내가 뭘 봐야 하는지」를 몰랐다.**
   실물을 열어보긴 했는데 «단추로 보이나»·«크게가 정말 크나»를 안 봤다.
