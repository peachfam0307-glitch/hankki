## 2. 학습 (이번에 배운 것 · 규칙화)

### 🎬 스토어 "움직이는 화면" = 프로모 영상(YouTube)만 (2026 서치 확인)
- **피처그래픽(1024×500)·스크린샷 = 무조건 static PNG/JPEG.** 애니 GIF·동영상 파일 **업로드 불가.**
- 움직이는 걸 보여주려면 **프로모 영상 1개** = **YouTube에 올리고 그 링크를 Play Console에 붙임**(직접 영상 업로드 아님).
- 영상 붙이면 **스크린샷보다 먼저** 뜨고, **피처그래픽이 그 영상 썸네일**이 되며 **가운데 재생버튼**이 얹힘.
  - → 그래서 피처그래픽은 **가운데를 비워야** 함(재생버튼 자리). 이번 스토어 그래픽 이미 그렇게 설계함(곰 오른쪽·로고 왼쪽·중앙 여백).
- **결론**: "움직이는 레시피 화면" = **레꾸 꾸미기 과정 화면녹화 → 짧은 영상 → YouTube → 링크**. = 이미 백로그 **[#24] 레꾸 과정 영상**과 같은 작업. 스토어·인스타 겸용.

### 🖼️ 피처그래픽 원칙 (서치 종합)
- 메시지 **한 줄(5~7단어)**, 마스코트 **크게**, **채도 있는 배경**(흰/검 배경은 스토어 UI에 묻힘 → 캐러멜 웜톤), **가운데 비움**(재생버튼), **정확히 1024×500 · 불투명 24bit PNG/JPEG**(알파 금지). Asset Library(Grow>Store presence>Main store listing>Graphics)에서 관리.
- ⚠️ **가장자리는 스토어가 잘라내거나 UI 얹을 수 있음** → 곰·글자는 가장자리서 여백 두기(이미 지킴).
- **"붕뜸" 교훈**: 밝은 요소를 **작은 카드로 띄우면** 배경과 따로 놀아 떠 보임 → **전체높이 구조영역(색면 분할)으로** 바꾸면 "의도된 레이아웃"으로 읽혀 안착. 물결 곡선으로 브랜드(물결곰)와도 연결.

### ✍️ 스토어 태그라인 = "레꾸(꾸미기)" 훅 (정리 아님)
- 스토어=**획득 자리** → 옛 "흩어진 레시피를, 한곳에"(정리 포지셔닝=레드오션)는 **뺌.** → **"내 레시피, 예쁘게 꾸미고 자랑해요"**(꾸미고+자랑=바이럴 훅, 포지셔닝 doc §3 방향).
- ⚠️ 신규유저는 "레꾸" 은어 모름 → **쉬운 말로 풀어** 씀(꾸미기·자랑). → `docs/포지셔닝-왜한끼-뾰족-2026-07-23.md`
- ⬜ **미정**: 앱 내부 태그라인(`version.js`·`index.html`의 "흩어진 레시피를, 한곳에.")도 레꾸 라인으로 통일할지 = 별도 결정(앱코드=배포라 창업자 신호 때).

### 🐛 크롭 검정버그 원인
- 새 캔버스는 처음 **투명** → 모바일 WebView에서 `drawImage`가 늦으면 투명 캔버스가 JPEG로 나가며 **검정**. → 흰배경 먼저 채우고 `img.decode()`로 비트맵 준비 보장 = 방어.

### 🎨 확정된 디자인 규칙
- **색반전 세트**(창업자 아이디어): 밝은 배경=크림바탕+브라운글자 / 어두운 배경=브라운바탕+크림글자. 배경 밝기 양쪽 대응.
- **물결곰 canon 일관성**: 로고·아이콘·앱 전부 뉴 음영 물결 곰펭만. (옛 매끈곰 로고는 아카이브 보존)
