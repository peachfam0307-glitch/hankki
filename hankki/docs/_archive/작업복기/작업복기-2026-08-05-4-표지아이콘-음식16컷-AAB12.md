## 3️⃣ 🍱 음식 아이콘 — 시트 6장(35칸) → **16컷만**

### 대조를 코드로 했다 (손으로 안 셌다)

`ICON_RULES`·`FOOD_NAMES` ＋ `photo/*.png` 존재 여부를 맞추고 **실물 컨택트시트로 눈까지** 봤다.

- ⛔ **13칸은 앱에 이미 같은 그림이 있어 뺐다** — 탕수육·튀김·오이소박이·짜장면·동파육·육개장·스프·회덮밥·연어장·간장새우장·어묵탕·꼬막비빔밥·간장찜닭
- ⛔ **A장·D장이 5칸을 같은 요리로 다르게 그렸다** → 하나씩만
- ⛔ **방방지** = 창업자 판정 *"이상하게 나왔어;;"* (그림은 부추전인데 이름이 중국식 닭냉채였다)

### ⚠️ 대조하다 «내가» 두 번 틀렸다 — 둘 다 «방식»이 틀렸다

| 틀린 것 | 뿌리 |
|---|---|
| 「두부조림·육개장·스프·튀김은 앱에 없다」 | **별칭을 나중 것으로 덮어써** 범용 도형이 이겼다. **앱은 «처음» 걸리는 규칙을 쓴다** |
| 「이름이 걸리니 그림이 있다」 | **범용 도형은 png 가 없다.** 「이름이 걸린다」 ≠ 「진짜 그림이 있다」 |

📌 규칙 18 그대로다 — **「없다」·「이것이다」는 «확인 방식»부터 의심한다.**

### 🐛 대조하다 버그 둘이 나왔다 (아무도 몰랐다)

- **「계란찜」 → 계란말이 그림**(`fh_k17`)이 붙고 있었다
- **「두부간장조림」 → 고추장 매운 두부조림**(`fe_35`)이 붙고 있었다

둘 다 **옛 규칙에서 낱말을 빼** 바로잡았다. 새 그림이 그 자리를 받는다.

### ⛔ 그리고 내가 또 틀렸다 — 「콩나물무침」

3배로 키워도 **굵은 가닥이 면으로 보여서** 「비빔면 아니냐」고 물었다.
창업자 *"콩나물 맞아"*.

📌📌 **확대는 「어디를 볼지」를 정해줄 뿐이고 「무엇인가」는 «아는 사람»이 정한다.**
(v9.16 교훈 — *"숫자는 어디를 볼지만 정하고, 맞나 틀리나는 눈이 정한다"* 와 같은 결)

### 절차
`sheet-index.py` 갱신 → `--check` 6장 통과 → `cut.py --diecut 3` → 3단계 검수 → 앱 등록 → 실물 확인

## 4️⃣ 🍱 픽커 탭 순서 (v9.79) — 창업자 확정

- ⭐ **끼니가 앞, 군것질이 뒤** — 분식·빵디저트를 맨 뒤로
- 창업자가 「회」를 두 번 적었는데 *"일식뒤에 회빼고"* 로 확정 → **한식 묶음 맨 끝 한 곳**
- 볶음 맨 끝 = 양념장 › 달래양념장 › 샐러드드레싱 › 소스

### ⛔ 여기서도 한 번 틀렸다

*"볶음 마지막에 소스넣자"* 대로 **배열 끝**에 넣었는데 화면엔 **가나다순에 섞여 나왔다.**
`FOOD_ICON_GROUPS_SORTED` 가 그룹 안을 다시 정렬하기 때문이다(v8.81 · 아이콘 300개라 찾기 편하라고).

📌 **「배열에 넣은 순서」 ≠ 「화면 순서」.** 코드로 넣었다고 그렇게 보이는 게 아니다 — **실물 렌더가 잡았다.**
✅ `TAIL_KEYS` 로 정렬에서 빼고 맨 뒤에 그대로 붙인다.

## 6️⃣ 📝 출시 노트 — 창업자가 방향을 통째로 바꿨다

> 창업자: *"이것만 고치면 돼? 우리 어제도 많이 수정한 것 같은데 (설문에 쓸것도 넣어야 하는거 아냐?)"*
> → *"**테스터 의견을 넣고 수정한걸 반영해야 구글에서 알지**"*

⛔ **내가 「오늘(8/5) 고친 것」만으로 노트를 썼다.** 실제로 이 판에 실리는 건 **v9.50 ~ v9.79 = 30판**이다
(콘솔 최신 = versionCode 11 = **v9.49**). 어제 고친 것이 통째로 빠져 있었다.

⭐⭐ **더 큰 지적 = 출시 노트가 곧 「증거」다.**
반려 사유 ②가 「앱 업데이트를 통해 의견을 수집·조치하지 않았습니다」인데,
재신청 답변에만 쓰고 노트를 기능 나열로 내면 **앞뒤가 안 맞는다.** 심사자가 보는 자리가 둘이다 —

| 자리 | 분량 | 무엇이 보이나 |
|---|---|---|
| 재신청 답변 | 넉넉함 | 우리가 **말한** 것 |
| **출시 노트** | **500자** | 우리가 **한** 것 (버전마다 남는다) |
| 출시 내역 | 자동 | 판 수 자체가 증거 (11 → 12) |

→ 노트를 **「테스터 의견 → 직접 찾은 것 → 새 기능」** 순서로 다시 썼다. **422자 / 500.**

### ⛔ 「500자」도 내가 확인 안 하고 적었다
창업자 *"출시노트 길게써도 돼?"* 를 듣고서야 확인했다 — **언어당 500자**(유니코드·공백·줄바꿈 포함).
⚠️ 공식 페이지는 이 환경에서 못 연다(403) — 검색 요약 ＋ 도구 문서 셋이 일치. 근거 관문 통과.
⛔ **`<ko-KR>` 태그는 지우지 말 것** — 안내문 한 줄만 지운다.

### ⛔ 부풀리지 않았다
확실한 테스터 의견 **3건** 중 이번 판에 실린 건 **2건**(한살림 링크 v9.52 · 요리 모드 버튼 v9.57).
나머지 20여 건은 **창업자 실사용 제보**라 「직접 써보며 찾은 것」으로 갈라 적었다.
아이폰 지인 둘은 Play 테스터가 아니라 「테스터」로 쓰면 거짓이다.
