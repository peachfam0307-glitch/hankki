## 1. 💰 수익 모델 최종 확정
- **무료** = 웰컴 20장(첫 가입 1회) + 매월 5장 (둘 다 고품질 Google Vision) + 기본 OCR(tesseract) 무제한
- **유료** = 990원 20장팩 (50원/장, 원가 2원/건, 마진 95%+)
- **카운트** = 저장 1건 = 1장 (멀티포토·재시도·실패는 안 깎음)
- **왜 안 후한가(핵심 논리)** = 마진 레버 = "매월 5장" 하나. 기본 OCR 무제한이 안전망이라 무료 AI 짜도 이탈 없음. 웰컴 20은 1회성·원가$0이라 마진 안 깎음.
- 웰컴 20 확정 (창업자 "초기 가입자 적어 900 걱정 없음"). 옛 `CLAUDE.md` '웰컴20 금지' 핀 = **창업자 본인 결정으로 대체.**
- **숫자 일치화**: CLAUDE.md 핀 · §9-2 · §9-4 · `ocr-proxy/README.md` 전부 갱신(옛 25장·30장 정리). 날짜 붙은 기록물(작업복기·할일 스냅샷·변경이력)은 이력이라 보존.

## 2. 🩺 건강보험 함정 → 해결
- 창업자 직접 사업자등록 시: 사업소득 발생 → 건보 **피부양자 탈락 → 지역가입자 전환.** 모의계산 **월 69,500 ~ 296,000원**(집 명의 여부 차이).
- 재산 = 개인 명의 기준 / 자동차 = 2024.2부터 건보 계산서 폐지 / 지역 = 세대 단위 합산.
- 손익분기(직접 등록 시): 순익 ~900원/팩 → 월 69,500원 = ~77팩, 296,000원 = ~330팩.
- ⭐ **해결 = 직장 다니는 가족(일반회사) 명의로 등록** → 보수외소득 연 2천만↓면 추가 건보 **0**. 세금 = 순이익만 종소세 합산(손해 아님·부가세/연금 미미). 커지면 창업자 명의 전환(폐업→신규).
- 창업자 가족 = **일반회사 확인**((A)경로 유효). 남은 체크 = 취업규칙 겸업금지 하나(소규모 부업이라 저위험).

## 3. 🧾 사업자 절차 (Q3)
- 홈택스 사업자등록(간이과세·3영업일·무료) → 통신판매업(간이면 면제 가능, PG 요구시 신고) → PG 심사 3~10일 = **총 2~3주.**
- 그 전 실결제 불가 / 코드는 샌드박스로 미리 준비 가능.
- **사업자등록 ≠ 통신판매업** (별개 절차).

## 4. 🛠 #54 결제 설계 (서치 완료 · 미구현)
- PG = **토스페이먼츠 결제위젯** + 샌드박스(등록 전 개발) + 서버(worker) 승인·금액 검증.
- 크레딧 = **Durable Objects per uid** (⭐무료플랜 OK·카드 불필요, KV 경쟁조건 회피).
- **900 효율화(창업자 지적 "재시도하면 900 깎임")** = ① 재시도 캐싱(같은 이미지 재호출 X) ② 성공했을 때만 900 차감.
- 계정 없는 복원 = 990팩 소모성이라 재설치 소멸 → 구매 시 이메일로 복원.
- **Phase A**(크레딧·저장당·안내문구) = 지금 가능 / **Phase B**(990팩 결제) = PG 계약 후.
- ⚠️ 창업자 "서치 제대로 하고 시작하자" → **서치 완료, 코딩은 다음.**

## 5. 📎 6개 질문 배치
- **Q1 꾸미기팩(출시 한달 한정판)** = 찬성(원가 0·희소성·레꾸 부각). "한정" 약속은 지킬 것.
- **Q2 장보기 라벨 아이콘** = 우리 아이콘/스티커(⛔유니코드 금지 준수). **곰펭 미니(`gom_shop`) vs `cart` 라인아이콘 = 창업자 택 대기.**
- **Q4 기능별 업뎃주기(제안)** = 추천레시피 주1 · 주부의장바구니 격주 · 꾸미기 월1+계절 = **확정 대기.**
- **Q5 AI 안내문구** = 'OCR' 단어 빼고 쉽게(3줄), #54 때 반영. "가입 선물 20장 / 매달 5장 / 다 쓰면 기본 읽기로 무료".
- **Q6 쿠팡파트너스** = 출시 후 장보기 트래픽 생기면(사업자 불필요·승인 1~3일). 수익 커지면 건보 논리 동일.
