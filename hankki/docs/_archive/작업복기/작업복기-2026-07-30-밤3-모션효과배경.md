## 2. 기술적으로 오늘 배운 것 — **하나의 실수가 다섯 곳에서 터졌다**

### ⭐ `transform` 의 `%` 는 「제 몸 크기」 기준이다

```
16px 하트에 translateY(-85%)  →  13.6px 뜬다  →  238px 스티커의 5.7%
```

**떠오르는 것 4개, 떨어지는 것 4개, 터지는 것, 도는 것, 지나가는 것 — 전부 같은 실수였다.**
겉으로는 "작아 보인다 / 먹통이다 / 안 움직인다" 로 **다르게** 나타나서, 하나씩 고치다 원인이 하나임을 늦게 알았다.

**고친 방식이 중요하다** — 값을 크게 바꾼 게 아니라 **계산을 코드에 박았다**:
```js
const rel = (size, pct) => `${Math.round(pct / (size / 238))}%`   // 스티커 기준 % → 조각 기준 %
```
→ 이제 **조각 크기를 바꿔도 이동 거리가 안 변한다.** 전엔 크기를 키우면 거리도 같이 커졌다.

📌 **교훈: 같은 실수가 여러 곳에 있으면, 각각 고치지 말고 「계산」을 한 곳에 만든다.**

### ⭐ 이름 규칙으로 분류하지 마라 (오늘 두 번째)

여름 곰펭 `sm_`, 가을 곰펭 `au_b` 가 `gp_` 접두어 검사에 안 걸려 **캐릭터인데 안 움직였다.**
**같은 검사가 네 파일에 복사**돼 있어서 넷 다 동시에 빠졌다.
→ `FRIEND_IDS`(친구들 탭)로 통일. **새 계절 곰펭은 탭에만 넣으면 자동으로 붙는다.**

⚠️ **손으로 셋을 고치고 "다 고쳤다"고 생각했는데, 게이트가 네 번째를 잡아냈다.**
   📌 **같은 규칙이 여러 곳에 복사돼 있으면 눈으로는 반드시 하나를 놓친다.**

### ⭐ 파일 이름에 "투명"이 있으면 열어서 알파를 확인한다

`여름프레임-16종-투명.png` — 이름만 투명이고 실제는 RGB.
**AI가 "투명 배경"을 회색 체커 격자로 진짜 그려 넣었다.** 격자가 **246/253 두 톤**이라
옛 도구의 배경 문턱(246)이 **246쪽을 그림으로 남겨** 프레임 테두리에 점점이 붙었다.

⚠️ 고치는 과정에서 두 번 더 배웠다:
   - 격자 판정을 **채널차 ≤8** 로 잡으니 **크림색 선까지 지웠다** → 격자는 **완전 무채색(≤2)** 이다
   - 다시 자르니 `--frame` 창 뚫기가 **조개 프레임의 진주를 먹었다**
     → 📌 **재컷보다 「조각만 제거하는 수술」을 먼저 시도한다**
   - 재컷은 원본 해상도(≈280px)라 **해상도 게이트(626px)에 걸린다** → 예전 긴변으로 키워 넣는다

### ⭐ 가끔만 움직이는 모션은 「안 움직이는 것」과 구별이 안 된다

어지러울까 봐 빙글을 3.6초에 한 번, 그것도 마지막 30%에서만 돌게 만들었다.
→ 창업자가 **보고 있어도 아무 일이 안 일어났다.** 주기를 줄이고 멈춘 구간을 없앴다.

## 3. 수익 구조 — 오늘 정한 것 (창업자 확정)

### ⭐ 팩당 모션·효과 **딱 1개** (1+1 아님)
처음에 "모션 1 + 효과 1"로 잡았다가 창업자가 잡았다:
*"각각 1개 총 2개가 아니라 그냥 1개씩. 왜냐면 **매달 나오는건데** 부족해."*
→ 만들어 둔 13개로 **1+1이면 6개월, 1개면 1년.**

### ⭐ **축이 겹치는 건 팩에 안 넣는다**
개수를 늘려도 **축이 같으면 늘어난 걸로 안 보인다.**
`MOTIONS.axis` · `FX_KINDS.dir` 이 그 축이고, 게이트가 **팩당 1개**를 강제한다.

### ⚠️ 재고 한계 — 창업자가 짚은 진짜 문제
*"가을만해도 유료팩이 3개야... 계절당 2개씩 나올텐데 **진짜부족할것 같아**"*
→ 맞다. 그림 한 장으로 만들 수 있는 축은 **8~10개가 끝**이다. 매달 새 축은 **불가능**하다.

**답 세 가지:**
1. **간판 팩 방식** — 계절마다 대표 팩 하나만 새 축. 연 4개 → **재고 9개로 2~3년** *(⏳창업자 확정 대기)*
2. **같은 축에 다른 그림 = 유저에겐 새 효과** — 낙하 코드 하나로 벚꽃·눈·낙엽·빗방울… **비용 거의 0**
3. **배경은 재고가 거의 무한** — 색×질감×빛, **그림 0장**

### ⭐ 배경 — 기본은 **단색 ＋ 모눈 ＋ 웜크림**만
창업자: *"유료 배경효과에 그라 넣으려면 우리 기본으로 준 노을, 세이지 빼야한단 뜻이야"*
→ **팔 것을 먼저 공짜로 주면 안 된다.** 그리고 **이미 준 걸 회수하는 건 더 안 되니
   정식 출시 전인 지금이 정리할 마지막 타이밍**이었다.

| | |
|---|---|
| ✅ 무료 16 | 단색 14 ＋ **모눈**(노트라서) ＋ **웜크림**(제일 중립적이라) |
| 🔒 그라데이션 팩 | 민트·파스텔·노을·세이지 |
| 🔒 종이 질감 팩 | 도트·스트라이프 ＋ 만들 것(줄노트·크라프트지·린넨·수채지) |

📌 **모눈만 무료인 기준**: *"아까운가"가 아니라 **"없으면 앱을 못 쓰나"** 로 정한다.
📌 **그리고 무료가 초라하면 유료도 안 팔린다.** 단색만 14개면 *"다 그냥 색이네"* 가 된다.

### ✅ 시간대 연출은 **무료로 앱 전체에** (다음 업뎃)
저녁에 노을빛이 도는 앱은 "정성 들인 앱"으로 읽힌다. **팔면 대부분이 못 봐서 그 효과가 0이 된다.**
