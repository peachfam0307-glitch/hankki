## 🎯 PART 1. 상표 — 최종 확정

### ✅ 결론: "한끼" 이름 그대로 등록 가능
- KIPRIS·KIPO 직접 조회로 확정:
  - 오팬하우스 '한끼'(등록 **4025697090000**) = 09류, **전자서적, 유사군 G5206**
  - 우리 = 소프트웨어/앱, **유사군 G390802**
- **G390802 ≠ G5206** → 상품이 다름 → 상표 거절(제34조1항7호)은 **①이름유사 + ②상품유사 둘 다** 필요한데 ②가 깨짐 → **한끼 등록 가능. 이름 안 바꿔도 됨.**

### 📝 출원 지정상품 (실제 고시명칭 — KIPO 직접 조회, 전부 G390802)
- **내려받기 가능한 데이터베이스 관리용 소프트웨어 애플리케이션** (레시피 저장·목록관리)
- **디지털 이미지 파일 처리용 컴퓨터 소프트웨어** (카드 꾸미기·이미지편집)
- **데이터 처리용 컴퓨터 소프트웨어** (넓게 백업)
- ⚠️ "레시피"·"애플리케이션"·"정보제공용 소프트웨어" = 고시명칭 아님(검색 0건). "레시피" 단어는 지정상품에 **안 넣음**(브랜드는 상표에 담김). 표준 명칭이 더 넓게 보호.
- ❌ **"전자출판물/전자서적"은 절대 넣지 말 것**(G5206 함정). PDF 내보내기는 부가기능이라 전자서적 분류 아님.

### 🏗️ 출원 구조 (결합 vs 따로)
- A. 한끼+곰(결합) = 그 조합만 보호 (펭펭 ❌)
- B. 한끼+곰+펭펭(결합) = 셋 조합만 (각각 따로 ❌)
- **C. 따로따로(한끼 / 곰 / 펭펭 개별) = 각각 독립보호 (다 단독 OK)** — 스티커·이모티콘처럼 따로 쓸 거면 이게 정답. 대신 건수만큼 비용.
- **우선순위(예산)**: ①지금 = 로고(한끼+복슬곰) 결합 **1건(~4.6만)** ②나중 = 펭펭·곰 단독(굿즈·이모티콘 낼 때) ③나중 = 디자인권

### 🛡️ IP 3겹 (각 층의 요건·타이밍) ⭐
| 권리 | 지금 AI캐릭터로? | 요건 | 타이밍 |
|---|---|---|---|
| **상표권** | ✅ 그냥 됨 | **식별력**(구별) — 곰 많아도 상관없음 | **지금**(~4.6만) |

## 🐻 PART 2. 캐릭터 — 복슬곰 확정

### ✅ 결정: **B. 복실곱슬 곰곰이**로 확정 (매끈곰 → 복슬곰 교체)
- 두 방향 비교 후 **B 채택**:
  - A. 말랑몰랑볼(매끈) = 리락쿠마·브라운·푸랑 **계열 겹침**(차별화 약)
  - **B. 복실곱슬(곱슬털) = 실루엣부터 다름 → 차별화·각인·굿즈(인형) 유리** ⭐
- 유명 곰들 전부 "매끈털" → **곱슬 텍스처가 우리만의 시그니처.** 디자인권 신규성에도 유리.
- **시그니처 고정**: 이마 앞 곱슬 한 덩어리 + 몸 외곽 구름결 + 'ㅇ' 입 + 셰프모자·프릴앞치마·냄비로고.

### 🔄 매끈곰 → 복슬곰 전면 교체 (지금이 타이밍: 상표출원 전·정식출시 전 = 공짜)

- 기존 매끈 스티커는 **"구버전" 아카이브**(버리지 않음)
