## 1️⃣ 「오늘의 한끼」 속지

창업자가 시안 4종 중 **이 하나만 무료**로 정했다(ⓒ안). 파일 2장을 받았다 —
속지 판(1086×1448) ＋ 낱개 시트(1086×1448). **둘 다 내가 준 규격을 전부 충족**했다
(배경 254 순백 · 글자 0 · 메모칸 빈 칸).

### 좌표는 눈대중이 아니라 픽셀로 쟀다

- 사진칸 x 18.7~82.2% · y 11.5~53.9%
- 아이콘 다섯 y 58.0~64.9% · 가운데 x 18.1 / 35.0 / 51.2 / 66.4 / 81.1 (폭 6.8%)
- 만족도 점 다섯 y 69.4% · x 31.4 / 39.2 / 46.8 / 55.1 / 63.2
  ⭐ **점 다섯은 「어두운 픽셀」로는 안 갈렸다** — 마테 배경에 묻혀서.
  **초록색으로 찾으니** 정확히 다섯이 나왔다.

### ⛔ 첫 실측이 틀렸다 — 메모칸은 테두리가 **두 겹**이다

처음엔 메모칸을 `x 11.0~90.8%` 로 쟀다. 그런데 **90.8% 는 오른쪽 아래 「도장」**(x 79.7~89%)
을 테두리로 잡은 값이었다. 장식이 없는 y 74~82% 띠에서 다시 세로선을 찾으니 —

| | 왼쪽 | 오른쪽 |
|---|---:|---:|
| 바깥 둥근 **실선** | 11.4% | 86.9% |
| 안쪽 **점선** ⭐ | **12.1%** | **86.2%** |

글칸은 점선 «안»이라야 한다 → `write: { left: 13.7, right: 15.4 }`(양옆 1.5%씩 안으로).

📌 **`right: 10.7` → `12.5` → `15.4` 로 세 번 고쳤다.**
   앞의 두 번은 «틀린 실측값» 위에서 계산했으니 몇 번을 고쳐도 안 맞을 일이었다.
   ⭐ **숫자를 고치기 전에 「그 숫자를 어떻게 쟀나」를 다시 본다**(규칙 18).

### ⭐⭐ 줄을 「틀 그림 아래」로 내렸다 — 오늘 제일 큰 것

`rule: 'write'`(줄을 메모칸 «안»에만) 는 창업자 질문의 답이었다:
> *"근데 아래 줄만 보이게 어떻게 해? 배경이 줄이면 사진칸도 줄일거 아냐"*

그런데 줄을 **글상자 배경**으로 줬더니(`zIndex:1`) 줄이 **틀 그림보다 위**에 그려져
메모칸에 인쇄된 **꽃·마테·도장 위로 줄이 지나갔다.**

✅ **고침 = 층을 안 준다.** `.paper.art::after`(틀 그림)는 **pseudo 라 마지막 자식**이라
층이 없는 형제보다 **나중에** 칠해진다 → 줄이 그림 아래로 들어간다.
이제 줄은 **빈 종이에서만 보이고 인쇄된 장식 뒤로는 숨는다. 종이가 원래 그렇다.**

📌 **검사는 초록불이었다.** 지금 검사는 «칸이 있나»를 보지 «줄이 그림을 넘나»를 안 본다.
   **캡처를 2배로 키워서** 잡았다(규칙 18 ⓘ — 검사가 «무엇을 보는지»를 봐야 한다).

## 2️⃣ 낱개 24컷 — 한 컷도 안 버렸다

```
python3 tools/cut.py <시트> <폴더> dy --diecut 2 --join 20 --drop 0 --min 3000
```

기본값으로는 셋이 깨졌다:

| 옵션 | 왜 |
|---|---|
| `--join 20` | **해의 살 · 빗방울 · 번개가 본체와 떨어져 있다.** 기본 5 면 딴 컷이 되거나 버려진다 |
| `--drop 0` | 그 조각들은 «장식»이 아니라 **그림의 일부**다 |
| `--diecut 2` | ⚠️**`keep` 을 못 쓴다** — 하트·구름엔 흰 테가 그려져 있고 해·번개엔 **없다**(한 시트 안에서 섞였다) → 픽셀 값으로 통일. 긴변 204px 의 0.5% |

### 🏷 이름이 `dc_td` 인 이유 둘

1. **`dy` 는 이미 다이어리 꾸미기 팩이 쓰고 있다**(`pf_dy`·`wt_dy`·`dyf`·`dys`·`dyl`·`dyh`).
2. ⭐ **`dc_` 는 「크기 등급」이다.** `addSticker` 가 `dc_`·`ch_` 면 **s 0.15(162px)**, 아니면 0.22(238px).
   이 컷들은 긴변 **107~292px** 이라 238px 로 올리면 **위치핀이 1.74배**로 확대돼
   해상도 게이트(1.7배)에 **걸린다**. 162px 이면 전부 «줄여서» 그려지니 선이 산다.
   ⛔ `dc_dma` 로 시작하면 «밑판(isBacking)» 취급이라 `dc_td` 로 뗐다.

### 서랍에 들어간 자리

| 그룹 (탭) | 컷 |
|---|---:|
| 우표 · 해와 달 (데코) | 6 |
| 날씨 (데코) | 4 |
| 하트 · 바느질 (데코) | 4 |
| 일기 라벨 · 소품 (데코) | 7 |
| 일기 · 점·격자·도트 (마테) | 3 |

⭐ **계절도 날짜(`from`)도 안 붙였다** — 속지가 오늘 나가는데 스티커만 9월에 열면 세트가 갈린다.
서랍 등록 사진 스티커 **481 → 505.**

### 👁 검수

3단계 자동(격자 찌꺼기 최대 0.1% · 의심 컷 0) · 빨간 판에 **갇힌 흰 판 0** ·
🈵 **글자 박힌 컷 0**(시계에 숫자가 없다) · 앱 실물 `_shot-tdstickers.mjs` 전부 통과.

⛔ **검사가 한 번 거짓말했다** — 「마테 3컷이 판에 안 뜬다」고 했는데 **검사가 틀린 것**이었다.

   그림 스티커를 «같은 탭에 놓을» 뿐이다.
