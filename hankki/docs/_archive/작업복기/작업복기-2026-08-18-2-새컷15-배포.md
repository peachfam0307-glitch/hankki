## 2. ⭐⭐⭐ 오늘 얻은 규칙 — **흰 테는 「px」이 아니라 「비율」로 맞춘다**

`cut-guard` 훅이 커밋을 막았다: *"자르고 나서 «까만 판»을 아직 안 열어봤다."*
열어보니 **단독 컷 둘만 접시 둘레 흰 테가 거의 안 보였다.**

🔢 재보니 원인이 나왔다 — **앱은 컷을 전부 238px 로 줄여 그린다.**

| | diecut | 원본 긴변 | 비율 | **앱 238px에서** |
|---|---:|---:|---:|---:|
| 시트3 | 7 | 702 | 1.00% | 2.37px |
| 시트4 | 5 | 483 | 1.04% | 2.46px |
| 시트5 | 5 | 493 | 1.01% | 2.41px |
| 단독 대파 | 8 | 1246 | **0.64%** | **1.53px** ⛔ |
| 단독 갈비 | 8 | 1202 | **0.67%** | **1.58px** ⛔ |

→ `--diecut` **13** 으로 다시 잘랐다 (1.04% · 1.08% → 앱에서 2.46 · 2.55px)

⛔ **게이트(`cut-check`)는 비율만 본다 — 0.35~1.30% 안이라 8도 «통과»했다.**
   막은 것은 게이트가 아니라 **「보여주기 전에 실물을 연다」(절대원칙 21)** 였다.
⚠️ 다시 자르면 **비율도 바뀐다** → `PHOTO_RATIO`(1.3427→1.3390 · 1.2430→1.2405) ＋
   `icon-checked.json` 해시를 같이 고쳤다(검수 절대원칙 ④).

## 3. ⛔ 틀린 것 · 놓칠 뻔한 것

| | 무엇 | 어떻게 잡혔나 |
|---|---|---|
| ① | **업로드 파일을 못 찾아 「없다」고 했다** | 창업자가 *"방금 보낸 파일을 왜 찾아?"* |
| ② | **스모크 exit 를 «0»으로 잘못 읽었다** | 백그라운드 알림의 exit code 는 `echo` 까지 포함한 값. 실제는 **1**(판독 기록 게이트). 직접 `$?` 를 찍어 확인 |
| ③ | **진한 판을 안 열고 커밋하려 했다** | `cut-guard` 훅 |
| ④ | 「구체어 먼저」를 잊을 뻔 | 규칙을 위쪽에 넣어 예방(v10.89 기억) |
| ⑤ | 박힌 `icon:` 을 잊을 뻔 | v10.76 기억 — 14편 전부 갈아끼움 |

📌 ②가 제일 위험했다 — **「통과했다」고 창업자에게 말할 뻔했다.**
   판정은 «알림»이 아니라 **내가 직접 찍은 `$?`** 로 한다.
