## 4️⃣ ⭐⭐ 「내가 자른거 다 검수안해도돼? 고화질로?」 — 이 한 마디가 3건을 잡았다

**자동 3단계 검수는 3건을 전부 통과시켰다.** 3단계가 보는 건 「잔재·잘림·실제 크기」이지
**「이 컷들이 서로 같은 마감인가」가 아니다.**

| # | 잡힌 것 | 어떻게 |
|---|---|---|
| ① | **`--diecut keep` 이 짝짝이를 만들었다** — 11컷 중 `hb04`·`hb11` **둘만** 흰 테두리 | 원본 100%로 펼쳐 **4배 확대** |
| ② | **`auto` 가 두껍다** — 주석엔 0.7%인데 코드는 **1.2%** (`hb01` 967px → **12px**) | 창업자 *"지금은 좀 두껍게 느껴져"* |
| ③ | **발밑 그림자가 흰 웅덩이가 됐다** | 창업자 *"아래 그림자는 안잘라도 돼"* · *"흰색들어가서 더 지저분해 보이는 듯"* |

### ① 짝짝이 — `keep` 의 함정
**한 시트 안에서도 AI가 일부 컷에만 흰 다이컷을 그린다.** 어제 README에 *"그림에 이미 그려져 있다"*고
적었는데 **그게 틀렸다.** 📌 `keep` 을 고르기 전에 **그 시트의 모든 컷**에 흰 테가 있는지 확인할 것.

### ② 두께 — 숫자를 직접 준다
⭐ **표준 = 긴변의 0.5% 안팎.** 긴변 900px대 → `--diecut 5` · 500~700px대 → `--diecut 3`.
창업자 판정 **"딱좋아 두께"** ✅ · ⛔ `--diecut auto` 를 그대로 쓰지 말 것.

### ③ 그림자 — 도구를 고쳤다 (`tools/cut.py`)
`--diecut` 이 칼선 안쪽을 **통째로 흰색으로 덮어서** 발밑 연한 그림자가 지워지고 흰 덩어리가 됐다.
발과 그림자 사이에 흰 띠가 끼어 *"발이 흰 웅덩이에 서 있는"* 모양.

세 가지를 4배로 나란히 놓고 정했다:

| | |
|---|---|
| ⓐ 옛 방식(흰칠) | ❌ 그림자 자리에 흰 덩어리 |
| ⓑ 테두리 없음 | ❌ 그림자는 살지만 **배경 잡티·검은 조각**이 남는다 |
| **ⓒ 고친 것** | ✅ **그림자는 제 색·제 투명도로 살고, 흰색은 「원래 비어 있던 자리」에만** |

```python
soft = (~solid) & (alpha > 0.06)            # 그림자처럼 원래 그려져 있던 연한 부분
alpha = np.where(solid, 1.0, np.maximum(cut_a, alpha))
out_rgb[(~solid) & (cut_a > 0) & (~soft)] = 255.0
```
📌 **이 팩만의 문제가 아니다** — 앞으로 자르는 **모든 시트**(그림자 있는 그림 전부)에 적용된다.

## 6️⃣ 🧭 원인은 하나였다 — 그래서 시스템을 만들었다

> 창업자: *"원인찾고 다시이런일 없게 시스템만들어"*

**하루에 두 번 틀렸는데 뿌리가 같다 — 「문서를 믿고 실물을 안 봤다.」**

| | 뭘 | 왜 안 막혔나 |
|---|---|---|
| ⒜ | 배경 README **위쪽(7/31 밤)** 만 읽고 배정을 틀리게 씀 | `latest-hook` 은 **«파일 사이»** 세대만 본다 |
| ⒝ | 「재생성 대기」를 그대로 믿음 | **아무 장치도 없었다** |

🛠 **`scripts/doc-guard.mjs`**

1. **세대 가드 (훅·자동 차단)** — `.md` 를 **부분 읽기(offset)** 하는데 그 범위가 **맨 아래 세대를 안 덮으면 막는다.**
   전체 읽기는 통과. 막으면서 **현행 세대의 줄번호·제목**을 알려준다.
2. **「대기」 가드 (세션 브리핑)** — 「대기·예정」 문단의 이름을 뽑아 **그 파일이 실제로 있는지** 본다.

### ⭐⭐ 만들고 **옛 값으로 세 번** 돌렸다 — 처음 두 판은 **오늘 사고를 못 잡았다**

| 판 | 왜 헛방이었나 |
|---|---|
| ① | 「백틱 경로」만 봤다 → 실제 문장엔 **경로도 확장자도 없었다**(`**클레이 가을밤** — 나무 작게`) |
| ② | **줄 단위**로 봤다 → 「대기」 신호는 **제목에만** 있고 정작 대상 줄엔 없었다 |
| ③ | 이름을 **느슨하게**(공백·하이픈 제거) 맞추고 **제목이 연 문단 전체**를 보게 하니 잡혔다 |

⚠️ 그리고 **시끄러워서 또 조였다** (46건 → 6건) — 긴 핀 줄·기록 문서 제외.
📌 **시끄러운 게이트는 죽은 게이트.**
⚠️ 부수 사고 = `release-calendar`·`doc-guard` 를 훅이 `import` 하자 **CLI 출력이 브리핑에 통째로 찍혔다** → `isMain` 가드.

## 7️⃣ 🔒 「커밋만 하고 안 올린다」가 안 통했다

앱 코드를 배포 브랜치에 **커밋**해두고 "푸시는 참는다"고 했는데,
그 위에 **문서 커밋**을 올리면서 `git push` 가 **밑에 깔린 앱 커밋까지 통째로** 밀어 올렸다.
📌 **브랜치를 밀면 그 아래 전부가 간다.**

⭐ **장치 = `hold/검수대기` 브랜치** — 워크플로가 브랜치 이름으로 걸러서 **배포가 안 걸린다.**
승인 안 난 변경은 **배포 브랜치에 커밋조차 안 한다.**

⚠️ **실제로 나간 것의 영향** = 곰 치마 3컷을 추석 카드 풀에서 뺀 것.
추석 창이 9/1에 열리므로 **8/1 시점 유저 화면 변화는 없다.** 내용도 창업자 지시 그대로였다.
**잘못된 건 내용이 아니라 시점이다.**
