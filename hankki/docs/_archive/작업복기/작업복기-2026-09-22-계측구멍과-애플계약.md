## 3. 🕳🕳 계측 구멍 셋 — 창업자 물음이 파냈다

### ① 레꾸자랑은 «네 길 중 한 길»만 세고 있었다
📮 창업자 = *"요 며칠 통계에 레꾸자랑 보낸 사람있어?"* → 장부 15일치 `brag_shared` **0**.

⛔ 9/21 에 고친 것은 `BragScreen` 의 **이름 겹침 하나**뿐이었다. 나머지 셋은 그대로였다 —
   `SendNowSheet`·`ShareDrawCard` 의 `onShared` 둘, 그리고 **`RecipeDetailScreen` 은 stats 에서 자랑보냄을 «아예 안 가져오고» 있었다.**
   📌 `detail` 은 그날 조회 **52로 제일 많이 본 화면**이다 — 거기서 보낸 사람이 통째로 빠져 있었다.
⛔ 붙이기 «전»에 지역 ref 이름부터 갈랐다(`자랑보냄` → `보냈나`).
   **그대로 import 했으면 9/21 과 똑같은 겹침 버그를 내가 다시 만들 뻔했다.**

### ② `push_open` 이 «만들어만 놓고» 부르는 곳이 0곳이었다
워커는 「보냈다」까지만 안다 — 이게 없으면 **몇 명이 «열었나»를 영영 못 본다.**
· 웹 = 서비스워커가 주소에 `?push=1` 을 남기고 앱이 읽은 뒤 **지운다**(두 번 안 세게)
· 아이폰 = 서비스워커가 없다 → 애플 사건을 직접 듣는다

### ③ 🌲 뿌리 = 게이트가 `export const` 를 통째로 안 보고 있었다
`계측-구멍검사` 가 **`export function` 만** 봤다. 그런데 **관문 17개는 전부 `export const`** 다.
＋ `(A ? B : C)()` 꼴 호출을 못 읽어 멀쩡한 것을 「안 부른다」로 잘못 잡던 것도 같이 고쳤다.

⭐⭐ **교훈 = 검사가 못 보는 «꼴»이 생기면, 그 꼴로 쓴 것은 전부 «안 재진 채» 늘어난다.**
   이름 짓는 법을 바꿀 땐 **검사도 같이 봐야 한다.**

### 🚨 내가 낸 사고 하나 — 웹 빌드를 죽였다
아이폰 전용 `pushNative.js` 를 `App.jsx` 에서 불렀는데 **그 파일은 아이폰 갈래에만 있다**
→ `Could not resolve "./pushNative.js"` 로 **웹 빌드가 죽었다.**
✅ 웹 갈래에선 그 줄을 빼고 «왜 뺐는지»를 주석으로 남겼다. 재현판도 **파일이 있을 때만** 재게 고쳤다.
📌 **갈래마다 있는 파일이 다르다** — 아이폰 갈래에서 만든 것을 배포 갈래에 얹을 땐 이걸 먼저 본다.

## 4. 🔐 로그인 실패를 «왜»로 가른다 — 창업자 물음에서 나왔다
📮 창업자 = *"이거는 본인 계정 비번 까먹어서 못들어온거 아냐?"*

✅ 넷으로 갈랐다 = `closed`(마음 바꿈) · `blocked`(브라우저가 막음) · `net` · `other`
🙈 **여전히 모르는 것** = 구글·애플은 「비번이 틀렸다」를 우리에게 **안 알려준다.**
   그래서 `other` 는 「그 밖」이지 **「비번 탓」이 아니다.**
👉 읽는 법 = `closed` 가 대부분이면 정상 · `other` 가 많으면 그때 판다.
