## ⚖️ 객관성 원칙 (창업자 명시 2026-07-21) — ⭐ 최우선

## 🧠 창업자가 짚은 것 (대부분 정확했음 — 기록)
1. 오팬 vs 우리 겹치는지 → **유사군 대조가 답** (→ G390802 ≠ G5206 확인)
2. 겹치면 이름 바꿔야 하니 **출시 전에 확인**해야 함 (신중·리스크 회피)
3. 상표 신청하려면 **캐릭터 확정이 선행**. 곰+한끼 vs 곰+펭+한끼 구조 이해함
4. **곰은 디자인권에 흔해서 반려 가능** → 차별화 필요 (정확한 직감)
5. **복슬곰이 차별화 우위** — "복슬 곰은 아무도 없을 것 같다" (직감 정확)
6. 복슬로 바꾸면 **상표·템플릿 전부 복슬로 통일**해야 함 (일관성 지적)
7. **"물결 꼭 있어야 저작권 통과 쉬워?"** → 아님. 물결 ≠ 필수 (정확)
8. **하트주걱·앞치마 넣으면 기존 것 다 다시 뽑아야 함** — 재생성 함정 지적 (날카로움)
9. **"저작권 안 되면 새로 뽑아야?"** → "다시 뽑기"는 답 아님(새 AI도 같은 문제) → 재창작이 답
10. ⭐ **무한반복 루프·"정확한 게 없음"·반복이 제일 힘듦** (meta 지적) → 반복노가다는 클로드가
11. ⭐⭐ **"작가가 AI 똑같이 그리면 = AI 베낀 것 = 법적책임"** → **창업자 맞음, 클로드 틀렸음.** (트레이싱 = 창작기여 부족 + 허위등록 리스크)
12. **AI 저작권 판례 없음, 대신 디자인권, 그것도 내가 그려야 함** (정확)
13. **"이것도 100% 아니야, 반려 가능, 객관성 유지"** (지금 — 정확)

## 🔴 클로드가 틀렸던 것 (정정 기록)
- ❌ "사람이 그렸으면 사람 저작물" → **틀림.** 관건은 **"방식·기여"(통제가능성·예측가능성)**. 트레이싱/사소한 변경은 인정 안 됨.
- ❌ "반려돼도 재신청 가능 = 영구탈락 아님"을 **과하게 안심시킴** → 정정: 반려 실재, 재신청 성공 보장 아님.

## ✅ 검증된 법적 사실 (클로드 원문 확인)
- **한국저작권위 「생성형 AI 활용 저작물 등록 안내서」(2025.6)**: 순수 AI/트레이싱 = 인정 X. 통제가능성·예측가능성 + 창작과정 기록 필요.
- **저작권법 제136조 제2항 제2호**: 거짓(허위) 등록 = **3년 이하 징역 또는 3천만원 이하 벌금**(병과 가능).
- 심사 = 형식심사(신고주의) + 소명자료 요구. 사후 분쟁 시 창작기록으로 입증.
