# 📦 _archive — 구버전 보관함

> **삭제 대신 격리·보존** (창업자 보존원칙). 최신은 `docs/` 최상단에, 지난 버전은 여기로.
> `/청소`(또는 하루 마감 `/잘자`)가 이 규칙으로 자동 정리한다 → 그래서 **"최신순으로 쌓임"**.

## 규칙
- 같은 계열의 날짜/버전 문서는 **최신 1개만 `docs/` 위에**, 나머지는 계열별 하위폴더로 이동.
- 전부 `git mv`로 옮겨 **히스토리 유지**. 파일을 경로로 하드참조하는 문서가 있으면 그 참조도 같이 고친다.
- **한끼와 무관한 타프로젝트 잔재**(다른 앱 코드·엉뚱한 README)는 저장소 루트 `_archive/타프로젝트-*/`로.

## 폴더
- `할일-정리/` — 지난 `할일-전체정리-*` 스냅샷 (최신은 `docs/` 위에)
- `작업복기/` — 오래된 세션 복기 (최근 2~3개는 `docs/` 위에 유지) *(스윕 예정)*

## 참고 — 이미 있던 보관 관례
- `docs/stickers/_구버전-곰펭-보관-2507/` — 음영 전 옛 곰펭 소스
- 루트 `_archive/타프로젝트-오답노트-소이/` — 레포 초기 타프로젝트(오답노트) 잔재
