## 7️⃣ ⛔⛔ **오늘 내가 틀린 것 — 전부 「확인 안 하고 단정」**

## 8️⃣ ⭐⭐ **오늘 값을 한 것은 창업자가 한 실험들이다**

| 창업자가 한 것 | 그게 밝힌 것 |
|---|---|
| **문자로 링크를 눌러봄** | 한끼 앱 «안»이라는 증거(`android-app://`) ＋ 앱 링크 검증이 살아 있다 |
| **끝까지 기다림** | 구글의 «진짜 오류 문구»가 나왔다 — 「처리 중」이 아니라 「오류」였다 |
| **✈️비행기모드** | **「붙음 ✅」이 가짜라는 것** ← 내가 생각도 못 했다 |
| **삭제 페이지를 끝까지 돌림** | 기기 번호 표시 → 복사 → **메일 실제 발송**까지 |
| *"난 봐도 무슨말인지 모르겠다"* | 삭제 페이지를 **절반 길이**로 만들었다 |
| *"통상적으로 다른 앱 수준으로"* | 방향을 잡아 줬다 — 이 페이지는 «읽으라고»가 아니라 «요건을 채우려고» 있다 |
