## 2️⃣ 창업자가 «정한 것» — ⛔재론 금지

| | 무엇 | 창업자 원문 |
|---|---|---|
| ⓐ | **첫 화면을 아래로** (곰펭 크게 · 단추는 엄지 자리) | *"B로 가자"* · *"단추를 조금 내리고 레꾸해요위는 좀 올리자"* |
| ⓑ | **구글 단추를 «규정 모양»으로** (네 색 G ＋ 흰 바탕 ＋ 얇은 테두리) | 다른 앱 로그인 창 캡처 ＋ *"다른사이트로그인창"* |
| ⓒ | 「매어둘까요」 안 쓴다 | *"매어둘까요 그런거말고"* (2026-08-21 낮) |
| ⓓ | 「올라가는 것」 안 쓴다 | *"안내도 올라가는 것 이런거 말고 직관적이고 명확하게"* |
| ⓔ | 「둘러보기」 아니라 **「나중에 하기」** | *"그냥 둘러보기??"* |

### ⓐ 를 어떻게 물었나 — ⛔말로 물어서 한 번 헛돌았다
내가 *"가운데 vs 아래, 어느 쪽?"* 이라고 **글로만** 물었더니 창업자 답 = *"단추자리??"* · *"B는 안보이는데"*.
📌 **자리는 «보여야» 고른다.** 판을 찍어 나란히 놓자 그 자리에서 정해졌다.
🛠 그래서 만든 판 = `scripts/_판-단추자리-0821.mjs` (⛔소스를 안 고치고 브라우저에서 자리만 바꿔 찍는다)

## 3️⃣ 확정된 화면 글자 — «세 곳이 한 글자도 다르지 않다»

### 첫 화면 (`CloudGate.jsx`) — 소개(온보딩)보다 **먼저** 뜬다
```
[꼬르곰·펭펭 210px]
한끼
꼬르곰·펭펭과 레꾸해요
[ (G) Google 계정으로 시작하기 ]
        나중에 하기                ← 단추가 아니라 작은 글씨
로그인하면 새 폰에서도 이어서 써요 ⌄
```

### 펼친 안내 — 첫 화면 · 설정 시트가 **같은 글**을 쓴다
```
· 새 폰이나 패드에 다시 깔아도 레시피 · 일기 · 냉장고 · 장보기가 그대로 이어져요.
· 꾸민 표지도 같이 저장돼요 (스티커 · 글씨 · 배경).
· 직접 넣은 사진은 저장되지 않아요.  ← 굵게
  사진은 이 폰과 백업 파일에 그대로 남아요.
· 잠가둔 일기는 잠긴 채로 저장돼요.
```
⭐ **사진 줄만 굵게** — 창업자 지적(*"그 사진이라는게 내가 직접올린 음식사진인거자나"*).
   ⛔「사진」이라고 뭉뚱그리면 반대로 읽힌다 — **기본 레시피 그림은 «주소»라 그대로 따라온다.**
   ✅ 「없어진다」가 아니라 **「이 폰과 백업 파일에 남는다」**까지 붙였다.

### 「나중에 하기」를 누르면 (`ConfirmSheet`)
```
로그인 없이 시작할까요?
레시피와 일기가 이 폰에만 저장돼요.
폰을 바꾸거나 앱을 지우면 없어져요.

설정에서 언제든 로그인할 수 있어요.
[ 그냥 시작하기 ]  [ 취소 ]
```
⛔⛔ 창업자 말 중 *"앱에 내 레시피나 정보들은 저장이 안된다"* 는 **정확히는 틀리다** — 코드로 확인했다(`store.jsx:691`).
   로그인을 안 해도 **폰 안에는 저장된다.** 안 되는 건 «폰 밖»이다.
   ✅ 그래서 **「이 폰에만 저장돼요」**로 썼다. 📌 더 정확하면서 **더 무서운** 사실이기도 하다.

### 홈 한 줄 (`HomeScreen.jsx`) — **이미 쓰고 있는 사람**이 만나는 자리
```
☁ 로그인하면 새 폰에서도 이어서 써요
  지금은 레시피·일기가 이 폰에만 있어요            [×]
```
⭐ 창업자가 걱정한 그 사람들이다 — *"백업하는지도 모르고 폰바꿀수있어"*

### 설정 (`ProfileScreen.jsx` · `CloudSheet.jsx`)
```
백업 · 내보내기   폰을 바꾸거나 앱을 지워도 안 잃게 저장해요      ← 파란 테두리(강조)
클라우드 저장     로그인하면 새 폰에서도 이어서 써요             ← 테두리 없음
```
⛔ **테두리는 백업에만** — 둘 다 두르면 둘 다 안 튄다.

## 4️⃣ ⛔ 내가 틀렸던 것 넷 — 전부 «게이트가 초록불»인 채로 있었다

### ⑴ 창업자가 무른 말이 **두 곳 더** 살아 있었다
낮에 *"매어둘까요 그런거말고"* 를 듣고 **첫 화면만** 고쳤다.
**홈 한 줄**(「레시피를 계정에 매어둘까요?」)과 **설정 카드**(「구글 계정에 매어 두면」)는 그대로였다.
＋ 설정 시트는 「**뭐가 올라가는지** 자세히」로 남아 있었다(ⓓ 위반).

⭐⭐ **v11.02 「책갈피」가 «일곱 곳»이었던 것과 같은 뿌리** — 칩·사용법·설정 메뉴·통계·모아보기·빈칸·상세.
📌 **말은 한 곳에 안 산다.** 한 곳만 고치면 앱이 두 말을 하게 된다.

### ⑵ 설정 시트에 `import` 를 빠뜨렸다
`GoogleButton` 을 쓰면서 import 를 안 썼다. **빌드는 통과한다**(런타임 오류라서).
→ **그 시트를 «열면» 죽는다.** 화면을 열어보지 않으면 영영 안 드러나는 자리다.

### ⑶ 테스트 잣대가 헐렁했다 (절대원칙 18 ⓘ)
스모크의 일기 판이 죽었다. 범인은 문구가 아니라 **잣대**였다 —
`getByRole('button', { name: '일기' })` 가 **「일기」가 든 «아무 단추»**나 집는다(Playwright 는 기본이 부분일치).
새 홈 문구 *"지금은 레시피·**일기**가 이 폰에만 있어요"* 가 DOM 에서 더 앞이라 **그걸 눌러 설정으로 갔다.**

✅ 탭 여섯(홈·가져오기·레시피·일기·장보기·레꾸자랑)을 **`exact: true`** 로 좁혔다 — 파일·낱말 **열 짝**.
📌 **문구를 되돌리는 게 아니라 잣대를 좁히는 게 맞다.** 테스트가 «무엇을 보는지»가 틀렸던 것이다.

### ⑷ 「단추 자리」를 말로 물었다
→ 2️⃣ 의 ⓐ 참조. **보여주고 물었어야 했다.**
