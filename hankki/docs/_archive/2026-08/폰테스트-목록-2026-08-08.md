3. **눈** — 예쁜지·읽히는지·속도가 괜찮은지. 규칙 11(미감 판정은 창업자).

## 🔴 1순위 — 손가락과 키보드

### 01. 사진을 끌어서 보일 부분 고르기 (v10.02)
**어디** = 한끼 일기 → 꾸미기 → 속지 사진칸에 사진 넣고 → 손가락으로 끌기
- [ ] 끌면 사진 속 보이는 부분이 진짜 따라 움직인다
- [ ] 끌다가 손을 떼도 **파일 고르는 창이 안 뜬다**
- [ ] 그냥 한 번 톡 누르면 **사진 바꾸기**는 그대로 열린다
- [ ] 앱 나갔다 들어와도 맞춰둔 위치가 그대로다
- [ ] 세로로 긴 사진을 넣어도 위·아래가 안 잘린다

**왜 폰이라야 하나** — 「톡」과 「끌기」를 **6px** 로 가른다. 그 문턱이 맞는지는 손가락으로만 판정된다.

### 02. 서랍 칩 줄에 막대가 보이나 (v9.99)
**어디** = 꾸미기 → 글자 탭 → 글씨체 · 움직임 · 효과 세 줄
- [ ] 줄 아래에 짧은 막대가 보인다 (＝ 옆에 더 있다는 표시)
- [ ] 옆으로 밀면 막대도 같이 움직인다

**왜** — 안드로이드 크롬은 스크롤 막대 꾸미기를 **통째로 무시**한다. 그래서 우리가 직접 그렸다.
창업자 제보 *"스크롤바가 처음부터 안보여서 글자체 저게다처럼보임"* 이 이 자리다.

### 03. 유령 「글씨·크기」 줄 (v9.99)
**어디** = 종이에 글 치다가 → 폰 뒤로가기로 키보드만 닫고 → 다른 탭 누르기
- [ ] 안 쓰는 「글씨·크기」 두 줄이 안 남는다
- [ ] 그래서 고르는 칸이 한 줄로 쪼그라들지 않는다

**왜** — 폰은 뒤로가기로 키보드만 닫혀서 `blur` 가 안 온다 → 커서가 종이에 남는다.

### 04. 각도 자석 · 돌리기 문턱 (v9.98)
**어디** = 스티커 하나 붙이고 오른쪽 아래 손잡이 끌기
- [ ] **크기만** 끌 땐 각도가 안 흔들린다 (문턱 6°)
- [ ] 똑바로(0·90·180·270°) 근처로 가면 착 붙는다 (±5°)
- [ ] 반 바퀴 돌리면 정확히 180°
- [ ] 그래도 **일부러 삐딱하게**는 얼마든지 붙는다

**왜** — 창업자 확정 문장 *"맘대로 삐딱하게도 정확하게도 붙일수있다는거지"* 를 옮긴 게 이 넷이다.

### 05. 메모지·라벨은 붙이면 바로 글 (v9.99)
**어디** = 꾸미기 → 데코 탭 → 메모지·라벨 붙이기
- [ ] 붙이자마자 글이 쳐진다 (탭 옮길 일 없이)
- [ ] 아래에 글자색 고르는 줄이 뜬다

### 06. 설정 접기 (v9.98)
**어디** = 꾸미기에서 갈래 하나 누르고 → 그 갈래를 한 번 더 누르기
- [ ] 접혀서 서랍이 넓어진다

**왜** — 창업자가 직접 요청했던 건데 대수술 때 통째로 사라졌던 것. 되살렸다.

## 🟡 2순위 — 눈으로 판정

### 07. 레시피 상세 꾸미기 — 방금 나간 것 (v10.03)
**어디** = 아무 레시피나 열기
- [ ] 「재료」·「만드는 법」 옆 꼬르곰이 오물오물 움직인다
- [ ] 두 제목에 노란 형광펜이 그어져 있다
- [ ] 그림과 글자가 붙어 보이지 않는다 (한 칸 뗐다)
- [ ] 맨 아래 「다 됐어요 / ○○ 완성!」 칸에서 꼬르곰이 툭 떨어져 착지한다
- [ ] 음식 조각이 떠오르는데 **글자를 안 가린다**
- [ ] 움직이는 속도가 폰에서도 괜찮다
- [ ] **그레이지** — 형광펜이 잘 보인다
- [ ] **크림** — 형광펜이 잘 보인다
- [ ] **다크** — 형광펜이 안 죽고 살아 있다

**⚠️ 테마 셋 다 봐야 한다** — 형광펜은 「곱하기」라 **다크에선 통째로 검게 죽는다.**
다크만 「screen」으로 뒤집어 놨는데, 그게 진짜 먹는지는 폰 화면이 답한다.

**⚠️ 속도도** — 검수판이 2배 빨랐던 그 건. 판이 틀렸고 앱은 원래 멀쩡했지만 **그건 내 계산**이다.

### 08. 속지 세 장 (v10.01)
**어디** = 한끼 일기 → 꾸미기 → 속지
- [ ] **사진 기록** — 글이 줄 «위»에 앉는다
- [ ] **기록 3칸** — 사진칸 셋이 각각 **다른** 사진을 비춘다
- [ ] **스크랩 사진첩** — 기울어진 폴라로이드에 사진·제목이 같이 기울어 앉는다

### 09. 레꾸 상황·평가 스티커 99컷 (v10.00)
**어디** = 꾸미기 → 글자 탭 (맛 평가·반응 평가·조리법·요리 상황·식사 상황·미리 준비·보관·건강 태그)
- [ ] 여덟 묶음이 다 보인다
- [ ] 캡션 글자가 **폰 화면 크기에서 읽힌다**
- [ ] 붙여봤을 때 크기가 적당하다

**왜** — 3배로 키워 150컷 글자를 다 읽었지만 그건 「오타가 없다」까지다.
**폰 화면에서 읽히는지**는 다른 문제다.
