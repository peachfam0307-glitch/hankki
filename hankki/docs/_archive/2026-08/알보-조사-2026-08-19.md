# 🔍 알보(Albo) 조사 — 「인스타 레시피를 자동으로 정리해 주는 앱」

> ⭐현행 · 이 주제는 여기부터 읽는다.
> 📮 창업자 = *"알보albo라는 레시피앱이래 조사좀해봐"* → *"어떤ai로 어떻게 레시피 저장정리하는지 자세히파봐"*
> → *"우리는 인스타내용뽑아 정리못해줘?"* → ✅ **판정 = 영상은 패스**(아래 3️⃣절)

| 패키지 | `com.thesortdapp.sortd` |
| 낸 곳 | iOS ＋ **안드로이드(2026년 2월)** |

| 기사 | **TechCrunch 2026-08-02** 「앱스토어 히든젬」 |

**하는 일** = 틱톡·인스타 릴스·유튜브·웹 링크를 **공유 시트로 던지면** AI 가 내용을 뽑아
갈래별(레시피·여행·맛집·영화/드라마·책·운동)로 정리한다. 여행은 위치를 지도에 핀으로 꽂고,
컬렉션을 친구와 나눌 수 있다.

⛔ **약점(스토어 리뷰)** = *"뽑아낸 레시피를 다른 앱으로 내보낼 수 없다 — 결국 또 하나의 저장소를 관리하게 될 뿐"*

⚠️ **어떤 AI 를 쓰는지는 «못 찾았다».** 이 환경은 웹 페이지를 못 연다(WebSearch 요약만 된다) —
`albo.inc` · `instagram.com` 전부 `EGRESS_BLOCKED`. 개인정보처리방침을 봐야 공급자가 나온다.
📌 **「없다」가 아니라 «내가 아직 못 찾았다»** 이다(규칙 17).

## 2️⃣ 창업자 릴스 녹화본에서 «실물로» 본 것

📮 창업자가 소개 릴스(17.35초 · 1080×2340)를 화면 녹화해서 줬다. 프레임을 뽑아 눈으로 읽었다.

브라질 사람이 만든 릴스(포르투갈어 UI — `Compartilhando link` · `Faça um comentário`)인데
한국어 자막이 붙어 있었다. 흐름 = **릴스 → 공유(↗) → Albo → 정리된 레시피.**

**Albo 가 내놓은 결과** (일본식 돼지 항정살 스테이크 · 돈테키)

| 칸 | 값 |
|---|---|
| 제목 | **일본식 돼지 항정살 스테이크 (돈테키)** — 원문을 번역했다 |
| 자동 분류 | `20 mins` · `Japanese` · `Dinner` |
| 인분 | **2인분** ＋ `1×` 조절(− +) ＋ 「변환」 |
| 재료 | **10줄** · 체크박스 · 줄마다 그림 |
| 순서 | 그림 붙여 차례대로 |
| 원본 | 앱 «안»에서 영상 재생 ＋ 「Instagram ↗」 |

⭐ **구멍이 보인다 — 번역이 반쪽이다**
· 양배추 **1/4 head** · 감자 전분 **2 tbsp** · 소금 **to taste**
→ **제목만 한국어고 단위는 영어 그대로다.** 한국 사람은 「1/4 head」·「to taste」라고 안 쓴다.
· 탭 이름도 **「래시피」** 로 오타가 나 있었다.

## 3️⃣ ✅ 판정 — 「영상에서 뽑기」는 «접는다». 재론 금지

📮 **창업자 원문 = *"영상은 의미가 없는게. 내가 다운받은건 말로 설명하는거거든."* · *"영상은 패스해도 될듯"***

⭐⭐⭐ **이 한 마디가 조사를 끝냈다 — 릴스는 «말로» 설명한다.**
화면에 재료·계량이 «글자»로 안 뜨면, 프레임을 아무리 잘 뽑아도 **읽을 글자가 없다.**
우리 OCR 은 «글자»를 읽는 도구지 «말»을 듣는 도구가 아니다.
→ 말을 글로 바꾸려면 **음성 인식**이 필요하고, 그건 **서버 일**이다. 우리는 서버가 0이다.

📌 **그래서 「프레임을 뽑을 수 있나」는 «맞는 질문이 아니었다».**
   나는 그걸 재느라 반나절을 썼고 **실제로 된다는 것까지 확인했는데**, 되든 말든 소용이 없었다.
   ⭐ 창업자가 **「그 영상에 뭐가 들어 있나」**를 한 마디로 짚어서 끝났다 — 규칙 25(먼저 물어본다)를 지켰으면 안 썼을 반나절이다.

### 그래도 남기는 값 — 잰 값은 사실이다

`scripts/_재본다-영상프레임-0819.mjs` (WebM 으로 바꿔서 · 540×1170 · 17.35초)
· 영상 여는 데 **46ms** · 프레임 **35/35장** · 한 장 평균 **108ms** · pageerror **0**
→ **서버 없이 폰 안에서 영상을 잘라내는 건 «된다».** 나중에 다른 일로 쓸 날이 오면 이 값이 있다.

⛔ **자동 고르기는 못 한다** — 「글자스러움(가장자리 밀도)」이 1.5배밖에 안 벌어지고
   정작 «레시피 목록 화면»이 제일 낮게(9.19%) 나왔다. 흰 바탕에 얇은 검은 글자라 가장자리가 적다.
   📌 그 가늠자는 «글자»가 아니라 **«복잡한 화면»**을 골랐다.

## 4️⃣ 그래서 우리 「인스타 담기」는 지금 이대로 간다

**되는 것** (코드로 확인 · 2026-08-19)
| 길 | 어디 |
|---|---|
| 캡처 → 재료·순서 자동 분리 | `src/ocr.js` ＋ `parseRecipeText` |
| 인스타 「공유(↗) → 한끼」 | `vite.config.js` `share_target` — ⚠️인스타는 **링크만** 준다(캡션은 안 온다) |
| 블로그 링크 자동 읽기(베타) | `src/linkReader.js` |
| 보면서 쓰기 | 인스타 미리보기를 위에 두고 아래에서 받아적기 |

⛔ **「인스타·유튜브 링크만 던지면 자동」은 v8.79 에 «뺐다»** — 창업자 판정 *"제목만 가져오는 건 의미 없어"*.
   로그인·동의 벽이라 제목만 오고, 심지어 「Before you continue to YouTube…」 같은
   영어 동의문이 재료칸에 박혔다.

⭐ **알보와 우리는 애초에 다른 것을 판다** — 알보는 「모아두기」이고 우리는 「해먹고 기록하기」다.
   알보 리뷰의 불만(*"또 하나의 저장소를 관리하게 될 뿐"*)이 정확히 그 자리를 가리킨다.
