# 🧭 꾸미기 기능 대조표 — 우리 것 vs 남의 앱 (2026-08-06)

> 창업자: *"참고자료는 쓸만한거 정리해서 문서화하자. **그냥 묻어놓으면 안쓰잖아 아깝고..**"*

📌 **이 문서의 쓸모 = 「꾸미기 뭘 더 넣지」 할 때 여기서 꺼내 쓴다.**
창업자가 준 남의 앱 기능표 3장(무료 12 · 감성 PRO 12 · 스마트 PRO 12)을
**우리 코드와 하나씩 대조**한 것. 원본은 `docs/stickers/한끼일기-추가-2026-08-06/참고-기능카탈로그/`.

⛔⛔ **기능 «아이디어»는 저작권이 없지만 화면 «디자인»은 있다.**
이 표는 「무엇을 만들까」에 쓰고, **아이콘·레이아웃·배색을 베끼지 않는다.**

⚠️ 표의 판정은 `grep` 이 아니라 **한 줄씩 눈으로 확인**했다 —
처음 grep 은 `align`(=`alignItems`) · `group`(=`groupsByTab`) · `gif`(=`gift`) 를
전부 「있음」으로 잡았다. **낱말이 걸린 것과 기능이 있는 것은 다르다.**

## 1️⃣ 「무료 기본 편집툴」 12 — 남들이 «공짜로» 주는 것

| 기능 | 우리 | 메모 |
|---|---|---|
| 선택·이동 | ✅ | `DecorLayer` 드래그 |
| 크기·회전 | ✅ | ⟳ 손잡이 (소스 크기 × 1.7 상한) |
| 자르기 | ✅ | `cropSquare` · `cropRatio`(2026-08-06 신설) |
| 좌우반전 | ✅ | **2026-08-06 넣었다.** ⛔글자 그려진 42컷(tw_·tn_)·직접 쓴 글자·포스트잇엔 안 뜬다 |
| 투명도 | ⛔ | 스티커에 없다 |
| 레이어 | 🔶 | ⬇맨 뒤로 / ⬆맨 앞으로 **둘뿐**. 목록·눈 아이콘 없음 |
| 정렬·간격 | ⛔ | 없다 |
| 색상 선택 | ✅ | 색 바꾸기 13색 (`STICKER_COLORS`) |
| 기본 펜 | ⛔ | **손으로 긋는 게 없다** |
| 지우개 | ✅ | 아이템 삭제 |
| 기본 글자 | ✅ | 글씨체 6종 · 색 · 굵기 |
| 실행 취소 | ✅ | **2026-08-06 넣었다.** 서랍 맨 위 「되돌리기」 · 최대 30칸 · 되돌릴 게 없으면 안 뜬다 |

### ⭐ 여기서 읽을 것
**남들이 무료로 주는 12개 중 우리에게 없던 게 6개였고, 그중 아픈 둘을 그날 다 채웠다.**

- ✅✅ **실행 취소 — 2026-08-06 완료.** 그전엔 스티커를 잘못 옮기거나 지우면 **되돌릴 방법이 없었다.**
  꾸미기는 «실수하면서 노는 것»이라 되돌리기가 없으면 과감하게 못 논다.
  다른 앱이 이걸 **무료 기본**에 둔 이유가 있다.
  ⭐ **X 버튼과 다르다** — X = 그 스티커를 «없앤다»(되살릴 길 0) · 되돌리기 = 방금 한 짓을 «무른다».
  **X 로 지운 것도 되살아난다.** 검사 = `scripts/_repro-undo.mjs`
- ✅ **좌우반전 — 2026-08-06 완료.** 코너 장식은 «네 귀퉁이»에 다 쓰는데, 우리 코너 6컷은
  왼쪽 위 모양 하나뿐이라 **오른쪽 아래에 못 놓는다.** 반전 하나면 6컷이 24컷이 된다.
  📌 **자산을 4배로 늘리는 가장 싼 방법이다.**

🔶 **투명도·기본 펜·정렬은 급하지 않다** — 투명도는 뮤트 톤이라 덜 필요하고,
펜은 손가락으로 긋는 거라 폰에서 잘 안 예쁘다. 정렬은 다꾸 감성과 오히려 어긋난다.

## 2️⃣ 「감성 꾸미기 PRO」 12 — 남들이 «돈 받는» 것

| 기능 | 우리 | 메모 |
|---|---|---|
| 스티커 테두리 | ✅ | `--diecut` 로 **자를 때 이미 둘러서** 준다. 유저가 켜는 건 아님 |
| 입체 그림자 | ✅ | 스티커에 `drop-shadow` 가 들어가 있다 |
| 종이 질감 | ✅ | 종이 다섯 색 ＋ 배경 23개 |
| 찢어진 가장자리 | 🔶 | 그림으로는 있다(찢은 종이 메모지). **효과로는 없다** |
| 마테 자동 생성 | ⛔ | 없다. 우리는 미리 만든 마테를 고른다 |
| **형광펜** | ⛔⛔ | **없다.** 속지 「고른 표시」엔 쓰는데 **유저 손엔 안 줬다** |
| 손글씨 보정 | ⛔ | 없다(우리는 글꼴이라 애초에 반듯하다) |
| 곡선 글자 | ⛔ | 없다 |
| 글자 스티커화 | 🔶 | 글자에 테두리·굵기는 있다. 「스티커처럼 오려내기」는 없다 |
| 색감 맞추기 | ⛔ | 없다 |
| 빛·반짝임 | ✅ | 효과 14종(반짝이·하트·뽀글…) |
| 블렌딩 | ⛔ | 없다 |

### ⭐⭐ 여기서 읽을 것 — **형광펜이 제일 크다**

다꾸에서 형광펜은 «스티커»가 아니라 **«행동»** 이다. 쓴 글 위에 쭉 긋는 것.
- 우리는 **그 색을 이미 만들어 놨다**(속지 고른 표시에 쓰는 형광펜)
- 일기 = **글 쓰는 화면**이라 형광펜이 제일 어울리는 자리
- ⛔ 그런데 **유저는 못 쓴다.** 만들어 놓고 안 준 셈이다

📌 그리고 이 표가 알려주는 더 큰 것 — **남들은 「효과」를 유료로 판다.**
우리는 효과 14종·모션 15종을 이미 갖고 있고 **팩마다 하나씩** 붙이기로 정해뒀다
(`docs/모션-효과-설계.md`). **방향이 같다** = 우리 판단이 시장과 어긋나지 않았다.

## 3️⃣ 「스마트 편집 PRO」 12 — 사진 다루는 것

| 기능 | 우리 | 메모 |
|---|---|---|
| 자동 콜라주 | ⛔ | 없다 |
| 스마트 여백 | ⛔ | 없다 |
| 배경 지우기 | ⛔ | 없다(우리는 «자를 때» 우리가 지운다) |
| 오브젝트 지우기 | ⛔ | 없다 |
| 사진 확장 | ⛔ | 없다 |
| 스타일 일괄 적용 | ⛔ | 없다 |
| 그룹·잠금 | ⛔ | 없다 |
| **클리핑 마스크** | 🔶 | **프레임에 사진 끼우기**(2026-08-06)가 이것의 «작은 판»이다 |
| 버전 기록 | 🔶 | 자동저장(초안 복구) ＋ 되돌리기 30칸. **저장한 판으로 돌아갈 목록은 없다** |
| 움직이는 효과 | ✅ | 모션 15 · 움직이는 배경 |
| GIF·영상 저장 | ⛔ | 없다 |
| 고화질 내보내기 | ✅ | 공유 카드 1080×1350 |

### ⭐ 여기서 읽을 것
**이 12개는 대부분 「AI 사진 편집」이고 서버가 필요하다.** 우리는 서버가 0이라
**따라갈 수도 없고 따라갈 이유도 없다** — 배경 지우기·오브젝트 지우기는 우리 컨셉(감정·기록)과 멀다.

⭐ 단 **클리핑 마스크**는 우리가 오늘 «프레임에 사진 끼우기»로 한 발 들어갔다.
**하트·구름 모양으로 사진을 오리는 것**까지 가면 다꾸에서 크게 쓰인다.

## 🎨 4️⃣ 「다꾸 도구 견본」 — 우리 도구와 대조

| 견본이 보여주는 것 | 우리 |
|---|---|
| **색 팔레트 12장**(4색 묶음) | 색 13개를 **낱개로만** 고른다. 「어울리는 4색 묶음」이 없다 |
| **필기 6종**(펜·연필·크레용·마커·붓펜·파스텔) | 글씨체 6종. **개수는 같은데 결이 다르다** — 우리 건 «글꼴», 저건 «필기 질감» |
| **형광펜 6색** | ⛔ 위 참고 |
| **구분선 8종**(가로 전체) | 방금 들어온 속지 패키지의 구분선 4가 처음이다 |

⭐ **색 팔레트가 값싸고 효과가 크다.** 유저가 스티커 다섯 개 색을 따로 고르면 촌스러워지기 쉬운데,
**4색 묶음을 주면 아무나 골라도 통일된다.** 우리 리컬러가 이미 13색이니 **묶기만 하면 되는 일**이다.
