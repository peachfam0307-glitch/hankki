## 2. ⭐ 오늘 제일 크게 배운 것

### ⓐ 「칙칙하다」의 정체 = **색이 아니라 «배경과의 차이»**

같은 모양의 사고가 **하루에 두 번** 났다. 둘 다 **색을 한 글자도 안 바꿨는데** 칙칙해졌다.

```
배경(--bg) 0.946
  흰 카드            1.000   +0.054  떠 보인다
  주간 카드(옛 cream) 0.749   −0.083  가라앉는다   ← 1차
  추천 카드(옛 grad)  0.909   −0.037  가라앉는다   ← 2차
```

**뿌리 = 톤D 로 배경을 밝히면 «가만히 있던 카드»가 상대적으로 가라앉는다.**
📌 **배경을 손대면 그 위의 것을 «전부» 다시 재야 한다.** 1차를 고칠 때 2차를 같이 봤어야 했다.

🛠 새 도구 `scripts/_probe-홈밝기-0822.mjs` — 화면에 «칠해진» 값을 읽어 밝기 차이를 잰다.
⛔ CSS 변수로 짐작하지 않는다. **그라데이션은 `backgroundColor` 가 «투명»으로 나온다** → `backgroundImage` 도 같이 본다.

### ⓑ 「정신없다」의 정체 = **여백이 아니라 «개수»**

```
검색바 47 · 임시보관함 43 · 소식 62 · 안해봤어요 48 · 오늘뭐해먹지 98 · 이번주 807
→ 키 110px 이하가 «다섯 연달아» · 틈 10~14px
```

⭐ **키가 비슷한 상자가 셋 이상 연달으면 눈이 «하나씩 세지 않고» 한 덩어리로 본다.**
그래서 여백만 늘려선 안 풀린다 — **개수부터 줄여야 한다.** 다섯 → 셋으로 줄이니 풀렸다.
(여백 20px 은 그렇게 «번 자리»를 리듬으로 돌려준 것이다)

🛠 새 도구 `scripts/_probe-홈상자-0822.mjs` — 키·틈·바탕을 잰다. 묶음(`.home-pair`) 안까지 한 겹 들어간다.

### ⓒ **「＋ 가져오기」는 중복인 걸 «알면서» 뒀다**

`BottomNav.jsx:17` 에 내가 이렇게 적어놨었다 —
*"B 안이면 홈으로 갔다 와야 한다(**홈 맨 위에 「＋ 가져오기」가 있긴 하다**)"*
그때 판단은 「하단바가 있으면 어느 탭에서든 눌린다」였고 그게 채택됐다.
📌 **그러면 홈 위의 것은 «남은 것»이지 «필요한 것»이 아니다.** 창업자가 그걸 물어서 드러났다.

## 5. 🔢 파서 — 「내 레시피」 걸음이 끊기고 번호가 남던 것

📮 창업자 폰 캡처(순살찜닭) = STEP 1 「…10분 데친 뒤」 · STEP 4 「**3** 10분 뒤 …」

⭐⭐ **증상 둘이 «한 뿌리»였다** — `STEP` 정규식이 번호 뒤에 «점·괄호»를 요구했다(`1.` `1)`).
사람들은 점 없이 **「1 」「2 」「3 」** 으로도 쓴다 → 파서 눈엔 번호가 아니라 그냥 글자.
⑴ 번호가 본문에 남고 ⑵ 새 걸음의 시작으로 안 읽혀 **앞 걸음이 다음 걸음을 삼킨다**(4걸음 → 3걸음).

✅ 고침 둘 —
- `markBareNumberSteps` = 숫자가 **1, 2, 3… 으로 «이어질 때만»** 점을 찍는다
  (⛔「숫자로 시작하면 무조건」은 「3 큰술」·「2 인분 기준」을 자른다)
- **「번호가 붙어 있었다」를 기억**해 `mergeStepFragments` 로 넘긴다 —
  사람이 번호를 매겼으면 «여기서부터 새 걸음»이다. ⭐이건 점 찍힌 「2.」에도 있던 구멍이었다.

⛔⛔ **아직 안 풀린 것 = 이미 «저장된» 레시피.** 파서는 앞으로 담는 것만 고친다(규칙 18 ⓙ).
📮 창업자 = *"네가 고쳐도 나한테 반영이 안되니까.."* — 맞는 말이고 **원문이 어디에도 안 남는다**(코드로 확인).
✅ 창업자 판정 = **ⓑ 다시 담기 ＋ ⓒ 앞으로는 원문도 같이 저장** (ⓒ 는 아직 «안» 만들었다)
