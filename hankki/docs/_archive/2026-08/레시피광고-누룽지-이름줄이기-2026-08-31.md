## 1️⃣ 🐛 누룽지 — 메모의 «설명 문장»에서 광고가 걸렸다

| | |
|---|---|
| **재료 14줄** | 누룽지 **없다** |
| **메모 셋째 줄** | *"약불에 눌러 가며 볶는 게 핵심이에요. 바닥에 **누룽지**가 생기면서 고소해져요."* |
| **뿌리** | 호출부가 `picksForIngredients([...ingredients, memo])` 로 **한 자루에 섞어** 넘겼다 |
| **결과** | `matches: ['누룽지']` 가 **메모에서** 걸려 「자연다음 현미누룽지」 광고가 붙었다 |

⭐⭐ **메모는 «설명하는 글»이지 «장 보는 목록»이 아니다.**
　 요리 이야기에 나온 낱말로 광고를 붙이면 「밥을 눌리면 누룽지가 된다」가 「누룽지를 사세요」가 된다.
　 **유저가 헛것을 산다** — 광고는 돈 받는 자리라 더 나쁘다.

### ⛔ 「그냥 메모를 빼면 되지」가 안 되는 이유
메모 맨 아랫줄에 창업자가 **「제가 쓰는 양념 — 「성가정 우리콩 진간장」…」** 을 적어 뒀고(**67편**),
그게 **풀네임 매칭**으로 광고를 붙이고 있다. 메모를 통째로 빼면 그 지정이 전부 날아간다.

### ✅ 고침 — 갈랐다
```js
// src/data/curation.js
export const picksForIngredients = (ingredients = [], notes = '') => {
  const text = [...(ingredients || []), notes || ''].join('  ')   // 풀네임은 메모까지
  ...
  const tokens = (ingredients || []).flatMap(...)                  // ⛔ 낱말은 재료 줄만
```
📌 **같은 눈이 게이트엔 이미 있었다** — `scripts/check-picks.mjs` ⑤ *"재료 줄만 본다 —
　 메모의 설명 문장까지 막으면 시끄럽다"*. **규칙만 여기에 없었다.**

## 2️⃣ 🚫 고춧가루 — 「레시피 광고에서만」 뺀다

📮 창업자 = *"**레시피 광고에서만 뺀다고**"*

· 제품에 표식 **`noRecipePick: true`** → `picksForIngredients` 가 건너뛴다
· ✅ **장보기 탭 큐레이션 목록엔 그대로 있다**(올리브유 때와 같은 뜻 — 목록에서 지우는 게 아니다)

⛔ **`matches` 만 떼는 걸로는 못 뺀다** — 풀네임 「복이네먹거리 고춧가루」가
　 **재료 줄 6편 · 메모 12편**에 박혀 있어 `direct` 로 계속 붙는다.
　 (올리브유 때는 `matches` 만 떼도 됐다 — 풀네임을 아무 데도 안 적었으니까)

⛔ **「고춧가루를 빼기로 한」 옛 결정은 내가 못 찾았다**(없다가 아니라 못 찾았다).
　 찾은 건 반대쪽뿐이다 — `docs/기능-아카이브.md:310`·`docs/주부의장바구니-큐레이션.md:50` 둘 다 «등록»이다.
　 👉 그래서 **2026-08-31 창업자 지시**를 근거로 삼는다.

## 3️⃣ 🔠 이름 줄이기 — 셋 다 (창업자가 셋 다 골랐다)

### ⓐ 픽 카드 제품 이름 — 브랜드를 «작은 윗줄»로
실물에서 **다섯 줄이 전부 두 줄로 접혔다**(「성가정 우리콩 / 진간장」처럼 브랜드 가운데서 끊긴다).
```
전   성가정 우리콩 진간장  (19px 한 덩어리 → 두 줄)
후   성가정              (14.5px 연한색)
     우리콩 진간장        (19px 굵게 → 한 줄)
```
⛔ **브랜드를 지우지 않는다** — 어느 회사 것인지가 이 큐레이션의 값어치다.
＋ **「자연드림 / 우리밀 올리고당 [자연드림]」** 처럼 **같은 말이 두 번** 나오던 것도 잡았다
　 → `mallBadge()` 가 **브랜드＝몰 이름이면 배지를 안 그린다**.

### ⓑ 재료 줄 — 괄호 안 갈래 이름 중복 제거 (22가지)
```
전   복이네먹거리 고춧가루 1/2큰술 (고춧가루 어떤 것이든)   31자
후   복이네먹거리 고춧가루 1/2큰술 (어떤 것이든)           26자
```
🛡 **괄호가 «새 정보»인 5가지는 그대로 뒀다** — 줄이려다 정보를 지우면 안 된다
　 `(소면 어떤 것이든)` · `(포도·오렌지·자몽 어떤 것이든)` · `(맛술·미림 어떤 것이든)` · `(시판 냉면육수…)` · `(시판 콩국물…)`

### ⓒ 메모 「제가 쓰는 양념 —」 줄 — **122자 → 81자** (중간값 73 → 53)
```
전   제가 쓰는 양념 — 고춧가루 「복이네먹거리 고춧가루」 · 간장 「성가정 우리콩 진간장」 · 액젓 「와촌식품 초피액젓」
     · 맛술 「요리맛샘 맛술」 · 설탕 「아우노슈가」 (아래 ‘주부의 장바구니 픽’에서 담을 수 있어요)
후   제가 쓰는 양념 — 「성가정 우리콩 진간장」 · 「와촌식품 초피액젓」 · 「요리맛샘 맛술」 · 설탕 「아우노슈가」
     (아래에서 담을 수 있어요)
```
· 갈래 이름은 **제품 이름에 이미 들어 있을 때만** 뺐다
　 🛡 `설탕 「아우노슈가」` · `감칠맛 「연두 우리콩 요리에센스」` · `육수 「올바른가 요리의정수 해물맛」` 은 **남겼다**(빼면 뭔지 모른다)
· 꼬리표 `(아래 ‘주부의 장바구니 픽’에서 담을 수 있어요)` 28자 → `(아래에서 담을 수 있어요)` 15자 · **68곳**
· **고춧가루 18곳 제거** — 광고에서 뺐으니 「아래에서 담을 수 있어요」가 **거짓말**이 된다
　 「로제 파스타」는 그 줄이 고춧가루 하나뿐이라 **줄째** 지웠다(68편 → 67편)

　 `direct` 매칭으로 붙는다. 다만 **메모에 적힌 이름으로 검색하면 유저가 못 찾는다.**
