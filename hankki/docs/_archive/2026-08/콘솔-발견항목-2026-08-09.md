## 2️⃣ 🔎 우리가 «확인한» 것 (⛔짐작과 갈라 적는다)

| 확인한 것 | 결과 | 어떻게 |
|---|---|---|
| 우리 소스에 그 API 가 있나 | **0건** | `grep -rn "setStatusBarColor\|setNavigationBarColor\|enableEdgeToEdge" src/ android/` |
| 그럼 어디 있나 | **`com.google.androidbrowserhelper`** = 구글이 만든 TWA 껍데기 라이브러리 | 콘솔이 「시작 위치」로 직접 대줬다 |
| 우리가 쓰는 판 | **`androidbrowserhelper:2.6.2`** | `@bubblewrap/core` 1.25.0 의 `dist/lib/features/FeatureManager.js:28` |
| bubblewrap 이 아는 alpha | `2.7.0-alpha02` | 같은 파일 29줄 |
| 웹 쪽은 준비됐나 | ✅ **됐다** | `index.html` 에 `viewport-fit=cover` · `styles.css` 91~92줄 `env(safe-area-inset-top/bottom)` 을 화면 곳곳에서 쓴다 |

⭐⭐ **즉 이건 「우리가 짠 코드」가 아니라 「구글 껍데기 라이브러리」다.**
우리는 안드로이드 코드를 한 줄도 안 쓴다 — bubblewrap 이 만들어 준다.

⚠️ **확인 «못» 한 것** (⛔여기를 짐작으로 메우지 말 것)
- `androidbrowserhelper` **2.7.0 이 이 경고를 정말 없애는지** — 릴리즈 노트 요약에 *"edge-to-edge support for the splash screen"* 이 보였을 뿐이고,
  이 환경은 **maven 을 못 연다**(`dl.google.com` = CONNECT 403 · `mvnrepository.com` = egress 차단).
- **실제로 유저 화면이 가려지는지** — 우리 환경엔 안드로이드 기기가 없다. **창업자 폰이 유일한 실물.**
