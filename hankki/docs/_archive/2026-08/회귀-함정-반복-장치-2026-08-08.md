## 1. 💾 회귀 — `wip-snap.sh` (자동 스냅샷)

**PostToolUse(Edit·Write) 훅.** 5분에 한 번, 안 커밋된 워킹트리 전부를 원격 브랜치 `wip/auto` 에 담는다.

- ⭐ **브랜치·인덱스를 안 건드린다** — 임시 인덱스(`/tmp`)로 트리만 떠서 `commit-tree` 로 커밋 객체를 만든다.
  지금 하던 작업·스테이징이 하나도 안 꼬인다.
- ⭐ **배포를 안 돌린다** — 워크플로가 `branches: [claude/chatgpt-…]` 하나만 보므로 `wip/auto` 는 무반응.
  **푸시해 보고 run 번호가 그대로인 것까지 확인했다**(규칙 9 안전).
- ⭐ **규칙 13 을 안 어긴다** — 승인 안 난 코드가 «배포 브랜치»에 안 들어간다(`hold/*` 와 같은 방식).
- ⭐ **조용하다** — 출력 0. 시끄러운 게이트는 죽은 게이트다.

### 만들면서 두 번 틀렸다 (둘 다 「돌려 봐서」 잡았다)

1. **통째로 백그라운드로 던졌더니 아무것도 안 남았다** — 훅이 끝나며 자식이 죽었다.
   게다가 `.git/wip-index.lock` 이 남아 **그 뒤 모든 스냅샷을 막았다.**
   → ⑴ref 만들기는 **동기**(0.1초) ⑵임시 인덱스를 **저장소 밖(`/tmp`)** 으로 (잠금이 저장소를 오염 안 시킴)
2. **`refs/wip/*` 로 못 민다 — 403.** 이 환경 git 자격이 «브랜치가 아닌 ref» 를 막는다.
   (같은 이유로 `git push --delete` 로 hold 브랜치 정리도 안 된다.)
   → **브랜치 `wip/auto`** 로.

### 되살리는 법

```bash
git fetch origin wip/auto
git show --stat FETCH_HEAD          # ⛔ 먼저 «본다». 스냅샷이 더 낡을 수도 있다
git checkout FETCH_HEAD -- <파일>   # 통째로는 -- .
```
`repo-guard` 가 회귀를 감지하면 **「스냅샷에 지금 없는 파일 N개가 있다」** 를 자동으로 알려준다(오늘 붙였다).

## 2. 🪤 함정 — `check-mistakes.mjs` ⑧ 「옛 함정 사전」

**배포 게이트(`npm run smoke`)에 들어 있다.** 재현판(`_repro-*`·`_shot-*`·`_measure-*`)을 훑어
**전에 밟은 함정 패턴**이 다시 나타나면 배포를 막는다.

### 첫 항목 = `reload` ＋ `addInitScript`

- ⛔ `page.reload()` 로 「저장이 남나」를 재면, `addInitScript` 가 **되돌아올 때마다 처음 상태를 다시 심어**
  **저장값을 «검사 자신»이 지운다.** → 앱이 멀쩡한데 「안 남는다」로 나오고, 그 거짓 실패를 좇게 된다.
- 📌 **2026-08-06 에 `_shot-diary.mjs` 안에 경고를 적어뒀는데 2026-08-08 에 또 밟았다.**
  경고가 **그 파일 안에만** 있었기 때문이다 — 새 파일을 쓸 땐 옛 파일을 안 본다.
  ⭐⭐ **그래서 파일 «바깥»에서 본다.** 이게 이 사전의 존재 이유다.
- ✅ 대신 = ⑴**뒤로 갔다 다시 들어오기**(유저가 실제로 하는 행동) ⑵**새 탭**(앱 껐다 켜기)
- 🔓 일부러 쓰는 경우는 «왜 괜찮은지»를 옆에 적으면 통과한다(근거가 있으면 함정이 아니다).

### 함정을 새로 넣는 법

같은 함정을 **두 번** 밟았으면 사전에 한 줄 넣는다 — `TRAPS` 배열에 `{ name, hit, waive, why }`.
⛔ **한 번 밟은 것은 안 넣는다** — 사전이 커지면 시끄러워지고, 시끄러우면 아무도 안 본다.

## 4. 📌 이 셋을 관통하는 한 줄

> **「알려주는 것」과 「지켜주는 것」은 다르다.**

- `repo-guard` 는 회귀를 **알려줬다** — 그런데도 30분이 날아갔다. 알림은 이미 잃은 뒤에 온다.
- 경고 주석은 함정을 **알려줬다** — 그런데도 또 밟았다. 그 파일을 안 열면 안 보인다.
- ⭐ 그래서 오늘 만든 둘은 **행동을 대신 해준다**(스냅샷을 «찍어» 두고, 함정이면 «막는다»).
