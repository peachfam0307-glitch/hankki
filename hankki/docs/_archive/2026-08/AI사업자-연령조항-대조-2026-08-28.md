# 🔀 「다른 앱은 정책을 어기는 건가?」 — 사업자별로 답이 다르다 (2026-08-28)

> 📮 창업자 = *"다른앱들이 하는 건 구글정책을 안지키고 한다는거네..."*
> ⛔ **그렇게 말할 수 없다.** 왜 그런지 근거를 남긴다.

---

## 1️⃣ ⭐⭐ 제일 중요한 것 — 「18세 조항」은 **법도 Play 정책도 아니다**

| 무엇 | 18세 제한이 있나 |
|---|---|
| **대한민국 법** | ❌ 없다 |
| **Google Play 정책** (AI 생성 콘텐츠 · answer/13985936) | ❌ 없다 (2026-08-27 전문 확인) |
| **Play 콘텐츠 등급** | ❌ 없다 — 우리도 해먹으리도 **3세 이상**으로 통과했다 |
| **Google 의 «생성 AI 약관»** | ✅ **있다** (Gemini 추가약관 · GCP SST 20.d) |

📌 **이건 「우리가 못 하는 일」이 아니라 「구글이 자기 AI 를 그렇게 팔지 않는 것」이다.**
   가게가 「미성년자 출입금지」를 붙인 것에 가깝다. **다른 가게는 다른 규칙을 붙인다.**

---

## 2️⃣ 🔄 실제로 사업자마다 «정반대»다

### 🔴 Google — 전면 금지

> **SST 20.d** *"Customer will not ... use a Generative AI Service as part of a ... Customer Application ...
> that is directed towards or is likely to be accessed by individuals under the age of 18."*

**예외 조항이 없다.** ＋ 20.f = 「위반 «의심»」만으로 즉시 해지.

### 🟢 OpenAI — 조건부 **명시 허용**

공식 문서에 아예 **「Under 18 API Guidance」**라는 페이지가 따로 있다
(developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance).

- *"Developers should implement **additional safeguards** when using the API to **serve minors** (under 18)"*
- 요구 = 아동보호·안전·개인정보 법(COPPA 포함) 준수 · 최신 플래그십 모델 사용 ·
  **13세 미만 개인정보는 zero data retention 을 켠 뒤에만** · 미성년에게 안전·연령적합 콘텐츠
- 감사·경고·정지 조항은 있다(우리와 무관한 수준)

⭐⭐ **금지가 아니라 «지침»이다.** 구글은 문을 닫았고 OpenAI 는 **조건을 걸고 열어 뒀다.**

### 🟢 Cloudflare Workers AI — 연령 조항 자체가 **없다**
(2026-08-27 확인 · 카드 0 · 하루 10,000 Neurons 무료 · 고객 콘텐츠로 학습 안 함)

⛔ **남의 영상을 내려받아 다른 AI 에 먹이는 길**은 YouTube 약관 위반이라 **처음부터 죽어 있다**(2026-08-27 확정).

## 4️⃣ 🤔 그럼 해먹으리는? — **모른다. 셋 다 가능하다**

1. **구글이 아닌 사업자를 쓸 수 있다** — 그러면 연령 조항이 아예 안 걸린다
2. **20.d 를 다르게 읽었을 수 있다** — *"directed towards"*(누구를 겨냥했나)는
   COPPA 식 판단이라 **주부용 레시피 앱은 「아동 대상」이 아니라고 볼 여지가 있다.**
   ⚠️ 다만 *"likely to be accessed by"*(닿을 가능성) 쪽은 우리에게 불리하다. **문언으로는 답이 안 난다**
3. **정말 안 지키는 것일 수도 있다**

📸 **그들이 «자기 입으로» 밝힌 것**(hemogry.com/terms-en) = *"플랫폼 약관·API 정책을 준수한다"* ·
   *"서버에 영상을 다운로드·저장하지 않는다"*

⛔⛔ **「경쟁사가 불법이다」라고 말하지 않는 이유 둘**
   ⑴ **틀릴 수 있다** — 위 1·2 가 살아 있다
   ⑵ ⭐**그 논리가 우리를 망친다** — 「쟤들도 하잖아」는 판단 기준이 못 된다.
      우리는 **출시한 앱**이고 20.f 는 「의심」만으로 앱을 끊는다.

## 5️⃣ ✅ 그래서 실제로 할 수 있는 것 (오늘 기준)

| 하는 일 | 사업자 | 상태 |
|---|---|---|
| **글 → 레시피 정리** | Cloudflare / OpenAI | ✅ **열려 있다** (연령 조항 0 또는 조건부 허용) |
| **사진 → 글자** | Google Vision (생성 AI 아님) | ✅ **이미 쓰고 있다** — 20.d 대상 아님 |
| **영상 → 레시피** | Gemini 뿐 | ⛔ **닫힘** |

⭐⭐ **그리고 「사진 → 재료·순서 자동」은 «지금 코드에 이미 있다»**
   `hankki/src/App.jsx:353~365` — 공유로 들어온 **사진**이면 OCR 로 읽어
   `ingredients`·`steps` 를 **자동으로 채운다.**
   → **인스타 보다가 → 스크린샷 → 공유 → 한끼** 면 창업자가 원한 그 화면이 «지금» 나온다.
   ⛔ 창업자가 실험한 건 **「링크」 공유**였고, 링크에는 글이 안 실려서 주소만 담겼다. **코드가 아니라 «무엇을 공유하느냐»의 차이다.**
