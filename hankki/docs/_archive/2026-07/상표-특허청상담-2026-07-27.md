# 상표·IP — 특허청 특허고객상담센터(☎1544-8080) 상담 기록 · 2026-07-27

> 창업자 직접 통화 (2026-07-27, KST). **권위 있는 출처(특허청) 확인 = 사실.** 우리 IP 전략 업데이트의 근거. (이전 "공익변리사 6006-4300 개인 OK"는 오정보였고 → 일반 개인은 특허청 1544-8080이 맞음.)

## ✅ 상표 (한끼 + 복슬곰 결합상표)
- **결합상표 등록 가능** — 우리와 **유사군코드가 같은 업체가 없어서.** (09류라도 유사군코드 다르면 등록 가능)
- **지정상품 = 10개까지 무료**(기본 관납료 내), 우리는 **3개 → 전부 등록 가능.**
- **선출원주의 = 먼저 출원한 사람이 이김** (먼저 "쓴" 사람 아님). 양면:
  - ① 우리가 지금 출원 → 나중 출원자는 **거절**(우리 승).
  - ② 미뤄서 **남이 먼저 출원 → 그 사람이 이기고 우리는 못 받음** (창업자가 특허청서 들은 리스크 = 맞음).
  - **→ 유일한 안전장치 = 지금 당장 출원.** 선행조사 완료라 지금은 우리가 1등 → 미루지만 않으면 됨.
- ⚠️ **(별개) 등록 전(출원 중)엔 카피 '사용자'를 못 막음** — 권리행사는 등록돼야 가능. 우선심사 = 빨리 등록 = 빨리 단속. (위 '출원 순서 경쟁'과 다른 얘기)

## 💰 우선심사 vs 일반등록 (창업자 결정 사항)
- 특허청은 **우선심사 권함** = 등록까지 빨라 완전한 보호를 빨리 받음. 단 **추가비용**(개인 선택 사항).
- **일반등록** = 무료지만 ~1년 대기. 대기 중엔 권리행사가 약해, 그 사이 남이 (사용상) 선점하면 보호가 약한 게 단점.
- **클로드 의견**: 출시 전이라 카피 위협이 급하지 않음 → **일반으로 지금 출원해 우선권부터 확보**(돈 아낌)로 충분. 카피 우려 크면 우선심사. → **우선심사 정확 비용·요건은 확인 후 결정**(지어내기 X).

## ⛔ 유료 레시피북 = 불가 (오펜하우스 선점)
- **유료 전자 레시피북/전자출판물은 오펜하우스가 선점 → 우리 못 팜.** (= 기존 G5206 함정 실제 확인)
- **무료로 주는 건 가능.** → 레시피북 PDF는 **무료 기능**으로만.
- ⭐ **우리 수익원은 레시피북이 아니라 OCR 크레딧(990팩)이라 수익모델엔 영향 없음.**

## ⏰ 디자인권 = 12개월 시계 이미 시작
- 곰펭이 앱에 **공개**됨 → **신규성 12개월 카운트 시작.** **12개월 안에 출원해야** 디자인권 받을 수 있고, 넘기면 (자기 공개가 선행자료 돼) 못 받음.
- → 기존 "디자인권 나중" 방침에 **시한 생김.** 12개월 내 출원할지 결정 필요(비용 발생).

## 🎨 저작권 = 판례 없어 곰펭 보호 가능
- AI 생성 캐릭터 저작권 **판례가 아직 없어서 꼬르곰·펭펭도 보호 가능성 있음.**
