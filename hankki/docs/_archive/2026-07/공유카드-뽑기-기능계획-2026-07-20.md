> 어제 만든 **카드 6스타일**(A컬러팝·B볼드타이포·C폴라로이드·D매거진·E허니·F민트)을 **아무 레시피에나 자동 적용**되는 공유 기능으로. 창업자 "뽑기 너무 재밌을거같아" → 방향 확정.

## 1. 큰 그림 — 공유 누르면 두 갈래 (유저가 하나 고름)

### 갈래 ① 예쁜 카드 자동 = "뽑기" (귀찮은 사람용, 0초)
| 자동(랜덤) | 유저가 만짐 | 안 건드림(데이터로 자동) |
|---|---|---|
| 처음 뜰 때 **스타일 + 캐릭터** 랜덤 | 🔄 **다시 뽑기**(새 랜덤) · 📷 **내 음식사진** 넣기(캐릭터 자리에) | 레시피 **제목** · **태그·카테고리** |
- **랜덤이지만 🔄로 계속 바꿈 = 사실상 "맘에 들 때까지 뽑기".** 곰까지 같이 도니까 안 질림.
- 조합 = 스타일 6 × 범용 곰 9(+펭 4) = 수십 가지.
- ⭐ **희귀도(rarity) — 가챠 감성** (창업자 "곰뜨다가 얘네 랜덤뜨면 재밌겠다"): **곰=자주 / 펭=가끔 / 콤비="곰펭 같이!" 레어**. 곰 계속 뜨다 가끔 펭·콤비 뜨면 "오 이거 떴다!" = 계속 🔄 누르게 만드는 재미. (구현: 가중치 랜덤 — 곰 70%·펭 20%·콤비 10% 정도, 튜닝)

### 갈래 ② 내가 꾸민 표지 (직접 꾸미는 사람용)
- **템플릿 0개.** 앱에서 유저가 꾸민 그대로(배경색·스티커·글자·포스트잇) **캡처**해서 공유. 100% 유저 창작물, 랜덤 없음.
- 기존 프로토타입 `src/shareCover.js` 참고(창업자 "아니야 이거" → 재설계 필요). CLAUDE.md 핀: "공유 = 앱 레시피 꾸미기 그대로 캡처".

### "다시 하고 싶으면?" (창업자 질문)
- **응, 뽑기라 🔄 누를 때마다 새 조합.** 맘에 들 때까지. 이게 오히려 재미 포인트(가챠 감성).

## 3-1. 🐧➕ 펭펭 추가 발주 (창업자 GPT 생성 — 2026-07-20 결정)
> 현재 범용 펭 4마리는 대부분 **뒷모습·시크 라이프스타일**이라 "자랑/기뻐" 앞모습이 부족. → **더 생성 필요**(창업자: "펭펭 더 뽑아야겠네"). 캐릭터 전신 생성 = GPT 몫(규칙: 효과는 클로드, 전신은 GPT).

**필요한 펭 포즈** (2×2 **대형 4컷**, 컷당 600px+ / 베레모+트렌치+앞치마 / **음식 안 들기** / **얼굴 보이게** 앞·살짝옆):
1. **시크하게 뿌듯** — 무심한 듯 만족 미소 (= 곰 "만세"의 펭 버전)
2. **무심한 따봉** — 엄지척, 시크 표정 (자랑) ※보너스시트 00에 작은 따봉 펭 있음 → 대형 재생성
3. **시크 볼하트/손하트** — 새침하게 하트 (= 곰 "하트안기"의 펭 버전)
4. **브이·윙크 셀카** — 일상 귀여움
- 있으면 좋음: 박수, 앞치마 당당 요리사 포즈, 두손모아.
- ⭐ **핵심 톤**: 펭은 곰처럼 활짝 X → **"무심한 듯 시크하게" 자랑.** 곰(활짝)×펭(시크) 대비가 매력.

## 9. 🔄 교체주기(신선도) + 🎴 띠부씰 스타일 (2026-07-20 방향, 창업자 제안)

### 9-A. 교체주기 = 상시 코어 + 시즌 드롭
> 창업자: "이거도 교체주기가 있어야겠네. 템플릿이랑 애들.." — 1년 내내 같으면 질림 → **신선도 = 재방문·바이럴 훅.**
- **상시 코어(evergreen)**: 6스타일 + 곰9/펭/콤비. 안 사라짐(기본 경험 보장).
- **시즌 드롭(한정, 날짜 자동 in/out)**: 봄=벚꽃폴꾸·소풍콤비 / 여름=시원톤·빙수 / 겨울=산타꼬르곰🎅·눈·새해 / 명절=한복 곰펭. → 같은 레시피도 계절마다 다른 옷.
- **비용 0**(부트스트랩 핵심): 자산=앱 정적 번들(서버X). 앱이 "몇 월?" 보고 시즌 세트 자동 포함. 템플릿=CSS(공짜)·캐릭터=GPT 1회(영구)·API/서버=0.
- **훅**: "12월엔 크리스마스 꼬르곰!" = 시즌마다 다시 공유할 명분 + 한정=FOMO.
- **타이밍**: 출시엔 상시 코어만(스코프 유지). 시즌은 **출시 후 하나씩**. 단 구조는 "시즌 슬롯" 들어가게 설계해둠(나중 자산만 꽂기).

### 9-B. 띠부씰(수집형 씰) 스타일 — 뽑기=수집과 완벽 결합
> 창업자: "애들을 띠부씰 스타일로 뽑아도 귀엽겠어." 포켓몬빵 띠부씰 열풍 = 수집·가챠 감성. **우리 뽑기(가챠)랑 정체성 일치.**
- 요소: **두꺼운 흰 다이컷 테두리**(이미 함) + **글로시 하이라이트**(비닐 광택) + **에폭시 돔**(볼록 3D) + **넘버링**(No.03/50 수집표) + 옵션 **홀로그램/오로라 반짝**.
- ⭐ **희귀도 → 마감 매핑**(가챠 등급감): **곰=글로시(공통) / 펭=펄(언커먼) / 콤비=홀로그램✨(레어)**. 레어 뜰 때 무지개 반짝 = "오 이거 떴다!" 극대화.
- **구현**: 효과 전부 **CSS(클로드)** — 광택·홀로그램 그라디언트·에폭시 그림자·넘버뱃지. 베이스 캐릭터 = GPT(현행 유지). **추가 원가 0.**

- 현재 대세: **띠부씰·에폭시 도무씰** / **홀로그램·오로라·유리홀로** / **인쇄소 그레인·리소 질감** / **레이어링·마테(워시테이프) 모서리 물기** / **여백 미니멀(포인트 하나)** / 씰 대지(한 판 모음) 감성.
