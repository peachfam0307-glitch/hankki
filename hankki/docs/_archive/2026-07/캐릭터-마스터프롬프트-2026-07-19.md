# 🐻🐧 캐릭터 마스터 프롬프트 (2026-07-19 확정)

> 꼬르곰·펭펭 고화질 재생성용 **마스터 프롬프트**. 창업자 완성본 + 클로드 보강.
> ✅ 이름 확정: **꼬르곰**(곰) · **펭펭**(펭). (기존 튜브펭·곰곰이(대파곰)와 별개)

## 🎯 마스터 이미지 (GPT에 첨부할 기준 한 장)
- **꼬르곰** = 나무숟가락 든 **정면 기본 포즈** (셰프모자·앞치마, 소품 없이 깔끔).
- **펭펭** = **하트 안기** (미드 슬레이트 머리 잘 나온 것).
- ⚠️ 마스터는 **고화질 원본**을 첨부. (떠다니는 하트·반짝이 있으면 "주변 장식은 빼고" 한 줄 추가)

## 🔑 워크플로 규칙 (오늘 배운 것 — 꼭 지킬 것)
- **① "똑같이 재현" ❌ → "마스터 주고 새 표정 그려줘" ✅.** GPT는 복잡한 포즈 정확 복제를 못 함(비율 뭉갬). 표정·감정만 던지면 잘 그림.
- **② 한 장에 4컷(2×2) = 컷당 ~500px = 안 깨짐.** 25컷/장은 컷당 ~250px라 **깨져서 못 씀.** (대표 히어로컷만 2컷/장으로 더 크게)
- **③ 3~4장 뽑으면 GPT가 흐트러짐 → 새 채팅 + 마스터 재첨부로 리셋.** 흐트러진 채팅 붙들지 말 것.
- **④ 캐릭터마다 채팅 분리** (곰 채팅 / 펭 채팅 / 콤비 채팅). 섞이면 오염됨.
- **⑤ 잘 나온 장이 생기면 그걸 새 마스터로** 교체 (점점 안정됨).
- **⑥ 클로드에게 넘길 땐 인라인 말고 "첨부(파일)"로** — 그래야 낱개 컷·배경제거 처리가 됨. (흰 배경이어도 OK)

## 🐻 꼬르곰 마스터 프롬프트 (복붙용)
```
첨부한 원본 꼬르곰 캐릭터를 100% 동일한 얼굴·비율·색감·그림체로 유지한다.

[캐릭터]
- 통통한 2등신 아기곰
- 밀크카라멜 브라운 털
- 크림색 주둥이
- 검은 콩눈, 분홍 볼
- 흰 셰프모자
- 크림색 스트라이프 앞치마
- 주로 나무숟가락 (설거지·빨래·청소 등 안 맞는 상황엔 생략)
- 얼굴·비율·실루엣 절대 변경 금지

[성격]
먹보, 순수함, 착함, 감동을 잘함, 잘 웃고 잘 울며 행복을 참지 못한다.
음식을 보면 눈이 반짝이고 사람을 행복하게 해주고 싶어하는 순수한 셰프.

[표정·동작]
카카오톡 인기 이모티콘처럼 감정과 몸짓을 20~30% 과장한다.
눈은 더 초롱초롱, 입은 더 크게, 볼은 통통하게 표현한다.
몸 전체(머리·모자·귀·숟가락·앞치마·몸통)가 함께 움직인다.
모션라인, 반짝이, 하트 등을 적극 활용한다.
귀여움이 가장 중요하며, 보는 순간 미소가 나는 리액션을 만든다.

[그림체]
얇고 부드러운 연속선. 살짝 삐뚤한 손그림 느낌.
플랫컬러. 음영 없음. 그라데이션 없음. 부드러운 파스텔톤.
정사각형. 흰 배경. 여백 넓게. 글자·말풍선 없음.
★한 장에 4컷(2×2)으로 배치, 각 컷을 크고 선명하게(컷당 500px 이상), 컷 사이 여백 넉넉히.★
원본보다 더 귀엽고 말랑말랑한 느낌.

[이번 4컷]  ← 매번 아래 리스트에서 4개만 골라 지정

[금지]
얼굴 변경 / 비율 변경 / 실사풍 / 일본 애니풍 / 디즈니풍 /
과한 명암 / 긴 팔다리 / 딱딱한 포즈 / 원본과 다른 캐릭터 해석

[최종 지시]
원본 꼬르곰과 100% 동일한 얼굴·비율·색감·그림체를 유지하면서 카카오톡 인기 이모티콘
스타일로 귀여움을 한 단계 더 높이고, 순수하고 착한 먹보 셰프의 행복과 감정을 몸 전체로
표현한다. 표정과 행동은 20~30% 과장하되 따뜻하고 사랑스러운 분위기를 유지한다.
```

### 꼬르곰 상황·표정 리스트 (4개씩 골라 `[이번 4컷]`에)
- **일상·감정**: 신남·눈하트·눈물·화이팅·졸림꾸벅·삐짐뿌루퉁·꼬르륵(배고픔)·윙크·엄지척·박수·냠냠먹방·굿나잇·손인사·뿌듯·당황·놀람
- **요리·생활**: 반죽 휘젓기·팬 돌리기·냄비 젓기·계란 깨기·플레이팅·빵 굽기·쿠키 굽기·케이크 데코·오므라이스·장보기·냉장고 정리·설거지·청소·빨래 개기·식탁 닦기·재료 손질·앞치마 털기·밀가루 뒤집어쓰기

```
첨부한 원본 펭펭 캐릭터를 100% 동일한 얼굴·비율·색감·그림체로 유지한다.

[캐릭터]
- 통통한 2등신 아기펭귄

[성격·표정]
시크하고 무심하지만 속은 다정. 반쯤 감긴 눈.

★한 장에 4컷(2×2), 각 컷 크고 선명하게(컷당 500px 이상), 여백 넉넉히.★
```
