## 1. 🔴 마스코트 이름 "곰곰이" — 위험 (개명 권고)
- **"곰곰" = 쿠팡의 대형 식품 PB 브랜드**(2018~, "곰곰 소중한 우리쌀" 시작, 현재 쌀·유제품·신선육·가공식품 전 식품군). 어원("곰곰이 생각하다")·발음 우리랑 **완전 동일**.
- 우리 = **음식/레시피 도메인** → 카테고리 정면 중첩. "음식+곰" 이중 겹침. 출처혼동·상표거절·분쟁 리스크 모두 높음.
- (내가 처음 "홈플러스"로 잘못 짚음 → 조사결과 **쿠팡**. 홈플러스 PB는 심플러스, 곰 마스코트는 e파란.)
- 카페곰곰(울산 개인 카페) MED. "곰곰이" 캐릭터 IP 자체 선점자는 없음(LOW) — 문제는 식품 클래스.
- KIPRIS 봇 차단으로 자동조회 불가 → **변리사/지역센터 정밀검색 필수**. 쿠팡이 29/30/35류 곰곰 상표 다수 보유 추정 → 식품/유통 클래스 등록 희박.
- **판정: 개명 권고.** 좋은 소식 = **지금이 제일 싸게 바꿀 때**(테스트 중·아직 안 유명·앱 이름은 한끼 그대로·곰 그림도 그대로, **이름만** 교체).
- 대안 이름 예(요리 톤·식품PB 회피): 오물오물 / 보글이 / 끄니곰·꼬미 — 전부 KIPRIS 확인 후 확정.

## 2. 🟢 앱 이름 "한끼" — 안전 (유지)
- "한 끼"는 흔한 일반어 → 아무도 독점 못 함, 분쟁 없음. 식품 브랜드 많지만 **클래스 다름**(앱=9/42류 vs 식품=29/30/43류). 앱 개명 강요 가능성 낮음.
- 단 ① **hankki.kr 도메인은 이미 "한끼밥상"(도시락) 사용** ② CJ "한끼 밥상" 존재 → 웹핸들·도메인 차별화 필요(예: 한끼레시피, 별도 .com).
- 글자만으론 상표 등록 어려움(식별력 없음) → **로고+캐릭터 결합상표**로 9류+42류 출원이 정답. 그게 "우리 look"을 보호.

## 3. 🟡 곰 캐릭터 디자인 — 관리 가능 (낮음~중간)
- "요리하는 곰" **개념(아이디어)은 아무도 독점 못 함** = 안전. 리스크는 **실행이 라인 브라운(민무늬 갈색곰)에 겹치는 것**.
- 침해 판단 = 의거성 + 실질적 유사성, 일반인 눈, "분해식 접근"(실제곰·일반적 요소 빼고 남는 시그니처만 비교). 2023 곰 판결: 전체 인상 달라도 **특정 시그니처 디테일 동일**하면 침해.
- 비교 IP 위험도: **라인 브라운 HIGH**(우리 핵심 실루엣과 동일) · 리락쿠마 MED(크림/브라운·단순) · 카카오 라이언 MED(카톡 스토어라 더 민감) · 푸/구루미/베어유 LOW.
- **카카오 이모티콘 심사는 "연상(evoke)"만 해도 반려** = 법보다 엄격. 남의 동작·포즈·소품 베끼면 반려. 표절 사례(무시맨·즐거우나루) 있음. 승인율 ~1/20, 차별성 부족이 흔한 반려사유.
- **가드레일**: 셰프모자 영구 고정 + 시그니처 소품(나무주걱/냄비) + 고유 비율·귀모양 + 고유 색(시나몬/밀크티브라운, hex 문서화) + 고유 마킹(밀가루 볼/앞치마). **금지**: 모자 없는 민무늬 갈색곰 포즈, 리락쿠마식 베이지+진한주둥이, 라이언식 튤립배, 디즈니푸 빨간셔츠, 남의 동작·소품.

## 4. 사업 법무 체크리스트
**개인도 상표 셀프 출원 가능.** 관납료 **류당 약 25만원**(출원 4.6만 + 등록 20만). 변리사 대리 류당 30~100만. 심사 **14~18개월**(우선심사 2~3개월).
- **류**: 제9류(앱·다운로드 이모티콘/디지털굿즈) 우선 → 41류(콘텐츠)·42류(SaaS) → 굿즈 16/25/28류.
- **문자상표(이름) + 도형상표(곰 그림) 각각 출원**이 이상적. 예산 빠듯하면 핵심 하나씩.
- **저작권**: 창작 즉시 자동 발생(등록 의무 아님). 등록(CROS, 건당 ~2.4만원)하면 법정손배 가능·입증 유리 → LATER 권장.
- **사업자등록**: "지속·반복 판매" 시작 시 필요. 지금 비공개테스트=매출0이라 아직 X. **정식 출시 직전** 처리. 통신판매업 신고 동반.
- **쿠팡 파트너스**: 개인 가입 가능(3.3%/8.8% 원천징수). 수익 커지면 사업자 전환(무료).
- 🔴 **NOW 필수(무료)**: ① 앱에 **개인정보처리방침** 게시 ② **환불/청약철회 정책** 게시(디지털콘텐츠는 "제공 개시 시 철회제한"을 명확 고지+체험본 제공 조건). 환급 3영업일.
- **쿠팡 링크 표기**: "쿠팡 파트너스 활동으로 수수료를 받습니다" 경제적이해관계 공개 필수.
- 🟢 **무료 지원 강력권장**: 지역지식재산센터(RIPC, 전국, **☎1661-1900**) 무료 IP상담 + **출원비 지원**. 셀프 출원 전 류선택·유사검토 무료로. (공익변리사센터 PCC ☎1544-8080은 별개 창구)
