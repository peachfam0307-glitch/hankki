## 0. 한 줄 결론
**프로는 "상세 캐릭터 일러스트"와 "로고"를 아예 따로 만든다.** 상세 물결곰(리락쿠마st)은 **스티커·굿즈·앱 일러스트용(그대로 유지)**, 로고·상표·앱아이콘은 **단순화한 플랫 버전 + 커스텀 "한끼" 글자**를 따로. 상세 일러를 그냥 로고로 쓴 게 촌스러움의 정체. **주아체는 미감 문제 이전에 법적으로 로고·상표에 못 쓴다.**

## 1. 왜 촌스러웠나 (정직한 진단 — 6가지 아마추어 신호)
1. **굿즈 일러스트를 그대로 로고로 씀.** 단순화 단계를 건너뜀. 상세 곰(계란포켓·앞치마 주름·하트주걱·음영)은 크게 볼 땐 예쁘지만, **아이콘·파비콘 크기로 줄이면 뭉개져** 못 알아봄. 큰 데서만 되는 로고 = 미완성.
2. **주아체 = 무료 대중폰트.** 배민이 뿌려서 마트 전단지·불닭 포장·PPT에 깔림. "우리 브랜드"가 아니라 "급하게 만든 한국 것"으로 읽힘. 게다가 획 굵기가 **일부러 들쭉날쭉**(옛 간판 감성)이라 프리미엄이랑 정반대.
3. **"그림 위에 큰 캡션" 구도.** 상세 그림 + 그 밑에 큰 이름 = 클립아트/상장/학교 과제 레이아웃. 둘 사이 **설계된 관계(비율·여백·정렬)가 없음.**
4. **시끄러운 요소 둘이 동시에 싸움.** 화려한 음영 일러 + 개성 강한 통통 폰트 = 둘 다 소리침. 프리미엄은 하나는 조용히 둔다.
5. **음영·그라데이션·많은 색.** 리락쿠마풍 렌더는 색 5~6개 + 소프트 3D. 인형엔 예쁘지만 로고에선 "옛날·싸구려"로 읽힘. 단순화 1순위 제거 대상.
6. **시스템이 없음.** 풀컬러 렌더 한 장뿐이면 1색 도장·자수·다크모드·16px 아이콘을 못 함 = 그 자체가 아마추어 신호.

→ **창업자 직감이 정확했다.** 스노비즘이 아니라 6개 원칙을 동시에 위반한 것.

## 2. 정석 = 2단(2-tier) 자산 시스템  ★핵심
| | 뭐 | 어디에 | 스타일 |
|---|---|---|---|
| **Tier 1 · 상세 물결곰** | 지금 그 리락쿠마풍 꼬르곰 | 스티커·굿즈·앱 온보딩·마케팅·패키지 | 상세·음영 OK (디테일이 자산인 자리) |
| **Tier 2 · 로고 곰 마크** | **단순화·플랫·기하학** 버전 | 상표·앱아이콘·파비콘·워드마크 옆 | 균일 선·2~3색 플랫·음영0 |

- **이게 촌스러움을 고치는 전부.** 곰을 "덜 귀엽게"가 아니라, **로고용 두 번째 곰을 따로 그리는 것.**
- 라이언·브라운·쿠마몬·미피·듀오링고 전부 이 방식(굿즈=입체/상세, 로고=완전 플랫).

## 3. 프리미엄 브랜드 실증 — "아무도 상세일러+큰폰트 안 함"
- **라인프렌즈/카카오프렌즈:** 대표로고 = **워드마크(글자).** 캐릭터는 분리된 별도 자산. **앱 아이콘도 캐릭터 아님**(라인=말풍선, 카톡=말풍선). 캐릭터는 스티커샵·별도 앱에.
- **산리오(헬로키티)·산엑스(리락쿠마):** 캐릭터가 곧 상품인 회사인데도 로고 = **얼굴을 두꺼운 라인으로 납작하게 줄인 심볼 + 이름 로고타입(커스텀).** 상세 렌더는 굿즈에만.
  - ⭐ 헬로키티 상표 = **이름·얼굴·리본을 각각 따로** 등록(3개). → 분리 등록이 프로의 표준.
- **미피:** 캐릭터 자체가 **이미 로고급으로 단순**(굵은 검은 윤곽·점 눈·×입·플랫 원색). "상세판=로고판"이 동일.
- **배달의민족(우리랑 제일 비슷한 케이스):** 로고는 늘 **한글 워드마크**, 캐릭터(배달이)는 **광고에만.** 2025 리뉴얼 때 **더 프리미엄해지려고 오히려 더 추상화** — 앱아이콘에서 캐릭터 빼고 "배" 글자를 굵은 막대 5개로. 커스텀 폰트(한나체→워크체).
- **당근:** 워드마크 + 심플 **당근 심볼.** 마스코트(당근이)는 **채팅·커뮤니티에만.** 앱아이콘=당근 심볼(캐릭터 아님).
- **곰표(우리 곰 선례):** 1952 밀가루 브랜드가 뉴트로로 부활 — 레트로 레터링 + 곰 마스코트(표곰이). **곰+한글이 "설계된 느낌"으로 되려면 확실한 태도가 필요**하다는 증거.

**공통 패턴:** ① 로고 = 워드마크 or 심볼(렌더 일러 아님) ② 캐릭터·글자는 **분리·모듈** ③ 마크에 캐릭터 넣을 땐 **글자 무게에 맞춰 납작하게** ④ 폰트는 **커스텀**(대중 무료폰트 = 아마추어 신호) ⑤ 앱아이콘 = 심볼/글자, 캐릭터는 스티커로 ⑥ 상표는 **이름·캐릭터·시그니처 요소 따로** 등록.

**한끼의 동료그룹 = 배민/당근/오늘의집(서비스앱 + 사이드킥 마스코트).** 산리오(캐릭터가 상품)가 아님. → **꼬르곰은 사랑받는 조연, 로고는 깔끔한 글자/심볼.**

## 4. 곰 단순화(Tier 2) 만드는 법 — 실전
1. **덜어내기:** 텍스처·음영·그라데이션·그림자 전부 제거.
2. **요부 2~3개만 남김.** 꼬르곰 = **셰프모자(요리 신호) + 캐러멜 몸색 + 콩눈 + 살구볼 + 둥근 귀.** 버림: 앞치마 주름·계란포켓·하트주걱·음영. (요부는 Tier1 상세곰에 그대로 살아있음)
3. **기하로 재구성:** 머리=원, 모자=깔끔한 호, 눈=일정 베이스라인의 점. **선 굵기 하나로 통일.**
4. **실루엣 테스트:** 윤곽만 남겨도 "꼬르곰"이면 통과.
5. **색 2~4개 플랫.** 캐러멜/크림/살구/눈코용 진한색.
6. **과단순화 금지:** 꼬르곰인 건 알아볼 만큼은 남김.
7. **머리(+모자) 위주**가 아이콘엔 정석(라이언·브라운·Mr.P). 16px·흑백에서도 또렷해야 함.
8. ⚖️ **Tier1 상세곰과 같은 얼굴구조·요부 유지** = 법적 "같은 상표(동일성)" + 브랜드 일관성. (등록 도안 ↔ 물결곰 = 쌍둥이)

## 5. "한끼" 워드마크 — 주아체 금지, 커스텀이 정답
- ⚠️ **주아체(및 배민·나눔 무료폰트) = 로고·상표에 사용 금지.** 무료라도 라이선스가 "브랜드명·로고·상표 사용 불가"인 경우가 대부분. **+ 남의 폰트로 만든 글자는 상표 등록 자체가 안 됨**(내 글자를 직접 그려야 등록 가능). → 주아체 "한끼"는 예쁘고 말고 이전에 **법적 탈락.**
- ✅ **Pretendard(프리텐다드) = SIL OFL → 로고·상표 사용 완전 합법**(폰트 자체 판매만 금지). 무료·오픈소스(길형진 제작). → **커스텀 레터링 뼈대로 최적.** (단, 등록 강하게 하려면 그대로 쓰지 말고 획을 커스텀)
- **스타일 방향 = "따뜻한 휴먼 고딕"** (붓X, 통통버블X): 균일한 획 굵기, 부드럽되 부풀지 않은 마무리, 넉넉·균일한 속공간, 살짝 단단한 비례.
- **시그니처 훅 = "한"의 ㅎ 동그라미** → 정확한 기하 원으로, **그릇·접시·얼굴**처럼 읽히게. 곰 머리·훅을 같은 원으로 통일. "끼"의 **쌍기역(ㄲ)**은 두 갈고리를 똑같이 맞춰 리듬 요소로. 한(받침 ㄴ, 아래 닫힘) vs 끼(아래 열림) **높이 차는 의도적으로 해결**(끼 세로 내려 바닥 맞추거나, 그 빈 공간에 곰/심볼).
- **레이아웃:** 가로 "한끼"가 기본 워드마크. 세로(한 위 끼)는 아이콘/배지용만.
- **곰과의 관계 = 시그니처 시스템**(심볼+워드마크 고정 비율). "그림 위 큰 글자" 대신 → 곰이 개성 담당·글자는 차분(당근 모델), 비율·여백 테스트(오늘의집 교훈), **딱 하나의 위트**(곰이 ㅎ 그릇을 들여다보거나 끼 빈칸에서 빼꼼)를 **글자와 같은 선 굵기**로.

## 6. 상표 출원 전략 (실무 — 최종은 변리사 확인)
- **단순화가 미감뿐 아니라 법적으로도 유리:** 사실적·상세 도형은 보호범위가 **좁고 흐리고** 분쟁 위험↑. **단순·상징적 도형**은 등록·보호·집행 다 유리. → Tier2 단순곰이 곧 등록용 도안.
- **출원 우선순위(정리):**
  1. **단순화 곰 = 도형상표(흑백) 단독** ← 진짜 자산·요부·집행 가능. **1순위.**
  2. **한끼 + 곰 = 결합상표(흑백)** ← 일상 사용과 일치, 등록 쉬움(곰이 식별력 공급). 보조.
  3. **"한끼" 단어 단독 = 보류.** "한끼"는 흔하고(채식한끼·한끼잇고 등 이미 다수) 식품/앱에서 **식별력 약함** → 거절·좁은 보호 위험. 선행조사 후, 나중에 "사용에 의한 식별력"으로 보강.
- **흑백(무채색) 출원** = 어떤 색으로 써도 인정(넓은 보호). 캐러멜/크림 팔레트를 꼭 독점해야 할 때만 색채 병행출원.
- **결합만 등록+실사용은 곰만** → 불사용취소 위험. 그래서 **곰 도형을 반드시 따로.**
- **분리 등록**(이름·곰·시그니처요소=하트주걱/계란포켓) = 헬로키티식, 보호 강함.
- **동일성:** 등록 도안과 "거래통념상 동일"하면 색·크롭·부기요소 변경 OK. 요부 바꾸면 재출원.
- ⚠️ **변리사 확정 항목:** "한끼" 단어 등록가능성 · 지정상품/류(대략 9류 앱 + 42류 SaaS, 필요시 43/41/35) · 선행상표 정밀조사(KIPRIS) · 도안 이미지 규격 · 비용(대략 출원 4.6~5.6만/류 + 등록 21만/류 + 변리사비). **무료상담 = 공익변리사 ☎02-6006-4300.**

## 7. ⛅ 앱 아이콘 갈림길 — 캐릭터 vs 심볼 (창업자 선택)
| | A. 단순화 곰(캐릭터) 아이콘 | B. 심볼/글자 아이콘 |
|---|---|---|
| 예 | 듀오링고(부엉이), 캐릭터앱 | 배민(배), 당근(당근), 토스 |
| 장점 | 사랑받는 꼬르곰이 얼굴 · 레시피앱 카테고리(냄비·수저 아이콘 천지)에서 **캐릭터가 눈에 띔** · 감정 연결 · 곰 도형상표와 아이콘 일치 | 초미니에서 제일 또렷 · 확장·추상 세련 · 서비스앱 정석 |
| 단점 | 반드시 **단순화 곰**이어야(상세곰 넣으면 다시 촌스러움) | 곰을 아이콘에서 뺌(창업자 애착↕) |
| 전제 | Tier2 플랫 곰 제작 필요 | 심볼(ㅎ그릇/한글자) 설계 필요 |

- **참고: 듀오링고 = 서비스앱인데 아이콘이 캐릭터(부엉이)** → **단순·볼드·플랫이면 캐릭터 아이콘도 최고로 프리미엄 가능.** 즉 "서비스앱=무조건 심볼"은 아님. 관건은 **곰을 제대로 단순화**하느냐.
- **내 추천:** **A(단순화 곰 아이콘)** — 창업자가 곰을 사랑하고, 레시피 카테고리에서 캐릭터가 차별화되고, 곰 도형상표와 아이콘이 일치(브랜드+법적 정합). 단 **반드시 Tier2 플랫 곰으로.** "한끼" 커스텀 워드마크는 앱 안 제목·웹·패키지에 따로. (최종은 창업자 취향)

## 8. 한끼 실행 방향 (권장 세트)
1. **Tier1 상세 물결곰** = 지금 그대로, 스티커·굿즈·인앱. (안 버림)
2. **Tier2 단순화 곰 마크** = 새로 제작(플랫·기하·요부만) → **앱아이콘 + 도형상표.**
3. **"한끼" 커스텀 워드마크** = Pretendard 뼈대로 휴먼고딕 커스텀(ㅎ 그릇 훅). 주아체 폐기.
4. **시그니처(곰+한끼)** = 결합상표·스플래시·패키지용, 고정 비율 락업(위트 하나).
