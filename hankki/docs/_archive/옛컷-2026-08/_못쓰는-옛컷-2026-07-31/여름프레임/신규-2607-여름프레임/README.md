## ⭐ 안쪽 뚫기 (v9.00 사고 방지)
프레임 안쪽 흰색을 투명으로 만들 때 **가운데 한 점에서만 번지게(flood fill)** 한다.
⚠️ v9.00 때 "흰색 지우기"가 과해서 **돛단배 돛·갈매기 몸통·데이지 꽃잎**까지 지웠다.
가운데에서만 번지면 프레임 선에 막혀 창 밖으로 못 나가고, **그림 속 흰색은 창과 안 이어져 있어 안전하다.**
→ 실제로 돛·갈매기·아이스크림·진주 전부 온전함을 렌더로 확인.

안전장치 3개: ①가운데가 흰색·불투명일 때만 ②번진 영역이 전체의 6~92%일 때만 ③가장자리에 안 닿아야
