## ⛔ 여기 있는 건 «안 쓰는 컷»이다

전부 **`docs/stickers/` 맨 위에 흩어져 있던 폴더**다. 이름이 스스로 「옛것」이라 말하는데도
**정본 폴더들과 나란히** 있어서, 뭘 찾다가 그냥 집어 쓰기 좋았다.

⭐⭐ **실제로 그렇게 사고가 났다** — 2026-08-14 에 창업자가 잡았다:
> *"우리 옛컷 다 보관소안으로 들어가있지? **너가 어제 또 꺼내와서 물어보는거야.**"*

그때 배운 것이 이것이다 — **「하지 마라」를 적는 것보다 «할 수 없게» 만드는 게 낫다.**
이제 이 폴더는 `archive-guard` 가 막는다. 열려면 창업자 지시가 있어야 한다.

## ✅ 지우지 않았다 — 전부 «이동»이다

`git mv` 라 히스토리가 그대로 붙어 있다. 되살릴 일이 있으면 그대로 꺼내면 된다.
📌 창업자 보존원칙 = *"삭제 금지 = 보존."*

## ⛔ 여기 «안» 들어온 것

- **`낱개-제외/`** — 각 시트 폴더 «안»에 그대로 뒀다.
  「이 컷을 왜 뺐나」는 **그 세트 옆에 있어야** 뜻이 통한다(예: `ci_05` 는 「추섴」 오타라서 뺐다).
  떼어 오면 이유가 사라진다.
- **정본 시트 폴더 전체** — 창업자가 준 원본이고 지금도 쓴다.
