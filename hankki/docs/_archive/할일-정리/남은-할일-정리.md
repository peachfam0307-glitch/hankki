## 🛠️ 새 AAB 빌드 방법 (PWABuilder, 같은 keystore)

> 목적: 새 앱 아이콘(곰=ㅎ)을 홈화면에 반영. **반드시 처음 쓴 keystore 그대로** 써야 업데이트로 인식됨(다른 키면 '다른 앱'이 되어 업데이트 불가).

1. **pwabuilder.com** 접속 → URL 입력: `https://peachfam0307-glitch.github.io/hankki/`
2. **Android** → **Generate Package**
3. 옵션에서:
   - **Package ID**: `io.github.peachfam0307_glitch.twa` (기존과 동일해야 함 — 절대 바꾸지 말 것)
   - **App version / Version code**: **기존보다 높은 숫자로 올리기** (예: 1 → 2). 안 올리면 업로드 거부됨.
   - **Signing key**: **Use existing** → 백업해둔 `signing.keystore` + 비밀번호(별칭·키·스토어 비번) 입력. (새로 만들지 말 것!)
4. **.aab 다운로드**
5. **Play Console → 테스트 및 출시 → 비공개 테스트('베타테스트') → 새 버전 만들기**
   - AAB 업로드 → 출시 노트 간단히 → **검토 → 게시**
6. 몇 분~시간 뒤 반영. 테스터는 Play 스토어에서 업데이트 받으면 새 아이콘.

**막히면**: keystore 비밀번호를 모르면 업데이트 자체가 불가하니, `signing.keystore`와 비번 백업 위치부터 확인. (2026-07-16 백업 완료 상태)
