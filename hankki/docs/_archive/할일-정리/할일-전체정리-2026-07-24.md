## 🎬 프로모 영상 완성 — 레꾸 영상 [#24] (2026-07-24, 창업자 승인 "넘 좋아")

**결과물**: `design/promo/프로모영상-2507/한끼-프로모-2507.mp4` (세로 9:16·~30.5초·H.264·무음) + `scripts/`(promo_build.mjs=애니HTML, promo_render.mjs=녹화+인코딩) + README.

**구성 6장면** (스토어 8장 시안과 레시피·곰펭 일치):
훅(밋밋 회색카드→플래시+색확산+곰점프+"짠!"도장 = 드라마틱 변신) → 꾸미기(큰카드 **연어포케볼 fe_06** + 곰펭 **콩콩점프** + 스티커 하나씩 + 트레이[곰·펭·떡볶이·**아보카도스무디 fe_15**]) → 공유(**폰 스토리 목업**: 배지→**감바스 fe_08** 카드 스토리에 올라가고→친구반응) → 큐레이션(보리면·대파소금·쯔유→담기→사기) → 감정(하트곰) → 로고(곰펭 **손흔들며 안녕인사 gp_duohi**).

**기술**: 이 환경에 ffmpeg 없어서 `ffmpeg-static`(npm 프리빌트) 설치해서 씀. Playwright로 1080×1920 녹화(webm)→ffmpeg mp4. 6MB 무거운 base64 페이지라 **이미지 디코드 완료 후 `__go` 신호로 애니 시작**해야 검은화면 트림과 타이밍 오프셋 0.
