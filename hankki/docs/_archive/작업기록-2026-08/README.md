# 🗄 작업기록 2026-08 — «끝난 것»만 들어 있다

> 📮 창업자 2026-08-15 *"이런 것들 막으려면 어떤 낡은 문서들을 지워야 할까"* →
> **"나눠서 반영구적으로 가둬. 내가 허락할때만 들어가도록."**

## ⛔ 왜 가뒀나 — 2026-08-15 사고

`레시피-정리-초안-2026-08-10.json` 이 **나를 속였다.**

- 이 JSON 은 **8/10 초안**이고, 편마다 그때 적어둔 `fix`(고친 것)·`ask`(물어볼 것)·`status` 가 들어 있다.
- ⭐⭐ **그 뒤 창업자 검수와 정정이 «코드»에 반영됐고, 이 파일은 그때 상태로 얼었다.**
- ⛔ 나는 코드를 안 보고 이 화석만 보고 **「창업자 확인을 못 받은 여섯 자리가 있다」** 고 보고했다.
  → **여섯 편 전부 이미 반영돼 있었다.** 창업자가 *"다 적어준 기억이 나. 찾아봐"* 라고 해서 잡혔다.
  → **이미 답한 것을 또 묻게 만들 뻔했다.**

📌 뿌리 = **`_대기/` 라는 이름이 「아직 안 한 것」으로 읽힌다.** 실은 «작업하며 만든 재료»가 섞여 있었다.

## ✅ 가른 기준

| 갈래 | 어디에 | 가두나 |
|---|---|---|
| **지금 쓰는 것** (현행 규칙·문서) | `docs/` 최상단 | ⛔ 안 가둔다 |

| **끝난 기록** (반영 완료·지난 검수·지난 재현) | **여기 `_archive/`** | ✅ **가둔다** |
