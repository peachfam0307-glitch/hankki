### 🔢 「218종」을 «코드에서 읽게» 고쳤다
```js
const 음식컷수 = (() => {
  const out = execSync(`node ${H}/scripts/check-foodtab.mjs`, { encoding: 'utf8' })
  const m = out.match(/픽커에 실린 음식 (\d+)컷/)
  if (!m) throw new Error('⛔ 음식 컷 수를 못 읽었다 — check-foodtab 출력 형식이 바뀌었나 확인할 것')
  return Number(m[1])
})()
```
⛔⛔ **그 자리가 벌써 두 번 낡았다 — 88 → 218 → 386.**
주석에 *"「88종」이 낡았다 → 218종"* 이라고 적어놓고 **그 218 도 글자로 박아서** 또 낡았다.
📌 **낡은 값을 고치면서 «또 글자로 박은 것»이 뿌리다.** 이제 배포 게이트가 센 값을 읽으니 자산이 늘면 저절로 따라온다.
⭐ 못 읽으면 **죽는다** — 조용히 낡느니 시끄럽게 멈추는 게 낫다.
