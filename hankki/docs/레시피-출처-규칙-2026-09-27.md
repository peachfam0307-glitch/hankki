# 레시피 출처 규칙 — 2026-09-27 (창업자 확정)

📮 창업자 = *"우리말투로 바꾸면 그냥 쓰는걸로 했잖아."* → *"좋아. 지금까지 그렇게 해오지 않았어? 순수 내 레시피가 20편 남짓이니까"*

## 세 갈래

| 갈래 | 무엇 | 표시 |
|---|---|---|
| 🧑‍🍳 **주인장 레시피** | 창업자가 «직접 만든» 레시피 (2026-09-27 기준 20편 남짓) | `made: '창업자'` → 제목 옆 꼬르곰 뱃지 |
| 🏠 **우리집레시피** | 창업자 백업에 있던 남의 레시피 — **문장을 우리 말투로 다시 써서** 쓴다 | `origin: '창업자'`(백업에서 왔다) · 뱃지 없음 · 원작자 링크 없음 |
| 📱 **SNS 레시피** | 원본 게시물 링크가 있는 편 | `sourceUrl` ＋ `sourceName` → SNS 상자(수요일) |

## 우리 말투로 다시 쓸 때
- 재료·양념 비율은 그대로 둔다.
- 원문의 문장·팁·말투(「무한흡입」 같은)는 가져오지 않는다 — 만드는 법은 우리 해요체로 새로 쓴다.
- 출처 메모를 레시피에 따로 적지 않는다(창업자 「그런거 안적어도 돼」).

## 주의
- 원본 링크가 있는 편(SNS)을 우리집레시피 칸에 같이 넣으면 SNS 상자와 겹친다 — SNS 는 수요일 SNS 상자로만.
- 이 규칙은 **창업자 결정**이다. `docs/유튜브스크립트-약관조사-2026-09-03.md` 의 「우리 말투로 바꿔도 가져온 사실이 남는다」는 **유튜브 자막(API 약관)** 이야기라 이 규칙과 자리가 다르다.
