## 2️⃣ 🚨 인스타그램 — **공식 경로가 «없다». 확정.**

| 경로 | 결과 |
|---|---|
| **oEmbed** | ⛔ **캡션 텍스트를 «안 준다»** — `html`·`author_name`·`thumbnail_url` 뿐 (⚠️`hidecaption` 은 «보일지 말지»만 정한다) |
| **Graph API** | ⛔ **자기 비즈니스/크리에이터 계정의 «자기 게시물»만.** 제3자 공개 게시물 캡션 엔드포인트 = 없음 |
| **Basic Display API** | ⛔ **2024-12-04 종료** |
| **그 밖의 공식 API** | ⛔ **없음** |
| **스크래핑** | ⛔ Meta 약관 = *"Only Meta's official APIs and developer tools may be used for automated data access."* |
| **Gemini 에 인스타 URL** | ⛔ **공식 지원 안 함** — 문서에 YouTube URL 만 있다 |
| **다른 AI(OpenAI·Claude 등)** | ❓ 인스타/틱톡 URL 직접 입력 = **확인된 사례 없음** |

📌 **즉 「인스타 URL 하나로 캡션 가져오기」는 약관 안에서 길이 없다.**
