## 1-옛. ⛔ 먼저 갈라야 할 것 — 「앱 안 WKWebView 에서 웹 푸시가 되나」 (＝위에서 풀렸다)
- 갤럭시 문서 85줄 「iOS 16.4부터 웹 푸시」는 **Safari · 홈 화면 웹앱** 얘기다. 우리 앱은 **WKWebView** 라 같은 조건이 아니다.
- 내 기억 = «WKWebView 에는 Push API 가 없다 → 네이티브 푸시(APNs)로 따로 붙여야 한다». ⛔ **오늘 공식 원문을 못 열었다**(webkit.org · MDN · capacitorjs.com 전부 망 차단 · 열람 시도 2026-09-19 22:1x). 기억은 값이 아니라 «미확인»으로 둔다.
- ✅ **1분짜리 판정 방법** = 다음 아이폰 빌드(30판)에 설정 운영자 칸(내부 기기만 보이는 자리)에 한 줄 표시: `푸시 API: 있음/없음` (`'PushManager' in window && 'serviceWorker' in navigator`). 딸 폰 TF 로 보면 끝. 코드 3줄 · 유저에겐 안 보인다.
  - 있음 → 갤럭시 1판(웹 푸시)이 아이폰 앱 안에서도 «그대로» 돈다. 이 문서 2절은 안 해도 된다.
  - 없음(내 예상) → 2절로 간다.

## 2. 네이티브 길 — 「받는 쪽만 다르고, 보내는 쪽은 같은 워커」
```
[갤럭시·웹]  서비스 워커 구독(VAPID) ─┐
                                    ├─▶ Cloudflare 워커 · KV { platform, 주소/토큰 } ─▶ 정한 시각에 한 번 보냄
[아이폰 앱]  APNs 기기 토큰 ──────────┘        (web-push 는 VAPID 로 · ios 는 APNs 로)
```
| 층 | 무엇 | 비용 |
|---|---|---|
| 앱 | `@capacitor/push-notifications` 플러그인 → 권한 묻기(같은 자리: 장바구니 담을 때·냉장고 넣을 때) → 기기 토큰 받기 → 워커에 `{platform:'ios', token}` 한 번 등록 | 0원 |
| Xcode | Signing & Capabilities → **Push Notifications** ＋ Background Modes(remote-notification) → `App.entitlements` 에 `aps-environment` 생김 | 0원 |
| 애플 | Developer → Keys → **APNs 인증 키(.p8)** 하나 만들기(팀에 하나 · 앱 여러 개 공용) | 0원(개발자 계정에 포함) |
| 워커 | ios 토큰엔 APNs HTTP/2 로 보냄(ES256 JWT · 키 ID · 팀 ID) — 또는 FCM 을 거쳐 보냄(이미 Firebase 있음) | 0원 |
| 저장 | KV 쓰기 = 토큰 등록 때 1번뿐(보낼 땐 읽기만) → 하루 1,000 쓰기 한도 안 | 0원 |

⭐ **APNs 직접 vs FCM 경유** — 둘 다 0원. 추천 = **APNs 직접**: 워커에서 이미 web-push 를 보내니 «보내는 코드가 한 곳»이고, Firebase 서버 SDK 를 워커에 얹는 것보다 가볍다. FCM 은 안드로이드도 네이티브로 갈 때 다시 본다.
⛔ **.p8 키·키 ID·팀 ID 는 워커 비밀칸(secret)에만** — 저장소·문서·대화에 안 적는다(App Store Connect 키 때와 같은 규칙).

## 3. 사람 눈에 보이는 것 (아이폰)
- 권한 창 = iOS 시스템 창(「"한끼"에서 알림을 보내고자 합니다」). **한 번 거절하면 앱이 다시 못 묻는다**(설정 앱에서만) → 갤럭시 ①번 규칙(아쉬운 순간에만)이 아이폰에선 더 중요하다.
- 알림 = 앱 아이콘·이름으로 잠금화면에 뜬다. 누르면 앱이 열린다 → 「새 레시피」면 그 레시피로(딥링크 = 지금 있는 `?recipe=` 길 그대로).
- 설정 화면에 「알림」 줄 하나: 켜짐/꺼짐(꺼짐이면 워커에서 토큰 지움 = KV 쓰기 1번).

## 5. 세 각도 검토 (설계 관문)
- 👩 사람: 아이폰 유저가 장바구니 담자마자 시스템 권한 창 → 무슨 알림인지 모르면 거절한다 → **시스템 창 «전»에 우리 시트 한 장**(「월·수 새 레시피, 토요일 장바구니만 보내요 · 하루 한 번」 · 「좋아요/다음에」). 「다음에」면 시스템 창을 안 띄운다(기회를 안 태운다).
- 💥 사고: 앱 지웠다 깔면 토큰이 바뀐다 → 옛 토큰으로 보내면 APNs 가 410 을 돌려준다 → **워커가 410 받으면 그 토큰을 지운다**(안 지우면 KV 가 죽은 토큰으로 찬다). 시뮬레이터·TestFlight 는 sandbox/production APNs 가 갈린다 → 워커에 둘 다 주소를 두고 토큰 등록 때 `env` 도 같이 받는다.
- 📈 규모: 91명 × 주 3회 = 월 1,200통 · KV 읽기 월 1,200 · 쓰기는 등록·해지 때만 → 무료 한도의 1% 아래. 1만 명이 돼도 쓰기 한도(1,000/일)는 «가입 러시 날»에만 닿는다 → 그때 등록을 «묶어 쓰기»로 바꾸면 된다.
- 잃던 것(지금) = 아이폰 유저를 부를 길 0. 잃을 것(고친 뒤) = 권한 거절 유저는 영영 못 부름 · .p8 키 하나 더 관리.
