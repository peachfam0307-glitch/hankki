| | 어디 | 빼먹으면 |
|---|---|---|
| ① | `src/assets/stickers/photo/<키>.png` | 그림이 없다(당연히 티가 난다) |

⭐ **③만 성질이 다르다.** ①②는 빼먹으면 «안 붙는» 정도인데,
③은 **①②를 다 해놔도 화면이 빈 접시**가 된다. 화면이 이 표를 «돌면서» 그림 목록을 만들었기 때문이다.

```js
// 옛 구조 — 표가 «주인»이었다
for (const key of Object.keys(PHOTO_RATIO)) {
  PHOTO_FAMILY[key] = { src: PHOTO_URLS[`../assets/stickers/photo/${key}.png`], ratio: PHOTO_RATIO[key] }
}
```

📌 **비율(모양 정보)을 안 적었다는 이유로 그림(존재)까지 잃는 구조**였다. 두 가지가 한 값에 묶여 있었다.

## 3. ✅ 고침 — 두 겹

### 1차 · 구조 (⭐이게 본체다 · 절대원칙 34)

**목록의 주인을 «손으로 적는 표»에서 «폴더에 있는 파일»로 옮겼다.**

```js
const 기본비율 = 1.25
export const PHOTO_FAMILY = {}
for (const 경로 of Object.keys(PHOTO_URLS)) {          // ← 폴더가 주인
  const key = 경로.slice(경로.lastIndexOf('/') + 1, -4)
  PHOTO_FAMILY[key] = { src: PHOTO_URLS[경로], ratio: PHOTO_RATIO[key] || 기본비율 }
}
```

⭐⭐ **실패의 «모양»이 바뀌었다** — 절대원칙 34 가 말하는 바로 그것이다.

| | 옛 구조 | 새 구조 |
|---|---|---|
| 비율을 빼먹으면 | ⛔ **그림이 아예 안 뜬다**(빈 접시) | ⚠️ 그림은 뜬다 · **비율만 조금 어긋난다** |
| 유저가 보는 것 | 「앱이 고장났네」 | 거의 눈치 못 챈다 |

⛔ **「값을 더 채운다」로 끝내지 않았다** — 그게 v13.35 가 한 일이고, 하루 만에 다시 났다.

## 6. 🕳 파다가 «더» 나온 셋 (2026-09-15 오전)

빈 접시를 고치고 검수판을 뽑아 **눈으로 열어 보다가**(절대원칙 21) 셋을 더 잡았다.

### ⓐ `물어볼것` 을 «검수판»이 안 읽고 있었다 — 어제 만든 장치가 절반만 붙어 있었다

📮 절대원칙(2026-09-14) = *"「나중에 물어볼 것」은 «레시피 안»에 `물어볼것: '…'` 로 적는다"*

🔢 실측 = `grep -n "물어볼것" scripts/*.mjs` → **`release-prep.mjs` 한 곳뿐**.
⛔ 그건 **내가 터미널에서 보는 도구**다. **창업자가 폰에서 보는 «검수판»(`_판-검수.mjs`)은 안 읽었다.**

📌 즉 *"검수판이 ❓로 띄운다"* 고 어제 문서에 적었는데 **그 절반이 거짓이었다.**
   ⭐ 「만들었다」와 「창업자 눈에 닿는다」는 다른 말이다.

✅ 고침 = 검수판 카드의 «메모 바로 위»에 빨간 ❓칸을 넣었다. 실물 캡처로 확인했다.

### ⓑ 검수판 카드마다 «편 이름 나열»이 제목 위에 겹쳐 떴다

카드 머리에 「비프페퍼브리또 · 무스비맛브리또 ⛔검수 안 받은 것 2편」이 **편마다 되풀이**됐다.

🌲 뿌리 = 줄 이름을 `g.what.split(' — ')[0]` 으로 뽑는데,
   **주간 레시피**는 「여름 시원한 것 — 콩국수 · …」 꼴이라 앞부분만 잘리지만
   **낱개로 넣은 편**은 그 꼴이 아니라 **설명이 통째로** 줄 이름 자리에 들어왔다.

✅ 고침 = 줄 이름 안에 **그 편의 제목이 들어 있으면** 줄 이름이 아니라 «목록»이니 안 쓴다 → `folder` 로 떨어진다.

### ⓒ 요리모드에서 «스크롤해야 하는 걸음»이 5 → 6개로 늘었다

`_repro-요리글씨-0821` 이 잡았다. 범인은 **내가 쓴 무스비맛브리또 11번(93자)** 이었다.
말기 요령까지 한 줄에 다 넣어서 길어졌다.

⛔ **부엌에서 스크롤은 잘린 것과 거의 같다** — 손에 물 묻은 채 흘깃 보는 자리다(그 재현판의 취지).

✅ 고침 = 두 걸음으로 갈랐다(비프페퍼브리또 8번도 같이). **최장 93자 → 67자** · 재현판 초록불.
⛔ 재료와 분량은 한 글자도 안 건드렸다.

내가 적은 물어볼것에 `curation.js` 라고 썼다. ⛔ 창업자가 읽는 글자에 개발 용어를 넣지 않는다(규칙 3).
