# 🗓 시즌 업데이트 전략 — 가을·겨울마다 뭘 어떻게 (2026-07-29 KST)

## 왜 이 문서

창업자 걱정:
> "근데 나 걱정이 초반에 이렇게 주면, **가을겨울때마다 다 어떻게 업뎃해?** ㅋㅋ
> 배경부터 스티커 프레임에 캐릭터에 일이 장난 아니네. **뽑는건 뽑겠는데 새로운 디자인 뽑기가 힘든데** 그게 제일 걱정.."

그리고 클로드가 "재사용·리컬러로 일 줄이자"고 답하자 **정확히 반박**:
> "**그럼 지겹잖아. 신선한 디자인이나 색다른 느낌이 나와야 재밌지. 맨날 비슷한 톤 비슷한 느낌이면 별루니까..**"

⭐ **창업자 말이 맞다.** 다꾸 앱은 **새로운 게 나오는 것 자체가 상품**이다. 리컬러로 때우면 유저가 바로 알아챈다.
이 문서는 "일을 줄이는 법"이 아니라 **"매 시즌 진짜 새롭게 보이되, 기획 고민은 0으로 만드는 법"** 이다.

## 1. 먼저, 부담의 실제 크기 (숫자로)

2026-07-29 기준 꾸미기 스티커 **386종** (v8.94 시점 측정):

| | 종수 | 비중 |
|---|---|---|
| 사철 쓰는 것 | 319 | **82%** |
| 계절 한정 | 67 | 17% |
| └ 그중 **캐릭터** | **12** | 3% |

- **`season` 필드는 숨기는 게 아니라 정렬만 바꾼다.** 겨울에 여름 스티커가 사라지지 않고 아래로 내려갈 뿐.
  → **업뎃 못 하면 큰일 나는 구조가 아니다.** 시즌은 "있으면 좋은 것"이지 "없으면 깨지는 것"이 아니다.
- 시즌 한 번에 필요한 시트 ≈ **5장** (캐릭터 4컷 시트 3 + 프레임 1 + 소품 1).
  참고로 창업자가 2026-07-29 하루에 준 프레임 시트만 14장이었다.

## 2. "새 디자인 뽑기"가 사실 제일 걱정 안 해도 되는 이유

**새로 디자인하는 게 아니다.**
- `한끼5인-캐릭터-브랜드바이블-v2.0.pdf`에 **AI 마스터 프롬프트가 이미 완성**돼 있다.
  그림체·색 HEX·비율·절대금지·4컷 템플릿·검수 체크리스트까지 전부 고정.
- 가을 = **같은 프롬프트에서 단어만 바꾸는 것**. 수박→군고구마, 튜브→목도리, 파라솔→낙엽.
- 이게 바이블을 만들어 둔 값어치다. **시즌마다 "우리 캐릭터 어떻게 생겼더라"를 다시 정할 필요가 없다.**

## 3. ⭐ 신선함은 '양'이 아니라 '축'을 바꿔서 만든다

같은 카테고리를 더 뽑으면 지겨워진다. **시즌마다 바꾸는 축을 다르게** 잡는다.

| 축 | 바꾸면 생기는 일 | 비용 |
|---|---|---|
| **① 마감(텍스처)** | 여름=수채 투명 / 가을=니트·코듀로이 질감 / 겨울=포일·홀로 반짝 / 봄=무광 파스텔 → **같은 캐릭터도 새 세트로 읽힌다** | 프롬프트 **한 줄** |
| **② 포맷** | 여름=낱개 씰 / 가을=**띠부씰**(도구 이미 있음) / 겨울=4컷 스트립·티켓 / 봄=도장·스탬프 → 포맷이 바뀌면 완전히 새로워 보인다 | 시트 수 동일 |
| **③ 컬러 시스템** | 여름=쿨 민트·블루 / 가을=테라코타·머스타드·딥그린 / 겨울=딥네이비+골드 | 프롬프트 |
| **④ 씬** | 여름=바다 / 가을=단풍 캠핑·군고구마 포차 / 겨울=크리스마스 베이킹·눈오는 창가 | 프롬프트 |

⛔ **리컬러는 시즌 콘텐츠를 대신하지 않는다.** (창업자 결정 2026-07-29 "리컬러는 아껴두자")
리컬러는 **유저가 자기 표지 색에 맞추는 도구**로 내는 것이지, 새 시즌을 때우는 수단이 아니다.

## 4. 시즌 기획 미리 짜두기 (초안 — 창업자 확정 필요)

**"뭘 뽑을지 정하는 것"이 진짜 부담**이라고 했으니, 그걸 미리 정해두면 시즌마다 고민이 0이 된다.

| | 테마 | 컬러 | 마감 | 포맷 | 소품 |
|---|---|---|---|---|---|
| 🍂 **가을** | 단풍 캠핑 · 군고구마 · 첫 국물요리 | 테라코타·머스타드·딥그린 | **니트/코듀로이 질감** | **띠부씰** | 낙엽·도토리·목도리·군고구마·따뜻한 컵·밤 |
| ❄️ **겨울** | 크리스마스 베이킹 · 눈오는 창가 · 붕어빵 | 딥네이비 + 골드·버건디 | **포일·홀로 반짝** | 4컷 스트립·티켓 | 눈사람·리스·양말·붕어빵·귤·전구 |
| 🌸 **봄** | 소풍 도시락 · 딸기 · 벚꽃 | 연핑크·라일락·연둣빛 | 무광 파스텔 | 도장·스탬프 | 벚꽃·딸기·도시락·나비·튤립 |

- **시즌 2개(여름·겨울)만 제대로**, 봄·가을은 가볍게 가는 것도 방법. 다꾸 시장도 크리스마스·여름이 메인이다.
- 배경은 **19개 전부 CSS·SVG 코드**라 뽑을 필요가 없다 — 색만 바꾸면 시즌 배경이 된다.

## 7. 📅 실제 업뎃 주기 — **매달 드립** (2026-07-30 추가)

(프레임 리컬러 48 · 여름다꾸B 89 · 여름다꾸A 나머지 54 · 파스텔 42 · 프레임J 8 · 띠부씰 씬 7 · 신규2508·음식라이프 다수)

**매달 30~40컷씩 풀면 8~10개월** — **창업자가 새로 한 장도 안 뽑아도.**
(⚠️ 꺼낼 때 해상도 검수 통과분만. 롤백된 172컷은 다시 뽑아야 하는 것으로 별도.)

### 그래서 운영은 이렇게
| | 무엇 | 누가 |
|---|---|---|
| **매달** | 재고에서 30~40컷 꺼내 검수 → 등록 | **클로드 혼자** (창업자 손 안 감) |
| **여름·겨울** | 큰 시즌팩 (위 §4 표) | 창업자가 시트만 → 나머지 클로드 |

→ 창업자 부담은 지금과 같은데 유저는 **매달 새 걸 받는다.** 다꾸 앱은 **새 게 나오는 것 자체가 상품**이라(§3) 매달이 훨씬 유리하다.

### ⛔ 단, UI엔 주기를 약속하지 않는다
`PreviewSheet`(곧 만나요) 문구는 **"새 스티커·프레임·마테가 계속 늘어나요"** 로 간다.
**'계절마다'·'매달' 둘 다 주기를 약속하는 말**이고, 한 번 못 지키면 신뢰가 깨진다.
