## 0️⃣ 왜 한 몸인가 — 한 문장

**둘 다 「이 사람이 누구인가」를 알아야 돌아간다.** 계정이 하나면 둘 다 되고, 계정이 없으면 둘 다 안 된다.

- 클라우드 = *「이 레시피가 **누구** 것인가」* 를 알아야 새 폰에 돌려준다
- 결제 = *「이 20장을 **누가** 샀나」* 를 알아야 새 폰에서도 쓰게 해준다

📌 그래서 **계정을 두 번 만들 이유가 없다.** 구글 로그인 하나로 둘 다 붙는다.

---

## 1️⃣ 지금 상태 — 무엇이 있고 무엇이 «막혀» 있었나

| | 상태 | 막힌 까닭 |
|---|---|---|
| 결제 코드 (`billing.js` 214줄) | ✅ 있음 | — |
| 상품 6개 (꾸미기팩 5 ＋ `ocr_pack_20`) | ✅ 코드에 있음 | 콘솔 등록은 승인 뒤 |
| 판매 스위치 `sellable` | ⏸ 전부 `false` | 일부러 |
| 🎨 꾸미기팩 **복원** | ✅ 저절로 됨 | Play(구글 계정)가 기억한다 |
| 📷 **산 20장의 「남은 장수」** | ⛔⛔ **막혀 있었다** | **셀 곳이 없었다** — 기기마다 다른 임의 번호로 세서, **폰 바꾸면 산 게 사라진다** |
| 📢 「몇 장 남았는지」 유저에게 보여주기 | ⛔ 막혀 있었다 | ↑ 어디에 두는지가 안 정해져서 **보여줄 수도 없었다** |

⛔ **CLAUDE.md 규칙** = *"「구매 → 복원」이 한 흐름으로 들어가기 전엔 실결제 스위치를 켜지 않는다."*
→ 즉 **위 두 칸이 막혀 있는 한 결제를 못 켠다.** 이게 여태 «못 정한 것»으로 남아 있던 이유다.

## 2️⃣ ⭐⭐ 로그인이 생기면 — 막힌 칸이 «열린다»

| | 옛날 (계정 없음) | 새 판 (구글 로그인) |
|---|---|---|
| 누구인지 | 기기마다 다른 **임의 번호** (`deviceId()`) | **구글 계정** |
| 앱 지웠다 깔면 | 임의 번호가 **새로 생김** → 산 게 사라짐 | 로그인하면 **그대로** |
| 폰 바꾸면 | 사라짐 | **그대로** |
| 남은 장수 | 둘 데가 없음 | **계정에 붙어 있음** |

📌 **그래서 「클라우드부터」가 순서가 맞다.** 결제를 먼저 켜면 «산 게 사라지는» 사고가 먼저 난다.

---

## 3️⃣ 무엇을 «어디에» 두나

| 무엇 | 어디 | 왜 |
|---|---|---|
| 레시피 글자 ＋ 표지 사진(640px) | **파이어베이스 DB** (계정별) | 한 칸 1MiB 안에 사진까지 들어간다 → 유료 사진창고 안 씀 |
| 일기 · 꾸민 종이 | 파이어베이스 DB | 〃 (⚠️ 용량은 따로 재야 한다 — 아래 7️⃣) |
| 🎨 꾸미기팩 소유 | **Play(구글 계정)** | 우리가 안 세도 된다. 이미 저절로 복원된다 |
| 📷 **AI 스캔 남은 장수** | **파이어베이스 DB** (계정별) | ⭐ 여기가 이번에 «풀린» 자리 |
| 🌍 전역 사용량(월 900) | **지금 쓰는 Cloudflare KV 그대로** | 우리 돈을 지키는 벽 — 손대지 않는다 |
| 🔑 비번 | **아무 데도 안 둔다** | 구글이 대신 한다. 우리는 비번을 «받지 않는다» |

⭐ **Cloudflare Worker(OCR 프록시)는 거의 그대로 둔다.** 바뀌는 건 하나 —
   앱이 보내는 `uid` 가 **임의 번호 → 구글 계정 번호**로 바뀔 뿐이다.

## 4️⃣ 흐름 셋 — 화면에서 무슨 일이 일어나나

### ⓐ 처음 로그인
```
설정 → 「구글로 로그인」 → 구글 창 → 끝
   ↓
폰에 있던 레시피가 «내 계정»으로 올라간다  (처음 한 번, 진행 막대)
```
⚠️ **로그인은 «강제하지 않는다».** 안 해도 앱은 지금처럼 다 된다.
   ⭐ 로그인해야 하는 이유를 **말로** 준다 — *"폰이 바뀌어도 레시피가 남아요"*.

### ⓑ 20장 사기
```
가져오기 → 「AI 스캔 더 사기」 → Play 결제창 → 구매 완료
   ↓
consume() 호출 (Play 는 잊는다 — 다시 살 수 있게)
   ↓
내 계정의 「남은 장수」 +20     ← ⭐ 여기가 예전엔 없던 자리
```
⛔ **로그인 안 한 사람에게는 «사기 전에» 로그인을 받는다.**
   안 그러면 폰 바꿀 때 산 게 사라지고, 그건 **환불·악평 1순위**다.

### ⓒ 새 폰
```
앱 깔기 → 「구글로 로그인」 → 레시피 내려받기 ＋ 남은 장수 그대로
   ↓
꾸미기팩은 Play 가 알아서 복원
```

## 5️⃣ 조작 걱정 — 우리 돈은 무엇이 지키나

「남은 장수」를 계정에 두면 «누가 숫자를 늘리면 어쩌나» 가 걱정된다.

✅ **이미 답이 코드에 있다** (`billing.js:192` · OCR 프록시 6중 방어벽) —
   **전역 월 900장 상한**이 우리 돈을 지킨다. 누가 숫자를 부풀려도 **900에서 막혀 구글 호출 자체가 안 된다**
   → 청구가 물리적으로 불가능하다.

📌 즉 **「완벽한 검증」을 만들 필요가 없다.** 손해가 날 수 없는 구조라 **간단하게 간다.**
⚠️ 나중에 유료 유저가 늘어 900을 올리는 날, 그때 **구매 영수증 검증**을 붙인다(그날의 일).

## 6️⃣ 순서 — 클라우드와 결제를 «한 줄»로

⛔ **전부 재심사 승인 «뒤».** 승인 전에 서버·AAB를 건드리지 않는다.

| | 할 일 | 누가 | 왜 이 순서 |
|---|---|---|---|
| **0** | 🧪 **진짜 폰 TWA 에서 구글 로그인 실험** | 내가 만들고 · **창업자가 눌러보기** | 여기서 막히면 **설계 전체가 바뀐다.** 제일 먼저 |
| 1 | 파이어베이스 프로젝트 만들기 (한끼 계정 · Spark · 카드 X) | **창업자**(콘솔) | 계정이 있어야 나머지가 붙는다 |
| 2 | 앱에 「구글로 로그인」 ＋ 올리기/내려받기 | 나 | 클라우드 본체 |
| 3 | 올릴 때 표지 사진 **640px** 로 줄이기 | 나 | 366명 → 996명 |
| 4 | **앱 안 계정 삭제 ＋ `privacy.html` 에 웹 삭제 신청** | 나 | ⛔ 둘 다 없으면 **반려** |
| 5 | Play **데이터 보안 폼 재신고** | **창업자**(콘솔) | 이메일·계정을 받으니 신고가 바뀐다 |
| — | — | — | ⬆ **여기까지가 「클라우드 출시」** |
| 6 | 「남은 장수」를 계정에 두기 ＋ **화면에 보여주기** | 나 | ⛔ 잔량 표시는 **결제 스위치를 켜는 조건**(창업자 2026-08-13) |
| 7 | 유료 소진 신호 가르기 (`pack_empty`) ＋ 「N장 남았어요」 미리 알림 | 나 | 돈 낸 사람에게 *"무료 5회를 다 써서"* 는 **틀린 말** |
| 8 | **BILLING 넣은 AAB** 굽기 (`twa-manifest.json` 29줄 두 줄) | 나 → 창업자 업로드 | 라벨이 붙으니 아래 넷과 «같이» |
| 9 | 콘솔 4단계 — 결제 프로필 · 상품 6개 · AAB · 라이선스 테스트 | **창업자**(콘솔) | `결제-준비상태` 5️⃣ 그대로 |
| 10 | `sellable: true` 한 줄 | 나 | **마지막 스위치** |

⚠️⚠️ **8~10은 「넷을 같이」다** — 콘텐츠 등급 재작성 · 데이터 보안 재신고 · `privacy.html` · Play 인앱구매 표시.
   **하나라도 빠지면 신고 위반.** (CLAUDE.md 규칙)

```
                    ┌──────────────┐
   구글 로그인 ────▶ │  내 계정 하나 │
                    └──────┬───────┘
                           │
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
   레시피·일기        AI 스캔 남은 장수      꾸미기팩
   (파이어베이스)      (파이어베이스)      (Play 가 기억)
        │                  │                  │
        └──── 폰이 바뀌어도 그대로 ────────────┘

   💰 우리 돈은?  →  전역 월 900장 상한이 막는다 (지금 그대로)
```
