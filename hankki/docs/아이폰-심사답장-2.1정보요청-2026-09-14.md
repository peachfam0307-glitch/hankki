2. PURPOSE AND AUDIENCE
Hankki ("한끼", Korean for "one meal") is a personal recipe notebook for home cooks in Korea. Problem: recipes people find on Instagram, YouTube or KakaoTalk end up as screenshots that are hard to find and unusable while cooking. Value: the user shares or picks a screenshot, the app reads the text (OCR), tidies it into a title, an ingredient list and numbered steps, and keeps it in one place with a shopping list, a hands-free cooking mode with timers, a simple meal diary and decorative recipe cards. Target audience: adults (rated 12+) who cook at home; the app is offered in Korea and the UI is in Korean.

3. SETUP AND ACCESS
- Sign-in is required. EASIEST: tap "Apple로 로그인" (Sign in with Apple) with any Apple ID — no demo credentials needed. Alternatively use the demo Google account in the sign-in fields above (Google may show a one-time security prompt for a new location). Both paths create the same single account type; no other account types exist.
- Main flows to test:
  (a) Share import: open any recipe screenshot in Photos → Share → "한끼" → open Hankki → Inbox ("임시보관함").
  (b) In-app import: Home → "가져오기" (Import) → "사진 고르기" (pick photos) or paste text.
  (c) Recipe → "요리모드 시작" (Cooking mode) → step-by-step view with timer.
  (d) Delete account: Profile tab (bottom bar, rightmost) → "계정 · 데이터 삭제" → "계정 삭제" → type 삭제 to confirm. This deletes the Firebase user and all of that user's data in Firestore.
- Sample files: any Korean recipe screenshot works; the recording uses one.
- Support: https://peachfam0307-glitch.github.io/hankki/support.html · Privacy: https://peachfam0307-glitch.github.io/hankki/privacy.html · Account deletion info: https://peachfam0307-glitch.github.io/hankki/delete-account.html

4. EXTERNAL SERVICES
- Firebase Authentication (Google Sign-In, Sign in with Apple) and Cloud Firestore (asia-northeast3, Seoul) — sign-in and per-user recipe backup.
- Cloudflare Workers (our own proxy; the app never holds API keys) calling:
  · Google Cloud Vision API — text recognition (OCR) of recipe screenshots.
  · Cloudflare Workers AI — text tidying into ingredients/steps (Meta Llama 3.3 70B, GLM 4.7 Flash; Google Gemma 4 as vision fallback). Used only after the user consents in the "AI 사용 안내" sheet, which can be declined; the app still works without AI.
- Google Analytics 4 (gtag) — anonymous screen/usage counts; an opt-out switch is on the privacy page linked from the app.
- Optional shopping links (Coupang) open in the system browser; no purchases happen in the app.
No payment processor, no ads SDK, no third-party login other than Google/Apple.
