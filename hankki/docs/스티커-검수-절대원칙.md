## ① 투명판 (체커보드) — 눈으로 본다
낱개 PNG를 **체커보드 위에 얹어 렌더**해서 직접 본다.
- 배경이 안 지워졌는가 (흰 네모가 남았는가)
- 지워지면 안 될 안쪽 흰색(셰프모자·앞치마·접시)이 뚫렸는가

> ⛔ **뷰어에서 회색·컬러로 보인다고 "투명 실패"라고 말하지 말 것.**
> 2026-07-29에 프레임 7장을 그렇게 오판했다가 정정했다. **판정은 알파 채널 수치로.**

### ⚠️⚠️ 체커보드만 보면 못 잡는 것 — **그림에 박힌 가짜 체커보드**
**AI로 뽑은 프레임은 "여기가 투명이에요"라는 뜻으로 안쪽에 회색 격자무늬를 그려 넣는다.**
이건 **진짜 투명이 아니라 알파 255짜리 그림**이다.
그런데 **체커보드 위에 얹어 검수하면 배경 격자와 똑같이 보여서 절대 안 보인다.**

> 🚨 2026-07-29 실제 사고 — 여름 프레임 `sf_*` **16장 전부**가 이 상태로 나갔다.
> 창업자 폰 제보: *"이거 이래.. 이 프레임세트 전체다"* — 어두운 배경에 얹으니 가운데가 격자무늬로 떴다.
> 검수 때 **체커보드 위에서만 봐서** 못 잡았다.

**→ 규칙: 투명 검수는 두 판에서 한다.**
1. **체커보드** — 배경이 안 지워졌는지 (①)
2. **⭐ 진한 단색 판**(예: `#22263A`) — **박힌 격자·흰 자국·헤일로**가 그제서야 보인다

**숫자로도 잡는다** — 프레임류는 *가운데가 투명해야 한다*:
```python
c = a[h//2-10:h//2+10, w//2-10:w//2+10, 3]
if c.min() > 200: print('⚠️ 프레임 가운데가 불투명 — 가짜 체커보드 의심')
```
반투명 밝은 픽셀(헤일로)도 0이어야 한다: `(alpha>8)&(alpha<200)&(rgb.min>=225)` → **0개.**

## ② 잘림 — 숫자로 잡는다
`alpha[0,:]`, `alpha[-1,:]`, `alpha[:,0]`, `alpha[:,-1]` 중 **40 넘는 값이 있으면 잘린 것**이다.
```python
edge = max(a[0,:].max(), a[-1,:].max(), a[:,0].max(), a[:,-1].max())
if edge > 40: print('⚠️ 테두리에 그림이 닿음 — 잘렸다')
```
- 격자 컷은 **전체 이미지에서 라벨링 → 무게중심으로 셀 배정**(`slice_grid`). 셀부터 자르면 격자선 넘은 부분이 통째로 사라진다.
- **버린 위성 조각(하트·반짝임·김) 경고를 꼭 읽을 것.** `keep_frac`은 *제일 큰 덩어리 대비* 비율이라
  `min_area`를 낮춰도 안 살아난다 → 조각이 중요하면 `keep_frac`을 0에 가깝게.
