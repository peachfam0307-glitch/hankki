## 2. ⭐ 제일 값진 한 걸음 — 「숫자를 일정과 맞춰 쪼갰다」

`이달: { 보냄 3, 성공 2, 만료삭제 1, 실행 3, 임박보냄 2, 임박성공 1 }` 은 **한 달 누적**이라
그대로는 「오늘 보냈나」를 못 말한다. 그래서 **일정표와 맞춰 쪼갰다.**

- 9/22 는 `push-schedule.mjs` 로 확인하니 **일정이 없는 날** → 임박(09:00) 갈래 → 실행 1
- 9/21 17:00 은 크론이 19:31 에 걸려서 **못 잡음** → 실행 0
- 남은 **실행 2 · 보냄 3 · 성공 2 · 만료삭제 1** 이 통째로 **9/23 17:00** 이다

👉 **워커는 오늘 깨어나서 진짜로 보냈다.** 이게 아니었으면 크론을 또 만지러 갔을 것이다.

⭐ 배운 것 = **누적값도 «옆 표»와 맞추면 하루치가 나온다.** 새 계측을 심을 필요가 없었다.

## 3. ⛔ 내가 틀린 것 셋 (다 창업자 화면이 깨줬다)

| 내가 말한 것 | 진짜 | 무엇이 깨줬나 |
|---|---|---|
| 「크롬이 요청을 조용히 삼킨다」 | 크롬 창은 **제대로 떴다** | 창업자 캡처(허용/차단 버튼이 보임) |
| 「안드로이드 한끼 앱 알림이 꺼져 있다」 | **이미 켜져 있었다** | 앱 알림 설정 화면 캡처 |
| 「알림 카테고리가 비어서 막힌 것」 | 그건 **정상**(한 번도 안 와서 빈 것) | 캡처 ＋ 안드로이드 동작 |

🌲 **뿌리 = 화면을 받기 «전에» 말한 것이 전부 틀렸다.** 받은 뒤에 말한 것은 전부 맞았다.
   ✅ 그래서 중간부터 **「이 값만 알려줘」로 좁혀 묻는 꼴**로 바꿨고, 그 뒤로 세 번 만에 잡혔다.
   ⛔ 「이럴 겁니다」를 말하지 말고 **「이 칸이 뭐라고 적혀 있어?」**를 묻는다.

## 4. ⭐ 진짜 범인 — WebAPK

크롬 「사이트 설정 → 알림」이 스위치가 아니라 **↗ 「한끼 …에서 관리함」** 이었다.
한끼가 홈 화면에 «설치»돼 있으면(WebAPK) 그 주소의 알림 권한이 **안드로이드 앱 소관**으로 넘어간다.
창업자는 **크롬 탭**에서 켜려 했고, 탭 쪽 `Notification.permission` 은 영영 `default` 였다.

✅ **홈 화면 🐻 아이콘으로 열자마자 `granted`.**

⚠️ **이건 유저에게도 그대로 일어난다** — 그리고 우리가 «홈 화면 설치»를 권하고 있다.
   설치한 유저가 시트에서 「예」 를 눌러도 폰이 막으면 **「알림을 켜지 못했어요」 한 줄**만 뜬다.
   왜 안 되는지 아무도 모른다. → 내일 고칠 것 ⓑ.
