# 📣 인스타 홍보 시안 — 통하는 공식 ＋ 검수 기준

> 2026-08-20 · 앱 v11.17 · ⭐**이 문서가 현행이다**
> 시안은 창업자가 지피티로 뽑고, 클로드가 **실물 대조로 검수**한다.
> ⛔ 시안 이미지는 저장소에 안 넣는다(공개 저장소) — **판정과 값만** 적는다.

## ⭐⭐⭐ 1. 통하는 공식 = 「컨셉이 먼저 · 캐릭터가 연기 · 앱은 소품」

**8/20 하루에 시안을 열 장 넘게 뽑았는데 통한 건 셋뿐이었다.** 그 셋의 공통점이 이것이다.

| | 떨어진 시안들 | ✅ 통한 셋 |
|---|---|---|
| 앱 화면을 | **가운데 크게 «전시»** | **세트장 «소품»**(브라운관 안 · 체육관 모니터 · 책상 위) |
| 글은 | 「이 앱은 ○○을 해줍니다」 **설명** | 캐릭터 **대사·상황** |
| 캐릭터는 | 서 있다 | **뭘 하고 있다** |
| 읽히기를 | 광고 | **장면** |

📮 창업자 = *"근데 있자나 별로 안예뻐 ㅋㅋㅋ 지금 시안 많이 뽑아봤는데 맘에드는게 없어서
   인스타 홍보 못할지도 몰라"* → *"지피티 수정 4개는 일단 보류할게. **너무 밋밋해서 ㅋ**"*
→ 그 뒤 컨셉을 씌운 셋이 전부 통과했다(*"ㅋㅋㅋㅋㅋㅋㅋㅋ"* · *"시안 너무 좋다"*).

⭐ **밋밋함의 뿌리 = 「설명」이다.** 사람은 설명을 넘기고 장면에서 멈춘다.

### 🎭 결이 둘이고 둘 다 필요하다
- **웃긴 것**(홈쇼핑 · 에어로빅) → 좋아요·댓글
- **찡한 것**(엄마 노트) → **저장·공유**
⭐ 섞어 쓴다. 하나로만 가면 계정 결이 납작해진다.

## 📏 2. [창업자 기준 · 2026-08-20] 「읽히는 글자」와 「분위기 글자」를 갈라서 본다

📮 창업자 = *"**너무 작은거는 패스하자 나도 못찾았어 잘 안보이지않아??**"*

> **확대 안 하고 읽히면 → 고친다 / 확대해야 겨우 보이면 → 패스**

⭐ **왜** = 유저는 인스타에서 손가락으로 확대 안 한다. 스크롤하다 0.5초 보고 지나간다.
⛔ **분위기 글자까지 파면 시안 한 장에 트집이 스무 개 나온다.** 그럼 검수가 시끄러워져
   **정작 중요한 걸 놓친다**(「시끄러운 게이트는 죽은 게이트」와 같은 뿌리).

| 갈래 | 예 | 처리 |
|---|---|---|
| **읽히는 글자** | 제목 · 말풍선 · 하단 띠 · 앱 화면의 큰 버튼 | ✅ 실물 대조 |
| **분위기 글자** | 브라운관 «안» 축소된 앱 화면 · 본문 설명 줄 | ⛔ 패스 |

⛔⛔ **[내가 틀린 것] 「무리집레시피」를 지적했는데 «내 눈으로 원본을 확인한 게 아니었다».**
   앞선 세션 메모에 *"「무리집레시피」로 보인다"* 라고 적힌 걸 **확정처럼 옮겼다.**
   창업자가 *"나도 못찾았어"* 로 잡았다. 📌**규칙 21(열어서 본다)·15(확인 후 말한다) 위반.**

| ② | **카롱의 집밥 에어로빅** (80년대 체육관) | 요리 타이머 | ✅ 고칠 것 없음 |
| ③ | **엄마는 노트에, 나는 폰에** | 한끼 일기 | ⛔ **노트 손글씨 거울글씨** ← 하나뿐 |

### ⛔ ③ 고칠 것 = 노트 손글씨 좌우 반전
- 꼬르곰 앞 노트 글씨가 **거울상**이다(「8/20 볶음면」 등). **시안 한가운데라 확대 없이 보인다.**
- ⭐ **오른쪽 「비빔국수」 메모지는 정상** — 그건 살린다(한쪽만 제대로면 대비가 산다).
- ✅ **처방 = 글자를 빼는 것** — AI 는 한글 손글씨를 다시 뽑아도 또 뒤집는다.
  **글자가 없으면 뒤집힐 게 없다.** 노트를 거의 비우고 **펜 끝만 종이에 닿게**
  → 「지금 쓰는 중」이 오히려 더 살아나고 오른쪽 폰과 대비도 는다.

## 🔢 4. 실물 대조로 «확인된» 값 — ⛔다시 재지 말 것

### ⏱ 타이머 화면 (`src/components/TimerSheet.jsx` · `src/timer.jsx`)
시안 ②가 **거의 한 글자도 안 틀렸다.** 지피티가 우리 UI 캡처를 실제로 보고 그렸다.

| 실물 | 값 |
|---|---|
| 머리말 | 「타이머 맞추기」 · 「닫기」 |
| 빠른 버튼 | `PRESETS = [1,3,5,10,15,30]` → **3×2 배열** |
| 스테퍼 | − **5**분 + : − **0**초 + (기본값) |
| 안내 | 「끝나면 이 소리로 알려드려요」 / 「눌러서 미리 들어볼 수 있어요」 |
| **알림 소리 다섯** | **딩동 · 뾰로롱 · 삐약삐약 · 마림바 · 종소리** → 폰 폭에서 **4+1 줄바꿈** |
| 시작 버튼 | 「5분 시작」 |
| 꼬리말 | 「소리와 진동으로 알려드려요」 / 「다른 화면에 있어도 울려요」 |

⭐ **「뾰로롱」이다** (`timer.jsx:34` · **ㅗ 아니라 ㅛ**). 시안은 「뽀로롱」.
✅✅ **[창업자 판정 2026-08-20] 이 오타는 «패스». ⛔재론 금지** (*"뽀로롱도 걍 넘어갈게 ㅋㅋ"*)

### 📔 한끼 일기 화면 (`4-diary/1-calendar.png`)
시안 ③이 실물과 맞는다 — 세그먼트 [모아보기 | 한끼 일기] · 「2026년 8월 · 0번」 ·
**20일 테두리**(오늘) · **19일 연필 아이콘** · 「오늘 일기 쓰기」 · 「이번 달 0번 · 총 0개 · 일기 1일」.
⛔ 어긋난 작은 글자 둘(「**속지를 고르고**」→「숙제로 고고」 · 그 아래 문단)은 **위 기준으로 패스.**
⚠️ 상단 아이콘도 실물은 **「?」 도움말**인데 시안은 톱니 — 작아서 패스.
