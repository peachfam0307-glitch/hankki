## 1. 🎬 화면 — 「몇 명이 어디를 봤고 얼마나 머물렀나」

`src/stats.js` 의 `화면봄(이름)` 이 보낸다. **자물쇠가 있어 아래 열다섯만 나간다.**

| 갈래 | 이름 |
|---|---|
| 탭 일곱 | `home` `search` `myrecipes` `log` `shop` `brag` `profile` |
| 쌓이는 화면 여덟 | `import` `detail` `editor` `inbox` `favorites` `cooked` `cook` `diary` |

⭐ **한 화면에 세 값이 같이 나온다** — 조회수 · 활성 사용자 · 사용자당 평균 참여 시간.
　 ＝ 창업자가 말한 **「몇 명이 봤고 얼마나 머물렀나」가 이미 잡히고 있다.** 캡처 「애널리틱스 — 이름」이 그 표다.
⚠️ 조회수에 꾸미기(`decor`·`decor_saved`)가 **섞여 있다** — 화면이 아니라 서랍인데 같은 통로로 보낸다.

## 2. 🖐 행동 — 「무엇을 했나」

| 흐름 | 이벤트 | 무엇을 아나 |
|---|---|---|
| 가져오기 | `import_share` `import_photo` `import_gallery` `import_write` → `import_read_ok`/`import_read_fail` → `recipe_saved` | 어느 길로 넣었나 · 읽혔나 · 저장까지 갔나 |
| 요리 | `cook_started` → `cook_done` · `cook_long_<자리>` | 끝까지 갔나 · 어디서 오래 켜 두나 |
| 꾸미기 | `decor`(열었다) · `decor_saved`(붙였다) · `decor_have_1`/`_2_4`/`_5plus` | 열고 안 붙인 비율 |
| 장보기 | `shop_added` · `pick_open` · `buy_pick_detail`/`buy_pick_shop`/`buy_cart` | **어느 자리에서** 사러 나갔나 |
| 자랑 | `brag_shared` | 실제로 내보냈나 (🔴 며칠째 0) |
| 일기·냉장고 | `diary_new` · `pantry_added` | |
| 검색 | `search_empty` | 찾다가 빈손으로 끝났나 |
| 가입·재방문 | `first_open` · `signup_*`/`login_*` · `login_ok` · `return_d1`/`return_d2_7`/`return_d8plus` | 새 사람인가 · 며칠 만에 왔나 |
| 징검다리 | `bridge` `bridge_go` `bridge_ios` `bridge_go_ios` | 광고 → 설치로 건너갔나 |

⛔ **안 보내는 것** = 무엇을 꾸몄는지 · 어느 레시피인지 · 무엇을 샀는지 (개인정보 규칙).
