## 1️⃣ 🚨 오늘 리서치로 새로 안 것 «넷» — 전부 설계를 바꿨다

### ① ⛔⛔ `signInWithRedirect` 는 **우리 환경에서 깨진다** (제일 큰 것)
> Firebase 공식 = *"`signInWithRedirect` 는 앱의 Firebase Hosting 도메인에 붙는 **cross-origin iframe** 을 쓰는데,
> **서드파티 저장소 접근을 막는 브라우저에서는 이 방식이 동작하지 않는다.**
> **2024-06-24 부터 Chrome M115+** 에서 권장 옵션 중 하나를 적용해야 리다이렉트 로그인이 동작한다
> (Firefox 109+ · Safari 16.1+ 는 이미 그랬다)"*

⛔ **우리는 정면으로 걸린다** — 앱이 **GitHub Pages**(`peachfam0307-glitch.github.io`)에 있고 **Firebase Hosting 을 안 쓴다.**
   📌 그냥 만들었으면 **창업자 폰에서 로그인이 안 되는 걸 나중에 발견**했을 자리다.

✅ **길 둘**
| | 방법 | 좋은 것 | 걸리는 것 |
|---|---|---|---|
| **ⓐ** | **`signInWithPopup`** | 공식 1순위 권장 · **서드파티 쿠키를 안 쓴다** · 코드가 제일 짧다 | ⛔**TWA 안에서 팝업이 도는지 «모른다»** — 실물로 재야 한다 |
| **ⓑ** | **8/19 흐름 재사용** — 우리가 직접 `id_token` 을 받아 **`signInWithCredential(GoogleAuthProvider.credential(id_token))`** | ⭐**이미 실물로 통과한 길**(창업자 폰 · 8/19 저녁) · 쿠키 문제와 무관 | 코드가 조금 더 · 토큰 받는 부분을 우리가 짠다 |

⭐ 공식 확인 = *"Google ID 토큰을 받은 뒤 `GoogleAuthProvider.credential(id_token)` 으로 Credential 을 만들고
   `signInWithCredential(auth, credential)` 로 로그인한다 … **팝업이나 리다이렉트에 의존하지 않고** 토큰 획득을 우리가 통제한다"*
👉 **판정 = 실물로.** ⓐ를 판으로 만들어 창업자 폰에서 «한 번» 눌러 보고, 안 되면 ⓑ. **8/19 와 똑같은 방식**(규칙 15).

### ② ⛔ Firestore **문서 하나 = 최대 1 MiB** → 백업 JSON 을 «통째로» 못 넣는다
🔢 레시피 한 편 ≈ **1.46KB**(실측) → 글자만 쳐도 **685편이면 한계**. ＋꾸민 것·일기까지 한 문서에 넣으면 훨씬 빨리 찬다.
✅ → **레시피 한 편 = 문서 한 개**로 쪼갠다(아래 3️⃣).

### ③ 무료(Spark) 한도 = **저장 1 GiB · 읽기 50,000/일 · 쓰기 20,000/일**
⭐ 넉넉하다 — 다만 **로그인할 때마다 전부 읽으면** 레시피 200편 = 200 읽기다.
✅ → **「마지막 동기화 뒤에 바뀐 것만」** 읽는다(`updatedAt` 기준). 그러면 평소 읽기가 한 자릿수로 떨어진다.

### ④ ⛔ **OAuth 동의 화면을 「게시」해야 한다** (⚠️우리 문서 두 곳이 정반대였다)
| 테스트 모드로 두면 | |
|---|---|
| 유저 수 | **100명 하드캡** — 넘으면 로그인 자체가 안 된다 |
| 로그인 유지 | **7일 뒤 만료** — 일주일마다 다시 로그인 |

✅ **검증(2~6주)은 «안» 걸린다** — *"기본 권한(`openid`·`email`·`profile`)만 쓰는 외부 앱은 **검증 없이 게시**할 수 있다"*.
   우리는 로그인만 쓰므로 그 조건에 딱 맞는다.
⛔ `출시행정-학습:1809` 의 *"「게시·프로덕션으로 푸시」 누르지 마"* 는 **8/19 «실험» 단계 얘기**였다.
   ⭐ **모순이 아니라 시점이 달랐다** — 실험 = Testing / 서비스 = In production. 📌**말을 옮길 땐 «언제의 말인지»를 같이 옮긴다.**

## 3️⃣ 🗂 데이터 모양 — 「쪼개되, 합치면 백업 JSON」

```
users/{sub}/                 ← 🔒 열쇠 = 구글 고유번호 sub (보험 ① · ⛔Firebase UID 금지)
  meta                       profile · folders · shops · wishlist · shoppingList · pantry
                             · seedV · memoCleanV · removedSeedIds · _v · updatedAt
  recipes/{id}               레시피 한 편 = 문서 한 개  (⛔ image 뺀 것)
  diary/{id}                 일기 한 장 = 문서 한 개    (⛔ photo 뺀 것)
```

⭐⭐ **쪼개도 보험 ②가 안 깨진다** — 문서 하나하나가 **백업 JSON 배열의 원소와 «같은 모양»**이라
   내려받아 합치면 **백업 JSON 이 그대로 나온다.** 🅱(D1)로 이사 갈 때도 그대로 올리면 끝.
⛔ **사진은 안 올린다**(창업자 확정 「글자부터」) — 폰 안과 백업 파일에 그대로 남는다.
📌 문서마다 **`updatedAt`** 을 박는다 — ③의 「바뀐 것만 읽기」가 여기에 걸린다.
