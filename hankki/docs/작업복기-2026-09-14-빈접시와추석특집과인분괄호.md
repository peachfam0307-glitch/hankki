## 6. 🍚 인분을 바꿔도 «괄호 안»이 안 바뀌던 것 (v13.36)

📮 창업자 = *"인분고칠때 괄호안에들어간 설탕이나 대체재료는 안고쳐짐"* → *"응 고치자 제대로고칠수있어?"*

🌲 **뿌리 = 수량 계산이 줄에서 «첫 숫자 하나»만 바꿨다**(`src/scale.js`).

🔢 **실측 = 재료 1029줄 중 괄호 안에 숫자가 있는 줄 78개(7.6%)**
```
아우노슈가 3큰술 (설탕 2큰술)  × 2  →  아우노슈가 6큰술 (설탕 2큰술)   ← 설탕이 그대로
```
⭐ **설탕으로 만드는 사람은 절반만 넣는데 화면은 «다 바뀐 것처럼» 보인다** — 알아챌 방법이 없다.

### ⛔ 같이 찾은 것 — 이게 더 나빴다
```
아우노슈가 1과1/2큰술  × 2  →  아우노슈가 2과1/2큰술   ← 「1」만 곱했다
```
**늘어난 게 아니라 «틀린» 값**이다. 혼합수를 한 수로 읽게 고쳤다.

### ⭐ 무엇을 «안» 곱하나 — 근거는 우리 규격 문서다
`docs/레시피-작성-규격.md` §1 계량 단위 표가 **온도는 「도」·시간은 「분」·비율은 「1:1」** 로 쓰라고 못 박아 두었다.
→ **그 셋은 곱하면 안 된다.** 반대로 **「1컵(200ml)」 같은 병기는 곱해야 맞다**(같은 표가 그렇게 쓰라고 시킨 것이다).

✅ 그래서 **「곱해도 되는 단위」에 든 것만** 곱한다 — 막을 것을 세는 게 아니라 **허락할 것을 센다.**
⛔ 모르는 단위는 **원문 그대로 둔다** — 조용히 틀린 값보다 원문이 낫다(눈으로 판단할 수 있다).

### 확인
- 설계 관문(`design-gate`) 통과 — 사람·사고·규모 셋 다 «고칠 것»이 나왔다
- 재현판 `_repro-인분괄호-0914` = **고치기 전 8/16 → 고친 뒤 16/16** · 스모크에 등록
- **전수 확인** = 괄호줄 78개 중 **76개가 바뀌고 2개는 일부러 안 바꿨다**
  - 「또띠아 2~3장(20cm)」 = 크기라 안 바꾸는 게 맞다
  - 「올리브오일 1과1/2큰술(버섯 1/2 + 고기 1)」 = «나눠 쓰는 몫»인데 **단위가 없어 판단 불가** → 원문 유지(⏳표기를 고칠지 창업자 판정)
