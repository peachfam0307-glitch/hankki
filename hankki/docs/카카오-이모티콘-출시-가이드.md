# 카카오 이모티콘 출시 가이드 (조사 2026-07-18)

> 곰곰이를 카톡 이모티콘으로 내는 계획의 실제 절차·규격·정산·"앱 연결" 규정 조사.
> **핵심 결론: 이모티콘은 "IP·브랜드 인지도(장기)" 플레이지, 초기 수익원/직통 설치 깔때기가 아님.** 테스트·앱 출시 이후 단계.

## ⚠️ 카톡 이모티콘은 2갈래 (이게 "연결" 답을 가름)
| | 창작 이모티콘 | 브랜드 이모티콘 |
|---|---|---|
| 경로 | **이모티콘 스튜디오**(무료 제안) | 카카오 비즈니스(**유료 광고상품**) |
| 브랜드명·로고 | **불가** (순수 감정/상황만) | 가능(로고 포함 3개 이하) |
| 외부링크(앱 연결) | **불가** | **가능**(이벤트/브랜드 URL 연결) |
| 비용/수익 | 무료 제안, 팔리면 정산 30% | 카카오에 **돈 내고** 뿌리는 광고(비쌈) |
| 우리 단계 | ✅ 이 길 | ❌ 대기업 마케팅용, 지금 아님 |

→ **우리는 "창작 이모티콘"**. 근데 창작 route는 **이모티콘 안에 링크·브랜드명 못 넣어.** 그래서 앱 연결은 **브랜드 방식(곰곰이=한끼 인지 + 곰곰이 SNS 프로필에 앱링크)으로만**. (직접 링크는 유료 브랜드 이모티콘에서만 되는데 그건 광고비라 지금 아님.)

## 제작 규격 (창작)
- **멈춰있는 이모티콘**: 32종 · PNG(투명배경) · 360×360px · 개당 150KB 이하 · 75dpi
- **움직이는 이모티콘**: 24종 = PNG 21 + GIF 3 · 360×360px · 개당 2MB 이하 · 72dpi (GIF는 24프레임 이하 권장)
- 모든 컷은 **감정/상황을 직관적으로** — 대화에 바로 쓸 수 있어야 함(홍보문구·브랜드명 X)

## 출시 절차 & 기간
1. 이모티콘 스튜디오에서 **제안** (무료)
2. **심사 2~4주** — 창의성·완성도·시장성·적합성 (창의성 最중요)
3. 승인 시 **작가 계약 + 상품화**(디자인 다듬기) 1주~수개월
4. **매주 화요일** 신규로 스토어 출시
5. 정산: 판매집계 익일 / 정산 월단위 / 입금 그 다음 달
- **제안→입금까지 넉넉히 6~8개월+**

## ⚠️ 통과율 = 바늘구멍
- 성공작가 김나무: **64개 승인받는 동안 135개 미승인**. 초심자는 여러 번 떨어지는 게 정상.
- 승인율 매우 낮음 = "마의 구간". 여러 번 도전 각오.

## 정산(수익) 구조 — 개별 판매 기준
- 2,500원 판매 시: 구글/애플 인앱 30%(750) + 카카오 40%(1,000) 제외 → **작가 750원(=30%)**
- 고정 수수료 vs 수익 비율 중 선택 가능. 구독(이모티콘 플러스) 풀은 **사용량 비례** 배분.
- (참고: 웹 직판이 아니라 카톡 인앱이라 30% 스토어 수수료를 못 피함 → 앱 자체 웹결제보다 정산률 낮음)

## 그래서 전략적 위치 (정직하게)
- 이모티콘 = **초기 수익원 아님**(정산 30%·6~8개월·통과율 낮음). **IP·브랜드 인지도 장기 투자 + 바이럴 씨뿌리기.**
- 앱 연결은 **직통 파이프 없음** → ① 곰곰이=앱 마스코트 동일성 ② 작가명 "한끼" ③ **곰곰이 SNS(프로필 앱링크) = 유일한 클릭 다리** ④ 앱↔이모티콘 크로스프로모션.
- **타이밍: 앱 테스트(7/31)·출시 이후.** 지금은 곰곰이 성격·표정 세트만 개념적으로 준비해두면 충분.

## 우리에게 유리/할 일
- 곰곰이 = 이미 있는 IP. 이모티콘 1세트 = **곰곰이 표정·상황 24~32컷**(요리 상황으로 → 요리앱 연상).
- SVG 자산 있어서 360×360 PNG 굽기 쉬움. 움직이는 것보다 **멈춘 32종부터**가 진입 쉬움.
- 곰곰이 성격(배고픈·허당 곰) → 표정 컨셉안 짜두기.
