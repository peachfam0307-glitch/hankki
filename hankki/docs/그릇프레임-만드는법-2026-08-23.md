## 2️⃣ 자를 때 — 명령 두 줄

```bash
# ① 배경이 순백이 아니면 «먼저» 편다 (⛔자르기 도구는 안 건드린다 · 창업자 2026-08-18)
python3 tools/시트-배경펴기.py <시트.png> <편시트.png>

# ② 표준 도구로 자른다 — ⭐그릇 프레임은 --drop 0
python3 tools/cut.py <시트.png> <낼폴더> <접두어> --diecut 5 --drop 0 --join 1

# ③ 회색 창을 뚫는다
python3 tools/그릇-창뚫기.py <낼폴더>
```

⛔⛔ **`--drop 0` 이 «반드시» 필요하다.**
`--drop` 은 「본체에서 떨어진 작은 조각은 뗀다」인데 **그릇 프레임은 가운데가 뚫린 «고리»**라
도구가 접시 **테**를 조각으로 오해한다.
🔢 실측 = `pb_o01` 보이는 넓이 **31%(테 없음)** → `--drop 0` 으로 **69%(온전)** · `pb_o04` **11% → 68%**

⛔ `cut.py --frame` 은 쓰지 않는다 — 그건 가운데 **순백**을 번지게 하는데 우리 창은 **연회색**이다.

## 3️⃣ 앱에 붙일 때 — 규칙 셋

### ⓐ 창을 «진갈색 선 바깥»까지 뚫는다 (도구가 `--grow 7` 로 한다)
🔢 실측(주름 접시) = 창 반지름 158px · 선 164px → 덮으려면 **3.8%** 필요한데
오버스캔 3%(163px)면 **1px 차이로 못 덮어** 선이 사진 둘레에 **링**으로 남는다.
📌 **그 선은 「남길 무늬」가 아니라 「자를 때 쓰는 길잡이」다.**
⛔ 앱 오버스캔으로 덮는 길은 접었다 — 프레임마다 필요한 양이 달라 하나는 반드시 어긋난다.

### ⓑ 사진을 «창 모양 그대로» 오려낸다
⛔ `border-radius: 50%` 로 자르면 **사각·삼각·오벌 접시는 네 귀퉁이가 빈다.**
✅ 뚫을 때 찾은 **창 마스크**를 그대로 CSS `mask-image` 로 쓴다.

### ⓒ 「닿는 그림자」는 그림이 아니라 코드로 얹는다
창업자가 요구한 *"안쪽 림 바로 아래 아주 약한 음영"* 을 지피티는 **그림에 그려 넣는데**,
그 음영이 회색 창 «위»에 있어 **창 뚫기가 통째로 지운다.**
✅ 그래서 얹는다 — 프레임마다 다시 안 그려도 되고 세기도 조절된다.
```css
box-shadow: inset 0 6px 14px rgba(60,42,28,.34), inset 0 -3px 9px rgba(60,42,28,.16);
```

### ⛔ ＋ 프레임을 «늘리지» 않는다
🔢 `pb_o03` 은 **566×418** 인데 360×360 정사각에 넣으면 세로로 **1.35배** 늘어난다.
1~2px 선이 방향마다 다른 두께가 되어 **파먹힌 것처럼 보인다**(창업자가 잡았다).
✅ 그리는 칸을 **컷의 가로세로 그대로** 만든다.

## 7️⃣ 🍽 접시 «바닥»이 한 입 베어 문 듯 깨지던 것 — 뿌리는 `--drop` 이었다 (2026-08-26 · ⭐현행)

### 뿌리 (실측으로 확정)
```

```
`--drop` 이 조각을 **하나라도** 버리면 그 아래에서 **실루엣을 이 236 문턱으로 다시 짠다.**
그런데 흰 접시의 **바깥테·굽이 237~249** 라 그 문턱을 넘는다 →

1. 236 아래로 내려온 픽셀만 **2~9px 짜리 점점이 30여 개**로 흩어지고
2. `--drop` 이 그 점들을 「조각」으로 보고 버린 뒤 **실루엣을 다시 짜서 접시테가 통째로 깎였다**

🔢 브라우니 **1,707px** · 수박화채 **1,289px** · 108컷 합계 **85,524px**

⭐⭐ 같은 뿌리가 **딸기라떼 유리잔 구멍**도 만들고 있었다 — 잔 벽이 같은 밝기라 같은 자리에서 뜯겼다.
   **하나를 고치니 둘이 같이 나았다.**

### 고침 — 둘을 «같이» 한다 (하나만으론 안 된다)
```
python3 tools/시트-접시굽-눌러주기.py <시트> <낼파일> 2 3 0.30
python3 tools/cut.py <눌린시트> <낼폴더> <접두어> --diecut auto --drop 0
```

① **바닥 띠(아래 30%)에서만** 몸통의 237~249 를 235 로 눌러 점점이가 «한 덩어리»가 되게 한다

② `--drop 0` = 버릴 조각이 없으니 **실루엣을 다시 짤 일이 없다** → 접시테가 그대로 산다
   ⛔ ①없이 `--drop 0` 만 주면 그 점점이가 «떨어진 조각»으로 남아 절대원칙에 걸려 죽는다(실측 4/6)
