  👉 **실물로 확인** = 창업자가 파트너스 사이트 → 「링크 생성 → API」(또는 비슷한 이름) 메뉴가 **열려 있는지 캡처 한 장**. 열려 있으면 지금 키를 받을 수 있다.

- 사진 = API 가 주는 URL 을 «그대로» 쓴다(저장 ✗ · 편집 ✗). 지금 우리가 하는 «옮겨 적기»와 반대 — 이건 쿠팡이 «쓰라고 주는 것».

## 두 번째 답 (챗지피티 · 2026-09-17 14:31) — ⚠️ 첫 답과 «갈리는» 곳이 있다
- **발급 조건** = *"파트너스 API는 최종 승인 된 쿠팡 파트너스 회원에게만 제공됩니다"* (API 가이드 인용 · 판 미상).
  승인 전에 꼭 필요하면 **AF ID ＋ 광고 게재 영역·형태를 보내 별도 검토**받는 길이 있다고 한다.
  ⚠️ 퍼플렉시티는 「조건 확인 안 됨」이라 했다 — **둘 다 요약이고, 근거 PDF(2025-07-14 판)는 우리 현행(2025-10-28)보다 옛것.**
  이 환경에선 그 PDF 를 못 연다(curl 000). ⛔둘 중 하나를 골라 단정하지 말 것 → **창업자 화면이 답이다**(API 메뉴가 열려 있나).
- **상품 검색 API 응답** = productId · productName · **productPrice** · **productImage** · productUrl(제휴 링크) · isRocket · isFreeShipping · rank.
  **딥링크 API 는 URL 변환만**(originalUrl→shortenUrl) — 사진·가격은 안 준다. 우리는 «검색 API»를 쓴다.
- **이미지 표시** = 공식 가이드 문구 *"회원님의 웹 사이트나 어플리케이션에 알맞게 적용할 수 있는 쿠팡 상품 정보를 … 제공"* → 등록된 앱에서 상품 카드로 쓰는 건 용도에 맞다.
  ⛔ 다만 productImage 는 **대표 사진 한 장** — 뒷면 원재료 라벨은 API 가 안 준다. 원재료는 지금처럼 «글자로 옮겨 적기»가 그대로 남는다.
  ⛔ 이미지 파일을 우리 서버(R2·Firebase)에 영구 복제 = 명시 허용 없음 → **URL 그대로 <img>**.
- **가격** = 호출 시점 값. DB 에 박아 몇 달 보여주지 말 것 · 「가격 및 판매 조건은 쿠팡에서 변경될 수 있습니다」 문구.
- **대가성 고지**는 API 를 써도 그대로 필요(우리 앱엔 이미 있다).
