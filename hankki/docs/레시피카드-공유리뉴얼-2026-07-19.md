# 🃏 레시피카드 공유 리뉴얼 — 계획 (2026-07-19)

> 인스타·SNS 공유 = 유저 획득의 핵심 엔진. 그 무기가 "레시피 카드"다.
> ⚠️ 배포는 창업자 `/픽스` 신호로만. 이 문서는 계획 저장용(창업자 지시).
> 🎨 **미감 기준 높음 · 카드 = 핵심 홍보전력.** 대충 금지 → 트렌드 리서치 후 신중히, 완성본만. (창업자 명시 2026-07-19)

## 🎯 왜 (전략)
- **유저 획득 = 인스타·SNS 공유가 핵심.** 광고 0, 오가닉·바이럴. (→ `메인컨셉-전략.md`)
- 그러려면 **우리 레시피 카드가 "공유하고 싶을 만큼" 경쟁력**이 있어야 함.
- → 어제 만든 **새 꼬르곰·펭펭(고화질)** 을 레시피 카드에 얹고, **"친구랑 공유하기"를 새롭게** 디자인한다.

## ⏸️ 왜 지금 보류인가 (중단 아님 — 순서 대기)
- 스티커 몇 개로 카드 꾸미기를 시도했는데, **파일이 작아서 지저분하고 화질이 별로**였음 → 카드 경쟁력이 안 남.
- **방향을 엎은 게 아니라, 화질(캐릭터 고화질화)이 먼저 끝나야** 카드 작업이 가능. 그때까지 보류.
- 📌 정정: 지난 **"아니야 이거"** = 방향 부정이 아니라 **화질(작은 파일 → 지저분) 문제**였음.

## 🔧 진행 순서
1. **(창업자)** 어제 받은 **최종시안 17종 × 4~5컷 strip(zip)** 으로, **오늘 저녁 9시부터 GPT에서 크게(고화질) 재생성**(수작업·노가다).
   - **우선순위: 카드에 넣을 곰·펭 먼저** 넘김 → 나머지 **꾸미기 재료 그림들은 틈틈이** 작업해서 넘김.
   - 프롬프트 = `자랑공유-캐릭터리뉴얼.md`(곰=연속 외곽선 / 펭=C컬 보브 / 콤비).
2. **(클로드)** 고화질 나오면 → 깨끗이 낱개 컷(투명 PNG). *(시트만 주면 코드로 다 오림 — `tools/cutout-stickers.py`)*
3. **(클로드)** 레시피 카드에 새 캐릭터 반영 + **"친구랑 공유하기" 새 디자인.**
4. **(클로드)** 배경 톤 `#f4f2ee` 등 마감.
5. **(창업자)** 확인 → **`/픽스`** → 배포.

> 🔑 **게이트: 2번(고화질 캐릭터)이 끝나야 3번(카드)이 돌아간다.** 지금은 1번 진행 중.

## 🎴 레시피 카드 디자인 (확정 방향 — 창업자 피드백 반영)
| 피드백 | 반영 |
|---|---|
| 레꾸(표지) 너무 안 보임 → 키워 | **표지가 카드의 주인공** — 카드의 **반 이상** 차지 |
| 그 안에 스티커 붙여 | **곰·펭을 요리 양옆에 크게** 얹음 (바닥 **그림자**로 붕 안 뜨게) |
| 곰·펭 깨져 보임 | **개별 스티커**로 (콤비보다 훨씬 선명). 요리 아이콘은 **SVG라 원래 무한 선명** |
| 레시피 작게 | 밑에 **제목 + 정보 + 재료 한 줄 + "5단계는 앱에서"** 만 |
| 글씨 다 따로 놈 | **주아 하나로 통일**(제목·"한끼"·브랜드), **본문만 고운돋움** |
| 배경 화이트톤 | 표지 배경 = **화이트 + 살짝 크림** |

- **카드 전체 배경색 = `#f4f2ee` (확정)** — 웜기 살짝 남긴 중립(곰 따뜻 + 펭 깔끔 둘 다 삼).
- 백업 = `#f3f4f4`(제일 밝고 살짝 쿨 — 펭 제일 쨍, 곰도 OK). 저장만 해둠.

## 🏷️ 캐릭터 이름 정리 (혼동 방지)
| 구분 | 이름 | 정체 |
|---|---|---|
| **새 메인 캐릭터 (감정 IP)** | **꼬르곰 · 펭펭** | 엄마(=창업자)·딸. 카드·공유·이모티콘의 주인공 |
| 기존 아바타 (부엌 식구들 8종) | 곰곰이(대파곰) · **튜브펭** · 토토 · 냄비냥이 · 삐약 · 몽몽 · 호두 · 햄찌 | 앱 꾸미기 보너스 스티커 |

- ⚠️ 충돌: 새 IP 펭귄 "펭펭" ↔ 기존 부엌식구 튜브 펭귄도 "펭펭" → 이름 겹침.
- ✅ 정리: **"펭펭" = 새 메인 IP 펭귄 전용.** 기존 튜브 펭귄은 **"튜브펭"** 으로 부른다.
  - 곰은 **꼬르곰**(새 IP) vs **곰곰이**(대파곰)라 안 겹침 ✓.
- (앱 화면에 옛 이름이 뜨는지는 반영 전 확인 — 우선 우리끼리 부르는 이름부터 이걸로 통일.)

## 🔄 앱 학습 후 정정 (2026-07-19)
> 클로드가 실제 앱 화면(스토어 스샷)·공유 코드를 직접 보고 정정.
- **앱 실제 스타일 = 크림톤 + 커스텀 아이콘 + 주아(통통) + 코랄 포인트 + 아기자기.** 실사 사진 카드 ❌ (첫 목업이 폴꾸 실사라 결이 틀렸음 — 정정).
- **카드 = "꾸민 표지 그대로 캡처"가 정답** (흰 바탕 + 아이콘/이모지/글자타일/내 사진 + 스티커·포스트잇·마테 + 곰·펭). = `src/shareCover.js` 컨셉이 이미 맞았음.
  - 창업자 "아니야"는 **컨셉 아니라 화질**(스티커 작아 지저분) → **고화질 곰·펭으로 해결.** 갈아엎기 아니라 **살려서 다듬기.**
- **현재 라이브 공유(`shareCard.js`)** = 아이콘 타일 + 레시피 텍스트 카드(프리텐다드 폰트). → shareCover(꾸민 표지 캡처) 방향으로 전환 예정.
- **🎬 움직이는 공유(모션·효과 캐릭터) = 가능하지만 fast-follow.** 지금 공유는 정지 PNG만(toPng/toBlob 스냅샷)이라 "안 됨"이 맞음. 단 애니메이션을 **짧은 MP4/GIF로 캡처 → 인스타 스토리/릴스** 공유는 기술적으로 가능(폰 인코딩 무겁고 안정성 테스트 필요). **아무도 안 하는 신선 훅 + 우리 캐릭터·모션이 유일 자산 → 출시 후 킬러 후보.**
- **레시피 전체 vs 티저 = 티저 확정(자랑/SNS 카드).** 전체 레시피를 다 보여주면 설치할 이유가 사라짐(획득 0) → 카드 = **꾸민 표지 + 제목 + "전체 레시피는 한끼 앱에서 →"**(호기심 갭·설치 유도). ※ 친구에게 레시피 통째 보내기는 목적이 다른 별도 유틸(나중).
- **⭐ "눈에 확 띄게"(평범함 탈출) 해법**: ① **캐릭터를 크게·주인공으로**(작은 스티커 X — 큐트 캐릭터 IP가 스크롤 스토퍼) ② **딥(어두운) 배경지 옵션**(반짝임·효과 pop, 꾸미기 필살기) ③ **감성 글귀 크게** ④ **모션**(움직이는 버전 = 궁극의 눈길). 첫 목업이 평범한 건 방향이 틀려서가 아니라 **주인공(캐릭터)이 플레이스홀더 + 크림 저대비 + 모션無**라서 — 진짜 화력은 **고화질 캐릭터 + 딥배경 + 모션.**
- **⭐⭐ 근본 해법 = "예쁘게"를 앱이 대신(감성 템플릿·원탭 꾸밈).** 지금 꾸미기는 유저에게 "빈 캔버스 + 스티커 더미"를 줘 **디자인을 시킴** → 취향 좋아도 어려움(창업자도 "내가 꾸민 것도 안 예쁘다"). **해법 = 완성된 감성 템플릿(배경+곰펭 배치+글귀+효과)을 원탭 선택 + 자기 레시피만 얹기.** 창작=앱(클로드 디자인), 선택=유저. → 예쁜 표지 **보장** → 공유 바이럴 발화 + 창작 장벽 제거. **카드 = 사실상 이 템플릿의 결과물.** (in-app 원탭 템플릿 시스템은 fast-follow, 템플릿 디자인은 지금부터)
- **역할**: 창작=클로드(시안 여러 개 던짐), 판단=창업자(고르기). 규칙 8.
