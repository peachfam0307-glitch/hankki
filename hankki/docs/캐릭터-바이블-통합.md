# 🐻🐧 한끼 캐릭터 설정 바이블 — 꼬르곰 · 펭펭

> 통합본 (`캐릭터-설정집` 2026-07-18 + `캐릭터-종합기록` 2026-07-19). 정리 2026-07-21.
> ※ 비주얼 그림체 리뉴얼 진행 중(미확정) — 색·정본은 현재 확정본 기준.

## 🌍 세계관
작은 부엌에서 요리하며 사는 캐릭터. 핵심 = **꼬르곰(엄마·나) × 펭펭(사춘기 딸)** 콤비. **창업자 실화 기반**(지어낸 마스코트가 아님).

## 🐻 꼬르곰 (곰) — 주인공·앱 마스코트
- **한 줄**: 순하고 어리숙한데 **맨날 배고픈** 먹보 순둥이. **F(감정형).**
- 이름 = **꼬르륵(배꼽시계) + 곰** → 성격이 이름에 박힘.
- 늘 난리법석, 뭐 하나라도 맛있는 거 해먹이려 전전긍긍 / 다이어트는 오늘도 실패 / 요리 완성하면 세상 다 가진 표정.
- **감정 크게**(표정 부자). 시그니처 = **셰프모자 + 앞치마 + 나무숟가락.**
- ⚠️ 모자는 감정 따라 붕뜸/처짐/삐뚤 (단, "안테나"라 부르면 방울 그림 → 금지).

## 🐧 펭펭 (펭귄) — 꾸미기 마스코트
- **한 줄**: **쌉T 시니컬 + 겁나 패셔니스타**. 패션엔 진심, 말투는 팩폭.
- 무표정·심드렁, 리액션 최소("맛있어?" "…응."), **근데 속으론 엄마를 사랑함.** 가끔 새어나오는 다정.
- **전략 역할 = 꾸미기 기능 마스코트** — 안경·썬글·베레·가방 등 **패션 소품 무한** → 꾸미기 아이템 콘텐츠 엔진.
- **크기 = 꼬르곰의 2/3**(곰 가슴 높이). 큰 순둥 곰 × 작은 시크 펭 (라이언×춘식 공식).

## ⭐ 콤비 컨셉 = F × 쌉T (밈 엔진)
**엄마(감성 F) × 사춘기딸(팩폭 쌉T)** = 한국 MBTI "F vs T 반응차" 밈 포맷 → 상황별 무한 생산.
- 요리 망함: 곰 "흑 나 요리 못하나봐😭" / 펭 "응 계량을 안 했잖아."
- 배고픔: 곰 "배고파서 힘이 없어🥺" / 펭 "냉장고에 계란 있어."

- **이모티콘**: 꼬르곰 단독 → 꼬르곰×펭펭 콤비 → 확장.
