# 📌 최신 지도 — 「지금 살아있는 것」이 어디 있나

> 창업자 2026-07-31:
> *"최근 건 왜 먼저 안보고 계속 옛날꺼보는거야 뭐든 일하기전에 최근 문서보기로 한거아니었어?"*
> *"규칙만 만들면 뭐해 안지키는데."* → **그래서 규칙이 아니라 검사로 만들었다.**

## 이 문서는 손으로 관리하는 목록이 아니다

날짜(`YYYY-MM-DD`)가 붙은 문서는 **코드가 알아서 최신을 고른다** (`scripts/latest-map.mjs`).
새 문서를 저장하면 그게 자동으로 최신이 된다 — 여기 손댈 필요 없다.

**여기 적는 건 「코드가 못 고르는 것」뿐이다:**
- 날짜가 늦다고 최신이 아닌 것 (확정본이 따로 있는 주제)
- **저장소 밖에 진실이 있는 것** — Play Console·구글폼처럼 파일로는 알 수 없는 자리

## 무엇이 막아주나

| 언제 | 무슨 일이 일어나나 |
|---|---|
| 세션 시작 | 주제별 최신 문서가 자동으로 눈앞에 뜬다 |
| 창업자가 말할 때마다 | 그 말의 주제에 걸리는 **최신 문서**를 먼저 들이민다 |
| `_구판/` 파일을 열려고 하면 | **차단** — 현행 경로를 알려준다 |
| 같은 주제의 **옛 문서**를 열려고 하면 | **차단** — 최신을 먼저 읽어야 열린다 |
| `npm run smoke` | 핀이 낡았거나 옛 세대가 되살아나면 **배포가 막힌다** |
