지금 왜 이걸 재나

클라우드 저장은 로그인 위에 얹혀요. 그런데 한끼 앱 안에서 구글 로그인 창이 뜨는지는 아직 아무도 몰라요 — 공식 문서에도 답이 없어요.

어느 쪽이 나와도 막다른 길이 아니에요. 안 되면 8/19 에 이미 통했던 길로 돌아가면 돼요. 어느 길인지만 정하려고 재는 거예요.
⛔ 이 판은 앱 레시피를 하나도 안 건드려요. 쓰는 곳은 시험용 칸 하나뿐이고, 지우는 단추도 달아 놨어요.

문지기(보안 규칙) 붙여넣기

지금은 모두 막힘 상태예요. 이걸 붙여야 “로그인한 사람이 자기 것만”이 돼요.

Firebase 콘솔 → Firestore Database → 위쪽 규칙 탭 → 있던 글자를 통째로 지우고 붙여넣기 → ［게시］

rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {

    function isGoogleUser() {
      return request.auth != null
          && request.auth.token.firebase.sign_in_provider == 'google.com';
    }

    function googleId() {
      return request.auth.token.firebase.identities['google.com'][0];
    }

    match /users/{gid} {
      allow read, write: if isGoogleUser() && googleId() == gid;

      match /{doc=**} {
        allow read, write: if isGoogleUser() && googleId() == gid;
      }
    }
  }
}

⭐ 문에 붙은 이름표는 구글 고유번호예요 — 파이어베이스 전용 번호가 아니고요. 나중에 파이어베이스를 떠나도 그 번호는 그대로라서, 데이터를 통째로 들고 나갈 수 있어요.

⚠️ ［게시］까지 눌러야 살아나요. 저장만 하면 안 붙어요.

동의 화면 열기

⛔ 헷갈리는 자리 — 전에 “게시 누르지 마”라고 적어 뒀던 건 8/19 «실험»할 때 얘기예요. 지금은 진짜로 서비스하는 거라 눌러야 해요.
