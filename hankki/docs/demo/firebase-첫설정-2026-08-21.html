Firebase 첫 설정

저녁에 10분. 이거만 끝나면 나머지는 내가 만든다.

고른 짝 🅰 파이어베이스 (2026-08-20 확정) 카드 0원 계정 창업자 것으로

⛔ 딱 하나, 되돌릴 수 없는 선택

Firestore 「위치(리전)」는 한 번 정하면 못 바꾼다

공식 문서 그대로야 — “데이터베이스를 만들고 나면 위치 설정을 변경할 수 없습니다.” 프로젝트를 지우고 새로 만드는 것 말곤 방법이 없어.

그 칸에 이걸 골라:

asia-northeast3 (서울)

목록이 길어서 눈에 잘 안 띄어. 「asia」로 시작하는 것만 세 개가 붙어 있는데 — northeast1은 도쿄, northeast2는 오사카, northeast3이 서울이야. 숫자 하나 차이라 제일 틀리기 쉬운 자리.

⚠️ 서울로 해도 로그인(Auth)은 미국에서 처리돼. 그건 못 바꾸는 거고, 개인정보 처리방침에 그렇게 적으면 돼 — 내가 쓸게.

순서

console.firebase.google.com 에서. 네 구글 계정으로 로그인한 채로.

  1. 1

    프로젝트 만들기

    프로젝트 만들기 → 이름은 아무거나(예: hankki)

    Google 애널리틱스는 꺼도 돼 — 우리는 안 쓰고, 켜면 계정 연결을 또 물어봐서 길어져.

    왜 네 계정이냐면 — 명의 이전은 Play 개발자 계정 하나만 바꾸기로 했잖아. GitHub·Cloudflare가 네 명의인 것처럼 Firebase도 네 계정이야. 남편 계정은 Play 전용.
  2. 2

    Firestore 만들기 — ⛔ 여기가 그 자리

    왼쪽 메뉴 빌드 → Firestore Database → 데이터베이스 만들기

    물어보는 게 둘이야:

    ① 위치 → asia-northeast3 (서울) ⛔되돌릴 수 없음
    ② 모드 → 「프로덕션 모드로 시작」(＝잠금)

    ⛔ 「테스트 모드」를 고르지 마 — 30일 동안 아무나 읽고 쓸 수 있게 열려. 잠금으로 시작하고, 규칙은 내가 짜서 줄게.

  3. 3

    구글 로그인 켜기

    빌드 → Authentication → 시작하기 → Google → 사용 설정

    「프로젝트 지원 이메일」을 하나 고르라고 해 — 안녕한끼 계정으로 하면 딱 좋아(스토어 연락처랑 같아서).

  4. 4

    ⭐ OAuth 동의화면을 「게시」한다

    이게 오늘 리서치로 새로 찾은 거야. 안 하면 나중에 크게 걸려.

    테스트 모드로 두면무슨 일
    유저 수100명이 하드캡 — 넘으면 로그인 자체가 안 된다
    로그인 유지7일 뒤 만료 — 일주일마다 다시 로그인하라고 뜬다

    Google Cloud 콘솔 API 및 서비스 → OAuth 동의 화면 → ［앱 게시］ / ［프로덕션으로 푸시］

    ✅ 검증(2~6주)은 안 걸려. 우리는 로그인만 쓰니까 권한이 openid · email · profile 뿐이고, 기본 권한만 쓰는 앱은 검증 없이 게시돼. 「확인되지 않은 앱」 경고도 그래서 안 떠.

    ⚠️ 우리 문서엔 「게시 누르지 마」라고 적혀 있었는데 — 그건 8/19 실험할 때 얘기였어. 지금은 서비스라 반대야. 문서는 내가 고쳐뒀어.

  5. 5

    웹 앱 등록 → 설정값 받기

    프로젝트 첫 화면에서 </> (웹) 아이콘 → 이름 아무거나 → 등록

    그러면 여섯 줄짜리 설정값이 나와. apiKey · authDomain · projectId · storageBucket · messagingSenderId · appId

    이건 나한테 그대로 줘도 돼. Firebase 설정값은 공개 전제로 만들어진 값이야 — 어차피 앱 안에 박혀서 나가거든. 보안은 이 값이 아니라 보안 규칙이 해. (⛔단 「비공개 키」·「서비스 계정 JSON」은 절대 주지 마 — 그건 완전히 다른 거야.)

    ⚠️ 나중에 못 찾겠으면 ⚙️ 프로젝트 설정 → 내 앱 에 늘 있어.

  6. 6

    우리 주소를 승인 목록에

    Authentication → 설정 → 승인된 도메인

    여기에 peachfam0307-glitch.github.io 가 있어야 로그인이 돌아. 없으면 추가.

    ⭐ 있는지만 봐주면 돼 — 없으면 내가 다시 알려줄게.

⛔ 안 누를 것

  • ✕「Blaze 요금제로 업그레이드」 / 카드 등록
    무료(Spark)로 충분해. 카드 0원이 우리 원칙이고, 카드가 없으면 한도를 넘어도 청구 대신 그냥 막혀.
  • ✕Firestore 「테스트 모드」
    30일간 아무나 읽고 쓸 수 있게 열린다.
  • ✕Storage(사진 창고) 켜기
    카드를 요구해. 사진은 지금 안 올리기로 했잖아 — 글자부터.
  • ✕Play Console 은 오늘 안 건드린다
    명의 이전이 걸려 있어. Firebase는 별개 서비스라 무관해.

담기

체크는 저장돼. 설정값은 아래 칸에 붙여넣고 「복사하기」 눌러서 나한테 주면 돼.
