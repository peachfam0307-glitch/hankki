지금 정할 수 있게 됐다

8/19 문서엔 “승인 뒤 로그인 실험을 보고 정하라”고 적혀 있었다. 그 실험이 끝났다.

마지막 미지수가 닫혔다 — 창업자 폰 실물

남아 있던 물음은 하나였다. “우리 앱(TWA) 안에서 구글 로그인이 진짜 되나.” 여기서 막히면 🅰도 🅱도 통째로 죽는 자리였다.

「로그인이 됐어요 · 구글이 열쇠를 돌려줬어요」 — 돌아온 뒤 referrer = accounts.google.com · 표시모드 standalone · 웹뷰 아님

로그인 왕복 뒤에도 저장한 것이 그대로 살아 있었고, 구글 화면을 거쳐도 앱 안으로 되돌아왔다.

그래서 두 짝이 둘 다 기술로 살아 있다. 남은 건 취향과 비용 판정뿐이다.

남은 둘

둘 다 카드 없이 공짜다. 놀아도 안 닫히고, 한도를 넘으면 돈이 나가는 대신 그냥 멈춘다. 뭘 골라도 우리 원칙이 안 깨진다.

🅰 파이어베이스 짝

구글이 다 해주는 창고

글자 = Firestore(서울) · 로그인 = Firebase Auth

좋은 것
  • 제일 쉽다 — 규칙만 쓰면 우리가 짤 서버 코드가 0
  • 폰↔패드 실시간 동기화가 이미 들어 있다 (오프라인 캐시까지)
  • 로그인 보안을 구글이 통째로 짊어진다
  • 서울 리전을 고를 수 있다
걸리는 것
  • 집이 두 채가 된다 (돈은 어차피 Cloudflare)
  • 무료 용량 1GB
  • Auth 는 미국에서 처리된다 (국외이전 신고 문구가 갈린다)
🅱 클라우드플레어 짝

우리가 이미 쓰는 그 집

글자 = D1 · 로그인 = Worker 가 직접 검증

좋은 것
  • 집이 하나로 끝난다 — 결제 장부도 어차피 여기 둔다
  • 무료 용량 5GB (다섯 배)
  • 업체가 하나라 삭제·장애·처리방침이 단순하다
걸리는 것
  • 동기화와 충돌 처리를 우리가 다 짠다 — 1인 팀이 제일 사고 내기 쉬운 자리
  • 로그인 검증도 우리 책임 (표준이긴 하다)
  • 앱이 커지면 우리 코드가 같이 늘어난다

폰＋패드 · 언젠가 사진 · 수천 명 · 언젠가 iOS — 한끼가 갈 자리에 놓고 본 값이다.

어느 쪽이든 안 바뀌는 것

이 줄들은 판정과 무관하다. 이미 정해졌거나, 둘 다 같다.

  • 결제·잔량은 Worker ＋ D1 — 🅰로 가도 돈 쪽은 Cloudflare 다. (AI 넷 합의)
  • 글자부터 올리고 사진은 나중에 — 사진 한 장이 글자 레시피 130~160편 무게다. 글자만 살아도 “폰 바꾸면 다 날아감” 문제의 8할이 풀린다.
  • 내보내기 단추는 안 없앤다 — 클라우드가 생겨도 그대로 둔다. 무료 조건이 바뀐 전례가 있다.
  • 평소 저장은 폰 안 — localStorage → IndexedDB 로 옮긴다 (5MB 벽 제거).
  • 구글 드라이브는 죽은 길 — Drive API 약관이 “앱이 유저 콘텐츠를 드라이브에 백업하는 것”을 사전 서면 동의 없이 금지한다. 다만 유저가 자기 손으로 백업 파일을 올리는 건 합법이고, 우리 「백업 공유하기」가 이미 그 방식이다.

갈아타기 보험 둘

이 둘만 처음부터 박아두면 🅰↔🅱 이사가 하루짜리가 된다. 그래서 지금 선택이 틀려도 싸다.

1

유저 열쇠 = 구글 고유번호(sub)

🅰🅱 둘 다 밑바닥은 같은 구글 로그인이다. sub 를 열쇠로 쓰면 갈아타도 같은 사람으로 이어진다. 파이어베이스 전용 UID 를 열쇠로 쓰면 그 순간 깨진다.

2

서버 데이터 모양 = 백업 JSON 과 똑같이

창고를 옮길 때 내려받아 새 창고에 올리면 끝이다. 유저는 재로그인 한 번 말고는 아무것도 모른다.

클로드 추천

🅰 파이어베이스 짝

질문이 「장기적으로 한끼에 뭐가 맞나」였기 때문이다.

  • ①창업자가 실제로 겪은 그 문제 — “패드에 깔면 처음 가입한 것처럼 된다” — 는 백업이 아니라 동기화 요구다. 장기의 한끼는 폰＋패드 앱이다.
  • ②1인 팀의 장기 리스크는 서버비가 아니라 우리가 짠 코드의 사고다. 로그인 보안과 동기화 — 제일 사고 나기 쉬운 둘을 🅰가 구글에 넘긴다.
  • ③집 두 채는 역할이 갈려서 견딜 만하다. 데이터는 파이어베이스, 돈은 클라우드플레어.

🅱의 값어치(집 하나·5GB)는 「작게 오래」에 맞는다. 그것도 좋은 답이다 — 다만 물음이 「장기」라서 🅰다. 판정은 창업자가 한다.
