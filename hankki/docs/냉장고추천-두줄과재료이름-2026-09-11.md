# 🧊 냉장고 추천 — 두 줄로 가르고, 재료 이름을 알아듣게 (2026-09-11)

> 📮 시작 = 창업자 *"냉장고재료를 추가하면 바로 추천레시피가 바뀌는건 아니야?"*
> ⭐ 이 문서 하나면 «지금 어떻게 도는지»를 안다. ⛔기억으로 적은 값은 없다 — 전부 실측이다.

---

## 1️⃣ 무엇이 문제였나

창업자가 **해물모듬·오징어·소고기·닭고기를 담았는데 맨 위 추천이 그대로**였다.

🔎 재현하니 — 냉장고 11칸 중 유통기한이 적힌 건 **두부 하나(1일 지남)**.
그 두부를 쓰는 4편이 「급함」이라 **맨 앞 4장을 통째로 잡고** 있었다.
새로 담은 재료를 쓰는 편은 **5·8·14번째**로 밀렸고, 14번째는 상한 12장 «밖»이라 아예 안 보였다.
가로줄엔 **2.5장**만 보이니 눈에는 **변화가 0**이었다.

⭐⭐ **앱은 시킨 대로 했다** — 9/10에 창업자가 정한 「임박 1순위」가 너무 세서 앞자리를 다 먹은 것이다.
📌 그러니 고칠 것은 「순서」가 아니라 **「한 줄에서 다투게 둔 구조」**였다.

---

## 2️⃣ ✅ 지금 어떻게 도나 — 줄이 «둘»이다

```
🚨 임박재료부터 쓰기                    ⟳
   [된장찌개] [두부들깨전골] [돼지…      ← 임박 재료를 쓰는 편 · 12장까지
   오늘까지 양파 · 재료 4개

🥕 가진 재료로 만들기                   ⟳
   [떡국] [수제떡갈비] [엄마표김밥]      ← 나머지 전부 · 재료 많이 쓰는 순
   가진 재료 2개
```

| | 규칙 | 왜 |
|---|---|---|
| ① | **윗줄** = 임박(D-3 이내) 재료를 쓰는 편 **전부** · 급한 재료를 많이 쓰는 순 · **12장**에서 자름 | 📮*"보통 장은 한꺼번에보자나"* — 날짜가 조금씩 다르니 하나만 보면 안 된다 |
| ② | **아랫줄** = 나머지 전부 · 가진 재료 많이 쓰는 순 | 담는 대로 **즉시** 반응한다 |
| ③ | **겹치면 아랫줄에서 뺀다** | 안 빼면 보이는 3장 중 2장이 두 줄에 똑같이 떴다(실측) |
| ④ | **임박 0개면 윗줄이 아예 안 뜬다** | 제목만 뜨는 빈 줄을 안 만든다 |
| ⑤ | 유통기한 **이틀 지나면** 그 재료는 안 센다 | 📮*"디데이 끝나고 하루지나면 빼고"* · 전엔 바닥이 없어 30일 지나도 1순위였다 |
| ⑥ | **🔁 돌리기** — 줄마다 따로 · 3장씩 · 4장 이상일 때만 그림 · 재료가 바뀌면 0으로 | 📮*"각줄끼리만"* |
| ⑦ | 제목은 **「임박재료부터 쓰기」로 고정** | 📮창업자 확정 · 이름을 넣으면 길이가 변해 두 줄로 접혔다 |

🔢 **실측 — 아랫줄이 어떤 경우에도 안 마른다** (두 줄을 합치면 «걸린 편 전부», 잃은 편 0)
```
임박 0개 → 0 ＋ 35    임박 1개 → 4 ＋ 31    임박 3개 → 12 ＋ 33
임박 6개 → 12 ＋ 35   고기만 5칸 → 7 ＋ 6
```

## 3️⃣ 🥩 재료 이름 — 「좁게 쓰면 좁게, 넓게 쓰면 넓게」

📮 창업자 시험 = *"샤브용소고기 찌개용돼지고기 사태 채끝 닭다리살 부채살 오리로스… 소고기(채끝)"*
→ 실측하니 **26개 중 9개가 0편**이었다.

### 맞추는 차례 (`hasIngredient` · ⭐위에서부터)

```
① 고기를 «직접» 썼나        소갈비살 = 소 ＋ 갈비살  → 소고기만
② 이름이 그대로 맞나         샤브용소고기 → 「소고기」로 끝난다
③ 부위 사전에 있나          채끝 → 소고기 · 갈비살 → 소·돼지 둘 다
```

| 이렇게 쓰면 | 이렇게 나온다 | 편수 |
|---|---|---|
| **소갈비살** | 소고기만 | 20편 |
| **돼지갈비살** | 돼지고기만 | 11편 |
| **갈비살** (부위만) | **소·돼지 둘 다** | 29편 |
| **안심** | 소·돼지·닭 | 35편 |
| 한우갈비살 · 흑돼지목살 | 소 / 돼지 | 20 / 11편 |
| 소고기(채끝) · 계란(특란) | 괄호를 잘라서 | 20 / 10편 |
| 채끝 · 부채살 · 오리로스 | 부위 사전으로 | 20 / 20 / 1편 |

📮 창업자 = *"갈비살하면 소,돼지 레시피 다보여주면돼"* ＋ *"직접소갈비살 쓰면 소만보여주면되고"*
⭐⭐ **여기서 하는 건 «추천»이지 «판정»이 아니다.** 안 갈랐으면 둘 다 보여주고 사람이 고른다.

### ⛔ 일부러 «안» 넣은 것
- **후지**(사과) · **전지**(분유·건전지) — 갈래가 아니라 **딴 물건**이다
- **우둔 · 국거리 · 닭한마리 · 오리슬라이스** — 앱 재료 낱말과 부딪힌다
- **「모든 낱말을 후보로」** — 「우유(1L)」가 3→7편, 「양파 1개」 ＋13편. **용량·개수가 걸린다**

## 4️⃣ ⛔ 오늘 잡은 구멍 — 전부 «재거나 봐서» 잡았다

| | 무엇 | 뿌리 | 무엇이 잡았나 |
|---|---|---|---|
| ① | 담아도 맨 위가 그대로 | 임박 1순위가 앞자리를 다 먹음 | **창업자 제보** |
| ② | 돌려도 화면이 안 바뀜 | **크롬 스크롤 앵커링**(scrollLeft 4976) | **캡처를 열어봐서** |
| ③ | 제목이 두 줄로 접힘 | 개수로 지었는데 접히게 하는 건 **글자 수** | 폭을 재서 |
| ④ | 소고기(채끝) 0편 | 한 파일 «안»에서 **두 쪽이 다른 잣대** | **창업자 시험** |
| ⑤ | 채끝·오리로스 0편 | 부위명과 「소고기」는 **글자가 하나도 안 겹친다** | 창업자 시험 |
| ⑥ | 돼지갈비살에 **소고기 요리 3편** | 일반 맞추기가 좁힘보다 **먼저** 돌았다 | **재현판** |

### ⛔⛔ 제일 큰 교훈 — ②번
```
DOM 첫 카드  = 엄마표 김밥    ← 재현판이 본 것 (통과)
화면 그 자리 = 떡국           ← 창업자가 볼 것 (그대로)
```
**재현판이 «DOM 순서»만 보고 «보이는 것»을 안 봤다.** 초록불인데 화면은 안 바뀌고 있었고,
**캡처를 눈으로 열어서야** 잡혔다(규칙 18 ⓘ · 21).
✅ 이제 `elementFromPoint` 로 **그 자리에 실제 있는 것**을 묻고 `scrollLeft` 도 같이 잰다.

### ⛔ 내가 틀렸고 창업자가 바로잡은 것
- 갈리는 부위(등심·갈비살·안심)를 *"한쪽으로 정하면 반은 틀린다"* 며 **통째로 뺐다**
  → 📮 *"갈비살하면 소,돼지 레시피 다보여주면돼"* — **맞다.** 추천이지 판정이 아니다.
- 「아랫줄 10장 이상」 문턱을 **재료 많은 냉장고에서 뽑아** 고기만 든 냉장고에 들이댔다
  → ✅ 잣대를 **「두 줄을 합치면 한 편도 안 잃나」**로 바꿨다
