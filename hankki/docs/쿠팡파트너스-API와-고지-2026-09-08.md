## 🔎 ② 를 판 것 — 「코드가 69개를 다 바꾼다」는 «틀린 말이었다»

⛔ 9/8 오전에 내가 *"되면 그때 69개를 코드로 한 번에 바꾼다(창업자 손 0)"* 라고 적었다.
   **근거 없이 적은 말이다.** 공식 문서로 다시 재서 정정한다.

### 확인된 것
- 파트너스 **deeplink API 는 실재한다** — 여러 공개 구현이 같은 엔드포인트를 쓴다
  `POST https://api-gateway.coupang.com/v2/providers/affiliate_open_api/apis/openapi/v1/deeplink`
  · 인증 = HMAC-SHA256 (`Authorization: CEA algorithm=HmacSHA256, access-key=…, signed-date=…, signature=…`)
  · 요청 = `{"coupangUrls": [...], "subId": "…"}` · 응답 = `shortenUrl` · `landingUrl`
- **키 발급 조건 = 「최종 승인」** — 파트너스 화면이 «글자로» 말한다(창업자 캡처).
- 그러므로 **API 가 열리면 69개는 정말로 코드가 한 번에 만든다.** 지금 못 하는 것은 «자격»이지 «방법»이 아니다.

### ⛔ 아직 모르는 것 (짐작으로 채우지 말 것)
1. **「최종 승인」의 조건** — 「누적 판매 15만원 이상」이라는 말이 여러 곳에 있으나 **공식 원문 확인 못 했다.**
   이 컨테이너에서 `partners.coupang.com`·`developers.coupang.com` 이 **전부 403** 이라 원문을 못 읽는다.
   👉 **창업자가 파트너스 화면에서 「최종 승인」 조건 안내를 캡처해 주면 그 자리에서 닫힌다.**
2. **검색 주소(`/np/search?q=`)를 deeplink API 가 받아주나** — 공개 예시는 전부 상품 상세(`/vp/products/`)뿐이다.
   🔢 우리 69개 중 **검색 길이 65개** 라 이게 답을 가른다.
   ⭐ 판정법 = 키가 생기면 검색 주소 하나를 넣어 `rCode` 를 본다. **그때 3초면 끝난다.**
3. **`lptag=AF3157673` 를 주소에 손으로 붙이면 실적이 잡히나** — ⛔**공식 근거를 하나도 못 찾았다.**
   👉 **하지 않는다.** 안 잡히면 69개가 통째로 헛일이고, 그 사실은 정산 때까지 모른다.
