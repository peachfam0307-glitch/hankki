# 🐻🐧 곰곰이·펭펭이 종합 기록 (마스터) · 2026-07-19

> 캐릭터 관련 **모든 확정 사항을 한곳에.** 세부는 각 원본 문서 링크. "캐릭터 뭐였지?" 하면 여기부터.

## 1. 캐릭터 개요
- **꼬르곰(곰곰이)** — 순둥이 먹보 곰 셰프. F(감정형). 한끼 앱 마스코트.
- **펭펭이** — 시크 패셔니스타 아기펭귄. 쌉T(팩폭). 꾸미기 마스코트.
- **핵심 = F × 쌉T 콤비** (라이언×춘식식 대비). 케미가 진짜 자산.

## 2. ⭐ 정본 (드리프트 방지 — 항상 이거 첨부 + "이 캐릭터 그대로")
- **곰곰이 정본**: `docs/곰곰이-정본.png` ✅ (소프트 그림체, 요리라이프 스타일, 방울·안테나 없는 흰 셰프모자)
- **펭펭이 정본**: 소프트 그림체 + **검정 일자단발** + 블랙/베이지 베레 + 베이지 트렌치. 슬림 세로계란형(통통 chibi 제외). ⚠️ 이미지 파일은 창업자 보관(인라인 전송분 레포 미저장 → 깔끔한 컷 1장 📎로 주면 `docs/펭펭이-정본.png` 저장 예정).

## 4. 성격·표정 기준
- **곰곰이**: 순하고 어리숙, 맨날 배고픔. 감정 크게. 시그니처 = 셰프모자+앞치마+숟가락.
  - ⚠️ 모자는 감정 따라 붕뜸/처짐/삐뚤(**'안테나'라 쓰면 GPT가 실제 방울 그림 → 금지**).
- **펭펭이**: 무표정·심드렁, 리액션 최소, 감정은 눈썹·행동으로. 팩폭("응 별로"·"흠"·"…")이 매력. 패션 소품 무한 변주.
- **표정 세기**: 평소=담백(순한 미소) / 감정컷=과감하게 과장(귀여움 유지). **이모티콘 메인 톤=과장.**
- **크기**: 펭펭이 = 곰의 2/3(가슴 높이). 큰 순둥 곰 × 작은 시크 펭.
