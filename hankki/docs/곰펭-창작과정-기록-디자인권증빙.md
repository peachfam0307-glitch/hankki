> 목적: AI를 **도구로** 쓰되 **사람(창업자)이 지배적 심미감을 형성·설계**했음을 증명하는 창작과정 기록.
> (법률신문 등: AI 결과물의 권리화에서 "결과물만이 아니라 그에 이르는 과정도 권리화의 일부." 심사관이 창작과정 기록·확인서를 요구할 수 있음.)

## 1. 창작자
- **창작자 = 창업자(사람).** AI(ChatGPT 이미지 생성)는 **초안 생성 도구**로만 사용.
- 최종 심미감(형상·비율·색채·구성·인상)의 착상·선택·수정·확정은 전부 사람이 수행.

## 2. 사람이 착상·설계한 "요부(핵심 심미)" — AI가 아니라 사람이 정한 것
- **캐릭터 컨셉**: 꼬르곰=창업자 자신, 펭펭=딸 — 실제 감정에서 착상(단순 "곰 그려줘"가 아님).
- **스타일 확정**: **"물결(복슬)" 털 스타일**로 지정(매끈한 리락쿠마·브라운과 차별화하려고 사람이 방향 결정).
- **시그니처 요소(사람이 지정)**: ① **하트 모양 주걱** ② **계란후라이 앞치마** ③ 복슬복슬 털 ④ 요리사 모자.
- **몸색 지정**: `#EBAB73`(웜 브라운).
- **펭펭 헤어**: 바깥 뻗침 ❌ → **끝이 안으로 말리는 단발 보브(C컬)**로 사람이 교정 지시.
- **곰·펭 조화(전체 인상 설계)**: 펭의 "음영"과 맞추려고 **곰에도 음영(모자·앞치마)을 사람이 직접 넣어** 두 캐릭터의 통일된 인상을 완성 → 이게 "지배적 심미감 형성"의 핵심 증거.

## 3. 반복 선택·수정·재구성 과정 (AI 결과 그대로 X)
- 수십 회 시안 생성 → **사람이 취사선택**(예: "볼수록 물결곰이 예쁘네", "펭은 눈반짝 버전").
- **드리프트 교정**: AI가 "프롬프트 넣으면 그림체가 바뀌어 버림" → 사람이 **재생성 대신 기존 안에 음영을 직접 얹는 방식**으로 스타일 유지(사람의 능동적 개입).
- **정본(캐논) 확정·락**: 앞으로 모든 곰펭 = 물결 스타일만, 음영만 사용으로 **사람이 규칙을 세움**.
- **낱개 컷 정리·오리기**: 원본시트 → 낱개 컷 분류·배경제거 후 앱 반영(추가 편집).
