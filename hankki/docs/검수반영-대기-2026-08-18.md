## 🦀 꽃게찜 → **어머니 레시피로 통째로 교체** (2026-09-07 · `basic-kkotge-jjim`)

📮 창업자 = *"꽃게찜? 이건 **우리엄마 레시피가 있는데 맛있거든.** 그걸로 바꿀까"*

### ✍️ 창업자가 준 원문 — ⛔**한 글자도 고치지 않는다**

```
(꽃게 5~6마리 기준)양파1, 다진마늘듬뿍1, 진간장2~3 물 200ml
 꽃게 등껍질을 떼고, 칫솔로 사이사이 이물질과 아가미 제거, 다리 뾰족한 부분 가위로 잘라낸다.
등껍질에 있는 내장을 잘 발라내어 따로둔다.
(꽃게가 크면 반으로 자르기)
넓은 냄비 바닥에 꽃게와 꽃게 내장을 깔고 위에 양파 얇지않게 채썬 것 올린다
물, 간장, 마늘을 넣고 뚜껑닫아 10분간 중불에 조린다.
10분뒤 뚜껑열고 간장 추가 넣기. (꽃게 한번찍 뒤집어준다) 간이 짭짤해야 맛있음
10분간 중약불에 끓인 뒤 마무리.

꽃게살에 남은 양념국물 넣어 밥 비빈 후 참기름 뿌리면!
```

### ⭐ 내가 읽어낸 것 (반영할 때 쓸 뼈대)

| | |
|---|---|
| **방식** | ⭐ **「찜」이 아니라 «조림»** — 넓은 냄비에 깔고 간장 양념으로 20분 조린다 |
| **같은 주와 겹치나** | ✅ **오히려 좋다** — 간장게장(생으로 담근다) ↔ 이건 «익혀서 조린다». 같은 게로 세 갈래(탕·생·조림)가 된다 |
| **어머니 요령 셋** | ⑴**등껍질 내장을 발라 «따로 뒀다가 바닥에 같이 깐다»** ⑵**칫솔로 아가미·이물질** ⑶**간이 짭짤해야 맛있다**(10분 뒤 간장을 «더» 넣는다) |
| **마무리** | ⭐ **남은 양념국물에 꽃게살 넣고 밥 비벼 참기름** — 이게 이 레시피의 값어치다 |
| **불** | 앞 10분 **중불**(뚜껑 닫고) → 뒤 10분 **중약불**(뚜껑 열고) |

### ❓ 창업자에게 물어볼 것 — ⛔**체크 끝난 뒤에 한 번만** (규칙 31)

1. **인분** — 꽃게 5~6마리면 몇 인분? (지금 판은 2인분)
2. **양파 1** = 1개 맞나 · **다진마늘 듬뿍 1** = 1큰술? · **진간장 2~3** = 큰술?
3. **10분 뒤 추가하는 간장** = 얼마나? (1큰술? 간 보고?)
4. **이름** — 방식이 조림인데 이름이 「꽃게찜」이다. 그대로 둘까 「꽃게 간장조림」으로 바꿀까?
5. **손질 시간** — 20분(조리) ＋ 손질이 얼마나 걸리는지 (지금 판은 25분)
6. **밥 비빔을 «순서»에 넣을까 «메모»에 넣을까** (내 생각엔 순서 마지막 걸음이 좋다 — 그게 목적인 요리라서)
