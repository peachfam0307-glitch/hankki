## 🔴 지금 출시 전 (무료 앱 단계에서도 해당)

### 1. 제휴(어필리에이트) 링크 표시 ✅ 반영함(2026-07-16)
- **공정위 추천·보증 심사지침**: 제휴 링크로 수수료를 받으면 "제휴 링크·수수료" 고지 의무.
- 현재 상태: 쿠팡·오아시스·네이버 등은 **직접/검색 링크라 아직 수수료 없음**. 하지만 곧 제휴 전환 예정 → **미리 고지 문구 삽입**(과다표시는 무방, 누락만 위반).
- 반영 위치: `ShopScreen.jsx` 주부의 장바구니 상단 — "‘사러가기’는 외부 쇼핑몰로 연결… 일부는 제휴 링크로 수수료를 받을 수 있어요 · 가격 그대로, 추가 부담 없어요."
- 👉 실제 제휴 링크로 바꿀 때 이 문구가 이미 있어 안전.

### 2. 개인정보처리방침 = 실제와 일치
- 앱은 **데이터 수집 안 함(로컬 저장)** → 방침(`hankki/privacy.html`)도 "수집 안 함"으로 정확히.
- Play **데이터 보안 신고**도 '수집 안 함'과 일치(이미 신고됨).
- ⚠️ 나중에 분석 도구·결제·계정 붙이면 **방침 + 데이터 보안 신고 반드시 갱신**(정직 원칙).

### 3. 저작권 — 기본 레시피·사진
- 유저가 남의 레시피 저장(개인용)은 일반적으로 OK.
- **우리가 앱에 기본 탑재하는 레시피·사진은 남의 것(캡처 등) 금지** — 직접 작성/촬영 or 출처 안전한 것만. (이미 "예시 레시피 최소" 방향이라 리스크 낮음)

### 4. 데이터 손실 = 신뢰(정직) 이슈
- 로컬 저장이라 **브라우저 데이터 삭제·앱 삭제 시 레시피 전부 소실** 가능.
- "레시피 안전 보관"이 약속이므로 **백업/내보내기 기능을 눈에 띄게** 안내(기능은 이미 있음). 온보딩·설정에서 백업 권유 고려.

### 5. 상표 — 별도 문서
- `상표-확인.md` 참조. 결론: "한끼" 사용 리스크 낮음, 출시 전 변리사 30분 권장.

## 🟡 수익 붙일 때 (나중에)

- **결제 = 무조건 Google Play Billing.** 디지털 상품 자체 결제 금지(정책 위반 시 앱 삭제).
- **전자상거래법**: 유료 판매 시 청약철회(환불) 안내 의무. Play가 상당 부분 대행.
- **통신판매업 신고**: 판매 규모·횟수 기준 넘으면 필요.
- **사업자등록·세금**: 제휴·결제 수익 발생 시 종합소득세 신고, 규모 커지면 사업자등록.
- **PDF 유료화 ≠ 전자책 판매**: `상표-확인.md`의 "레시피북 PDF 유료화" 항목 참조(기능/서비스로 브랜딩, "한끼 전자책"으로 상품화 금지).
