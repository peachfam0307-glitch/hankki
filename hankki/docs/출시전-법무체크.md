## 🔴 지금 출시 전 (무료 앱 단계에서도 해당)

### 1. 제휴(어필리에이트) 링크 표시 ✅ 반영함(2026-07-16)
- **공정위 추천·보증 심사지침**: 제휴 링크로 수수료를 받으면 "제휴 링크·수수료" 고지 의무.
- 현재 상태: 쿠팡·오아시스·네이버 등은 **직접/검색 링크라 아직 수수료 없음**. 하지만 곧 제휴 전환 예정 → **미리 고지 문구 삽입**(과다표시는 무방, 누락만 위반).
- 반영 위치: `ShopScreen.jsx` 주부의 장바구니 상단 — "‘사러가기’는 외부 쇼핑몰로 연결… 일부는 제휴 링크로 수수료를 받을 수 있어요 · 가격 그대로, 추가 부담 없어요."
- 👉 실제 제휴 링크로 바꿀 때 이 문구가 이미 있어 안전.
- **현실: 우리 쇼핑몰 중 실질 제휴 프로그램은 쿠팡 파트너스가 사실상 유일.** (오아시스·한살림·직접사이트·네이버스마트스토어는 제휴 거의 없음) → 제휴 수수료는 쿠팡 링크에서만 발생.
- **쿠팡 파트너스 전용 고지 문구 요구:** 실제 파트너스 붙일 때는 쿠팡 규정 문구를 넣어야 함 →
  > "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."
  그때 현재 문구를 이걸로 맞추면 됨.
- **수익 관점:** 제휴는 쿠팡 하나 의존이라 좁은 레버(용돈 수준). **진짜 수익 = 꾸미기 유료권(자체 상품)**, 제휴는 보조.

### 2. 개인정보처리방침 = 실제와 일치
- 앱은 **데이터 수집 안 함(로컬 저장)** → 방침(`hankki/privacy.html`)도 "수집 안 함"으로 정확히.
- Play **데이터 보안 신고**도 '수집 안 함'과 일치(이미 신고됨).
- ⚠️ 나중에 분석 도구·결제·계정 붙이면 **방침 + 데이터 보안 신고 반드시 갱신**(정직 원칙).

### 3. 저작권 — 기본 레시피·사진
- 유저가 남의 레시피 저장(개인용)은 일반적으로 OK.
- **우리가 앱에 기본 탑재하는 레시피·사진은 남의 것(캡처 등) 금지** — 직접 작성/촬영 or 출처 안전한 것만. (이미 "예시 레시피 최소" 방향이라 리스크 낮음)

### 4. 데이터 손실 = 신뢰(정직) 이슈
- 로컬 저장이라 **브라우저 데이터 삭제·앱 삭제 시 레시피 전부 소실** 가능.
- "레시피 안전 보관"이 약속이므로 **백업/내보내기 기능을 눈에 띄게** 안내(기능은 이미 있음). 온보딩·설정에서 백업 권유 고려.

### 5. 상표 — 별도 문서
- `상표-확인.md` 참조. 결론: "한끼" 사용 리스크 낮음, 출시 전 변리사 30분 권장.

## 🟡 수익 붙일 때 (나중에)

- **결제 = 무조건 Google Play Billing.** 디지털 상품 자체 결제 금지(정책 위반 시 앱 삭제).
- **전자상거래법**: 유료 판매 시 청약철회(환불) 안내 의무. Play가 상당 부분 대행.
- **통신판매업 신고**: 판매 규모·횟수 기준 넘으면 필요.
- **사업자등록·세금**: 제휴·결제 수익 발생 시 종합소득세 신고, 규모 커지면 사업자등록.
- **PDF 유료화 ≠ 전자책 판매**: `상표-확인.md`의 "레시피북 PDF 유료화" 항목 참조(기능/서비스로 브랜딩, "한끼 전자책"으로 상품화 금지).

## 🟠 2차 검토에서 새로 발견 (2026-07-16)

### 6. 오픈소스·폰트 라이선스 고지 ⚠️ (미반영 — 챙기면 좋음)
- 앱에 **OFL 폰트**(Jua·Gaegu·GowunDodum·NanumPen) 내장 + 오픈소스 라이브러리(React=MIT, tesseract.js=Apache 등) 사용.
- **OFL 라이선스는 "폰트와 함께 라이선스 고지"를 요구**함. 관행상 오픈소스 라이브러리도 attribution 두는 게 안전.
- 👉 **설정에 "오픈소스 라이선스" 항목**(또는 `licenses.html`) 추가 권장 — 폰트/라이브러리 목록 + 라이선스. (법적 리스크는 낮지만 정석)

### 7. 광고 없음 — Play 선언 일치 확인
- 우리는 광고 없음(개인정보처리방침에도 명시). Play Console "앱에 광고 포함?" = **아니오**로 돼 있는지 확인만.

### 8. 식품 건강표현 과대광고 주의 (경미)
- 주부의 장바구니 문구 중 "다이어트 건강식", "건강 식재료" 등 → **식품표시광고법상** 일반식품에 질병예방·치료·다이어트 효능을 단정하면 문제 소지.
- 현재 표현은 대체로 온건("첨가물 적은/깔끔한/성분 좋은")하나, **효능 단정 표현은 피하고 "개인 의견·경험"임을 유지.** (필요 시 장바구니에 "개인 사용 경험이며 효능을 보증하지 않아요" 한 줄)

### 9. Android 15 / SDK 35 edge-to-edge (기술)
- Play 사전출시 경고 있었음(넓은 화면/edge-to-edge). 우리 앱은 safe-area(`--safe-top/bottom`) 처리돼 있어 대체로 OK지만, **새 AAB 빌드(PWABuilder) 시 타깃 SDK·표시 확인.**

### 10. 계정 삭제 요구 = N/A
- 구글은 "계정 생성 앱"에 인앱 계정삭제 의무 부과. **우리는 계정·로그인 없음 → 해당 없음.** (나중에 로그인 붙이면 그때 계정·데이터 삭제 기능 필요)

### 11. 개인정보처리방침 = ✅ 양호(정확)
- 수집 안 함·로컬 저장·온디바이스 OCR·백업 사용자 관리·외부링크·광고/추적 없음·아동·문의처까지 정확히 기재됨. (분석/결제 붙이면 갱신 필요)
