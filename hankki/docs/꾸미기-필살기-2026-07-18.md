## 🎯 핵심 결론 (양념 말고 본체)
| 층 | 필살기 | 왜 |
|---|---|---|
| 🥇 **본체** | **살아 움직이는 꼬르곰·펭펭이 스티커** | 우리만 있음(해자) + 창업자 취향(귀엽고 웃김) + 이모티콘까지 연결 |
| 🥈 **확산** | **음식 네컷/폴꾸 프레임** | 꾸민 걸 카톡·인스타에 자랑 → 본 사람이 유입(초반 끌어오기 직결) |
| 🥉 **양념** | 반짝임·유리질감·딥 배경 | 위 둘을 "오! 예쁘다"로 마감 |
- **깨달음**: 홀로그램·글리터 같은 순수 효과는 커먼디티(남도 함) → 그것만으론 필살기 안 됨. **캐릭터가 먼저.**

## ✨ 확정 효과 (킵 — 창업자 큐레이션)
- **진주빛 마테**(저채도 은은 이리데센스) · **샴페인 호일 마테**(뮤트 골드+스윕)
- **별 반짝반짝(트윙클)** · **홀로그램**(딥 배경 위에서) · **오로라 원형**
- **유리질감(글래스모피즘) 스티커** · **골드호일** · **젤리 통통**(캐릭터 얹는 자리)
- ⚠️ v1 풀 무지개·쨍한 골드 = 촌스러움 → **폐기.** 뮤트 톤 + 절제 = 고급.

## 🌙 어두운(딥) 배경지 — 무조건 추가 (확정)
- 진주빛·샴페인·홀로그램·별 반짝임은 **밝은 배경에선 죽고, 어두운 배경에서 산다**(창업자 지적, 정확).
- 순검정 X → **따뜻한 딥 톤**(에스프레소·딥플럼·미드나잇)으로 우리 브랜드 유지. = "밤하늘 다꾸" 감성.
- 밝은 배경엔 담백한 것(유리질감·젤리·매트)으로 강약.

## 🏠 홈 반영 확인 (코드 검증됨)
- 꾸민 레시피는 **홈 카드에 그대로 반영**됨: `HomeScreen`(오늘의 추천 124 / 목록 149 / 가로 168) + `MyRecipes`(366) 가 `showDecor` 켬. 상세는 크게.
- 애니메이션도 CSS라 **홈 카드에서도 움직임** → 꾸민 게 쌓이면 **홈 = 살아있는 갤러리**(앱 켜자마자 "우와").
- ⚠️ 절제: 홈 카드=은은/느리게, 상세=풀로 (여러 카드 동시 격한 반짝임 = 산만·배터리).

## 🐻 역할 분담 (헷갈리지 말 것)
- **나(클로드) = 효과(CSS) + 딥 배경지 + 네컷 프레임 + 앱 UI 벡터.** (진주·샴페인·별·홀로·유리는 **이미지가 아니라 움직이는 코드**라 GPT가 못 만듦.)
- **GPT = 전신 꼬르곰·펭펭이 캐릭터**(스티커+이모티콘 공용). 줄 건 **캐릭터 기준 이미지**(배경사진 아님).
- **작가 외주 = 나중**(이모티콘 최종, 카카오 AI 불허라).

## 📌 진행 순서
1. (창업자) GPT로 귀엽고 웃긴 **전신 꼬르곰·펭펭이** 뽑기(투명배경) → 클로드 판정
2. (클로드) 딥 배경지 + 반짝임 효과(진주·샴페인·별·유리) 앱에 심기

4. 첫 접속 데모를 "우와 버전"으로 (지금 밋밋한 건 홀드)
