# 한끼 — 친구 초대 안내 (카톡 복붙용)

앱 주소: **https://peachfam0307-glitch.github.io/hankki/**

> 지금은 **웹으로 써보는 단계**야 (아이폰·안드로이드 다 가능).
> Play스토어 정식 테스터(안드로이드 12명)는 신원확인 통과 후 따로 링크가 나와.

---

## 📱 아이폰 친구에게 (사파리)

```
안녕! 나 요리 레시피 앱 '한끼' 만들었어 🥰
아이폰은 이렇게 써봐~

1. 사파리(Safari)로 이 링크 열기
   👉 https://peachfam0307-glitch.github.io/hankki/
2. 화면 아래 공유 버튼(⬆️) 누르기
3. 목록에서 '홈 화면에 추가' 누르기
4. 생긴 한끼 아이콘 누르면 앱처럼 열려!

써보고 어떤지 편하게 알려줘 💛
```

> ⚠️ 아이폰은 꼭 **사파리(Safari)** 로 열어야 '홈 화면에 추가'가 잘 돼. (크롬 말고)

---

## 🤖 안드로이드 친구에게 (크롬)

```
안녕! 나 요리 레시피 앱 '한끼' 만들었어 🥰
안드로이드는 이렇게~

1. 크롬(Chrome)으로 이 링크 열기
   👉 https://peachfam0307-glitch.github.io/hankki/
2. 오른쪽 위 점 세 개(⋮) 메뉴 누르기
3. '홈 화면에 추가' 또는 '앱 설치' 누르기
4. 생긴 한끼 아이콘으로 열면 돼!

써보고 피드백 부탁해 💛
(나중에 '정식 앱' 테스터도 부탁할 수 있어. 그땐 따로 링크 줄게!)
```

---

## 💡 친구들에게 미리 알려주면 좋은 것
- **일반 창**으로 쓰기 (시크릿/비공개 모드는 저장 안 됨)
- 레시피 넣으면 **그 폰 안에 저장**돼 (계정 없어도 됨)
- 소중한 레시피는 **설정 → 데이터 내보내기**로 가끔 백업

## 🗓️ 나중에 (Play스토어 정식 테스터 — 안드로이드만)
신원확인 통과 → 앱 생성 후 구글이 **테스터 초대 링크**를 줌.
그 링크를 안드로이드 지인에게 보내면 → 지인이 '참여' 누르고 Play스토어에서 설치.
이렇게 **참여한 12명**이 14일 유지되면 정식 출시가 열림.
(그 안내는 링크 나오면 따로 만들어 줄게!)
