## ✂️ 자른 값

```bash
python3 tools/cut.py <시트> docs/stickers/펭펭-정본-2026-09-01/낱개 pp0N_ --diecut 6
```

⛔ **`--diecut` 을 손으로 찾아야 했다** — CLAUDE.md 의 안내(*"500~700px대 --diecut 3"*)가
**이 시트엔 안 맞았다.** 실측 = **3px → 0.18%** (규칙 0.35~1.30% 아래라 게이트가 막았다) ·
**10px → 1.31~1.47%** (위로 넘쳐서 또 막혔다) · **6px → 통과**.
📌 px 은 시트마다 다르다. **게이트가 말하는 %를 보고 맞춘다** — 안내의 px 을 그대로 믿지 말 것.

✅ 20컷 전부 = 잘림 0 · 잡조각 0 · 회갈색 잔재 0 · 흰 테 규칙 안.
