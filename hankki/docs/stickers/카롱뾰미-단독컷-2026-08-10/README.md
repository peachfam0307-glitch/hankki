## 자른 방법

```
python3 tools/cut.py <시트> <낼폴더> <접두어> --grid 2x2 --drop 0 --diecut 3
```

- **`--grid 2x2`** — 한 칸에 캐릭터 ＋ 떨어진 소품(도마·그릇·매트·쇼핑백)이 흩어져 있다. **칸으로 묶기만** 한다.
- **⭐`--drop 0`** — ⛔기본값 0.12 로 두면 **눈·볼터치·하트·반짝처럼 본체에서 떨어진 조각이 통째로 사라진다.**
  2026-08-06 에 「얼굴만 사라짐」으로 겪은 그것(`docs/자르기-먼저읽기.md` 116줄).
- **`--diecut 3`** — 컷 긴변 544~577px 이라 **긴변 0.5% 안팎**. ⛔`auto`(1.2%)는 두꺼워 「띠부씰」처럼 보인다.
