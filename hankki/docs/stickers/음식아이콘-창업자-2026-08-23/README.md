## 🛠 자르며 알아낸 것 (다음에 또 헤매지 않게)

1. **`--diecut 3` 이 0.00% 로 계산돼 절대원칙에 걸린다** → `auto`(긴변 0.7%)를 쓴다
2. **사진 톤 시트는 표준 라벨 지우개가 못 잡는다** — 접시 드롭섀도가 라벨까지 «끊기지 않고» 이어져
   그림+라벨이 한 띠가 되고, 두꺼워서 「그림」으로 판정돼 통과한다(실측: s12 칸1 = y380~468 잉크가 0이 안 됨)
   → **`tools/시트-라벨지우기-가운데.py` 신설.** 글자는 칸 «가운데»에 좁게 모이고 접시는 칸 폭을 넓게 쓴다
3. **밝은 판만 보면 못 잡는다** — `check-cutouts` 게이트가 통과한 판에서 진한 판을 여니
   접시 둘레에 흰 호(弧)가 여럿 있었다. `cut-guard` 훅이 그걸 막았다 (2026-08-12 과 같은 자리)
