# 🎃 핼러윈 유료팩 — 2026-07-30 창업자 제공

> ⭐⭐ **이 팩은 PET 스타일이다** — 창업자 *"할러윈은 PET스타일이라 투명하고 반딱거려. 그거 꼭 살려야해ㅠ"*
> **반투명 흰 필름 테두리 + 광택**이 이 팩의 정체성이다. 컷할 때 절대 날리지 말 것.

## ⚠️⚠️ PET 컷 방법 (보통 방식으로 자르면 망가진다)

**왜 보통 방식이 안 되나**: 배경이 `252~254`, **필름 테두리도 `250~254`** 라 밝기로 못 가른다.
흰 배경을 지우면 **필름까지 통째로 지워진다.** (실제로 한 번 그렇게 돼서 PET 느낌이 다 날아갔다)

**⭐ 그래서 반대로 간다** — 배경을 지우는 게 아니라 **그림을 찾아 바깥으로 넓힌다**:
1. 진한 색(`mn < 232`) = 확실한 그림
2. `binary_fill_holes` → **흰 유령 몸통**처럼 외곽선으로 닫힌 흰색도 포함
3. `binary_dilation(film)` → 그림을 두른 **필름 띠**가 들어온다
4. 그 영역만 남긴다

도구 = `/tmp/cut_pet.py` 방식 (`film` 값 = 필름 두께 px)

| 종류 | film |
|---|---|
| 띠부씰 | **34** |
| 마스킹테이프 | **22** |

⛔ **종이·라벨은 PET가 아니다** — 종이 질감이라 덩어리(blob) 컷을 쓴다(`cut_blob` 방식).
PET 방식으로 자르면 아이템들이 서로 붙어 5컷으로 뭉친다.
