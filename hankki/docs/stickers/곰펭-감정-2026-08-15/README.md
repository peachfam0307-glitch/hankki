## ✂️ 자른 방법

```
python3 tools/cut.py 원본시트/시트N.png 낱개 ge_sN --diecut auto            # 시트 2·4·5
python3 tools/cut.py 원본시트/시트N.png 낱개 ge_sN --diecut auto --grid 2x2  # 시트 1·3
```

⛔⛔ **처음엔 24컷이 나왔다 — 두 가지가 어긋났다**
- **콤비가 쪼개졌다** — 시트3은 꼬르곰과 펭펭이 «떨어져» 있어서 덩어리 칼이 **따로 잘랐다**(7컷).
- **말풍선만 한 컷이 됐다** — 시트1의 「…」이 혼자 떨어져 있었다.
✅ **`--grid 2x2`** 로 고쳤다 — 격자는 «나누는 데만» 쓰고 **한 칸 안의 것은 한 컷으로 묶는다.**

⚠️ **`--diecut 3` 은 게이트가 막았다** — 흰 테가 **0.16%** 로 규칙(0.35~1.30%) 밖이었다.
   CLAUDE.md 의 *"500~700px대 --diecut 3"* 은 이 시트엔 안 맞는다(컷이 그보다 크다) → `auto`.
