## 🏷 접두어 — `xb_` · `xw_` 를 쓴 이유

⛔⛔ **`xn` 을 쓰면 안 된다.** 크리스마스 유료팩 접두어라, 등록하는 순간
`paidPacks.js` 의 `key.startsWith(접두어)` 판정에 걸려 **통째로 유료팩에 딸려 들어간다.**
그러면 **무료로 닿는 어떤 자리에도 영영 못 나간다**(2026-08-03 절대원칙).

지금 쓰이고 있는 유료팩 접두어 전부 (`src/data/paidPacks.js` 실물에서 읽음):

| 팩 | 접두어 |
|---|---|
| 추석 | `cs_` `hb` `hd0` `hp0` `wc_` `cp_` `ct_` `cm_` `cf2_` `ci_` |
| 핼러윈 | `hw_` `hp_` `hs_` `hf_` `ht_` |
| 가을 다꾸·수채화 | `pi_` `pp_` `pt_` `ws_` `wh_` `wm_` `wf_` |
| 크리스마스 | `xi` `xd` `xp` **`xn`** |
| 겨울 | `xs` `xl` `xt` |

✅ `xb_`·`xw_` = 위 어느 것으로도 «시작하지 않고», 앱 코드에도 **0건**이다(grep 확인).
