## ✅ 연한 판 채택 — **어두운 배경에 얹어서 판단했다**

창업자: *"한복색이 너무 진한가 싶어서 연한것도 뽑는 중"* → 두 판을 **클레이 가을밤(어두운 배경)** 위에 올려 비교.

| | 결과 |
|---|---|
| 진한 판 (남색·짙은 쑥) | ❌ 도포가 **밤하늘과 같은 계열**이라 옷이 배경에 묻히고 **얼굴만 뜬다.** 옷과 청사초롱이 서로 세서 싸운다 |
| **연한 판 (회색-하늘·연두)** | ✅ **전신이 또렷하고 청사초롱의 빨강-파랑이 주인공으로 산다.** 앱 톤(그레이지 뮤트)·펭펭 분홍 한복과 밝기가 맞는다 |
