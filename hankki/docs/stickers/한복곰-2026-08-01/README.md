## 1️⃣ 1차 — 연한 판 채택 (h01)

창업자: *"한복색이 너무 진한가 싶어서 연한것도 뽑는 중"* → 두 판을 **클레이 가을밤(어두운 배경)** 위에 올려 비교.

| | 결과 |
|---|---|
| 진한 판 (남색·짙은 쑥) | ❌ 도포가 **밤하늘과 같은 계열**이라 옷이 배경에 묻히고 **얼굴만 뜬다** |
| **연한 판 (회색-하늘·연두)** | ✅ **전신이 또렷하고 청사초롱의 빨강-파랑이 주인공으로 산다** |

📌 **색 판단은 「흰 바탕」이 아니라 「실제로 얹힐 배경」 위에서 한다.** 흰 바탕에선 진한 판이 더 또렷해 보였다.

## 2️⃣ 2차 — 셰프모자 판 2장 (h02·h03) · **같은 기준을 그대로 적용**

창업자: *"골라서 써. 이것도 이미 준거야. 2장은 지금 뽑은거고.."*

받은 5장 중 **새 것은 2장**이고 3장은 이미 저장소에 있었다 (픽셀 대조로 확인):

|---|---|
| **h02-셰프모자판-A** | ⭐새 시트 |

| 콤비 추석 4컷 | = `가을-창업자-2507/원본시트/a22.png` — **이미 잘려 앱에 있다** (`cs_b23·b24·b25·b26·b27·b28`) |
| (5번째) | 콤비 4계절과 **완전 동일 파일** |

### ⭐ B(h03) 채택 — 이유는 1차와 같다
어두운 배경에 얹어 보니:
- **A = 남색·초록 「도포」** — 옷 면적이 넓고 진해서 **A1·A5는 밤 배경에 몸통이 묻힌다**
- **B = 남색 「조끼」 + 연두 저고리·바지** — 진한 색이 조끼(작은 면적)뿐이라 **4컷 다 전신이 또렷하다**
- A에서 건질 것 = **A2(달토끼 부채＋보름달)** 는 초록이라 밝고 **B에 없는 포즈** · **A3(「즐거운 한가위」 말풍선)** 은 캐릭터가 아니라 **문구 스티커**라 값어치가 따로 있다

### ⚠️⚠️ 여기서 사고가 하나 났다 — 창업자 질문이 잡아냈다

창업자: *"내가 자른거 다 검수안해도돼? 고화질로?"*

**처음엔 `--diecut keep` 으로 잘랐다.** 근거는 「그림에 흰 다이컷이 이미 그려져 있다」였는데 — **그게 틀렸다.**
100% 원본 크기로 펼쳐 4배 확대해 보니 **11컷 중 `hb04`·`hb11` 둘만 흰 테두리가 있고 나머지 9컷은 없었다.**
📌 **한 시트 안에서도 AI가 일부 컷에만 다이컷을 그린다.** 그래서 `keep` 은 **짝짝이 세트**를 만들었다.

⛔ **자동 3단계 검수는 이걸 전부 통과시켰다.** 3단계가 보는 건 「잔재·잘림·실제 크기」이지
**「이 컷들이 서로 같은 마감인가」가 아니다.** → `CLAUDE.md` **규칙 13** 신설.

**그다음 `auto` 로 다시 잘랐더니 창업자: *"지금은 좀 두껍게 느껴져"*** — 이것도 맞았다.
`auto` 는 **긴변의 1.2%**(주석엔 0.7%라 적혀 있었지만 코드는 `0.012`) → `hb01`(967px)이 **12px**.
→ **0.5% 안팎(3~5px)으로 재컷** → 창업자 *"딱좋아 두께"* ✅

### 🩹 그리고 도구 자체를 고쳤다 — 「발밑 그림자가 흰 웅덩이가 되던 것」

창업자: *"아래 그림자는 안잘라도 돼."* · *"흰색들어가서 더 지저분해 보이는 듯."*

**둘 다 맞았고 원인은 하나였다.** `tools/cut.py` 의 `--diecut` 이 칼선 안쪽을 **통째로 흰색으로 덮어서**
발밑 연한 그림자가 **지워지고 흰 덩어리로 바뀌었다.** 발과 그림자 사이에 흰 띠가 끼어
*"발이 흰 웅덩이에 서 있는"* 모양이 됐다.

세 가지를 4배로 확대해 나란히 보고 정했다:

| | 결과 |
|---|---|
| ⓐ 옛 방식(흰칠) | ❌ 그림자 자리에 흰 덩어리 |
| ⓑ 테두리 아예 없음 | ❌ 그림자는 살지만 **배경 잡티·검은 조각**이 그대로 남는다 |
| **ⓒ 고친 것** | ✅ **그림자는 제 색·제 투명도로 살고, 흰색은 「원래 비어 있던 자리」에만.** 칼선은 그대로라 윤곽도 매끈 |

🔧 **`tools/cut.py` 수정** — `soft = (~solid) & (alpha > 0.06)` 를 흰칠에서 빼고 알파는 `maximum` 으로 합친다.
📌 **이건 이 팩만의 문제가 아니다** — 앞으로 자르는 **모든 시트**에 적용된다(그림자 있는 그림 전부).
