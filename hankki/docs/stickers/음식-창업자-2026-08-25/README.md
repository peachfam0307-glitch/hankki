## ⭐⭐ 이 시트가 중요한 이유 — 「자르기 편차」가 여기서 풀렸다

8/24 에 192컷 중 **86컷이 파먹혀** 다시 뽑아야 했다. 원인은 상관계수 −0.796 으로 확정한
**「그릇 중 흰 여백 비율」**이었고, 창업자에게 프롬프트 한 줄을 드렸다 —
*"음식이 그릇을 꽉 채우게. 넓은 빈 접시 여백이 안 보이게."*

창업자가 그 줄을 넣고 **＋ 접시에 테두리 선까지 넣어서** 다시 뽑은 것이 이 시트다.
**여섯 칸 전부 깨끗하게 잘렸다.**

| | 흰 여백 | 결과 |
|---|---:|---|
| 시트 02·03·12 (전멸) | 43~52% | ⛔ |
| **시트 17** (위에서 내려다봄 · 테두리 있음) | **25.9~31.9%** | ⛔ **테두리가 있어도 파먹혔다** |
| **이 시트** | **8.7~12.1%** | ✅ 6/6 깨끗 |

⭐⭐ **시트 17 이 결정적인 반례다** — 진갈색 테두리가 «있는데도» 파먹혔다.
→ **자르기 성패를 가르는 건 «테두리»가 아니라 «흰 여백»이다.**
