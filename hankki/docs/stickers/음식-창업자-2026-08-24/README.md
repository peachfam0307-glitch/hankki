## ⭐⭐ 이번에 배운 것 = **`--drop 0` 이 파먹힘을 막는다**

🔢 실측(계란장) = `--drop 0` 없이 **75,944px** · 좌우 **16%** 어긋남
   → `--drop 0` 으로 **116,914px** · 좌우 **3%**. **41,000px(35%)이 되살아났다.**

⭐ 왜 = 그릇은 가운데가 뚫린 «고리»라 도구가 **접시 테를 「떨어진 조각」으로 오해해 통째로 버린다.**
   `docs/그릇프레임-만드는법-2026-08-23.md` 의 *"그릇은 `--drop 0` 이 반드시 필요하다"* 와 같은 답이다.

⛔ **8/24 낮 판(폐기)의 실수 기록엔 *"`--drop 0` 도 안 고쳐졌다"* 라고 적혀 있는데 이번엔 고쳐졌다.**
   그때는 시트가 달랐다(진갈색 테두리 없는 판). 📌 **시트가 다르면 답도 다르다 — 짐작으로 메우지 않는다.**

⚠️⚠️ **단 `--drop 0` 이 «모든» 시트에 맞지는 않는다** — 32장 중 **2장(04·21)** 은 그걸로 자르면
   컷을 잃었다(**04 = 0컷 · 21 = 2컷**). **그 둘만 `--drop 0` 없이** 자른 판을 썼다.
   📌 **한 값을 전부에 밀어붙이지 않는다.** 시트마다 확인하고, 안 되면 되돌린다.
