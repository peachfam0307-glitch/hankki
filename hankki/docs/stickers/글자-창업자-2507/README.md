# 글자 스티커 — 창업자 제공 (2026-07-29)

다꾸의 절반이 글자인데 앱엔 응원 문구 6개뿐이고 숫자·날짜·요일은 0개였다.
창업자가 프롬프트로 **20장**을 뽑아줌(같은 세트를 스타일 여러 버전으로).

원본 = `원본시트/` · 채택분 낱개 = `낱개/`

### ❌ 숫자 1~10 은 뺐다 (창업자 결정 2026-07-29)
넣을 땐 '레시피 순서 매기기'용이라 생각했는데, **우리 레꾸는 표지 한 장**이라
순서를 매길 자리가 없다(순서는 상세 화면에 이미 번호로 나온다).
날짜로 쓰기엔 10까지뿐이라 반쪽. → `낱개-미반영-숫자/` 에 보관(버리지 않음).

⭐ **'한끼 문구'를 맨 위에 둔 이유** = 창업자가 직접 뽑은 우리만의 말이라
다른 다꾸 앱엔 없다("내가 한 게 맞나?"·"파는거 보다 맛있음"·"밤티ㅠ"·"5분 컷"·"오늘도 해냄").

## 어울림 판정 기준

**우리 앱에 이미 들어간 스티커 옆에 놓았을 때 한 세트로 보이는가.**
우리 톤 = **진갈색(다크브라운) 굵은 외곽선 + 파스텔 채움 + 흰 다이컷 테두리**
(주방도구 `tk_*`·데코 `dn_*`·프레임 `fn_*`·마테 `wt_*`가 다 이 마감).

## ⚠️ 라인 스타일은 자동 오림이 안 된다 (기술 메모)

`tools/cutout-stickers.py`는 **테두리에서 시작하는 흰 영역을 배경으로 지우는** 방식이다.
채움이 없는 라인 스티커는 **속이 흰색이고 바깥 흰 배경과 이어져 있어** 속까지 통째로 지워진다.
실제로 이번에 라인 시트는 컷이 반만 나왔다(문구16-F = 16개 중 **6개**, 숫자요일20-F = 20개 중 **10개**).

→ 라인 세트를 나중에 쓸 땐 `cutout-stickers.py --line`(선화 전용 모드)으로 자를 것.
