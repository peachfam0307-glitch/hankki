## ⭐⭐ 어제 물어둔 것의 답 — **표준도구 «안»에 한 덩어리로 자르는 길이 있었다**

⛔ 어제 이 문서에 *"cut.py 는 낱개로 쪼개니 `배경빼기-한장.py` 를 써야 한다"* 고 적었다. **반쪽이었다.**
✅ `cut.py --grid RxC` 가 그 일을 한다 — 도구 머리말에 이렇게 적혀 있다:

> `--grid RxC` 씬 컷용 — 격자는 «나누는 데만» 쓰고 **한 칸의 덩어리를 한 컷으로 묶는다**

👉 **`--grid 1x1` = 시트 전체가 한 칸 = 덩어리 둘이 한 컷으로.** 창업자 말이 맞았다.
📌 배운 것 = **도구가 「못 한다」고 말하기 전에 그 도구의 머리말을 끝까지 읽는다.**
