> ⭐ **이 팩의 정체성 = 수채 질감 + 얇은 선.** 기존 굵은 선 컷과 섞지 말고 **팩 안에서만** 쓴다.

> ✅ **독립 990원 팩으로 확정 (창업자 2026-07-30)** — *"방금 준거만 모아서 수채화팩으로 990원 세트 추가?"*
> 처음엔 추석·가을 팩에 나눠 넣으려 했는데 창업자가 *"추석은 어울릴지 모르겠어"* 라고 짚었고 맞는 지적이었다.
> 추석 팩은 이미 **쨍한 굵은 선이 83컷**이라 수채화 8컷만 섞으면 그 8컷이 겉돈다.

## 왜 이 스타일이 유료에 유리한가
| | 선 | 채움 | 느낌 |
|---|---|---|---|
| 무료(기존) | **굵은 진갈색** | 또렷한 파스텔 | 캐주얼 |
| **유료(이 팩)** | **얇은 갈색** | **수채 질감·번짐** | 고급 |

기본 문법(갈색 외곽선 + 파스텔)은 같아서 **한 세트로 안 겉돌면서도**,
나란히 놓으면 **"유료가 확실히 더 예쁘다"** 가 한눈에 보인다.
→ 마테를 무료(담백)/유료(화려)로 가른 것과 같은 원리.
