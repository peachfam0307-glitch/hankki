## ⛔ 가을 프레임 12개는 쓸 수 없다 (다시 뽑아야 함)

**⚠️ 먼저 정정** — 처음에 "배경 통째"라고 판정했는데 **틀렸다.** `a09`는 **RGBA(투명 80.8%)** 로 이미 투명 처리돼 있다. RGB로만 읽어서 알파를 못 봤다.

그런데도 **못 쓴다. 이유 3개:**

1. **투명처리가 프레임 선을 파먹었다.** 크림색 얇은 선이 배경으로 오인돼서 **선이 갈라지고 좀먹은 모양**이 됐다.
   ⭐ **원본 시트를 그대로 크롭한 것과 내가 자른 것이 똑같다** → 내 컷 문제가 아니라 **원본이 그렇다.**
   (반투명 픽셀 3.6% — 가장자리 램프가 거의 없다)
2. **선이 얇고 연한 크림색.** 우리가 **이미 두 번 걸러낸 스타일**이다 —
   v8.94에서 *"B·C·E·J·D는 선이 연해 배경에 묻힌다"* 로 제외, `docs/_아껴둠/` 7번에도 같은 기록.
   크림 배경에선 묻히고, 진한 배경에선 갈라진 게 다 보인다.
3. **크기 309~388px** vs 프레임 표시크기 626px = **1.6~2.0배 확대.**

### ✅ 다시 뽑을 때
**⛔ 프레임은 투명처리 하지 말 것.** **흰 배경으로 주면 내가 오려낸다** — 배경제거 도구가 크림색 선을 파먹는 게 이번 원인이다.
