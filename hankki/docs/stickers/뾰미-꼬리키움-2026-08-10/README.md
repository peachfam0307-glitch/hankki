## ⛔ 클로드가 이날 틀린 것 넷 (전부 「무엇을 보는지」 · 규칙 18)

| # | 무엇 | 왜 |
|---|---|---|
| ① | *"3번은 꼬리가 25% 작다"* | 꼬리 면적을 「순백 아님」으로 셌는데 **3번은 꼬리 끝이 흰색**이라 통째로 안 세어졌다. 셋 다 같은 크기다(창업자 *"같은 그림을 꼬리끝만 다르게 뽑은거야"*) |
| ② | *"사막여우는 꼬리 끝이 진하다"* 를 우리 기준처럼 말함 | 그건 **실제 페넥의 사실**이지 우리 목적이 아니다. 우리 목적 = **「코기로 안 보이게」**. 창업자가 제일 예쁘다고 본 안을 포기할 뻔했다 |
| ③ | 대비를 외곽선 없이 재서 1번 추천 | 위 표 참고 |
| ④ | 판정판 다크 줄이 검게 얼룩짐 | 흰 배경을 지우는 문턱(`>246`)이 **캐릭터의 흰 부분**(얼굴 줄·가슴·발·레이스)까지 뚫었다. 📌 우리 자르기 표준에 이미 있는 함정 — *"흰 그림도 흰색이다"* |

⭐ ①과 ④는 **같은 뿌리** — 「흰색」을 배경으로 친 것.
   📌 **흰 부분이 있는 그림을 다룰 땐 「순백=배경」 가정을 쓰지 않는다.**
