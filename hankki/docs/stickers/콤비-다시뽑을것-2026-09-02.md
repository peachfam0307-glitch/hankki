## 🎨 규격 (여덟 컷 «전부» 같게)

| | 값 |
|---|---|
| 🐧 펭펭 | 베레모 · 단발 · 리본(또는 진주 목걸이) · **벨트 버클이 있는 «진한» 베이지 트렌치** |
| 🐻 꼬르곰 | 셰프 모자 · **계란후라이 앞치마** · 복슬복슬한 물결 털 |
| 표정 | 🐧 펭펭은 **웃기지 않는다**(무표정이 매력) / 🐻 꼬르곰은 활짝 |
| 배경 | **흰 배경** (⛔배경을 그려 넣지 않는다 — 자를 때 다 지워진다) |
| 크기 | **시트 한 장에 4컷** · 컷당 **긴 변 600px 이상** |
| 효과 | 김·하트·반짝이는 **몸이나 물건에 «닿게»** 그린다 |
| 글자 | ⛔ **그림 안에 글자를 넣지 않는다** |

⛔ **왜 「벨트」를 콕 집나** — 창업자가 옛 컷을 가른 잣대가 그것이다:
   *"연한베이지트렝치랑 트렌치에 벨트없는거."* 코트색을 재도 갈래가 딱 둘로 갈렸다
   (옛것 R−B **11~15** ↔ 정본 **30~52**).

⛔ **왜 「떨어진 조각 금지」인가** — 자르기 절대원칙이 **본체에서 떨어진 조각을 0으로** 만든다.
   반짝이·효과선이 공중에 떠 있으면 **자를 때 사라진다**(2026-08-14 곰 엄지척 컷이 그랬다).

⛔ **왜 「글자 금지」인가** — 옛 `duo_menu` 에 「Special Menu」가 박혀 있었다.
   ⑴ AI 가 글자를 자주 틀리게 그린다(2026-08-01 「추섴」 사고) ⑵ 화면에 보이는 영어 낱말을 안 늘린다.

## 🍳 시트 A 「둘이 한 끼를 만든다」 — 4컷

| | 무엇 | 왜 이게 필요한가 |
|---|---|---|
| **A-1** | **부엌에서 둘 다 손을 움직인다** — 꼬르곰은 냄비를 젓고, 펭펭은 볼에 거품기 | 카드의 심장. 「같이 해냈다」가 한 장에 다 들어간다 |
| **A-2** | **완성 접시를 들고 온다** — 꼬르곰이 접시를 들고, 펭펭이 옆에서 본다 | 「해냈다」의 순간 |
| **A-3** | **마주 앉아 먹는다** — 식탁에 접시 둘, 둘 다 숟가락·포크를 들고 | 먹는 컷이 지금 하나뿐이라 자주 겹친다 |
| **A-4** | **장보기** — 꼬르곰이 카트를 밀고, 펭펭이 장바구니를 든다 | ⭐창업자가 콕 집은 그 컷 |
