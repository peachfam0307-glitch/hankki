## ⛔⛔ 여기서 배운 것 — 「검은 바탕」은 흰 바탕과 «반대»가 아니다. 더 위험하다

창업자가 펭펭을 **검은 바탕**으로 먼저 줬다(`원본/펭펭-검은바탕-옛것.png` · 보관용).
그걸 그대로 배경빼기 했더니 창업자가 ***"펭펭 외곽선이 좀 흐려"*** 라고 잡았다.

🔢 **실측이 창업자 말을 그대로 뒷받침했다** —

| 원본 밝기 | 픽셀 | 옛 판 알파평균 | 무엇인가 |
|---|---:|---:|---|
| 0~2 | 1,218,484 | 0.8 | 바탕 ✅ |
| **3~20** | **25,819** | **160.5** | ⛔**외곽선의 제일 진한 심지** |
| 21~120 | 88,907 | 255.0 | 그림 ✅ |

⭐⭐ **뿌리 = 「바탕도 검고 외곽선도 검다」.** 흰 바탕에선 외곽선(검정)과 바탕(흰색)이 정반대라
문턱을 어디에 둬도 안전한데, **검은 바탕은 둘이 같은 쪽에 있어서 문턱 하나가 둘을 가른다.**
문턱 20 으로 잡으니 외곽선 심지가 바탕과 함께 먹혀 **선이 반투명해지고 일부는 구멍**까지 났다(y=1000 줄: 원본 16px → 완전불투명 10px).

✅ 고침 둘 = ⑴문턱 **20 → 2** (바탕은 밝기 0~2 가 이미 77.4%다) ⑵**창업자가 흰 바탕 판을 새로 줬다 → 그걸 쓴다**
🔢 결과 = 외곽선(밝기≤60) **52,267px 전부 완전불투명**(알파평균 255.0) · 떨어진 조각 0

⛔⛔ **＋ 내 검사가 이걸 «못 잡고 100% 라고 했다»** — 잣대가 **`알파 > 25`** 였다.
   **알파 30 이면 거의 투명한데도 「살았다」로 센다.** 규칙 18 ⓘ 그대로 — 검사가 «무엇을 보는지».
   ✅ 잣대를 **「완전불투명(알파 ≥ 250) 비율」과 「알파 평균」**으로 바꿔야 창업자 눈과 같아진다.

📌 한 줄 = **「빠졌나」가 아니라 「얼마나 진하게 남았나」를 재야 «흐림»이 잡힌다.**

## 🛠 만든 명령 (그대로 다시 돌릴 수 있다)

```bash
python3 tools/배경빼기-가장자리고르기.py <원본> <낼PNG> --문턱 244 --채도 14        # 흰 바탕
python3 tools/배경빼기-가장자리고르기.py <원본> <낼PNG> --바탕 검정 --문턱 2 --채도 14  # 검은 바탕
```
⭐ `--바탕 검정` 은 이 날 새로 붙였다. ⛔`tools/cut.py`(자르기 표준)는 손대지 않았다(창업자 확정).

## ⚠️ 넘길 때 같이 알 것

- **카롱만 발밑에 옅은 갈색 그림자**가 원본에 그려져 있다 → 색 있는 카드에 얹으면 타원이 비친다. 나머지 넷은 깨끗.

  ⛔ 앱 스티커(`gp_*`)와 다른 점이 이것이다 — 앱 것은 테가 둘려 있다.
