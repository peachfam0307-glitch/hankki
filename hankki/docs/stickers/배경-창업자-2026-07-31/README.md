## ⭐⭐ 여기서 나온 원칙 두 개

### 1. 배경은 **스티커와 같은 소재**를 쓰지 않는다
잎·꽃·음식처럼 **우리가 스티커로 가진 것**을 배경에도 깔면 둘이 싸운다.
배경은 **질감·하늘·천·종이** 처럼 «스티커가 될 수 없는 것» 이어야 한다.
📌 단풍길이 딱 그 사고였다.

### 2. 배경은 **단독 상품이 아니다** (창업자 판단 2026-07-31 *"나는 안팔릴거 같애 ㅋㅋ"*)
다꾸 앱에서 돈을 내는 건 **모으는 재미가 있는 것** — 스티커·캐릭터·시즌 한정 세트다.
배경은 팩을 **완성시키는 부속**이지 그 자체로 990원 값어치가 안 난다.
📌 우리 유료팩 계획도 원래 그랬다 — 추석 59+44 · 가을다꾸 51 · 수채화 46 · 핼러윈 52+16
   **전부 스티커 팩**이고 배경은 딸려가는 것이었다. 하룻밤 배경만 파다 그걸 잠깐 잊었다.
→ **배경은 3개로 충분.** 더 만들지 않는다.

### 3. 팔릴지 안 팔릴지는 **지금 정할 수 없다**
테스터 12명도 자세한 피드백이 없었다. 아직 아무도 제대로 안 써봤다.
→ **출시기념 무료팩을 먼저 뿌리고 반응을 본다.** 그게 「살까 안 살까」의 진짜 답이고, 원래 계획이기도 하다.

### 왜 우리한테 유리한가
**효과는 창업자 손이 하나도 안 간다.** 그림만 주면 움직임은 코드가 붙인다.
→ 팩이 늘어도 **창업자 일은 안 늘어난다.**

### ⛔ 팩당 «하나»만
기존 규칙과 같다 — 스티커 모션도 **팩당 1개**로 12개월치를 배정해뒀고 게이트가 검사한다.
효과가 여러 개면 성능·배터리도 문제고, *"이 팩은 이게 움직인다"* 가 흐려진다.

## 🛠 앱에 넣는 법 (구현 확인 완료 · 아직 등록 안 함)

배경은 `Thumb.jsx` 에서 **div 하나**에 `bgStyle(key)` + 클래스 `bgAnim(key)` 로 그린다.

⚠️ **`background-image` 레이어는 겹마다 따로 투명도를 못 준다** → 별을 한 겹으로 넣으면
   **다같이 깜빡이는 「전구」** 가 된다.
✅ **해결 = `::before` / `::after` 두 겹.** 같은 div에 붙는 가짜 요소라 각각
   **다른 별 배치 · 다른 주기 · 다른 지연**을 줄 수 있다. 거기에 늘 켜져 있는 옅은 별 한 겹을
   `background-image` 에 두면 완전히 꺼지는 순간이 없다.

```
.hk-bg-star::before { animation: hk-star 3.2s ease-in-out infinite alternate; }
.hk-bg-star::after  { animation: hk-star 2.1s ease-in-out infinite alternate; animation-delay: -.7s; }
@keyframes hk-star { from { opacity:.35 } to { opacity:1 } }
```

⚠️ 클래스는 **`hk-` 접두어**를 유지한다 — 「움직임 줄이기」 설정에 같이 걸려야 한다.
⚠️ **등록은 결제가 붙은 뒤에.** 지금 넣으면 유료팩이 공짜로 풀린다.
