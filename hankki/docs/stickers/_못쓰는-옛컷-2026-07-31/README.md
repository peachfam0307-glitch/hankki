## ⚠️ 앱에 등록된 PNG는 **안 지웠다** (`src/assets/stickers/photo/`)

**지우면 이미 그 스티커로 꾸며 저장한 표지가 깨진다.** 유저가 만들어 둔 레꾸가 망가지는 건
이번 정리로 얻을 것보다 훨씬 크다. (`kf_c_`·`kf_l_`·`sf_` 때와 같은 원칙 — *"뺀 컷의 파일·비율은 남긴다"*)

**그럼 겹치는 문제는?** → **새 컷이 오면 같은 key로 덮어쓴다.**
`ig_jae06`(양파) 자리에 새 양파가 들어가는 방식이라 **두 개가 같이 존재할 일이 없다.**
저장된 표지도 그대로 살고, 그림만 좋은 걸로 바뀐다.

## 🔍 그래도 겹칠까 봐 걱정되면
새 시트를 자를 때 **기존 등록 컷 전부와 픽셀로 대조**한다.
(예전에 프레임 `K`가 `F`와 **평균차 0.0**인 걸 이 방법으로 잡아냈다)
→ **창업자가 눈으로 중복을 확인할 필요 없다.**
