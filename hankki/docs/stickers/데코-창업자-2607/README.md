⚠️ **`데코-10.png` 은 `데코-08.png` 과 픽셀까지 완전히 같은 파일이다**(md5 동일).
   원본은 지우지 않는 게 규칙이라 그대로 두지만 **자를 땐 하나만 쓴다.** → 실제 10장 80컷.

## 자른 명령
```bash
python3 tools/cut.py <시트> <낼폴더> d --diecut auto --min 4000 --grid 2x4 --drop 0 --join 25
```
⭐ **`--join 25` 가 핵심** — 기본 5로 자르면
① **구름 말풍선의 속이 안 채워진다**(외곽선에 틈이 있어 `fill_holes` 가 못 메운다. 덩어리 7397px = 선만)
② **파티폭죽 색종이·해님 햇살**이 본체와 떨어져 딴 컷이 된다.
25로 올리면 ①은 61531px로 채워지고 ②도 한 컷이 된다. 칸 배정은 그대로 8칸.
