### ⚠️ 중복 1장 — 저장 안 함
창업자가 보낸 `697029a3-…048` 은 `xc01`(`61b3ba55-…046`)과 **md5까지 같은 완전 동일 파일**이다
(`45e2b2ce598d` · 평균 픽셀차 **0.00**). 같은 걸 두 번 첨부한 것이라 한 장만 남겼다.
📌 **이름이 다르다고 다른 그림이 아니다** — 2026-08-03 `wc_`↔`cs_i` 사고와 같은 확인 절차(픽셀 대조)로 잡았다.

## ⚠️⚠️ **20컷 전부 「콤비」다 — 솔로 컷이 0개**

한 컷도 빠짐없이 **꼬르곰과 펭펭이 같이** 있다. 확인 = 5장 × 4컷 전수.

📌 **이게 왜 문제냐** — 카드 뽑기(`ShareDrawCard`)는 풀을 **곰 · 펭 · 콤비** 셋으로 나눠 뽑는다
(가중치 곰 70 · 펭 20 · 콤비 10). **콤비만 20컷이면 겨울 카드가 전부 「둘이 같이」로만 나온다.**

### 🎴 겨울 카드 6컷(곰2·펭2·콤비2) 기준으로 보면

| 필요 | 있나 |
|---|---|
| 콤비 2 | ✅ **20컷 중 고르면 된다** — 넉넉하다 |
| 꼬르곰 솔로 2 | ⛔ **0컷** |
| 펭펭 솔로 2 | ⛔ **0컷** |

⭐ **그래도 크게 전진했다** — 8/3 밤에 온 119컷은 소품·프레임뿐이라 **캐릭터가 0**이었다.
달력 ①번(*"겨울 카드 6컷 — 캐릭터는 새로 뽑아야 한다"*)의 **콤비 몫은 이걸로 끝났다.**
