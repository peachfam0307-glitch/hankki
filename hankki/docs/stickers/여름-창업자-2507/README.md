### ⚠️ 씬카드 vs 스티커 (헷갈리지 말 것)
여름 12컷은 **배경이 통째로 붙어 있다.** 레꾸 표지에 작게 붙이면 네모 배경째 올라가 어색하다.
→ **표지 배경으로 크게 깔거나 카드 한 장**으로 쓰는 용도. (기존 `duo_night_market`·`duo_watermelon_picnic`도 같은 성격)
**콤비축하 4컷만 배경이 깨끗이 잘려** 스티커로 바로 쓸 수 있다.

### 🚫 맥주 컷(`낱개-콤비축하/04`)은 쓰지 말 것 — 권고
맥주병 들고 건배하는 컷. 앱 Play **콘텐츠등급 = 전체 이용가**라 술 이미지는 등급에 걸릴 수 있다.
**같은 시트 03(주스 건배)이 거의 같은 구도**라 대체하면 된다. 굳이 위험을 질 이유가 없다.
(※ 2026-07-29 기준 판단. 작업 환경이 외부망 차단이라 구글 등급 규정을 재확인하지는 못했다.)
