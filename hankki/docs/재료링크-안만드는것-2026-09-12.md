# 🚫 재료 링크를 «안 만드는 것» — 창업자 판정 (2026-09-12)

> 📮 창업자 = *"내가 못넣는다는 것도 다 빼고."*
> ⛔ 여기 적힌 것은 **목록에 다시 올리지 않는다** — 매번 다시 보면 창업자가 또 판단해야 한다.

## 까닭별

| 재료 | 왜 안 만드나 |
|---|---|
| 청주 | **술은 인터넷 판매가 안 된다** |
| 꿀 | 창업자가 안 사 먹어 봐서 추천 못 함 |
| 소고기 | 부위가 너무 많아 하나로 못 고름 |
| 우삼겹 · 차돌박이 · 항정살 | 추천 못 함 |
| 달래 | **제철이 아니라 지금 없다** (제철 오면 다시 본다) |
| 고마다래 소스 | 파는 게 아니다 (레시피에서 만드는 것) |

⭐ 「달래」는 **제철이 오면 되살린다** — 이 표에서 빼면 목록에 다시 오른다.

## 🫒 올리브오일 — 왜 파트너스가 아닌가 (창업자 2026-09-12)

> 📮 창업자 = *"올리브오일은 쿠팡 파트너스에 **선택지가 너무 없었어.. 별로더라고..**"*

- 올리브유는 **43편으로 재료 1위**다. 수수료로 치면 제일 큰 자리인데 **코스트코 주소**를 쓴다(수수료 0원).
- ⛔ **값어치가 먼저다** — 창업자가 안 쓰는 기름을 추천하느니 수수료를 버린다.
  「18년차 주부가 직접 써본 것만」이 이 앱의 값어치고, 그게 흔들리면 링크 전부가 값이 없다.
- ⏳ **나중에 다시 볼 것** — 쿠팡에 괜찮은 게 들어오면 그때 파트너스 주소로 바꾼다.
  ⛔ 그때까지 「수수료 0원이니 바꾸자」고 «내가 먼저» 밀지 않는다. 창업자가 이미 보고 정했다.
- 🔁 **창업자가 «가끔 들어가 보기로»** 했다 (2026-09-12) — 나는 묻지 않는다. 창업자가 바뀐 걸 보면 말해 준다.
