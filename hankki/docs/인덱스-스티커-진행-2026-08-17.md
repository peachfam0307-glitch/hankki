## 3️⃣ ⏳ 내일 창업자가 정할 것

### ① 놓는 방식 — 판 넉 장을 찍어 뒀다
| | 흰 동그라미 | 그림 크기 | 걸침 |
|---|---|---|---|
| **A** 지금 | 있음 | 19px | 없음 |
| **B** 테없이 | **없음** | **30px** | 없음 |
| **C** 살짝 걸침 | **없음** | **30px** | 9px |
| **D** 반쯤 걸침 ＋ 기울임 | **없음** | **32px** | 15px · −12° |

✅✅ **[창업자 확정 2026-08-17] 흰 동그라미(테두리)는 «없앤다».**
   📮 *"웅 **테두리는 없어야이뻐.**"* → **A 는 죽었다.** 남은 건 B·C·D 중 «걸침의 양».
⭐ 창업자 말(*"바깥에 걸쳐서"*)까지 보면 **C 또는 D**.
⚠️ D 는 오른쪽 열이 **화면 가장자리에 바짝 붙는다** — 폰에서 확인 필요.

### ② 어떤 그림 · 몇 개
⭐ **「몇 개」의 답은 「이름표를 몇 개까지 만들게 할 거냐」와 같은 질문이 됐다.**
   📮 창업자 새 아이디어 = *"**해먹을 것, 맛있었던 것** 이런식으로 유저가 정해서 쓰고
      **아이콘을 누르면 그 레시피만 쭉 보이게**"* · *"지금 우리딸이 레시피보는데 먹고싶은걸 적고 있거든"*
   → 처음엔 **취향**(예쁜 걸 고른다)이었는데 여기서 **기능**(이름표마다 다른 아이콘)이 됐다.
   ⛔ 이건 데이터 모양이 바뀐다(`folder` 하나 → 여럿) — 그래서 밤에 안 했다.

📌 창업자가 앞서 고른 셋 = **`ck_30`**(숟가락＋체크마테) · **`ck_27`**(요리사모자＋클립) · **`ck_29`/`ck_05`**(하트 요리사모자)

### ③ ⚠️ 아직 아무도 안 짚은 것 — **「안 눌린 상태」를 어떻게 그리나**
지금은 **채운 책갈피(브라운) ↔ 빈 책갈피(sand 외곽선)** 로 켜짐/꺼짐을 나눈다.
수채화 스티커는 **「빈 상태」를 만들 수가 없다.**
갈래 = ⒜안 눌린 건 **흐리게**(opacity 0.3) ⒝안 눌린 건 **아무것도 안 보이고** 길게 눌러야 나온다
⒞안 눌린 건 **지금 쓰는 빈 책갈피** 그대로, 누르면 스티커로 바뀐다
⛔ ⒝는 「누를 수 있는 줄」을 모르게 만든다 — 오늘 인덱스를 목록으로 뺀 «이유»와 정면으로 어긋난다.
