## 4. 우리가 이미 확인한 사실 (변리사 답이랑 대조용)
- **한끼 09류** = "한끼" 단독 문자상표 없음. 오팬하우스는 **전자서적(G5206)** → 우리 앱SW(**G390802**)랑 유사군 달라 🟢 **등록 여지 큼.** (창업자 KIPRIS 직접확인: `SC=[G5206+G390802]*한끼` = 15건 **전부 출판/전자책**, 우리 앱 유사군 직격 없음)
- **식품(29류) "한끼" 368건** = 상품이 달라(음식 vs 앱) **우리 등록 안 막음.**
- "한끼"는 흔한 단어 → 문자만으론 식별력 약함 → **곰 결합으로 식별력** 확보(변리사 권고와 일치).
- **⚠️ 변리사 통화 조언(2026-07-23, 창업자 전달·별도 요약파일 있음)**: 오펜(전자책)보다 **"한끼"가 식음료군(식당·덮밥 등)에 아주 흔한 게 더 리스크** — "한끼"=밥 한 끼 뜻이라 음식업에 수두룩 + 우리 앱도 요리 인접. **→ 문자 '한끼'에 기대지 말고 '도형(곰 캐릭터)'으로 독창성·식별력 확보가 핵심.** = 우리 결합상표 전략과 100% 일치. **우리 물결곰(셰프모자·하트주걱·계란앞치마·물결털) = 이미 독창적**(리락쿠마·브라운과 다름 확인). 출원은 **곰 도형이 확 드러나는 결합상표**(로고 곰=ㅎ)로. 나중 **곰 단독 도형상표** 별도 출원 + (식음료 확장 시 29/43류도) 검토.
- **비용(2026·전자출원)**: 출원 **56,000원/류**(고시명칭) + 등록료(등록결정 후 2개월 내, 10년치) + 우선심사·초과상품 별도.
