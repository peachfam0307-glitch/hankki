## 5️⃣ ⭐⭐ 우리에게 준 것 — 「그래서 우리는 뭘 바꾸나」

### ⓐ 화폐에 «이름»을 붙이면 단위 충돌이 사라진다
우리는 2026-08-21 하루를 「장 vs 회」로 태웠다 — 「사진 1**장**에 AI 스캔 1**장**」이 안 읽혔기 때문.
쟤네 답 = **셋째 길, 이름을 붙인다.** 「솔트 1」은 사진 「1장」과 절대 안 부딪힌다.
⏳ 우리도 「AI 스캔 N회」 대신 이름을 지을지 — **창업자 판정 대상**(⛔내가 정하지 않는다).

### ⓑ 「구구절절」의 답 = 「?」 하나
화면엔 숫자만, 설명은 **「? 언제 얼마나 차감되나요」** 뒤에. 창업자가 *"다 구구절절이야"* 라고 한 그 문제의 표준 해법.

### ⓒ 원장(내역)이 분쟁을 막는다
우리 CLAUDE.md가 *"분쟁·환불 1순위가 «샀는데 어디 갔지»"* 라고 적어놓고 **해결책은 안 정했다.**
쟤네는 **＋/− 내역 한 줄씩**으로 푼다. ⏳결제 켜는 날 같이 만들 것.

### ⓓ 우리 유튜브 배관은 «이미 있고 우리가 잠갔다»
- `vite.config.js:74` — 공유받기가 `url` 을 **이미 받는다**
- `App.jsx:382` — `if (!link || source === 'youtube' || source === 'instagram') return` ← **우리가 잠갔다**
- 잠근 근거 = 2026-08-19 커밋 `c19ed585`, 창업자 전제 *"영상은 말로 설명하는거거든"*
- 🚨 **그 전제가 틀렸다** — 업계 방식은 자막이지 음성 인식이 아니다. **되살릴 수 있는 결정이다.**
- ⛔ 다만 **머리가 없다** = 자막 가져오기 **0줄** · LLM **0줄**. 「잠금 풀기」가 아니라 «새로 붙이기»다.

### ⓔ ⭐ 영상 재생은 «이미 되고 있다» — 자리가 반대편일 뿐
- `EditorScreen.jsx:504` — 진짜 `<iframe>`, 앱 «안»에서 유튜브가 재생된다 (「영상 보면서 쓰기」)
- `linkReader.js:19` `youtubeId()` — 주소에서 영상 번호를 뽑는다
- 레시피는 `sourceUrl` 을 **저장한다**
- ⛔ 그런데 **레시피 «보는» 화면엔 iframe 이 0건** — 주소 한 줄만(`RecipeDetailScreen.jsx:679`)
- 📌 **해먹으리의 핵심(영상 보며 요리)이 우리한테 반쯤 있는데 하필 「쓰는 동안」에만 있다.** 옮기는 일이지 만드는 일이 아니다.

### ⓕ 커머스 사진·가격은 «가입»의 문제다
우리 큐레이션 실측 = 제품 **42개** · 가격 **0** · 제품 개별 사진 **0** · 쿠팡으로 이어지는 것 **30곳**.
`docs/제휴프로그램-확인-2026-08-03.md` = *"쿠팡 파트너스 ✅ 가입만 하면 그날부터 붙는다"*.
⛔ **손으로 가격을 박으면 안 된다**(매일 바뀐다 = 표시광고 문제) · **제품 사진을 퍼오면 저작권**.
✅ 가입하면 **사진 · 실시간 가격 · 수수료** 셋이 한꺼번에 정식으로 온다. ⚠️대가성 공시가 딸려온다.

   ① 가져오기(`ImportScreen`) ② 레시피 편집 캡처(`EditorScreen`) ③ 냉장고 영수증(`PantryView`)
   → **유튜브가 «넷째»가 된다.** 이름 정의는 한 곳뿐이라(`src/ocr.js:122` `KEY_NAME`) 손댈 데가 적다.

⭐ **왜 맞는 판단인가** — 열쇠는 «기능 이름»이 아니라 **「AI가 대신 읽어주는 일」의 값**이다.
   사진에서 글자를 읽든 영상 자막에서 레시피를 뽑든 **유저가 사는 것은 같다.**
   ⛔ 화폐를 하나 더 만들면 2026-08-24 에 「열쇠 ↔ 레꾸팩」을 굳이 가른 이유
      (*"열쇠 사서 → 다시 팩을 사야 해?"* = 한 단계 더 생각하게 된다)를 우리 스스로 어긴다.

## ⛓ 그래서 «자동으로» 따라오는 것 — 「언제 깎나」

**기존 규칙 그대로 = 「저장 1건 = 1개」** (2026-07-26 확정 · 창업자 *"2장 썼는데 4장 나오면 문제"*)
   · ✅ 레시피가 **저장될 때** 1개
   · ⛔ **자막이 없어 실패하면 «안» 깎는다**

🚨 **유튜브에선 이게 더 중요하다** — **자막이 아예 없는 요리 영상이 흔하다.**
   실패할 때 깎으면 *"돈 냈는데 아무것도 안 나왔다"* 가 되고, 그건 CLAUDE.md 가 적어둔
   **분쟁·환불 1순위**(「샀는데 어디 갔지」)다. ⭐기존 규칙을 그대로 쓰면 저절로 막힌다.

## ⏳ 아직 «안» 정한 것 — 창업자 판정 대기

⛔ **영상 1편에 열쇠 «몇 개»인가** — 「저장 1건 = 1개」가 기본이지만
   유튜브는 사진 1장과 **원가가 다를 수 있다**(자막 길이 ＋ LLM 호출).
   → **원가를 재고 나서** 판정받는다. ⛔지금 짐작으로 「1개」라 굳히지 않는다.

## ⛔ 걸림돌 둘 (판정과 무관하게 남는다)

⑴ **자막을 어떻게 가져오나 = 모른다** — 공식 YouTube Data API 의 자막 내려받기는 «영상 주인»만.
