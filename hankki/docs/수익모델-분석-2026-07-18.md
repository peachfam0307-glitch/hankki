# 한끼 수익모델 분석 · 결정 (2026-07-18)

> 다른 앱들 실제 수익구조를 조사(웹 리서치)해서 한끼 맞춤으로 검토·결정한 문서.
> 요약: **AI로 돈 버는 게 아니라, 커머스+꾸미기가 메인 · AI는 편의+번들 미끼.**
> ⚠️ 가격·구조는 "방향과 상한선"이고, 진짜 숫자는 **출시 후 결제 데이터로 미세조정**.

## 1. 조사 결과 (다른 앱 수익구조)

### 레시피 앱 = 직접결제(구독)로 벌기 어렵다
- Paprika·Mela = **1회 결제 $4.99**(구독 아님) · SideChef = $9.99/월 · Samsung Food(옛 Whisk) = **무료**
- **레시피 앱 유저 중 22%만 유료 결제** → 레시피 자체엔 지갑 잘 안 열림.

### 한국 1위 "만개의레시피"의 진짜 수익원 = 커머스 ⭐
- MAU 앱 100만 / 웹 포함 600만. 수익 = **콘텐츠 커머스(식재료 구매 유도) + 광고 + 출판**.
- **레시피→식재료 구매 클릭률 8%, 전환율 40%.** 유저가 재료 링크를 "광고" 아닌 **"유용한 정보"로 수용**.
- ⇒ 우리 **"주부의 장바구니 + 쿠팡 파트너스"가 정확히 이 모델** = 검증된 최강 수익원.

### AI 앱 = 하이브리드가 대세
- 건당 과금(Imagen 장당 $0.05) or 구독, **둘 다 섞음**. 구독에 크레딧 포함 + 추가 크레딧팩(소멸 안 됨).
- 2025년 **35%가 순수구독 버림→하이브리드**. 크레딧이 헤비유저 ARPU 20~30% 더 뽑음.
- ⚠️ 유저 불만 1위: **시도할 때마다 차감**(실패해도) → 우린 **성공한 가져오기만 차감**.

### 꾸미기(코스메틱) = 감성구매, 마진 100%
- 카톡 이모티콘 플러스 = 월 4,900(프로모 3,900 → 구글 인앱결제로 현재 5,700), 15만개 무제한. 대박이지만 리뷰 "가격만 더 쌌어도" = **3,900이 심리 저항선**.
- 다꾸 앱 = 테마·배경 IAP + **작가 마켓(500+ 입점, 유저가 스티커 판매)** → 나중 큰 판.

## 2. 우리한테 뭐가 더 이익? (순위)
1. 🥇 **커머스(쿠팡 파트너스 + 주부의 장바구니)** — 결제마찰 0·서버 0·온브랜드·이미 있음. (근거: 만개 전환율 40%)
2. 🥈 **꾸미기 코스메틱** — 마진 100%·감성 재구매·바이럴. (근거: 이모티콘/다꾸)
3. 🥉 **AI 소액팩/번들** — 좋지만 원가↑·import는 앞에만 몰림.

→ **결론: AI로 돈 버는 게 아님. 커머스+꾸미기가 메인, AI는 편의+번들 미끼.** 레시피 앱이 구독으로 망하는 함정 회피.

## 3. 가격대 (벤치마크)
- **지갑 여는 상한 = 4,900**(이모티콘 플러스), **스윗스팟 = 3,900**(그 밑 = "이득" 느낌).
- 충동존 = **990**, 첫결제 관행 = 3,300. 6,000원+ = 급락.

## 4. 기능당 가격 구조
| 기능 | 상품 | 가격 | 원가/마진 |
|---|---|---|---|
| 커머스 | 쿠팡 파트너스 링크 | 유저 0원 | 구매액 ~3% 수수료 |
| AI 가져오기 | 소량팩 15회 | **990원** | 마진 77% |
| | 큰 팩 50회 | **2,900원** | 높음 |
| 꾸미기 | 테마팩 1개(영구소장) | **990~1,900원** | 마진 100% |
| | 꾸미기 올패스(무제한) | **2,900원/월** | 마진 100% |

## 5. 묶어팔기(번들) = 채택 ⭐
> **한끼 프리미엄 = 꾸미기 올패스(무제한) + AI 월 30회 = 3,900원/월**
- 위치: 이모티콘 플러스(5,700)·커피(4,500) 밑 → "제일 이득" 앵커.
- 마진: 꾸미기 원가 0 + AI 30회 원가 ~150원 → 실수령 3,315(구글15%뗌) - 150 = **순익 ~3,160원/월(마진 81%)**.
- 심리: 꾸미기(재구매 강함)가 매달 결제 이유를 만들고, AI가 보너스. 각각 팔 때보다 지불의사↑.

### 전체 메뉴 (good-better-best)
| | 가격 | 대상 |
|---|---|---|
| 무료 | 0 | OCR 항상 + AI 체험 몇 장 |
| AI 소량팩 | 990원 | 가끔 가져오는 사람 |
| 꾸미기 올패스 | 2,900/월 | 꾸미기만 |
| **한끼 프리미엄(번들)** | **3,900/월** ⭐ | 다 쓰는 사람(주력) |

⚠️ 번들·무제한엔 **fair-use 소프트캡**(하루 50장↑ 속도제한) 필수 — 마이너스 방어.

## 6. 실행 원칙
1. **메인 수익 = 커머스(쿠팡)** — 지금도 가능, 여기부터.
2. **2번 = 꾸미기 코스메틱**(마진 100%).
3. **AI = 편의 + 3,900 번들 미끼**(주력 결제 상품).
4. **AI는 성공 시에만 차감**.
5. 지금은 방향·가격 틀만, 진짜 숫자는 **출시 후 데이터로**.
