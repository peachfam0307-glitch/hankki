## 2️⃣ ✅✅ 돈 — **우리 계산이 맞았다** (진짜 단가를 찾았다)

| | 값 |
|---|---|

| 출력 | **36,400 뉴런 / 100만 토큰** ($0.400) |
| 무료 | **하루 10,000 뉴런** · UTC 00:00 리셋 · **카드 불필요** |

🔢 **레시피 한 편 다시 계산** (지시 500토큰 ＋ 원문 1,500토큰 = 입력 2,000 / 출력 750)
   입력 `2,000 × 5,500 ÷ 1,000,000` = **11.0 뉴런**
   출력 `750 × 36,400 ÷ 1,000,000` = **27.3 뉴런**

⭐ 8/28 문서의 **「41 뉴런 · 하루 243편」과 거의 같다.** 그때 단가 없이 어림으로 낸 값이었는데 맞았다.

⏳ **다만 「신고를 다시 봐야 하나」는 내가 못 닫았다** → 아래 6️⃣.

## 4️⃣ ⚠️ JSON 을 «보장하지 않는다» — 폴백이 필수다

- Workers AI 에 **JSON Mode** 가 있다(`response_format` ＋ json_schema · OpenAI SDK 호환)
- ⛔ **그래도 보장은 안 된다** — 공식 원문 = *"can't guarantee that the model responds according to the requested JSON Schema … an error **JSON Mode couldn't be met** is returned and must be handled"*
- ⛔ **지원 모델 «목록»이 따로 있는데 glm-4.7-flash 가 거기 있는지는 확인 못 했다**

✅ **그래서 지금 판은 JSON Mode 를 «안 쓴다»** — 대신 답에서 JSON 을 «집어내는» 폴백 셋을 둔다
   ① ```` ```json … ``` ```` 울타리 안 ② 첫 `{` ~ 마지막 `}` ③ 통째로 파싱
   ⭐ 근거 = **창업자가 놀이터에서 세 번 다 JSON 을 제대로 받았다**(11/12). 지금 방식으로 충분하다.
   ⏳ JSON Mode 는 **나중 개선거리**로 남긴다(지원 목록을 확인한 뒤).

## 6️⃣ ⚠️⚠️ 못 닫은 것 셋 — ⛔여기를 짐작으로 채우지 않는다

| | 무엇 | 왜 못 닫았나 | 어떻게 닫나 |
|---|---|---|---|
| ⑴ | **얼마나 걸리나(속도)** | Cloudflare 기준 실측을 못 찾았다. 다른 제공자 기준 첫 글자 0.75초 · 초당 200토큰대 → **우리 750토큰이면 몇 초** | **창업자가 놀이터에서 한 번 재면** 끝난다(초시계) |
| ⑵ | **JSON Mode 지원 모델인가** | 목록 페이지를 못 열었다(`developers.cloudflare.com` = 차단) | 안 써도 도니까 **급하지 않다** |
| ⑶ | **Play 데이터 보안 신고를 고쳐야 하나** | 콘솔을 못 본다 | ⭐**사진은 이미 신고돼 있다.** 새로 생기는 건 «붙여넣기 글자»뿐 → **AI 를 켜기 «전»에** 판단 |

⛔ **이 환경은 `developers.cloudflare.com` 도 못 연다**(EGRESS_BLOCKED · 2026-08-28 실측).
   위 값들은 전부 **WebSearch 요약**으로 얻었다 — 공식 원문을 직접 본 게 아니다.

## 7️⃣ 🚨🚨 리서치가 «드러낸» 설계 문제 — 창업자 판정이 필요하다

**「붙여넣기」에도 AI 를 쓰면 무료 한도가 금방 마른다.**

🔢 지금 앱에서 **붙여넣기는 열쇠 0개**(무료)다. 거기에 AI 를 붙이면 —
   유저가 아무리 많이 붙여넣어도 우리는 못 막고, **하루 260편**이 차면 그날 AI 가 쉰다.

| 갈래 | |
|---|---|
| **ⓐ 붙여넣기도 AI · 열쇠 안 쓴다** | ⭐**내 추천** — 전역 하루 200편에서 막고, 넘으면 «말없이» 규칙 파서로 떨어진다. 앱은 안 죽는다. ＋「무료로도 잘 되네」가 유료로 가는 미끼가 된다 |
| ⓑ 붙여넣기 AI 는 열쇠 1개 | 안전한데, **지금 공짜인 걸 유료로 바꾸는 것**이라 유저가 «뺏겼다»고 느낀다(⛔한 번 준 것은 안 빼앗는다) |
| ⓒ 사진만 AI · 붙여넣기는 규칙 파서 | 제일 안전하지만 **붙여넣기가 우리 앱에서 제일 많이 쓰는 길**이라 값어치가 반으로 준다 |

⛔ **돈이 걸린 자리라 내가 정하지 않는다**(규칙 11). 다만 **ⓐ 로 만들어도 한 줄로 ⓑ·ⓒ 가 된다** — 설정값으로 빼둔다.
