| **저장 API** | `ctx.storage.sql` — 생성자에 들어온다. `sql.exec(...)` · **정식 출시됨**(2025-04) |
| **설정** | `durable_objects.bindings` ＋ `migrations` 의 **`new_sqlite_classes`** 에 클래스 이름 |

```toml
[[durable_objects.bindings]]
name = "KEYS"            # 우리 이름은 정하면서
class_name = "KeyCounter"

[[migrations]]
tag = "v1"
new_sqlite_classes = ["KeyCounter"]
```

⚠️ **아직 모르는 것** — 대시보드(웹)에서 DO 를 만들 수 있나, 아니면 **wrangler(명령줄)가 필요한가.**
   ⭐ 이게 중요한 이유 = 창업자는 **웹 대시보드로 복붙**해 왔다. wrangler 가 필요하면 절차가 달라진다.
   ⛔ **내일 이것부터 확인한다.**

### ⏭ 내일 할 순서
1. **DO 를 웹 대시보드로 만들 수 있나** 확인 ← 이것부터
2. 카운트 서버(DO) ＋ **사고 재현판**(동시 5번·실패 되돌리기·달 바뀜·거짓 신호·오프라인)
3. AI 다듬기 워커 마무리(`ocr-proxy/worker-tidy.js` 초안은 `hold/AI다듬기-0828` 에 있다)
4. 앱 쪽(보너스 열쇠 · AI 정리 붙이기)
5. 그다음 창업자가 **Cloudflare 5분**
