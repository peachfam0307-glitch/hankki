# ✅ "왜 한끼?" 포지셔닝 문구 확정 — 2026-07-27

> 로드맵 백로그 "왜 한끼? 포지셔닝 1문장(온보딩·스토어)" 항목 해결. 창업자가 다수 후보 직접 제시 → 클로드가 겹치는 것 정리·자리 배정 → 창업자 확정("좋아").

## 확정본 (4개, 자리 배정)
| 문구 | 자리 | 비고 |
|---|---|---|
| **"한 끼를 해낸다면, 레꾸하세요."** | 온보딩 히어로(1번째 장면) / 스토어 대표문구 | "해냈다"(자기위로)+"레꾸"(차별점)를 한 문장에 — 최상위 포지셔닝 |
| **"레시피를 넘기면, 그날의 내가 보입니다."** | 온보딩 감정 장면(하트곰) | 레시피북=다이어리 메타포. 가장 독창적("신박") |
| **"레꾸하면, 한 끼가 추억이 된다."** | 온보딩 꾸미기 장면(펭펭 콩콩) | 레꾸 기능의 효과·베네핏 설명 |
| **"한 끼를 만든 마음까지 저장하세요."** | 스토어 소개 부제 | "저장"=우리 핵심 동작과 연결 |

## 탈락 사유 (기록만, 참고용)
- **비슷한 말 반복이라 정리한 것**: "한 끼를 해낸 당신의 기록" / "한 끼를 해낸 마음까지 담다" (→ "한 끼를 만든 마음까지 저장하세요"로 통합) · "레꾸하세요. 오늘의 한 끼를" (→ "한 끼를 해낸다면, 레꾸하세요"가 더 강함)
- **예쁘지만 앱 차별화가 안 보여서 보류(감성 콘텐츠용으로 보관)**: "한 끼는, 사랑의 다른 이름" · "오늘의 감정은, 오늘의 한 끼에" · "위로는 한 숟갈에서 시작된다" · "내 마음에도 레시피가 있다" · "맛있는 하루를 차곡차곡" · "오늘도 누군가를 위한 한 끼" — 나중에 인스타 감성 포스트 캡션 등으로 활용 가능
- **다른 자리가 더 어울려서 재배치 추천**: "오늘도 레꾸 완료!" → 꾸미기 저장 후 토스트 메시지로 / "오늘도 한 끼, 잘 해냈다" → 저장 완료 토스트·랜덤카드 문구로
