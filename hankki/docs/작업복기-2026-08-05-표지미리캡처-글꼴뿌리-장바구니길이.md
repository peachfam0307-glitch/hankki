## 2️⃣ 오늘의 큰 것 — **글꼴 꾸러미가 왜 «반쪽»이었나**

아침에 넣었다가(v9.63) 카드가 깨져서 뺐고(v9.66), 오후에 **원인을 찾아 다시 켰다**(v9.73).

### 📖 코드가 답을 갖고 있었다
`node_modules/html-to-image/lib/embed-webfonts.js`
- **238~253줄** `getUsedFonts(node)` = 그 노드와 자식들이 «지금 쓰는» font-family 만 모은다
- **263~266줄** = @font-face 를 그 목록에 있는 것만 남기고 **나머지는 버린다**

→ **꾸러미 내용은 «어떤 조각으로 만들었나»에 통째로 달려 있다.**

### 🔬 실측 (`scripts/_measure-fontembed.mjs`)
앱이 선언한 것 = **@font-face 8줄 · 글꼴 4종** (Jua · Gowun Dodum · Gaegu · Nanum Pen Script)

| 어디서 만드나 | 담기는 글꼴 |
|---|---|
| 앱 켠 직후 `document.body` ← **옛 코드가 한 방식** | 2종 — **Jua 빠짐** |
| 레꾸자랑 탭 | 2종 (그대로) |
| 선택 시트 열린 뒤 | 3종 |
| **꾸민 표지** 하나 | Gowun Dodum · Gaegu |
| **레시피카드** 하나 | **Jua** |

⭐⭐ **두 장이 서로 다른 글꼴을 쓴다** → 한쪽으로 만든 꾸러미로 둘 다 덮으면 반드시 한쪽이 깨진다.
⭐⭐ 그리고 빠진 게 하필 **Jua** 였다 — 창업자 캡처에서 깨진
**「한끼」·「15분」·「레시피 보러가기」가 전부 Jua** 다. 우연이 아니었다.

### ✅ 처방
**4종을 «전부» 쓰는 표본 조각**을 화면 밖에 잠깐 붙여 그걸로 만든다(`src/fontEmbed.js`).
라이브러리 자기 코드가 4종을 다 담는다. 🔒 **4종이 다 안 들어 있으면 아예 안 쓴다**
(느려도 정확한 옛 길로 — 깨진 카드가 친구한테 나가는 건 못 되돌린다).

### 📌 덤
라이브러리는 **파일→base64 결과를 이미 캐시한다**(`dataurl.js` 83~137줄).
어제 *"글꼴 파일 미리 받아두면 빨라질 것"* 이 효과 0이었던 것과 앞뒤가 맞는다.

## 3️⃣ 내가 틀린 것 (전부 남긴다)

### ⛔ ① 카드 글자 깨짐 — **내가 만든 회귀** (v9.63 → v9.66)
빈 값을 영구 캐시했고, 빈 `fontEmbedCSS` 는 「글꼴 심지 마」로 읽힌다.
📌 그리고 **눈으로 카드를 안 봤다.** 오후엔 반드시 봤다(그래서 통과).

### ⛔ ② 「기본값을 신호로 읽었다」 (v9.64 → v9.65)
`source !== 'manual'` 로 「가져온 것」을 골랐는데 `EditorScreen:136` 이
**출처를 모르면 `manual` 을 넣는다**. 창업자 세 편이 통째로 건너뛰어졌다.
→ 판정을 「말투」로 바꿔 `source` 를 아예 안 본다.

### ⛔ ③ 장바구니에서 **딴 문제를 고쳤다** (v9.70)
창업자 *"왜 장바구니 초성찾기했어? 길이가 문제인데"* — 맞다.
8/3 창업자 말(*"많아지면 검색 추가하자"*)을 근거로 찾기를 넣었는데
**오늘의 문제는 「훑을 때 세로로 길다」**였다.

### ⛔ ④ **자르기만 하고 「더보기」를 안 달았다** (v9.71 → v9.73)
창업자 *"올리브오일 250ml짜리는 목록에서 사라졌어."*
`기름·육수` = 스톡·육수(4) ＋ 올리브오일(2). 상한 5라 스톡이 4를 먹고
올리브오일엔 1칸만 남아 250ml 가 잘렸는데, **더보기 버튼은 「전체」에서만 그려졌다.**
📌 **자르는 코드와 더보기 코드가 서로 다른 조건을 봤다. 자를 땐 꺼낼 길을 같이 단다.**

### ⛔ ⑤ **개수를 줄이면서 «무엇을 세는지»를 안 봤다** (v9.73 → v9.74)
창업자 *"양념류가 9줄이야."* — 제품을 2개씩으로 줄여도
**칸 이름이 줄줄이 남으면 화면은 그대로 길다.** 「제품」과 「줄」은 다른 단위다.

### ⛔ ⑥ 「캐시 때문에 빨라졌다」는 설명이 틀렸다
글꼴 파일 미리 받아두기(`warmShareAssets`)를 넣고 재보니 **25초 그대로**.
병목은 네트워크가 아니라 CPU 였다 → **효과 없는 코드라 되돌리고 정정 보고.**

### ⛔ ⑦ JSX 주석을 화살표함수 여는 괄호 «안»에 넣어 빌드 깨짐 (v9.67)
**바로 위 `more()` 에 똑같은 경고가 내 손으로 적혀 있는데 또 밟았다.**

### ⛔ ⑧ 「설명 한 줄로 자르기」 추천이 틀렸다
실측 = 설명 39개 중 **20자 이하 0개**(최단 41자·가운데 74·최장 127) → 자르지 않고 «접기»로.
