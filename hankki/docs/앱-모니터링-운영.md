# 한끼 · 출시 후 모니터링·운영 가이드

> 출시하면 "잘 되고 있나?"를 어디서 보는지. 솔로 창업자가 부담 없이 챙길 수 있게 정리.
> 큰 원칙: 초기엔 **Play Console 숫자 + 익명 의견 폼**이 곧 대시보드. 유저 늘면 최소 분석만 추가.

---

## 1. 지금 바로 볼 수 있는 것 — Play Console (무료, 이미 있음)

| 항목 | 어디서 | 무슨 신호 |
|---|---|---|
| **설치/삭제 수** | 통계 | 삭제율 높으면 실망 포인트 있음 |
| **활성 사용자·기기** | 통계 | 나라·기종·안드로이드 버전별 |
| **평점·리뷰** | 평점 및 리뷰 | 별점 + 후기. **직접 답글** 달 수 있음(중요) |
| **Android vitals(비정상 종료)** | 품질 → Android vitals | 크래시·ANR 비율. 높으면 노출도 하락 → 낮게 유지 |
| **사전 출시 보고서** | 테스트 및 출시 | 구글이 실기기로 자동 실행 → 크래시·접근성·보안 리포트 |

## 2. 이미 연결된 질적 피드백
- **익명 의견 폼** (`설정 → 의견 보내기`) — 숫자로 안 보이는 "왜"를 받음. 초기엔 제일 값짐.
- 폼: 3문항(별점·불편한 점·바라는 기능), 익명. 응답은 구글 폼 '응답' 탭에서 확인.

## 3. ⚠️ 지금은 "못 보는" 것 (정직)

한끼는 **데이터를 하나도 안 모으는 로컬 앱**(개인정보 수집 '안 함' 신고)이라 **앱 안 행동은 안 보임**:
- 레시피 몇 개 저장했는지 / 꾸미기 얼마나 쓰는지 / 어디서 이탈하는지 / 재방문율

→ 프라이버시엔 최고지만 행동 데이터는 안 보임. **보려면 아래 4번(분석 도구)**을 나중에 붙여야 함.
붙이면 **Play 데이터 보안 신고를 '수집함'으로 변경 + 개인정보처리방침 수정** 필요(정직 원칙).

## 4. 사이트 다운 알림 — UptimeRobot (무료, 5분)

한끼는 GitHub Pages에 올라가 있어 사이트가 죽으면 앱도 안 열림. 무료 감시로 알림 받기:

1. **uptimerobot.com** 가입(무료 플랜: 모니터 50개·5분 간격)
2. **+ Add New Monitor**
   - Monitor Type: **HTTP(s)**
   - Friendly Name: `한끼`
   - URL: `https://peachfam0307-glitch.github.io/hankki/`
   - Monitoring Interval: 5분
3. **Alert Contacts**: 본인 이메일(또는 카톡 연동/앱) 추가 → 다운되면 즉시 알림
4. (선택) assetlinks도 하나 더: `https://peachfam0307-glitch.github.io/.well-known/assetlinks.json`

→ 이러면 사이트가 죽거나 assetlinks가 깨지면 바로 알아챔.

## 5. 나중에 — 프라이버시형 분석 도구 비교 (유저 100명+ 되면)

행동(재방문·인기 화면·이탈)을 보고 싶을 때. **개인정보 최소 수집** 위주로:

| 도구 | 특징 | 비용 | 추천도 |
|---|---|---|---|
| **Plausible** | 쿠키 없음·경량·EU서버, 개인정보 친화 | 유료(월 $9~) | ⭐ 브랜드 톤과 맞음 |
| **Umami** | 오픈소스·직접 호스팅하면 무료·쿠키 없음 | 무료(셀프호스팅) | ⭐ 비용 0, 약간의 세팅 |
| **GA4(구글)** | 무료·강력하지만 무겁고 개인정보 수집 많음 | 무료 | △ 정직 톤과 덜 맞음 |

**붙일 때 체크:**
- [ ] Play **데이터 보안** 신고 '수집함'으로 수정(수집 항목 정직히)
- [ ] **개인정보처리방침** 갱신(`hankki/privacy.html`)
- [ ] 최소한만 — 페이지뷰·주요 버튼 클릭 정도. 개인 식별 정보는 절대 X.
