## 📏 꺼낼 때 규칙

1. **한 번에 한 카테고리만.** 프레임 리컬러 + 새 캐릭터 + 효과를 같이 내면 다음에 줄 게 없다.
2. **캐릭터 카드는 시즌·이벤트에 붙여서.** 평상시 업뎃에 쓰지 말 것.
3. **꺼내면 이 표에서 지우고** 그 자리에 "언제 냈는지" 기록.
4. ⚠️ **아껴둔 걸 잊지 말 것** — 안 쓰면 아낀 게 아니라 잃은 것. 새 세트 뽑기 전에 **여기부터 본다.**
