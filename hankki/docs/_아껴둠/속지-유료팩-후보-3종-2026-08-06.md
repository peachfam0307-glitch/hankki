## 2️⃣ 창업자가 정한 파는 방식

> *"응 판매한다면 **속지랑 꾸미기세트**를 팔까해. **안겹치게** 내가 시안뽑고 있어."*
> *"얜 **스티커까지 다 패키지**라 좋아"*
> *"저런식으로 **풀 패키지로해서 2장이나 3장씩** 팔면 좋을 것 같아 **테마 다르게**해서"*

- **한 팩 = 속지 2~3장 ＋ 그 속지에 맞는 꾸미기 세트.** 그림이 한 세트라 따로 놀지 않는다.
- **테마별로 가른다** — 계절 5팩(추석·핼러윈·가을·크리스마스·겨울)이 「계절」 축이라면
  이건 **「쓰임」 축**이다. 축이 다르니 **한 사람이 둘 다 산다.**
- ⛔ **캐릭터는 시안 단계에서 뺐다** — 창업자 *"선택된 팩에만 정식 꼬르곰 친구들을 추가하면 돼."*

## 3️⃣ 만들 때 미리 알아야 할 것 (지금 코드로 확인한 값)

### ⭐ 속지는 «그림 한 장 ＋ 좌표»면 끝난다

`src/data/papers.js` 의 `PAPER_ARTS` 에 한 줄 넣으면 된다. 새로 만들 코드가 없다:

```js
{ key: '...', label: '...', src: dpXxx, note: '...',
  fields: { rule: 'write'|'paper'|'none', title: {...}, photo: {...}, picks: [...], write: {...} } }
```

- `rule: 'write'` = **줄이 쓰는 칸 «안»에만** — 사진칸에 줄이 안 간다
- `picks` = **그림에 인쇄된 아이콘 위에 투명 버튼**을 얹어 형광펜으로 칠한다. 축을 여러 개 받는다
- 종이색 5(아이보리·하늘·분홍·세이지·크라프트) · 선 4(무지·줄·모눈·도트)가 **자동으로 얹힌다**

### ⛔ 하나만 코드가 없다 — **사진칸 여러 개**

지금 `fields.photo` 는 **한 칸**이다(`PaperSheet.jsx`). 「같이 먹은 날」·「먹고 걷고 기억하기」는
사진이 둘 이상이라 **`photo` 를 배열로 바꿔야 한다.** → 할 일 목록에 있음.

### 📐 시안 뽑을 때 규격 (「오늘의 한끼」로 검증된 값 — 그대로 쓴다)

**속지 판**
- 세로 **3:4**(1086×1448 근처) · 배경 **순백 254~255** — ⚠️판 «안쪽»도 순백이라야 종이색 5가 산다
- ⛔ **글자 0** — 제목·날짜·메모는 앱이 얹는다(글자가 그려져 있으면 못 고친다)
- ⛔ **메모칸은 빈 칸으로** — 줄은 앱이 긋는다(유저가 무지·줄·모눈·도트를 고른다)
- ⛔ `transparent background` 라고 쓰지 말 것 — AI 가 **회색 격자를 그린다**

**낱개 시트**
- 같은 3:4 한 장에 **≤25컷** · 흰 배경 · 컷끼리 안 붙게
- 컷 긴변 **200px 이상**(그래야 서랍·캔버스에서 안 뭉갠다)
