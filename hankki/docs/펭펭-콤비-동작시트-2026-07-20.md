> 창업자가 GPT(ChatGPT 이미지)에 **복붙해서 바로 생성**하는 시트.
> 목적 = 앱 **꾸미기 스티커**용 캐릭터 늘리기. 펭펭(딸)·콤비(곰+펭) 위주.

## ✅ 먼저 기억할 것 (캐릭터 규칙)
- **펭펭 = 무표정 시크(deadpan chic).** 트렌치코트 + 베레모. **머리 = 끝이 안으로 살짝 말리는 단발 보브(C컬)** ← 바깥 뻗침 ❌.
  - 매력 포인트: **감정적인 행동을 무표정으로** 함(하트를 뿅 하면서도 얼굴은 시크). 이 갭이 펭펭의 정체성.
- **꼬르곰 = 표정 풍부·신남**(곰은 감정 다 드러남). 콤비에서 곰이 감정 담당, 펭이 시크 담당.
- **화질**: 개별은 한 장 **2×2 = 4컷**(컷당 500~600px+), 콤비는 한 장 **1컷**(둘이 함께라 크게). 6컷 이상 ❌(흐려짐).
- **배경**: 순백(#FFFFFF), 그림자·글자·번호·워터마크 없이 **전신**. 외곽선은 **굵고 끊김 없이 이어진 검은 선**.

## 🐧 펭펭 동작 리스트 (꾸미기용 · 전부 무표정 시크)
> 얼굴은 계속 무표정, **손·자세만** 바뀌는 게 핵심. 4컷씩 3장 = 12동작.

**1장 (기본 리액션)**
1. 그냥 무심하게 서 있기 (기본 포즈)
2. 두 손으로 하트 뿅 (얼굴은 무표정)
3. 아이스 음료(투명컵+빨대) 들고 시크하게
4. 엄지척 (무심하게 "최고")

**2장 (응원·자랑)**
5. 짝짝 박수 (무표정)
6. 주먹 불끈 파이팅 (무심한 응원)
7. 요리 접시 들고 자랑하듯 보여주기 (무표정)
8. 포크로 음식 냠냠 (무심하게 먹는 중)

**3장 (귀여운 시크)**
9. 하트눈(눈만 하트, 입은 무표정 — 살짝 좋아하는 티)
10. 브이(V) 손 셀카각 (무심)
11. 어깨 으쓱 ("몰라~" 시크)
12. 꾸벅 목례 (고마워, 무표정)

## 🐻🐧 콤비 동작 리스트 (곰=신남 / 펭=무심) · 각 1컷씩
> 대비가 포인트: **곰은 감정 활짝, 펭은 옆에서 시크.** 6동작 = 6장.

1. **[대표]** 곰이 요리 접시 들고 자랑 + 펭이 옆에서 포크로 무심하게 먹기
2. **[애정]** 곰이 두 손 하트 뿅 + 펭은 무표정으로 옆에
3. **[해냈다]** 곰 두 손 만세 신남 + 펭 엄지척(무심)
4. **[하이파이브]** 곰·펭 손바닥 마주침 (곰 활짝 웃음, 펭 무표정)
5. **[나란히]** 둘이 앉아 같이 먹기 (곰 냠냠 행복, 펭 오물오물 무심)
6. **[다정]** 곰이 펭 어깨 살짝 감싸고 둘 다 정면 (곰 웃음, 펭 시크)

## 📋 GPT 복붙 프롬프트 (포즈만 갈아끼우면 됨)

### 🐧 펭펭 — 4컷 한 장 (첨부: 기존 펭펭 그림 1~2장)
```
첨부한 펭펭 캐릭터 그대로 그려줘(트렌치코트·베레모·무표정 시크, 같은 화풍·굵은 검은 외곽선).
★머리 수정: 바깥으로 뻗치지 말고 끝이 안으로 살짝 말리는 단발 보브컷(C컬)로.
순백색(#FFFFFF) 배경에 2x2로 4컷, 각 캐릭터 아주 크게·서로 안 겹치게 넉넉한 간격.
그림자·글자·번호 없이 전신. 얼굴은 전부 무표정 시크, 손·자세만 다르게. 포즈:
1) 그냥 무심하게 서 있기
2) 두 손으로 하트 뿅 (얼굴 무표정)
3) 아이스 음료 들고 시크하게
4) 엄지척 (무심하게 최고)
```
> 5~8, 9~12는 위 포즈 4줄만 갈아끼워서 2장 더.

### 🐻🐧 콤비 — 1컷 한 장 (첨부: 기존 콤비 그림)
```
첨부한 꼬르곰+펭펭 콤비 그대로(곰=표정 풍부·신남, 펭=무표정 시크, 같은 화풍·굵은 외곽선).
★펭 머리: 끝이 안으로 말리는 단발 보브컷(C컬).
순백색(#FFFFFF) 배경, 한 장에 1컷만 크게(둘이 함께라 최대한 크게), 그림자·글자·번호 없이 전신.
[포즈] 곰이 요리 접시를 들고 자랑, 펭이 옆에서 무심하게 포크로 먹음.
```
> 콤비는 한 장에 1개씩, 6장 따로 생성(포즈만 교체).
