## 3️⃣ ⛔ 없는 것 = AAB 에 BILLING 권한

`android/twa-manifest.json` **29줄** 실물:
```
"features": {},
"alphaDependencies": { "enabled": false }
```

**둘 다 비어 있다.** 켜려면:
```
"features": { "playBilling": { "enabled": true } },
"alphaDependencies": { "enabled": true }
```
→ **AAB 를 다시 구워야 한다.**

### ⑧ 🔢🔢 [2026-08-13 창업자 확정] **카운트 = 「한 묶음 = 1장」 · 지금은 안내로 막고, 고치기는 다음 Deploy 때**

📮 창업자 *"스캔했다가 취소해도 카운트되는거지?"* → *"저장안하고 취소하면 그래도 스캔은 된거니까 카운트로?"*
📮 창업자 *"한번에 2장 넣으면 2장소진된다는 것도 알려야겠네"* → *"그래 그렇게 하자. **어차피 2장짜리 레시피는 많지 않아**"*

🔢 **실측 = 지금은 「사진 한 장 읽을 때마다 1장」이다.**
   · 자르기에서 **「취소」 = 안 깎인다** ✅ (`EditorScreen.jsx` 의 `onCancel` 이 `runOcr` 를 «안» 부른다 = 서버 호출 자체가 없다)
   · **「이 부분만 읽기」·「전체 사용」 = 깎인다** — 저장을 안 해도, 결과가 엉망이라 다시 해도.
   ⛔ 그래서 **캡처 3장으로 레시피 «하나»를 만들면 3장이 나간다.**

⛔⛔ **내가 오늘 여기서 틀렸다** — 창업자가 *"스캔했으면 카운트가 맞지 않냐"* 고 물었을 때
   확인 없이 *"맞다"* 고 답했는데, **문서엔 이미 반대로 적혀 있었다**:
   > `docs/AI-레시피추출-기능계획.md:184` · `CLAUDE.md:32` — **「저장 성공 시 1 차감」(멀티포토·재시도·실패는 안 깎음)**
   ⭐ 훅이 시키는 `decided.mjs` 를 «먼저» 돌렸으면 안 틀렸다. **기억으로 답하지 말 것.**

✅ **확정된 것 (오늘)**
   | | |
   |---|---|
   | 고치는 방식 | ⭐ **「같은 묶음이면 1장만 센다」** — 앱이 묶음 표시를 실어 보내고 서버가 1번만 깎는다 |
   | ⛔ 이어붙이기 | **안 한다** (내가 먼저 낸 안인데 창업자가 *"문제 없어?"* 로 물어 따져 보니 위험이 셋) |
   | 언제 | **다음 Deploy 때 한꺼번에** — 8/16 재신청 전까지 대시보드 왕복을 줄인다 |
   | 그때까지 | **안내로 막는다**(아래) |

⛔ **이어붙이기를 접은 이유 셋** (창업자 *"잘 안붙여진다거나, 편집하는데 복잡하다거나…"* 물음에 실제로 따져 본 것)
   ① **크기 초과** — 서버 한도가 `MAX_B64` ≈ 6MB. 캡처 3장이면 넘을 수 있고, 줄이면 «글씨가 뭉개져 인식률이 떨어진다»
   ② **하나 실패 = 전부 실패** — 지금은 3장 중 1장이 실패해도 나머지가 들어온다. 이어붙이면 통째로 날아간다
   ③ (편집 복잡은 «걱정 없음» — 이어붙이기는 안에서만 일어나 유저 화면은 그대로다)
   ⭐ 묶음 방식은 이 셋이 전부 없다. 구글은 3번 부르니 **원가 6원**이지만 990원 팩이라 마진은 그대로 99%.

✅ **지금 넣은 안내 (v10.55)**
   · 사진을 **2장 이상 고른 «직후»** 토스트 = *"사진 3장이라 AI 스캔 3장을 써요"*
     ⭐ **고르기 «전»이 아니라 «직후»** — 고른 장수를 알아야 정확한 숫자를 말할 수 있다.
     ⚠️ 잔량이 모자라면 = *"사진 5장인데 AI 스캔은 2장 남았어요 · 나머지는 기본 인식이에요"*
     ⛔ **한 장일 땐 안 띄운다** — 잔소리가 된다(⛔재촉 금지).
   · 「캡처는 이렇게 채워요」 첫 줄에 값을 같이 적었다 = *"여러 장을 한꺼번에 골라도 돼요 — **사진 1장에 AI 스캔 1장씩 써요**"*
     ⭐⭐ **권하는 줄에 값을 같이 적는다** — 「한꺼번에 고르세요」로 권해놓고 «조용히» 깎으면 안 된다.

⏳ **아직 «안» 정한 것 — ⛔확정처럼 쓰지 말 것**

   ⭐ 묶음 방식을 넣는 날 **하나로 정해야 한다** — 그 전엔 어느 쪽도 「정해졌다」고 적지 않는다.
   · Ⓐ 저장해야 차감 = 재시도·실패가 공짜라 유저에게 친절 / ⛔읽기만 반복하는 공짜 구멍(전역 900이 비용은 막는다)
   · Ⓑ 읽으면 차감 = 구글 요금과 정확히 맞고 구멍이 없다 / ⛔잘못 잘린 게 유저 잘못이 아닌데도 나간다
