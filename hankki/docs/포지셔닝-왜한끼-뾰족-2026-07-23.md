# 🎯 "왜 한끼?" 포지셔닝 — 뾰족하게 (2026-07-23)

> 기존(메인컨셉·포지셔닝문구·경쟁분석 2026-07-19)은 탄탄. 이 문서 = 그 위에서 **"획득 훅"만 날카롭게.**

## 0. 한 줄 결론
**"정리"로 경쟁하면 죽고, "꾸미고 자랑"으로 가면 산다. 획득 훅 = 곰펭으로 꾸민 카드 그 자체.**

## 1. 왜 이게 문제냐 (진단)
- "레시피 정리·저장·AI 가져오기" = **레드오션**(만개·해먹 + 신생앱 10개: 요리로그·요리조리·냠냠·해먹으리…). AI 가져오기는 이미 **무료 table stakes.**
- 심지어 **"감정 기록"도 Recipesoup**가 시작함(왜 만들었는지·그날 감정).
- → **아무도 안 하는 것 = 캐릭터 IP(꼬르곰·펭펭) + 다꾸 꾸미기 + 자랑 카드 + 18년 큐레이션 + 창업자 안목.** 여기가 유일한 생존 자리.

## 2. 포지셔닝은 2층이다 (핵심)
| 층 | 질문 | 답 | 상태 |
|---|---|---|---|
| **유지** | 왜 계속 쓰냐 | "오늘도 한 끼 해낸 나에게" (감정·위로·유산) | ✅ 확정 |
| **획득** | 왜 깔아/전환하냐 | **"저 귀여운 카드, 나도 만들고 싶다"** | ⭐ 여기를 뾰족하게 |

> **획득 훅은 언어가 아니라 시각이다.** 사람은 태그라인 읽고 안 깐다. **맘카페·인스타에서 곰펭으로 꾸민 카드를 보고 "어 귀엽다, 나도" 하고 깐다.** → **카드가 곧 광고.** 그래서 카드 퀄리티 + 원탭 꾸미기 = 획득 엔진의 심장.

## 3. 획득 한 문장 (후보 — 창업자 픽)
- **A. "내 레시피를, 다꾸처럼 예쁘게 — 꼬르곰·펭펭이랑."** ⭐ (시각·신규·캐릭터)
- B. "레시피 정리? 우린 레시피 '다꾸'해요."
- C. "요리하는 나를 위한 감정 레시피북 — 예쁘게 꾸미고 자랑해요."
- D. "오늘 뭐 해먹지 말고 — 오늘 뭐 해냈지." (감정 반전, 위트)

## 4. 카테고리를 바꿔라 (안 묻히는 법)
- ❌ "레시피 정리 앱" (= 만개·신생앱 10개와 같은 칸 → 비교당해 묻힘)
- ✅ **"레시피 다꾸 · 감정 레시피북"** = **새 카테고리 = 비교 대상 없음.** (다꾸/폴꾸 감성을 요리로 가져온 최초)

## 5. 포지셔닝 맵
| 앱 | 한 마디 |
|---|---|
| 만개·해먹 | "뭐 해먹지" **검색 도구** |
| 신생앱(요리로그 등) | AI로 레시피 **저장·정리**(효율) |
| Recipesoup | 감정 레시피 **다이어리** |
| **한끼** | **곰펭이랑 꾸미고 자랑하는 감정 레시피북** (감정+캐릭터+다꾸+자랑+큐레이션 = 유일 조합) |

## 6. 메시지 어디에 (적용)
- **맘카페·인스타**(획득 1채널): 곰펭 꾸민 **카드 이미지 + "18년차 주부가 만든" 스토리.** 홍보 톤 X, 공유 톤 O. (카드가 훅)
- **스토어 첫 스샷**: 지금 4장에 **꾸미기 화면 없음** → 꾸미기·공유를 맨 앞에 (획득엔 이게 1순위 비주얼).
- **온보딩 3초**: "이렇게 꾸며봐" **아하모먼트**(움직이는 예시 1개) — 깐 사람을 붙잡는 첫 관문.
- **홈 상단**: "오늘도 한 끼, 해냈어요"(유지·감정).

## 7. 실행 함의 (이 포지셔닝이 시키는 것)
1. **바이럴 카드 리뉴얼 + 원탭 감성 템플릿** = 획득 엔진 심장(게이트 풀림).
2. **스토어 스샷에 꾸미기·공유 전면 배치.**
3. **맘카페용 카드+스토리 세트 = 클로드 제작**(창업자는 붙여넣기만).
4. "정리/AI"는 기본기로 조용히(헤드라인 톤다운), **간판은 "꾸미고 자랑".**

> **결론: 한끼의 간판을 "레시피 정리"에서 "곰펭이랑 꾸미고 자랑하는 감정 레시피북"으로. 획득은 곰펭 카드가 대신 영업한다.**
