## ③ 가져오기 화면 — 창업자가 «구성까지» 줬다

```
① 인스타·유튜브 보다가 캡처 → 한끼로 공유
② 이미 저장된 사진(갤러리) → 한끼로 공유
③ 한끼 앱 가져오기에서 사진 가져오기
④ 직접 입력하기
```

⭐⭐ **이게 오늘 내가 물어본 둘에 대한 답이다** —
· *"② Instagram 줄은 ①에 합칠까 남길까"* → **①에 합쳐졌다**(「인스타·유튜브 보다가 캡처」)
