# 한끼 · 출시 실행 체크리스트 (D-day 순서)

> 개발자 계정 승인 완료(플레이 콘솔 "앱 만들기" 열림) 시점부터의 **실행 순서**.
> 큰 원칙: **2주 걸리는 비공개 테스트를 제일 먼저 걸어 시계를 돌리고, 그동안 그래픽·폼을 채운다.**

## ⚠️ 시간 장애물 먼저 이해하기
신규 **개인** 개발자 계정(2023.11 이후)은 **비공개 테스트에 12명 이상이 14일 연속** 참여해야
정식 출시(프로덕션) 신청이 열린다. → 이게 전체 일정의 병목. **오늘 바로 시작.**
(조직/회사 계정이면 이 규칙 없음 → 바로 프로덕션 제출 가능.)

---

## STEP 0 — 계정 유형 확인 (1분)
- [ ] 내 계정이 **개인**인가 **조직**인가? (Play Console → 설정 → 개발자 계정)
  - 개인 → 아래 STEP 1(테스트) 반드시 먼저
  - 조직 → STEP 1 건너뛰고 바로 STEP 4(프로덕션) 가능

## STEP 1 — AAB 앱 파일 만들기 (하루) ※테스트 업로드에 필요
- [ ] PWABuilder(https://www.pwabuilder.com)에 앱 주소 넣고 Android 패키지 생성
      → 앱 주소: https://peachfam0307-glitch.github.io/hankki/
- [ ] **signing.keystore + signing-key-info.txt 안전하게 백업** (분실 시 영영 업데이트 불가)
- [ ] zip 안의 `assetlinks.json` 확보 → STEP 3에서 사용
  ▶ 상세: `출시-가이드.md` 1단계

## STEP 2 — 비공개 테스트 걸기 (개인 계정) → **2주 시계 시작**
- [ ] Play Console → 앱 만들기(한끼 / 한국어 / 앱 / 무료)
- [ ] 비공개 테스트(Closed testing) 트랙 생성 → STEP 1의 AAB 업로드
- [ ] 테스터 **12명 이상** 이메일 등록 (가족·친구·맘카페 지인) → 초대 링크 공유
- [ ] 12명이 **설치하고 14일 유지**하도록 안내 (중간에 지우면 카운트 깨질 수 있음)
  ▶ 테스터 모집 안내문은 `친구초대-안내.md` 활용

## STEP 3 — 도메인 인증 (테스트 도는 동안, 30분)
- [ ] `peachfam0307-glitch.github.io` 저장소 새로 만들고
      `.well-known/assetlinks.json` 올리기 → Pages 활성화
- [ ] `https://peachfam0307-glitch.github.io/.well-known/assetlinks.json` 열려서 내용 보이면 성공
  ▶ 상세: `출시-가이드.md` 2단계

## STEP 4 — 스토어 등록정보 + 그래픽 (테스트 도는 동안)
- [ ] **앱 아이콘 512×512** — `public/icons/icon-512-v3.png` ✅ 있음
- [ ] **대표 그래픽 1024×500** — 제작 필요 (클로드가 제작) ← design/promo 폰트 재사용
- [ ] **스크린샷 최소 2장(권장 6장)** — 제작/캡처 필요
- [ ] 앱 이름·짧은 설명·자세한 설명 붙여넣기 ▶ `스토어-등록물.md` 복붙
- [ ] 카테고리: 음식 및 음료 / 문의 이메일 / 가격: 무료

## STEP 5 — 앱 콘텐츠(정책) 폼 (테스트 도는 동안, 30분)
- [ ] 개인정보처리방침 URL: https://peachfam0307-glitch.github.io/hankki/privacy.html
- [ ] **데이터 보안(Data safety): 수집·공유 "아니요"** (전부 폰 안 localStorage) ▶ `출시-가이드.md` 참고
- [ ] 콘텐츠 등급 설문 → 전체 이용가
- [ ] 타겟 연령, 광고 없음, 정부앱 아님 등 선언

## STEP 6 — 정식 출시 (14일 충족 후)
- [ ] (개인 계정) 프로덕션 액세스 신청 → 승인
- [ ] 프로덕션 트랙에 AAB 올리고 **출시 제출** → 심사 며칠 → 게시 🎉
