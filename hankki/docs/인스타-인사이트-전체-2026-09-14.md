⚠️ **다만 날짜가 한 칸 어긋난다 — 넘기지 않고 적어 둔다**
```
창업자 말   =  4일째
화면 값     =  기간 6일 · 「5일 후 종료」  →  거꾸로 세면 «2일째»

```
⛔ 셋 중 둘이 「2일째」를 가리킨다. **「4일째」가 릴스를 «올린» 뒤 날수(9/12 게시 → 오늘 9/14 로 3일째)일 수 있다.** [확인 필요]
   👉 갈리는 법 = 이 광고 상세에서 **시작 날짜 한 줄**만 보면 된다.

| 항목 | 값 |
|---|---:|
| 프로필 방문 | **25** |
| 프로필 방문당 비용 | **US$0.16** |
| 팔로우 | 10 |
| 댓글 | 0 |
| 지출 | **US$4.11 / US$18.00** |
| 기간 | **6일** (5일 후 종료) |
| 타겟 | 30-40대 주부, 요리에 관심있는 모든분들 |

🔢 여기서 나오는 값 (계산)
```
하루 예산      = $18 ÷ 6일        = $3.00
팔로우 1명당    = $4.11 ÷ 10      = $0.41
프로필 방문→팔로우 = 10 ÷ 25        = 40%
```
📈 **다 쓰면 프로필 방문 ≈ 109** — ⛔ 지금 페이스가 그대로 갈 때의 «추정»이다(초반 며칠치로 민 값).

⭐ **드디어 「프로필 방문」의 값이 붙었다** — 우리는 프로필 방문 다음 칸(징검다리 `bridge`)을 이미 재고 있다.
   👉 두 값을 이으면 **설치 1명당 광고비**가 처음으로 나온다. (⛔ 아직 잇지 않았다 — 광고가 둘 이상이라 방문 수를 다 모아야 한다.)

⛔ **이 한 장으로는 「가을 캐러셀이 왜 효율이 좋은가」를 못 가른다** — 광고 «하나»치라서 비교 상대가 없다.

## 10-3. ⏳ 오늘 밤 할 일 — 아이폰 캠페인 링크 (창업자 = *"내일부터 아이폰 릴스할거거든"*)

애플은 Play 와 **형식이 다르다.** `referrer=` 가 아니라 `pt`·`ct`·`mt` 다.
```

```
- `pt` = 제공업체 토큰(개발자 계정마다 하나 · 캠페인이 바뀌어도 같다)
- `ct` = 캠페인 이름 (최대 40자 · 영문/숫자/밑줄)
- `mt=8` = 앱

⛔⛔ **`pt` 가 없으면 `ct` 를 적어도 「획득 → 캠페인」에 안 뜬다.** 그래서 `pt` 를 먼저 받아야 한다.

🔗 공식 = [Apple 캠페인 링크](https://developer.apple.com/help/app-store-connect-analytics/acquisition/campaign-links/) ·
