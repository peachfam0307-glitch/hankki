# 🧭 한끼 메인 컨셉 · 타겟 · 전략 (마스터) · 2026-07-19

> 오늘(7/19) 창업자와 정한 **북극성.** 캐릭터·꾸미기·이모티콘·마케팅 모든 결정은 여기에 맞는지로 판단.
> ⚠️ 이 문서 = 방향 판단 기준. "이게 컨셉에 맞나?" 헷갈리면 여기부터.

## ⭐ 메인 컨셉 (확정)
> **만개의레시피 = "뭐 해먹지"를 찾는 곳.**
> **한끼 = "오늘도 한 끼 해낸 나"를 위로하고 기록하는 곳.**
>
> 레시피 "검색 도구"가 아니라 — **요리하는 나를 위한 감정·기록 공간.** (요리=노동 → 요리=자기돌봄)

- **핵심 감정 = 보편**: 음식으로 울고 웃는 건 나이·성별 초월. "밥은 먹었니?" = 한국인의 정(情)·챙김·사랑. 앱 이름 "한끼"가 이미 이 감정을 담음.
- **세 기둥**: 🫂위로("수고했어, 한 끼 했네") · 📖기록·성취(내 요리 아카이브=자기효능감) · 🐻캐릭터 힐링(꼬르곰·펭펭).

## 🎯 타겟 (데이터 기반)
- **1차 교두보 = 30-40대 여성 집밥러** (레시피앱 여성 68.8%, 40대 매일 해먹기 1위·매출 견인).
- 확장 = 보편 감정이라 남녀·전연령으로 번짐. **"만드는 건 모두를 위해, 파는 건 30-40 집밥러부터."**
- 이 세대 취향(이모티콘): 30대=감정대리인·병맛·리얼표정 / 40대=가볍지않게 귀엽+"수고했어·최고"·센스.
- 2026 소비: **필코노미(감정이 구매동력)** · 불안94%·외로움71% → 위로·힐링에 지갑. **어른 키덜트 코어층 = 딱 우리 타겟.**
- 시장 빈틈: 만개·해먹 = 기능만(감정·캐릭터·기록·자기표현 0). **"감정 있는 레시피앱"은 무주공산.**

## 🧊 냉정한 현실 분석 (장미빛 제거)
1. **지금 = 사실상 0**: 실사용자 ≈ 0(테스터 품앗이), 미출시, 매출·인지도 0, 무자본 1인+AI. **기능은 됨, 부족한 건 "유저".**
2. **시장 = 레드오션+거인**: 만개 1000만·해먹 350만 → "레시피 검색"으론 못 이김. 다꾸 트렌드 -69%, IP 성공은 로또급.
3. **컨셉 약점**: "감정"은 **리텐션엔 강하나 획득(첫 다운로드)엔 약함.** 캐릭터·꾸미기는 "있으면 좋은 것"(획득 동력 아님).
4. **🚨 제일 위험 = 순서 착오**: 유저 0인데 캐릭터·팩·이모티콘 유료화에 에너지 쏠림 = 김칫국. 캐릭터 작업은 싸서 자산이지만 **본진(출시+획득) 우선순위 착각 금물.**
5. **아직 답 없는 3질문**: ①왜 만개 놔두고 한끼를 깔지? ②획득 훅=뭐? ③리텐션 훅=뭐?
6. **핵심 분업**: 획득=실용("흩어진 레시피 한곳에")+바이럴(예쁜 공유) / 유지·전파=감정·캐릭터. **획득을 감정이 한다고 착각 금지.**

## 🐻🐧 캐릭터 = 창업자 진짜 감정에서 (IP의 힘)
- **꼬르곰 = 나(창업자)**: 혼자 난리법석, 다이어트 실패, 맛있는 거 먹고 싶은 먹보.
- **펭펭 = 딸**: 사춘기 뚱·단답, 가끔 다정, 애증. (F×쌉T 콤비 = 엄마×사춘기딸)
- **진짜 경험 = 30-40 엄마 보편 공감** → 억지 밈 아니라 실화라 힘셈(라이언·잔망루피급 잠재력).

### 실화 콤비 에피소드 (이모티콘/문구 원천 — 계속 수집)
- "맛있어? 괜찮아?" / "…응." → **"그 '응' 하나에 안도하는 중"**
- "뭐 먹고 싶어?" / "돼지고기"…"오리고기" → **"고기면 뭐든 오케이인 편"**
- "외식할까?!" / "아니" → (앞치마 스윽) **"…네가 그렇다면"**
- "이거 맛있는데 하나 먹어봐" / (골라내는 딸) → **"그거… 골라내지 말아줄래 ㅠ"**
