# 🎨 꾸미기(레꾸)팩 출시 아이디어 — 백로그

> 나중에 **유료 레꾸팩(꾸미기 확장팩)** 낼 때 넣을 자산·기능 아이디어 모음.
> 창업자 브레인덤프(2026-07-23) + 클로드 정리. 지금은 저장만 — 출시는 무료 코어 안정화 후.

## 📌 왜 팩으로?
- 무료 코어(기본 곰펭·마테·배경·글자·효과)로 **레꾸 재미**를 먼저 각인 → 유저가 "더 예쁜 거 없나?" 할 때 **유료 팩**으로 확장(수익화).
- 팩 = **테마 묶음**(예: "여름 바다팩", "골드 파티팩", "빈티지 다꾸팩")으로 내면 구매 동기↑.

## 🧩 창업자 아이디어(원문 리스트, 2026-07-23)
캐릭터 모션 / 효과 추가 / 배경효과 추가 / 뉴 마테 / 리컬러(확장) / 스티커(신규) / 매직펜? / 홀로그램 / 진주·유리알 반짝이 마테나 스티커 / 실버·골드 호일 스티커나 마테 / 배경 테두리 / 폴라로이드 등 액자틀 / 씰(seal) 스티커 / 등등…

## 🗂️ 카테고리로 정리
### 1) 캐릭터·모션
- 캐릭터 **신규 모션** 추가(레꾸 기본엔 없는 특수 모션 — 손흔들기·점프·하트뿅 등).
- 아기곰·아기펭 스페셜(정본 락 계획대로 나중에).
- 표정·포즈 시즌 세트.

### 2) 효과(양념) — ⭐ #23과 직결
- **홀로그램**(무지개 반사) · **골드/실버 호일**(메탈릭 반짝) · **진주·유리알**(글로시 하이라이트) 반짝이.
  - 구현 후보: CSS `background: conic/linear-gradient` 애니 + `mix-blend-mode` + 노이즈. 스티커/마테/글자에 오버레이.
- 배경 효과(파티클·빛번짐·보케·물결).

### 3) 마테(마스킹테이프)
- **호일 마테**(골드·실버 메탈릭) · **홀로 마테** · **진주 마테**.
- 시즌 디자인 마테(여름·크리스마스·생일 등).

### 4) 스티커
- 씰 스티커(밀랍 씰/왁스실 느낌) · 띠부씰 확장 · 폴꾸 소품(리본·레이스·구슬).

### 5) 프레임·틀
- **폴라로이드 액자틀** · 필름 프레임 · 배경 **테두리**(레이스·점선·워시 프레임).

### 6) 도구
- **매직펜**(손그림 낙서 — 자유 드로잉 레이어). 색·굵기 선택. (난이도 있음: 캔버스 드로잉 구현 필요)
- 리컬러 확장(더 많은 스티커에 색 변경 적용).

## 💰 수익화 방향(초안)
- **테마 팩 단위 판매**(한 팩 = 마테+스티커+효과+프레임 묶음).
- 또는 **효과 구독**(홀로·호일 같은 프리미엄 효과 월정액).
- 무료 코어는 계속 풍성하게(획득) → 팩은 "더 특별하게"(수익).

## ⚠️ 메모
- 효과(홀로·호일)는 **클로드가 CSS로** 구현 가능(전신 캐릭터는 GPT). → `docs/꾸미기-필살기-2026-07-18.md` 결과.
- 매직펜은 별도 캔버스 작업 → 공수 큼, 후순위.
- 우선순위: **무료 코어 완성·출시 → 실사용자·피드백 → 그다음 팩.** (지금은 저장만.)
