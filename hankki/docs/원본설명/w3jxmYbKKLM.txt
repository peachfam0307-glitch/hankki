# 원문 설명란 스냅샷 · https://youtu.be/w3jxmYbKKLM · EBSCulture (EBS 교양) · 받은 날 2026-11-23 (YouTube Data API · 넣은 날 이후 고쳐졌을 수 있다) · 이 편 요리 줄만 발췌(원문 줄 그대로 · 같은 영상의 다른 요리는 뺌)
공식 홈페이지 : http://home.ebs.co.kr/cook   굴 버섯죽

- 주재료

손질한 굴(150g), 밥(200g), 미나리(30g), 팽이버섯(60g), 양송이버섯(90g), 당근(30g), 양파(60g), 달걀물(1개), 참기름(1T), 김가루(1T), 깨소금(2t), 멸치 다시마 밑국물(8컵)

----------------------------------------------------------------------------------

1. 양파(60g), 양송이버섯(90g), 당근(30g), 밑동을 제거한 팽이버섯(60g), 미나리(30g)는 잘게 썬다 

2. 밥(200g)은 체에 밭친 뒤 찬물에 고루 풀어가며 헹군다

3. 달군 냄비에 참기름(1T)을 두르고 손질한 당근, 양파, 양송이버섯을 넣어 센 불에 볶는다 

4. 채소가 반 정도 익으면 멸치 다시마 밑국물(8컵)을 붓고 끓인다 

5. 밑국물이 끓어오르면 손질한 밥을 넣고 중간중간 저어가며 중불에 끓인다 

6. 밥이 무르게 퍼지면 손질한 굴(150g)을 넣고 한 번 더 끓인다

7. 굴이 어느 정도 익으면 달걀물(1개)을 돌려 넣고 살짝 섞은 뒤 손질한 팽이버섯, 미나리를 넣어 한소끔 끓인다

8. 그릇에 담은 뒤 깨소금(2t), 김가루(1T)를 얹는다
