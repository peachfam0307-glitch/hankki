## 2. 설계에서 «버린» 것 — 이게 제일 중요하다

| **「집밥 한 끼에 2,400원」** | 창업자 *"계산이 되는 건지? 멘트가 맞는건지"* → **둘 다 아니었다.** 검산하니 186,400÷14 = **13,300원**(2,400 은 시안 숫자를 검산 없이 들고 온 것). 게다가 분자는 장 본 것 전부인데 분모는 「만들었어요」 누른 수뿐이라 **늘 부푼다** · 안 누르는 사람은 6만원이 나온다 |

## 3. 만든 것
- **적기 두 길** — ⓐ장보기 줄에 값 적기 → 합계 → 「값 적은 것 식비로 적기」(장보기에서 빠지고 냉장고로) ⓑ외식·배달 숫자판
- **「두부 1990」 한 번에** — 이름 뒤 숫자를 값으로 가른다. 「돼지고기 600g」·「양파 3」은 값이 아니다(단위·세 자리 미만)
- **고치기** — 이름을 누르면 「두부 1990」이 통째로. 숫자를 빼면 값이 지워진다
- **보기 셋** — 주별(8칸) · 달별(12칸) · 날짜 고르기. 막대를 누르면 그 칸만. 막대 위 만원·아래 날짜
- **예산** — 주·달 따로 · 남은 돈을 제일 크게 · 만 원 미만 거절 · 넘으면 주황＋「N원 더 썼어요」(⛔빨강으로 나무라지 않는다)
- **계산기 ＋** — 여러 영수증을 더해 한 줄로
- **가서 보고 와서 적기** — 여덟 곳(쿠팡·컬리·네이버쇼핑·롯데마트·이마트몰·쿠팡이츠·배민·요기요) ＋ 직접 추가·삭제 · **누른 순서로 앞에 온다**
- **앱으로 열기** — 배민 `com.sampleapp` · 쿠팡이츠 `com.coupang.mobile.eats` · 컬리 `com.dbs.kurly.m2`(전부 Play 주소로 확인). ❓요기요·롯데마트·이마트몰은 못 찾아 웹
- 🛒 **쿠팡은 파트너스 링크가 아니라 그냥 주소** — 창업자 폰 24시간 규칙. 유저에게 열 때 파트너스로 바꾼다(창업자 *"유저들은 링크로. 그래야 우리도 수익이 나지"*)

## 5. 내가 틀린 것 · 장치가 잡은 것
- ⛔ **`)}` 가 화면에 글자로 찍혔다** — JSX 닫는 괄호를 하나 더 남겼다. 창업자 캡처가 잡았다
- ⛔ **「식비에 적었어요」가 거짓말했다** — 체크 안 하면 0줄이 적히는데 토스트는 떴다(창업자 *"적었는데 장보기에 반영안됐아"*) → 값이 적힌 줄이면 체크와 무관하게 옮긴다
- ⛔ **단수만 고쳐서 직접 입력이 안 먹었다** — 담는 길이 둘(`addShopItem`·`addShopItems`)이었다 → `이름값가르기()` 한 함수로 묶었다
- ⛔ **첫 주에 「주 평균 134,000원」** — 한 주뿐인데 평균이라 말했다(같은 수를 두 번) → 쓴 주 2개 이상일 때만
- ⛔ **날짜를 내가 만들었다** → `check-kst` 가 잡았다. `todayKST()` 로(절대원칙 27)
- ⛔ **아이콘 이름 `calendar` 는 없다** — 없는 이름은 조용히 빈 칸이 된다 → `clock`
- ⛔ **컬리 꾸러미 이름을 확인 없이 적었다**(`com.kurly.kurlymarket`) → 찾아서 `com.dbs.kurly.m2` 로
- 🛡 **한살림 검사가 헐거웠다** — ⓐ덩이를 «길이 900자»로 잘라서 주석이 붙자 「검사가 낡았다」로 죽었다 ⓑ주석에 적힌 `noBuy` 를 코드로 셌다 → 일부러 깨도 초록불이었다(규칙 18 ⓘ). **다음 case 까지로 자르고 주석을 떼고 `noBuy: true` 로 좁혔다.** 깨서 빨간불 확인
