# 한끼 출시 전 테스트 체크리스트

> 폰에서 직접 하나씩 눌러보며 확인. ✅ 되면 체크, ❌면 스샷+메모.
> **먼저: 설정 맨 아래 버전이 최신(v1.69)인지 확인.** 아니면 새로고침 2번.

---

## 1. 첫 실행 · 온보딩
- [ ] 앱 처음 켜면 온보딩 5장이 뜬다 (흩어진 레시피 → 담기 → 냉장고·요리 → 꾸미기 → AI 예고)
- [ ] 좌우로 넘기기 / '건너뛰기' 동작
- [ ] '한끼 시작하기' 누르면 홈으로, 다시 켜도 온보딩 안 뜸

## 2. 레시피 가져오기 (제일 중요!)
- [ ] **직접 쓰기**: 제목·재료·만드는 법·메모 입력 → 저장 → 목록에 뜸
- [ ] **계량바**: 재료 칸 누르면 키보드 위에 g·큰술·작은술… 버튼, 눌러서 입력됨
- [ ] **사진 OCR**: 📷 → 사진 선택 → 크롭 → 글자 읽힘 (초안)
- [ ] 크롭 화면에 **"특수문자 많으면 부정확" 안내가 크게** 보임
- [ ] 읽은 뒤 **"초안을 담았어요…" 토스트가 충분히 오래(약 5초)** 보임
- [ ] **보면서 쓰기**: 캡처가 위에 고정되고, 재료/만드는법 칸 눌러도 **사진에 안 가려짐**
- [ ] 재료·만드는 법 칸이 **넉넉하고 글씨가 잘 보임**
- [ ] **인스타/유튜브 링크**: 링크 넣고 '영상 보며 쓰기' 동작
- [ ] 쓰다 나갔다 와도 **초안이 남아있음**(임시저장)

## 3. 레시피 보기 · 검색
- [ ] **전체 레시피 목록에 사진·이모지가 골고루 섞여 있음** (한쪽에 안 몰림)
- [ ] 카테고리(한식·양식…) 누르면 필터됨
- [ ] 레시피 눌러 상세 → 재료·순서 보임
- [ ] **검색**: 돋보기 → 검색 → **← 뒤로가기 버튼으로 나가짐**
- [ ] 새 레시피 확인: **새우 크림 파스타 · 버섯 솥밥** 있고 사진 예쁨 (알리오올리오는 없어짐)

## 4. 꾸미기 (시그니처!)
- [ ] 레시피 상세 → 🎨 꾸미기
- [ ] 스티커(친구들·표정·재료·도구…) 붙이기 / 드래그 이동 / 손잡이로 크기·회전 / × 삭제
- [ ] **글자 타일**: 또박체 / **귀염체(동글동글 손글씨)** 둘 다 제대로 나옴
- [ ] **포스트잇**: 색 골라 붙이기 → **붙이면 서랍이 위로 올라가며 '무늬·모양' 옵션이 보임**
- [ ] 무늬: 민무늬·모눈·체크·줄노트 / 모양: 하트·별·구름·꽃·곰·테이프·핀 등 적용됨
- [ ] 저장하면 목록 카드 표지에 반영됨

## 5. 냉장고 · 오늘 뭐 해먹지
- [ ] 냉장고에 재료 추가 / 유통기한 입력
- [ ] '오늘 뭐 해먹지' 추천이 냉장고 재료 기반으로 뜸

## 6. 장보기 · 주부의 장바구니
- [ ] 주부의 장바구니 열림 (간장·된장·…·**두부(마른두부·몽글이 순두부)**)
- [ ] '담기' → 장보기 목록에 들어감
- [ ] '사러가기' → 쿠팡/오아시스/한살림 등 **바깥 쇼핑몰로 이동** (팝업 안 깨짐)
- [ ] 오타 확인: 누룽지 설명 '금방'으로 (금세 아님)

## 7. 요리 모드 · 타이머
- [ ] 레시피 상세 → 요리 시작 → 풀스크린, 큰 글씨
- [ ] 단계 넘기기 / 인분 조절 / 타이머 소리 알람

## 8. 요리 기록
- [ ] '만들었어요' 기록 남기기 (별점·팁·사진)
- [ ] 내 레시피 → 요리 기록 탭에서 보임
- [ ] (새 사용자는 기록이 비어있고 안내가 뜨는 게 정상)

## 9. 폰트 · 디자인
- [ ] 홈 상단 **'한끼' 로고가 동글동글 부드러운 손글씨(고운돋움)** 로 보임
- [ ] 귀염체 글자 스티커가 개구체로 제대로 나옴

## 10. 데이터 · 안전
- [ ] 설정 → 데이터 내보내기(백업) → 파일/카톡으로 저장됨
- [ ] 백업 불러오기(복원) 동작
- [ ] 설정 → 개인정보처리방침 링크 열림
- [ ] 설정 → 도움말·문의 → annyeong.hankki@gmail.com 메일 열림

## 11. 뒤로가기
- [ ] 각 하위 페이지(상세·에디터·검색·장보기·설정)에서 **안드로이드 백/← 버튼으로 잘 나감**
- [ ] 홈에서 뒤로가기 → 종료 확인 팝업
