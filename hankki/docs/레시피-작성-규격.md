# 한끼 레시피 작성 규격 (Recipe Style Guide)

> 모든 기본 레시피·큐레이션·앞으로 올릴 레시피는 이 규격으로 통일한다.
> 판단 기준: **아이덴티티(따뜻·쉬움) > 정직 > 편의 / 비용 게이트**. 타겟 = 요리·자취 초보, 젊은층.

---

## 1. 계량 단위 (통일)
> 원칙: **초보에게 제일 안 헷갈리는 것.** 축약(T·t)보다 우리말, 정확이 필요한 건 ml·g.

| 대상 | 단위 | 예 |
|---|---|---|
| 작은 양(양념·기름·가루) | **큰술 / 작은술** | 간장 1큰술, 설탕 1/2작은술 |
| 액체 다량 | **ml** | 물 500ml, 생크림 200ml |
| 무게 | **g** (1kg↑는 kg) | 돼지고기 200g |
| 밥·면·덩어리 | **공기 / 개 / 모 / 쪽 / 대 / 장 / 줌** | 밥 1공기, 두부 1/2모, 마늘 3쪽 |
| 온도 | **도**(섭씨) | 230도 |
| 시간 | **분** | 15분 |

- **1T/1t 같은 축약은 쓰지 않는다** — 초보가 T=큰술을 모를 수 있음. (계량 가이드에는 병기해 커버)
- **컵은 지양.** 꼭 쓰면 `1컵(200ml)`처럼 ml 병기(컵 크기가 제각각).
- 분수는 `1/2`, `1/3` 표기(유니코드 ½는 인분 환산에서 자동 변환됨).
- 비율 레시피는 `양조간장 1 : 맛술 1 : … (숟가락 비율)`처럼 명시.
- ❓ **미결정(창업자 확인)**: 클로드 권장 = **큰술/작은술**(초보 친화). 창업자가 1T 선호 시 전체를 1T/1t로 통일 가능 — 이때도 계량 가이드로 둘 다 커버.

## 2. 계량 지표 (앱에 넣을 참고표 · 초보용)
- **1큰술(T) = 15ml = 3작은술**
- **1작은술(t) = 5ml**
- **1컵 = 200ml**(계량컵) · 종이컵 = 180ml
- **밥 1공기 ≈ 210g**
- 손대중: 한 줌 ≈ 종이컵 1컵, 한 꼬집 = 두세 손가락으로 집은 양
- 애매 표현(약간·적당량)은 허용하되 남발 금지 — 가능하면 수량으로.
- → **인앱 '계량 가이드' 시트**로 제공(백로그). 레시피 상세·작성 화면에서 ? 로 열기.

## 3. 재료 표기 규칙
- 순서: **주재료 → 부재료 → `[양념]`/`[소스]`/`[드레싱]` 그룹**
- 형식: `재료명 수량` (예: 간장 1큰술). 수량은 항상 뒤.
- 양념/소스/드레싱이 **덩어리로 묶이면** `[양념]` 등 **대괄호 소제목 한 줄** + 항목별 한 줄. (콤마 뭉치기·"드레싱:" 반복 금지)
  - 재료가 자연스럽게 나열되면(감바스 등) 억지 헤더 안 붙임.
- 선택 재료: `재료 (선택)` / 대체: `재료 (또는 대체재료)`
- 대괄호 소제목 줄은 렌더러가 소제목으로 그리고 **장보기 담기·인분환산에서 자동 제외**.

## 4. 재료 손질법 (초보 배려) — 백로그 기능 + 데이터
> 초보는 "대파 어슷썰기", "새우 내장 제거", "고기 핏물 제거"를 일일이 찾아봐야 해 어렵게 느낌.
> → **재료명 옆 손질 팁**을 앱이 보여주는 기능(재료 사전). 지금은 데이터부터 모은다.

**야채**: 대파(어슷/송송), 양파(채/다지기), 마늘(편/다지기/으깨기), 애호박(반달), 가지, 시금치·부추(데치기), 숙주(살짝 데치거나 생), 공심채(줄기·잎 나눠 썰기)
**해산물**: 새우(등쪽 내장 제거), 오징어(껍질·내장), 조개(소금물 해감), 연어(2cm 큐브)
**고기**: 핏물 키친타월로 제거, 밑간, 재우기, 소분·냉동 보관
- (표준 손질 문구를 한 번 정리해두면 여러 레시피에서 재사용 + 사전 기능에 연결)

## 5. 문체 톤
- **만드는 법 = '~요'체 자동 통일**(politeSteps). 예: "볶아요", "끓여요".
- 재료·메모는 담백하게. 메모는 개인 팁/목소리 허용(파운더 톤).
- 과장·광고 말투 금지(강추·최고 등).

## 6. 조리시간·인분·난이도 = 선택 (몰라도·안 써도 OK)
> 감으로 요리하는 사람(=타겟)에게 정량 강요 X. 이게 아이덴티티.
- **비우면 자동으로 안 보임** — 상세의 시간/인분/난이도 칩은 값 없으면 렌더 안 됨(이미 구현).
- 인분(servings) 0이면 **인분 조절 UI 자동 숨김**(이미 구현).
- 작성 화면: 세 항목에 **"(선택 · 몰라도 괜찮아요)"** 안내. 강제 입력 금지.
- (백로그) 빠른 선택 칩: 시간 15·30·60분 / 인분 1·2·4 — 마찰 더 낮추기.

---

## 적용 상태
- ✅ 계량·표기 규칙 → 기본 레시피 전수 통일(v2.4, `[양념]`/`[소스]`/`[드레싱]` 소제목 렌더)
- ⏭️ 계량 가이드 시트 / 재료 손질 사전 = 백로그(데이터부터)
- ✅ 시간·인분·난이도 선택 처리 = 이미 graceful(비면 숨김)
- ❓ 계량 단위 큰술 vs 1T = 창업자 최종 확인 대기
