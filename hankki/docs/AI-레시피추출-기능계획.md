# 🤖 AI 레시피 추출 기능 — 계획 (2026-07-19 결정)

> 결정: OCR 위에 **LLM 보정/추출**을 얹어, 유저당 **무료 5~10장** 제공. 창업자 승인("응 그러자").
> 역할: **클로드가 뼈대 다 만들어둠(키 없이 가능한 것 전부)** → 창업자는 **계정·키만 준비** → 꽂으면 연결.
> ⚠️ **배포는 `/픽스` 때만**(규칙 9). 이 문서 저장은 배포 무관.

## 1. 왜 / 급한가
- OCR(`src/ocr.js`+`ocrCorrect.js`)은 이미 잘 됨(무료·키 불필요). 근데 **완벽친 않음** → AI가 재료·순서를 깔끔히 보정.
- 획득(실용성 "흩어진 레시피 한곳에")에 도움. **단 출시 필수는 아님** — 본진은 테스터·버그0·공유카드. **급하지 않음**, "있으면 좋은 보정".

## 2. 아키텍처 (핵심 = 키 숨기기)
```
앱(정적, GitHub Pages)  ──텍스트/사진──▶  Cloudflare Worker(프록시)  ──▶  LLM API
                         ◀──재료·순서 JSON──         (키 보관·횟수제한)
```
- 앱은 **정적 사이트라 API 키를 넣으면 안 됨**(누구나 훔침). → **Cloudflare Worker(무료티어)**가 키 보관 + 횟수제한.
- OCR은 계속 **클라 무료** 유지. AI는 **옵션 보정**(오프라인·초과 시 OCR만).

## 3. 모델 추천
- **Claude Haiku 4.5** (싸고 빠름·한국어 강함·비전 지원). 사진 바로 넣으면 **OCR 없이 한 번에 추출**도 가능.
- 대안: OpenAI. (비용·품질 비슷, 우리 생태계는 Claude)

## 4. 비용 (실측)
- **Claude Haiku 4.5 실측 단가**: 입력 $1 / 출력 $5 (per 100만 토큰). 1장 추출 ≈ 입력~1,900 + 출력~500토큰 → **장당 ~$0.004 ≈ 5~6원**(환율 1,400원/$). ※내가 앞에서 "부담 0"이라 한 건 과장 — 정확히는 "유저 적을 땐 작음", 0은 아님.
- 폭주 방지 = **횟수제한**(기기/IP별 일 N장) 필수. 안 걸면 파워유저 몇 명이 비용 키움.

## 5. 역할 분담
### 클로드가 함 (키 없이 가능한 것 전부, 내일 착수)
1. **추출 프롬프트** — 사진/텍스트 → `{제목, 인분, 시간, 재료[], 순서[]}` JSON 스키마 고정.
2. **Cloudflare Worker 프록시 코드** — 요청 받기·키 secret·CORS·**횟수제한**·에러처리.
3. **앱 UI** — "AI로 깔끔하게" 버튼 → OCR/사진 → Worker 호출 → `parseRecipe` 결과에 채움 → 유저가 편집. 남은 무료 횟수 표시.
4. **목업 키로 로컬 검증** (UI·플로우까지).

### 창업자가 함 (급하지 않음, 언제든)
1. **Cloudflare 계정** 생성(무료).
2. **API 키 발급**(Anthropic 콘솔, 카드 등록 — 소액).
3. Worker에 **키 secret 등록** — 클로드가 클릭 단위로 안내.

### 연결
- 키 꽂으면 끝. → 창업자 확인 → `/픽스` 때 배포.

## 6. 구현 순서 (체크리스트)
- [ ] 1) 추출 프롬프트+JSON 스키마 확정 (재료·순서·인분·시간)
- [ ] 2) Worker 프록시(횟수제한·CORS·secret) 코드
- [ ] 3) 앱: 추출 버튼 → 호출 → 결과 채움 → 편집 UI
- [ ] 4) 무료 횟수 표시·초과 안내
- [ ] 5) 목업 키 테스트 → 창업자 실키 전환 → `/픽스`

## 7. 리스크·대응
- 키 노출 → **프록시로 해결**(앱엔 절대 안 넣음).
- 비용 폭주 → **횟수제한**(일 5~10/기기).
- 오프라인·초과 → **OCR은 계속 무료 유지**, AI는 옵션.
- OCR 이미 있음 → AI는 "덮어쓰기"가 아니라 "보정 옵션"으로(유저 선택).

## 9-1. 🚫 광고 = 안 쓰기로 (창업자 확정 방향)
> 창업자: "**광고 보라고 하는 앱은 안 쓴다**(내가 타겟이기도 함)." + 한끼 컨셉(위로 공간)과 광고는 상충.
- **리워드 광고 데이터**(참고): 상위게임 97% 도입·자발 옵트인 ~80%·"통제감 있어 낫다" 46%. **강제 광고(이탈 유발) ≠ 리워드(선택 버튼).** 리워드는 안 누르면 안 봄.
- **그래도 안 씀**: ① 창업자=광고혐오 타겟 ② 광고 없어도 적자 0(무료층 $0) ③ **위로 컨셉엔 무광고가 정체성 강화.**
- **결론 구조(무광고)**: 무료 = OCR + Cloudflare 무료티어($0) / 프리미엄(Claude 고품질) = **소액 유료(구독·1회결제)로만**, 초반엔 미출시도 OK. → 광고 없이도 **적자 0** 유지.

## 9-2. 💵 요금 기본값 (출시 후 · 데이터로 조정) — 창업자와 확정
> 숫자는 **완벽 확정 아님** — 출시 후 실제 사용량 보고 튜닝(코드 한 줄). 창업자 "뭐가 괜찮은지 아직 모름"이 정상. 기본값 깔고 → 관찰 → 조정.

| 층 | 양 | 근거 |
|---|---|---|
| 무료 OCR | **무제한** | 항상 됨·원가 $0. 광고·결제 다 싫은 유저의 안전지대(안 막힘) |
| 무료 AI 보정 | **웰컴 5장** | 맛보기. Cloudflare $0. 넘어도 OCR로 계속 |
| 유료 팩 | **990원 = 30장**(소모성·일회성) | 다 써도 원가 ~150원 = 확실 흑자. 50은 몇 달치라 과함 → 30. 무제한 ❌(어뷰저 방어) |
- **재구매**: 소모성이라 "다 쓰면 또 충전". 단 실사용량 낮음(대부분 총 10장 미만) → 대부분 1회 구매/or 무료로 끝. **매출 기계 아님 = 보너스 수익.**
- 구글 수수료 15% 떼도 990원→~842원, 원가 150원 → 순익 ~690원/팩.
- **📊 사용량 근거**: 레시피앱 유저 평균 **월 18~24장 저장(주 4~6장)**, 근데 대부분 앱내 북마크고 **외부 추출(우리 AI)은 더 적음.** ReciMe 무료=주5장 = 활성 임포터도 주5장이면 충분하다는 계산. → **AI 추출 하루 1장 미만.** 그래서 무료 AI는 5장(OCR 무제한이 받쳐주니 10장 과함 — 창업자 지적), 990원 30장 = 활성유저 몇 주~한두 달치.

## 9-3. ⏰ 출시 타이밍 = **출시 후** (창업자 확정)
> 창업자 로드맵 원칙: "돈 드는 건 수익 난 뒤 · 출시 전엔 새 기능 그만."
- **출시엔 AI 유료 안 넣음.** 무료 OCR은 이미 앱에 있어서 출시엔 그걸로 충분.
- **순서**: ① 출시(무료 OCR+기존기능+공유카드) → ② 실사용자·리텐션 확인 → ③ 그때 AI(무료 웰컴+990원 팩) 붙이기.
- 이유: 유저 없을 때 결제 붙이면 매출 0인데 출시만 복잡·지연·버그위험↑. 사랑받는 앱인지 먼저 증명 후 수익화.
- **지금 1순위**: 출시(테스터 12명·7/31) + 바이럴 공유카드. AI 결제는 급하지 않음.
