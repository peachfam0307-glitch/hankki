# 🤖 AI 레시피 추출 기능 — 계획 (2026-07-19 결정)

> 결정: OCR 위에 **LLM 보정/추출**을 얹어, 유저당 **무료 5~10장** 제공. 창업자 승인("응 그러자").
> 역할: **클로드가 뼈대 다 만들어둠(키 없이 가능한 것 전부)** → 창업자는 **계정·키만 준비** → 꽂으면 연결.
> ⚠️ **배포는 `/픽스` 때만**(규칙 9). 이 문서 저장은 배포 무관.

## 1. 왜 / 급한가
- OCR(`src/ocr.js`+`ocrCorrect.js`)은 이미 잘 됨(무료·키 불필요). 근데 **완벽친 않음** → AI가 재료·순서를 깔끔히 보정.
- 획득(실용성 "흩어진 레시피 한곳에")에 도움. **단 출시 필수는 아님** — 본진은 테스터·버그0·공유카드. **급하지 않음**, "있으면 좋은 보정".

## 2. 아키텍처 (핵심 = 키 숨기기)
```
앱(정적, GitHub Pages)  ──텍스트/사진──▶  Cloudflare Worker(프록시)  ──▶  LLM API
                         ◀──재료·순서 JSON──         (키 보관·횟수제한)
```
- 앱은 **정적 사이트라 API 키를 넣으면 안 됨**(누구나 훔침). → **Cloudflare Worker(무료티어)**가 키 보관 + 횟수제한.
- OCR은 계속 **클라 무료** 유지. AI는 **옵션 보정**(오프라인·초과 시 OCR만).

## 3. 모델 추천
- **Claude Haiku 4.5** (싸고 빠름·한국어 강함·비전 지원). 사진 바로 넣으면 **OCR 없이 한 번에 추출**도 가능.
- 대안: OpenAI. (비용·품질 비슷, 우리 생태계는 Claude)

## 4. 비용 (껌값)
- 장당 **~3~5원**. 유저당 **무료 5~10장** = 부담 거의 0. Cloudflare Worker 무료티어(하루 10만 요청).
- 폭주 방지 = **횟수제한**(기기/IP별 일 5~10장) 필수.

## 5. 역할 분담
### 클로드가 함 (키 없이 가능한 것 전부, 내일 착수)
1. **추출 프롬프트** — 사진/텍스트 → `{제목, 인분, 시간, 재료[], 순서[]}` JSON 스키마 고정.
2. **Cloudflare Worker 프록시 코드** — 요청 받기·키 secret·CORS·**횟수제한**·에러처리.
3. **앱 UI** — "AI로 깔끔하게" 버튼 → OCR/사진 → Worker 호출 → `parseRecipe` 결과에 채움 → 유저가 편집. 남은 무료 횟수 표시.
4. **목업 키로 로컬 검증** (UI·플로우까지).

### 창업자가 함 (급하지 않음, 언제든)
1. **Cloudflare 계정** 생성(무료).
2. **API 키 발급**(Anthropic 콘솔, 카드 등록 — 소액).
3. Worker에 **키 secret 등록** — 클로드가 클릭 단위로 안내.

### 연결
- 키 꽂으면 끝. → 창업자 확인 → `/픽스` 때 배포.

## 6. 구현 순서 (체크리스트)
- [ ] 1) 추출 프롬프트+JSON 스키마 확정 (재료·순서·인분·시간)
- [ ] 2) Worker 프록시(횟수제한·CORS·secret) 코드
- [ ] 3) 앱: 추출 버튼 → 호출 → 결과 채움 → 편집 UI
- [ ] 4) 무료 횟수 표시·초과 안내
- [ ] 5) 목업 키 테스트 → 창업자 실키 전환 → `/픽스`

## 7. 리스크·대응
- 키 노출 → **프록시로 해결**(앱엔 절대 안 넣음).
- 비용 폭주 → **횟수제한**(일 5~10/기기).
- 오프라인·초과 → **OCR은 계속 무료 유지**, AI는 옵션.
- OCR 이미 있음 → AI는 "덮어쓰기"가 아니라 "보정 옵션"으로(유저 선택).
