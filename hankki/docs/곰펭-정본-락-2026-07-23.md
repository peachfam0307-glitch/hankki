# 🐻🐧 곰펭 정본 락 (2026-07-23 창업자 확정)

> 창업자가 "저장" 명시. 앞으로 곰펭 관련 모든 판단의 기준.

## 1. 확정 규칙 (락)

- **우리 곰·펭 = 앞으로 무조건 "물결(복슬) 곰펭" 스타일만.** 다른 스타일(음식시트 매끈 곰, 옛 매끈 곰곰이 등)은 정본 아님 → 앱의 대표 캐릭터로 쓰지 않는다.
- **우리 애기들(아기곰·아기펭)도 물결 곰펭이다.** 아기 버전도 같은 물결 스타일로 그린다. 별개 캐릭터 아님.
- **꼬르곰(곰) = 창업자 본인 / 펭펭(펭) = 딸.** 시그니처 = 복슬털 + 하트주걱 + 계란후라이 앞치마, 몸색 `#EBAB73`.
- **펭펭 = "쿨한" 캐릭터** — 베레모 + 트렌치코트. (정본에 양팔번쩍 "화이팅" 포즈가 거의 없음 → 필요하면 창업자가 새로 뽑음.)
- **⭐ 모든 시안·목업·홍보물에 "뉴 물결 곰펭"만 쓴다. 구 버전 금지(특히 곰).** (창업자 2026-07-23) — 예전 폭신 HD 곰컷(`큐레이션-2507`·`hd-원본-2507/꼬르곰` 등)은 "구 버전"이라 시안에 쓰지 말 것. 새로 뽑는(또렷한 외곽선·음영) 뉴 물결 곰펭으로 통일. 현재 보유: 뉴 펭 8컷(`곰펭-물결-신규-2507`). **뉴 곰은 창업자 생성 대기 중** → 오기 전엔 곰이 들어갈 시안 보류(펭 단독은 가능).

## 5. 창업자 생성 요청 포즈 리스트 (2026-07-23)

**현황**: 곰 HD 72컷(차고 넘침) vs 펭 깔끔단독 7컷(cook/emo). → **펭 위주**로 뽑아야 세트 균형. 곰은 재생성 불필요.

**우선순위**
- ⭐ 꼭: ①펭 화이팅 (유일하게 비는 칸)
- 있으면 예쁨(펭): ②펭 엄지척 ③펭 브이 ④펭 인사 ⑤펭 냠냠
- 콤비 HD(현재 211px로 작음→크게 재생성): ⑥콤비 하이파이브 ⑦콤비 나란히(브이/하트)
- **추천 1차(lean)**: ①+②+⑥ 3개면 딱. 나머지는 다음 드롭.

**복붙 스펙 (공통 프리픽스)**
> [공통] 흰/투명 배경 · 캐릭터 단독 · 소품 최소 · 전신 다 보이게 · 정사각 프레임 · 파스텔 라인 · 세트처럼 같은 톤.
> [펭펭] 검정 단발 보브(끝 안으로 C컬) + 베레모 + 베이지 트렌치코트, 노란 부리·발, 통통, 발그레 볼.
> [꼬르곰] 물결 복슬털(연갈 #EBAB73) + 셰프모자 + 하트주걱 + 계란후라이 앞치마, 통통, 발그레 볼.

**포즈별 액션**
1. 펭 화이팅 — 양 날개 번쩍 "화이팅!" 밝게 + 반짝임 (쿨하게: 한쪽 주먹 불끈도 OK)
2. 펭 엄지척 — 한 날개 따봉, 살짝 윙크 "좋아!"
3. 펭 브이 — 양 날개 V, 귀엽게
4. 펭 인사 — 한 날개 흔들며 반갑게
5. 펭 냠냠 — 볼 빵빵 맛있게 (숟가락 살짝)
6. 콤비 하이파이브 — 곰·펭 손 마주쳐, 신나게 (크게, 둘 다 전신)
7. 콤비 나란히 — 곰·펭 나란히 서서 같이 브이/하트, 다정하게
