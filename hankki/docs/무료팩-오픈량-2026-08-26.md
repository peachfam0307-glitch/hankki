## 1️⃣ ✅ 창업자 확정 셋 — ⛔재론 금지

| | 확정 | 창업자 원문 |
|---|---|---|
| **양** | **한 달에 35~40장 «이내»** | *"무료팩은 한달에 35-40장이내로 나가자."* |
| **종류** | **골고루일 필요 없다** — 그달 이야기에 맞는 것 | *"골고루일 필요가 없지 않을까?? 네 생각은?"* → *"그러자"* |
| **프레임** | **매달 안 줘도 된다** | *"프레임을 매달 줄 필요는 없으니까"* |

⛔⛔ **그래서 옛 정원 규칙의 «해석»이 바뀐다.**
　 `CLAUDE.md` 의 「한 계절 62컷 ÷ 3파 = 한 파 21컷 · 종류별 프레임4·소품8·메모3·마테2·캐릭터4」는
　 **종류별 균등 배분처럼 읽혔는데** 그게 아니다.
　 ✅ **양만 지킨다(35~40) · 종류는 그달 이야기가 정한다.**
　 ⭐ 정원표(`npm run assets`)는 **「기본이 뚱뚱한가」를 보는 용도**로 계속 쓴다.

## 2️⃣ 🚨 왜 정했나 — 무료가 유료를 죽이고 있었다

🔢 **실측 (2026-08-26)**

| | 컷 |
|---|---:|
| 9/1 에 열릴 예정이던 것 | **62** |
| 10/1 | **44** |
| 11/1 | **43** |
| 12/1 | **0** ⚠️ 겨울이 비어 있다 |

⛔ **석 달에 149컷이 쏟아지고 12월은 텅 비었다.**
⛔ **무료 가을(69컷) > 유료 「가을 다꾸」(56컷)** — 무료로 69장 받은 사람이 56장짜리를 살 이유가 없다.

⭐ **다만 「무료가 부실하다」는 걱정에는 숫자로 답한다** —
　 무료 가을 전체 **149컷** ↔ 유료 가을팩 **66컷** = **2.3배**.
　 유료는 **한 번에 다 줘서 커 보이고**, 무료는 매달 쪼개져 작아 보일 뿐이다.
　 📌 그러니 부실함의 정체는 «양»이 아니라 **「그달이 한 상으로 차려지는가」**다.

## 6️⃣ 🪟 `naf` 창 뚫기 — 새 도구 `tools/프레임-창뚫기.py`

📮 창업자 = *"이거 가운데 내가 잘라줘야하는거 아냐? 확인해봐"* → 🔢 **12컷 중 11컷이 막혀 있었다**
　 (가운데가 순백 254,254,254 로 꽉 참 · `naf04` 목도리 리스만 원래 뚫려 있다)

📮 ＋ 창업자 = *"네가 맨날 잘랐을때 망해서 프레임은 내가 잘라왔었어 ㅋ"* — **맞는 말이다.**
　 · v9.00 = 흰색을 지우다 **돛·갈매기·데이지 꽃잎**까지 지웠다
　 · 가을 프레임 `af01~12` = 배경제거가 **크림색 얇은 선을 파먹어** 선이 갈라졌다

⭐⭐ **그래서 이번엔 「가운데 한 점에서만 번지게」(flood fill) 한다.**
　 프레임 선에 막혀 창 밖으로 못 나가고, **그림 속 흰색은 창과 안 이어져 있어 안 지워진다.**

🛡 **안전장치 넷 — 하나라도 어긋나면 그 컷은 안 건드린다**
　 ①가운데가 흰색·불투명일 때만 시작 ②번진 넓이가 **6~92%** 일 때만 ③**가장자리 1px 에 닿으면 중단**(샌 것) ④흰 테 6px 보호

🔢 **결과 = 11/12컷 · 창 56~67% · 샌 것 0**
✅ **진짜 앱 화면 위에 얹어 눈으로 확인**(절대원칙 21) — 선 안 파먹힘 · 양초·버섯·다람쥐의 흰색 살아 있음
