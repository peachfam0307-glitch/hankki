# 🎬 릴스 스토리보드 — 「이거 불편하지 않았어요?」 (2026-10-18)

📮 창업자 = *"우리 기능을 이런거 불편하지 않았냐고 물어보고 그다음에 한끼는 있다거나 된다로"* ·
*"구체적이지만 핵심을 꿰뚫는 간단한 질문"* · *"둘 다 만들어줘 스토리보드만"*

## 틀 (두 버전 다 만든다 → 광고 링크 `utm_content` 로 갈라 잰다)
| | 흐름 |
|---|---|
| **A 공감형** | 「~한 적 있죠?」 → 「네, 그게 저예요」 → 「그래서 한끼는 ~돼요」 → 화면 → 끝 장 |
| **B 고백형** | 「이거 나만 불편했어요?」(창업자 목소리) → 「그래서 만들었어요」 → 화면 → 끝 장 |
| 끝 장(공통) | `App Store · Google Play 에서 「한끼 레시피북」 검색` |

🔎 어느 쪽이 나은지는 **모른다**(우리 데이터 없음) → 같은 기능으로 A·B 를 만들어 `postit_A` / `postit_B` 처럼 갈라 광고하고 GA4 「트래픽 획득」으로 본다.

- 📮 **창업자 원문(문서)** — 개발 때 남긴 말 · 파일:줄

## 0. 한끼 소개편 — «흩어진 것을 한 곳에»
- **이유** 🗣 *"레시피는 포스트잇에 저장은 캡쳐로 요리사진따로 장보기는 메모로 이런거 불편해서 등등 한끼에 다 넣었다"*
- A: 「레시피는 포스트잇, 저장은 캡처, 요리 사진은 사진첩, 장 볼 건 메모장… 다 따로 하고 있죠?」 → 「네, 그게 저예요」 → 「그래서 한끼에 다 넣었어요」
- B: 「레시피는 포스트잇에, 저장은 캡처로, 요리 사진은 따로, 장 볼 건 메모로. 이거 나만 불편했어요? 그래서 한끼 하나에 다 넣었어요」
- 화면(장면당 2초): 포스트잇 → 캡처 사진첩 → 메모장 → 한끼로 모임(레시피 → 장보기 → 냉장고 → 꾸미기) → 끝 장

## 1. 캡처 → 레시피 (가져오기)
- **이유** 🗣 *"레시피 포스트잇에 따라적어 요리한적"*
- A: 「레시피 포스트잇에 따라 적어서 요리한 적 있죠?」 → 「한끼는 캡처 한 장이면 재료랑 순서로 정리돼요」
- B ✍️: 「캡처만 수백 장인데, 정작 요리할 땐 못 찾는 거… 나만 그래요?」
- 화면: 캡처 고르기 → 글자 부분 자르기 → 재료·순서 채워짐

## 2. 공유로 받기 (인스타·갤러리 → 한끼)
- **이유** ✍️ 원문 없음
- A: 「인스타에서 본 레시피, 저장만 하고 잊은 적 있죠?」 → 「한끼는 공유 한 번이면 담겨요」
- B ✍️: 「저장 누르고 다시 안 보는 거, 나만 그래요?」
- 화면: 인스타 공유 → 한끼 → 받은 레시피함

## 3. 해 먹은 기록 (요리 일기·달력)
- **이유** 🗣 *"전에해먹은 레시피 기억안나서 못한적"* ＋ 📮 *"우리 아이들도 나중에 내가 해준 요리들이 가슴에 영원히 남았으면 좋겠다"* (`docs/메인컨셉-전략.md:58`)
- A: 「전에 해 먹은 레시피, 기억 안 나서 못 한 적 있죠?」 → 「한끼는 해 먹은 날이 그대로 남아요」
- B: 「엄마가 해 주던 밥솥카스테라는 마흔 넘어서도 기억나요. 우리 애들도 그랬으면 해서 만들었어요」
- 화면: 달력에 쌓인 요리 → 일기 한 장

## 4. 좋았던 레시피 (인덱스)
- **이유** 📮 *"좋았던 레시피는 인덱스로 남겨요(별대신)"* · *"누를 시간 없어서 안하기로 했잖아"* · *"그 북마크는 나도 한번도 안썼어 번거로워서. 레시피에 들어가서 눌러야 하니까"* (`docs/기능-아카이브.md:1331~1339`)
- A: 「맛있었는데… 그 레시피 어디 있었더라? 한 적 있죠?」 → 「한끼는 좋았던 레시피에 인덱스를 붙여요」
- B: 「별점은 누를 시간이 없고, 북마크는 들어가서 눌러야 해서 한 번도 안 썼어요. 그래서 목록에서 바로 붙이는 인덱스로 만들었어요」
- 화면: 목록 카드 → 인덱스 클립 → 인덱스만 모아 보기

## 5. 요리모드 (화면 안 꺼짐 · 큰 글씨)

- A: 「요리하다 꺼진 화면, 양념 묻은 손으로 켠 적 있죠?」 → 「한끼는 요리하는 동안 안 꺼져요」
- B ✍️: 「손에 양념 묻었는데 화면 꺼지는 거, 나만 짜증 나요?」
- 화면: 요리모드 큰 글씨 → 다음 단계

## 7. 인분 바꾸기

## 10. 가진 재료로 만들기

- B: 「재료를 넣으면 바로 추천이 바뀌어야 하잖아요. 그래서 그렇게 만들었어요」

## 12. 주부의 장바구니

- A: 「재료 하나 사려고 성분이랑 리뷰 검색만 백 번 한 적 있죠?」 → 「그래서 한끼는 18년 차 주부가 고른 걸 성분까지 보여줘요」
- B: 「재료 사면서 성분·리뷰 검색만 백만 번 했어요. 그래서 제가 써 본 것만 골라 담았어요」

## 13. 꾸미기 (레꾸)
- **이유** 📮 *"곰곰이(꼬르곰)는 나, 펭펭이는 사춘기 딸"* (`docs/메인컨셉-전략.md:67`) — 꾸미기 기능 자체의 이유 원문은 없음
- A: 「잘 만든 요리 사진, 사진첩에 묻어 둔 적 있죠?」 → 「한끼는 꾸며서 남겨줘요」
- B: 「꼬르곰은 저, 펭펭은 사춘기 딸이에요. 우리 집 부엌이 그대로 스티커가 됐어요」
- 화면: 요리 사진 → 스티커 붙이기

## 14. 레꾸자랑 — 레시피 보내기
- **이유** 🗣 *"레시피 보낼때 일일이 적어서 보내거나 캡쳐해둔거 찾기 불편하지 않았냐"*
- A: 「레시피 물어보면 일일이 적어 보내거나, 캡처해 둔 거 찾느라 사진첩 뒤진 적 있죠?」 → 「그래서 한끼는 레시피를 카드 한 장으로 바로 보내요」
- B: 「'그거 어떻게 만들었어?' 물어보면 하나하나 타이핑하거나 캡처 찾느라 한참 걸렸어요. 그래서 버튼 하나로 보내게 만들었어요」
- 화면: 레꾸자랑 → 「② 레시피」 → 공유 → 카톡에 카드 한 장 도착 → (덤) 「① 카드」 꾸민 사진
