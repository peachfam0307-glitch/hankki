## 🔎 증상이 «셋»이다 (하나가 아니다)

| | 증상 | 의심 지점 |
|---|---|---|
| **A** | **2장째가 안 들어왔다** | `EditorScreen.jsx` 221줄 `if (!img \|\| ocr.busy) return` — 225줄에서 `setOcr({busy:false})` 하지만 **React state 갱신은 비동기**라, 237줄이 곧바로 다음 장을 크롭에 넘기면 **두 번째 `runOcr` 가 busy=true 로 읽고 조용히 리턴**할 수 있다 |
| **B** | **재료가 통째로 「순서」로 갔다** | `parseRecipe.js` 분류 — 재료 줄이 붙어버려(C) 「분량 있는 짧은 줄」 판정을 잃었을 가능성 |
| **C** | **재료 두 줄이 한 줄로 붙었다** | `mergeWrappedLines`(v8.46) — **인스타 캡션이 여러 줄로 잘린 걸 합치려고** 만든 건데 **재료 목록까지 합쳤다.** 재료는 원래 한 줄에 하나다 |

⭐ **C가 B를 부르고, B 때문에 결과가 더 나빠 보인다.** A는 별개 문제.
