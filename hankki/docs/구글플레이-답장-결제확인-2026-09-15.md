## ✅ 답 ② — 영구 상품(비소모성)의 acknowledge

> Digital Goods API 에 `acknowledge()` 가 없으면, **백엔드에서** Google Play Developer API 의
> `purchases.products.acknowledge` 로 처리하라. **검증하고 권한(entitlement)을 준 «뒤에»** 하라.

📌 **왜 중요한가** = 구매를 제때 acknowledge 하지 않으면 **구글이 자동 환불하고 구매를 취소한다.**
   ＝ 유저가 돈을 냈는데 며칠 뒤 사라진다. **가장 아픈 실패 모양.**
⭐ **뜻 = 영구 상품을 팔려면 «서버»가 있어야 한다.** 앱(웹)만으로는 못 한다.
   🟢 우리는 **클라우드플레어 워커**가 이미 있다 → 거기에 붙이면 된다.

## ✅ 답 ③ — 소모품(우리 「열쇠」)의 consume

> 소모품은 **consume 해야 같은 상품을 다시 살 수 있다.** consume 을 늦추면 그동안 못 산다.
> **consume 은 acknowledge 도 겸한다.**

⭐ **뜻 = 열쇠는 `consume()` 하나면 끝이다.** acknowledge 를 따로 부를 필요가 없다.
