## ⭐ 먼저 알아둘 것 — **지금 앱 화질은 정상이다**

창업자가 폰에서 *"어두운색 테두리 있는 애들이 거의 이래"* 라고 잡은 그 화면 —
**파일은 멀쩡했다. 원인은 「확대」였다.**

```
재료·도구 소스 = 171~250px
손잡이 최대 = s 0.9 = 972px
        → 최대 4~5배 확대 → 가장자리 뭉갬 → 테두리가 지저분해 보임
```

✅ **앱에서 막았다** (`DecorLayer` 손잡이 상한을 **소스 긴변 × 1.7배**로) → **이제 키워도 안 뭉갠다.**
그래서 아래 목록은 *"안 고치면 깨진다"* 가 아니라 **"크게 못 써서 아쉽다"** 는 목록이다.

⚠️ 왜 게이트가 못 잡았나 = `check-sticker-res.mjs` 는 **기본 크기**만 쟀다. **유저는 키운다.**
→ 게이트에 「크게 못 키우는 컷」 경고를 붙였다(실패는 안 시킨다 — **시끄러운 게이트는 아무도 안 본다**).

```
정사각형 흰 배경에 여름 테마 폴라로이드형 프레임 4개를 2×2로 크게 배치.
각 프레임은 가운데가 뻥 뚫린 사각 액자 모양이고, 테두리에만 여름 소품이 그려져 있다.

음영 없음, 그라데이션 없음. 진한 갈색 외곽선.

★배경 규칙(꼭 지켜)★

- 그림자·글로우·테두리 박스 없음
- 4개가 서로 닿지 않게, 사방에 넉넉한 여백

```
⛔ **`transparent background` 라고 쓰지 말 것** — 그렇게 쓰면 **AI가 회색 격자를 진짜로 그려 넣는다.**
   (7/30 여름 프레임 검은 점선 사고의 원인이 정확히 이것이었다)

## 🔴 1순위 ② 재료·요리 도구 39컷 — **회갈색 점점이 때문에 다시 뽑는다** (2026-07-31 결정)

> 창업자: *"재료(계란후라이, 양파 등) 다시 검수해줘. 아직 검정색 지저분해"* → *"아 다시뽑으라했지. 프롬프트 줘."*

### 왜 수술로 못 고치나 (재본 결과)
| 스티커 | 바깥 3px 띠 밝기 |
|---|---|
| 계란후라이 `ig_jae03` | 최저 **98** · 중앙 201 · 상위 237 |
| 양파 `ig_jae06` | 최저 **93** · 중앙 196 |
| 셰프모자 `tk_hat` | 최저 **110** · 중앙 194 |

- 앞서 지운 격자 찌꺼기는 **어둡고 무채색**(밝기<130 · 채도≤24)이라 골라낼 수 있었다.
- 그런데 재료의 이건 **회갈색**(밝기 130~200 · 채도 있음)이다 → **같은 필터에 안 걸린다.**
- 문턱을 올려 잡으면 **크림·흰색 그림 자체**(계란 흰자·마늘·셰프모자)를 파먹는다.
  *(7/30에 여름 프레임에서 채널차 ≤8로 잡았다가 크림색 선까지 지운 것과 같은 함정)*
- ⭐ 게다가 **소스가 171~250px** 이라 어차피 크게 못 쓴다 → **고치는 것보다 다시 뽑는 게 이득.**
