
# 📏 한 장에 몇 개까지? — **실측으로 답** (창업자 질문 2026-07-31 *"하루종일 걸리겠어 ㅋ"*)

## 우리 원본 시트는 거의 다 **1254 × 1254**
저장소의 원본 시트 220장을 세어보니 **146장이 1254×1254**, 나머지도 1024~1536 사이다.
→ 시트 크기가 정해져 있으니 **격자 한 변이 컷 크기를 결정한다.**

| 격자 | 칸 크기 | 실제 컷 (여백 감안 ×0.8) | 판정 |
|---|---:|---:|---|
| 2×2 (**4개**) | 627px | **~500px** | ✅ 프레임처럼 크게 쓰는 것 |
| 3×3 (**9개**) | 418px | **~330px** | ✅ **재료·소품·도구 = 이게 상한** |
| 4×4 (16개) | 313px | ~250px | ⚠️ 지금과 똑같아진다 |
| 5×5 이상 | 251px↓ | ~200px↓ | ❌ 이번 문제의 원인 |

**실측 대조**: 여름 프레임 4×4 시트 → 실제 231~341px ✓ · 음식 마스터그리드 90컷 → 85px ✓ (표와 맞다)

## ⭐ 결론 = **한 장에 최대 9개(3×3)**

⚠️ **앞에 적었던 「4×2로 8개」는 내가 잘못 잡았다** — 가로가 4칸이라 컷당 250px밖에 안 나온다.
**정사각 시트에서는 `max(가로칸, 세로칸)` 이 컷 크기를 정한다.** 3을 넘기지 말 것.

## ⭐ 그리고 **600px는 과한 목표였다** → **350px면 충분**
손잡이 상한을 **소스 × 1.7배**로 막아 뒀으니 —
```
소스 330px  →  최대 560px 까지 키울 수 있다  =  표지(1080)의 절반 이상
```
기본 표시가 238px이니 **330px면 실사용에 넉넉하다.**
→ 영어 프롬프트의 `600 x 600 pixels` 를 **`350 x 350 pixels`** 로 낮춰도 된다(오히려 지키기 쉬워진다).
