# 꼬르곰·펭펭이 그림 생성 프롬프트 (ChatGPT용) · 2026-07-18

> **결정**: 이모티콘 출시용 그림은 클로드 손코딩으로 안 함(품질 한계 확인, "3단분리" 사건 ㅋㅋ).
> → **①창업자가 ChatGPT 그림 생성 + 안목 큐레이션** (지금, 공짜) → 잘 되면 그대로 / **②외주**(크몽·숨고, 출시 후 수익으로).
> 클로드 역할: 프롬프트 설계 · 결과 피드백 · 24종 세트 구성 · 자막 얹기.
> 앱 안 그림(부디·스티커)은 기존 클린 벡터로 클로드가 계속 담당(검증됨).

```
카카오톡 이모티콘 스타일의 캐릭터를 그려줘.

[캐릭터]
- 통통하고 동글동글한 2등신 아기곰 "꼬르곰"
- 몸 색: 따뜻한 크림 베이지(연한 카라멜), 주둥이는 더 연한 크림색, 볼터치 살구색
- 머리에 폭신한 흰색 요리사 모자를 항상 씀(시그니처)
- 눈: 작고 까만 콩눈(순둥한 인상)
- 성격: 순하고 어리숙한데 맨날 배고픈 먹보. 세상 서러운 표정을 자주 지음
- 짧고 통통한 팔다리, 전신이 다 보이게

[스타일]
- 한국 카카오톡 인기 이모티콘 감성: 깔끔한 손그림 벡터, 가는 갈색 외곽선, 플랫한 파스텔 색감
- 흰 배경, 정사각형, 글자 없이 캐릭터만
- 라인프렌즈 브라운·리락쿠마·곰돌이 푸와는 확실히 다른 얼굴과 비율로 (요리사 모자+크림 주둥이가 차별점)

[포즈]
- 배가 고파서 두 팔 번쩍 들고 엉엉 우는 모습. 눈물이 뽀짝 튀고, 배 옆에 꼬르륵 물결. 발밑엔 엎어진 빈 밥그릇
```

## 🐧 펭펭이 기본 프롬프트
```
카카오톡 이모티콘 스타일의 캐릭터를 그려줘.

[캐릭터]
- 짧뚱하고 동글동글한 2등신 아기펭귄 "펭펭이"
- 몸: 부드러운 블루그레이, 배는 흰색, 부리와 발은 주황색
- 패션: 삐딱하게 쓴 블랙 베레모 + 슬림한 검정 선글라스(젠틀몬스터 느낌) + 블랙 자켓, 가슴에 가는 은색 체인 — 겁나 패셔니스타
- 성격: 시니컬한 쌉T. 팔짱 끼고 심드렁. 근데 하찮게 귀여움
- 짧은 날개로 팔짱, 전신이 다 보이게

[스타일]
- 한국 카카오톡 인기 이모티콘 감성: 깔끔한 손그림 벡터, 가는 외곽선, 플랫한 색감
- 흰 배경, 정사각형, 글자 없이 캐릭터만
- 펭수·뽀로로와 확실히 다르게 (베레모+선글라스+자켓이 차별점)

[포즈]
- 팔짱 끼고 고개 살짝 기울이며 심드렁하게 쳐다보는 모습. 머리 옆에 "…" 느낌의 점 세 개
```

## 📱 사용법 (핵심)
1. **첫 그림 잘 나오면 같은 대화에서 계속** — "이 캐릭터 그대로 유지하고, 이번엔 ○○하는 모습". 새 대화 열면 얼굴 바뀜.
2. 잘 나온 그림 **저장 → 다음에 첨부** + "이 그림이랑 똑같은 캐릭터로" = 일관성↑.
3. **글자 넣지 말 것** — AI가 한글 자막 망가뜨림. 자막은 나중에 클로드가 얹음.
4. 수정은 **한 번에 하나씩**: "눈 더 작게" / "더 통통하게" / "선 더 얇게".
5. 잘 나온 것 클로드에게 전송 → 판정 + 다음 프롬프트 + 세트 구성.

## 🎬 성격 박힌 상황컷 (v2 — MZ 코드, 기준컷 첨부 후 복붙)
### 꼬르곰 (F·먹보)
- 밥그릇 앞에 무릎 꿇고 넙죽 절 (밥 리스펙) + 반짝이
- 냉장고에 상반신 집어넣고 뒤적 — 엉덩이·짧은 다리만 보임
- 샐러드 밀어두고 치킨 껴안기 + 행복 눈물 (다이어트 3초 포기)
- 바닥에 슬라임처럼 녹아 눈만 껌뻑 + 꼬르륵 (무기력한데 배고픔)
- 이불 김밥말이, 눈만 빼꼼 + 음식 생각풍선
- 볼 빵빵 문 채 감동 엄지척 + 눈물 찔끔
- 폰 쥐고 배달앱 심각 고민 + 치킨·피자 생각풍선
- 텅 빈 그릇 + 배 두드리며 만족 미소
### 펭펭이 (쌉T·패피)
- 영혼 없는 슬로우 박수 + "…"
- 손바닥 착 내밀며 단호 거절, 고개 딴 데
- 아이스아메리카노 쪽 빨며 무표정 (얼죽아)
- 무표정 셀카, 베레모 각
- 쇼핑백 주렁주렁 당당 워킹
- 어깨 으쓱 "어쩔 수 없지" + 선글라스 반짝
- 뒤돌아 폰만 봄 (관심 1도 없음)
- 고개 돌리고 마지못해 엄지척 + 볼 발그레 (츤데레)
### 콤비 (F×T)
- 곰 바닥 치며 광광 vs 펭귄 아아 마시며 무표정 구경
- 곰 요리를 펭귄이 한 입 → 눈썹 씰룩(맛있는데 인정 싫음), 곰은 초롱초롱
