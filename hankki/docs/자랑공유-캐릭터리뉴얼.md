- **펭펭 머리 수정**: 지금 바깥 뻗침 → **보브컷 C컬(안으로 말림)**로. 다시 그릴 때 반영.

## 📏 생성 크기 스펙 (창업자 요청)
- 캔버스: 큰 사이즈 그대로(1254×1254 / 1536×1024). 작게 뽑지 말 것.
- **한 장에 4컷(2×2) = 컷당 ~600px = 앱 스티커(622px) 동급 ✅ 추천.**
- 2컷=컷당 ~900px(표지 절반 차지도 쨍) / 6컷↑=~400px↓ 흐림 ❌.
- **컷당 최소 500px, 목표 600px+.**
- 개별 8포즈=2장(곰4/펭4). 콤비는 캐릭터 둘이라 **한 장에 1컷**(각 ~600px).
