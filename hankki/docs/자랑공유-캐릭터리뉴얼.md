## ✅ 확정된 지침
- **배포 신호**: 창업자 **`/픽스`** = 확정 + 저장 + 배포. (그 전엔 앱코드 푸시 금지 / 문서 저장은 예외 OK) → `CLAUDE.md` 규칙 9.
- **배경 톤**: `#f4f2ee` **확정** (웜기 살짝 남긴 중립 — 곰·펭 둘 다 어울림). 백업 `#f3f4f4`(더 밝고 쿨). 웜크림 계열(`--cream #f2ede3`, 커버 `--thumb #f8f3ea`)을 이 톤으로.
- **공유 방식**: 클로드가 따로 디자인한 카드 ❌ 폐기. = **앱 레시피 꾸미기(배경색·포스트잇·글자·마테·스티커) 그대로 이미지 캡처.**
- **화질 방침(중요)**: "얼마나 크게 보여줄 거냐"로 결정.
  - **캐릭터(주인공, 크게)** → 한 장 **4컷 이하**(컷당 500~600px+ = 앱 스티커 622px 동급). 2컷이면 ~900px.
  - **소품·음식·효과(작게 붙는 악세)** → 격자로 많이 그려도 됨(200~300px 충분). **기존 음식88·도구94 그대로 사용 OK.**
  - ❌ 한 장 6컷 이상 = 작아져서 흐림(= 지금 문제의 원인).
  - 테두리 보정(defringe+업스케일)은 오히려 지저분 → 폐기. **흰/크림 배경에 원본 그대로가 제일 깨끗.**
- **개별 vs 콤비**: 개별(곰·펭 따로)=꾸미기 스티커(따로 배치+화질↑). 콤비(곰+펭 함께)=자랑카드 대표/브랜딩용(한 장 1컷, 각 ~600px).
- **⚠️ 펭펭 머리 수정**: 지금 바깥 뻗침 → **끝이 안으로 살짝 말리는 단발 보브(C컬)**로. → 기존 펭·콤비 전부 재생성 대상(폐기).
