## 이 문서가 뭔가

**⛔ 규칙집이 아니다.** 규칙은 이미 `CLAUDE.md` 에 18개가 있고, 문제는 «안 지켜지는 것»이다.
창업자가 2026-07-31 에 정확히 말했다 — ***"규칙만 만들면 뭐해 안지키는데."***

그래서 두 쪽으로 나눈다:

| | 무엇 | 어디 |
|---|---|---|
| **기계가 잡는 것** | 돌리면 걸린다. 안 지킬 수가 없다 | `npm run 실수` (`scripts/check-mistakes.mjs`) · **스모크에 물려 있어 배포를 막는다** |
| **기계가 «못» 잡는 것** | 사람이 지켜야 한다. 그래서 **왜 틀렸는지**를 남긴다 | 이 문서 아래쪽 |

⛔ **「게이트가 초록불이니 괜찮다」로 읽지 말 것.** 아래 여덟 중 기계가 잡는 건 절반도 안 된다.

## 🅰 패턴 A — 「검사가 «무엇을» 보는지」가 틀렸다  ⭐제일 잦다

검사를 만들어 놓고 **엉뚱한 걸 재서 «거짓 통과»** 시킨다. 초록불이 거짓말이 된다.

**증거**
- 만족도 표시 — `aria-pressed` 만 봤다. **「눌렸나」는 「보이나」가 아니다.** 화면엔 거의 안 칠해져 있었다 (v9.88)
- 세로 사진 — 「안 잘렸나」를 비율로만 봤다. **종이를 통째로 덮어도 비율은 맞다.** 실제로 그랬다 (v9.88)
- 형광펜 — 「명암 퍼짐(std)」으로 쟀더니 **띠 테두리만으로 194%** 가 나와 통과 (v9.87)
- 문체 그물 — 이름은 「해요체로 나가나」인데 코드는 **「한다체가 있나」**를 봤다. 명사형이 통과 (v9.59)
- `document.fonts.check()` — **파일이 없어도 `true`** 를 준다 (2026-08-07)
- 오늘 하루에만 넷 더 — CORS 로 글꼴이 하나도 안 떴는데 숫자는 그럴듯 / 구멍 세기가 거꾸로 /
  덩어리 바닥선을 «자기 자신»에서 뽑아 무엇이든 통과 / 화면에 `.paper` 가 16개인데 뒤에 깔린 걸 쟀다
- **이 게이트 자신도 첫 판에 세 번 틀렸다** — 주석 속 경고문을 «사용»으로 읽고,
  `package.json` 전체를 훑고, 「손댄 것」을 파일 시각으로 봤다

**지금 막는 것** — 규칙 12(옛 값으로 돌려 진짜 걸리는지 먼저 본다) · `npm run 실수` 가
「지금 커밋하려는 검사에 그 확인 기록이 있나」를 본다

**구멍** — *「무엇을 재야 하나」는 기계가 못 정해준다.*
👉 **검사를 만들면 «틀린 값을 일부러 넣어» 걸리는 것부터 본다.** 안 걸리면 내 가정이 틀린 거다.

## 🅱 패턴 B — 「없다」의 «이유»를 내가 정한다

못 찾은 것을 «없다»로, 안 보이는 것을 «잘렸다»로 바꿔 말한다. **처방이 정반대가 된다.**

**증거**
- 활성 기기 그래프가 7/24 에서 끝난 걸 **「캡처가 잘렸다」**로 단정 → 실제는 **14일 지연**.
  창업자가 콘솔을 직접 보고 잡았다 (*"아직 안열렸어"*). 처방이 «다시 찍어줘» ↔ «기다려야 한다»로 갈린다
- 「유료팩 캐릭터 몇 개까지?」에 **「정한 적 없다」** → 정해져 있었다(계절 12·기본 24). 도구를 돌리니 11줄이 즉시 나왔다
- `ls` 가 안 잡히자 **「낱개 67컷이 날아갔다」**고 보고 → 91개 멀쩡히 있었다(자리 착각)
- 구글 폼 목록 캡처를 «전체»로 읽음 → 제목이 **「최근 설문지」**였다
- 「29는 어디서도 안 나오는 숫자」 → 숫자는 맞았고 **이름표**가 틀렸었다

**지금 막는 것** — `ask-guard`(매 턴) · `cwd-guard`(자리 착각을 실제로 막는다 · 오늘도 두 번 걸렸다) ·
`decided.mjs`(이미 정한 것 찾기) · 규칙 17·18

**구멍** — *창업자 캡처를 잘못 읽는 건 기계가 못 잡는다.*
👉 **화면을 근거로 쓸 땐 «그 화면의 제목»부터 읽는다.** 「최근」·「상위 N」·「필터」면 그건 전체가 아니다.

## 🅲 패턴 C — 문서·기억을 «실물»보다 믿는다

**증거**
- 릴리즈가 **「하나뿐」**이라 적힌 문서를 믿고 신청서를 썼다 → 콘솔 실물은 **일곱 판** (2026-08-03)
- **「재생성 대기」**라 적어놓고 하루를 갔는데, 그날 내가 판정에 쓴 배경이 바로 그 재생성본이었다
- 「여름 프레임 12는 아직 비어 있다」 → 이미 살아 있었다
- 모션 배분 **초안**을 코드에 먼저 넣어두고, 나중에 그 코드를 보고 *"이미 정해져 있었다"* 며 확정으로 굳혔다.
  창업자 *"추석에 아장아장은 처음들어."*

**지금 막는 것** — `latest-guard`(옛 문서 열면 막는다) · `doc-guard`(한 문서 «안»의 세대 ＋ 「대기」인데 파일은 있는 것) ·
`evidence-guard`·`submission-guard`(저장소 밖 주제는 실물부터) · `npm run 실수` 의 「대기 문서」 경고

**구멍** — *「저장소에 있는 것」 ≠ 「실제로 올라가 있는 것」.* 스토어 스샷·콘솔 값·구글 폼은 저장소가 모른다.
👉 **「대기」인 값을 코드에 «먼저» 넣지 않는다.** 넣으면 나중에 그 코드가 근거가 된다.

## 🅳 패턴 D — 「됐다」를 출력 줄로 판단한다

**증거**
- 빌드 출력에서 `✓ built` 줄을 세다 실패를 놓쳤다 → **배포 실패**(run 1010). 판정은 **exit code** 로 해야 했다
- **「푸시했다 = 배포됐다」**로 말했다가 틀렸다. 확인은 Actions 결론 하나뿐이다
- 스모크가 **빌드를 안 한다** — 옛 `dist` 로 통과해놓고 배포가 죽었다(2회)
- CI 는 **Node 20**, 이 컨테이너는 22 → `globSync` 를 써서 **배포가 세 번 연속 실패**. 그동안 v9.48·v9.49 가 안 나갔다
- ⛔⛔ **오늘 또 밟았다 (2026-08-07)** — 이 실수 시스템을 만들던 «바로 그 세션»에서.
  새로 만든 `check-fontchip.mjs` 가 파이썬 `fontTools` 로 woff2 를 열었는데 **CI 엔 그게 없다**
  → **v9.91 이 배포되지 않았다**(run 1128 · `ModuleNotFoundError`). 로컬 스모크는 초록불이었다.
  📌 `globSync` 와 «똑같은 종류»다 — **「내 자리에 있는 것」을 CI 에도 있다고 여겼다.**

**지금 막는 것** — `_fresh.mjs`(dist 가 src 보다 낡으면 재현판이 죽는다) ·
`npm run 실수` 의 ②(Node 버전) · **③-2(게이트가 파이썬을 부르나 · 위 사고로 신설)** · ⑦(dist 낡음)

**구멍** — 「내 자리엔 있는데 CI 엔 없는 것」은 파이썬 말고도 있다(이미지 도구·글꼴 파일…).
👉 **배포를 막는 게이트는 «노드만으로» 돌아야 한다.** 만들 때 쓰는 도구는 자유지만,
   검사에 필요한 값은 **만들면서 파일로 적어 둔다**(`chip-chars.json` 이 그 방식이다).
👉 배포 확인은 **`actions_get` 의 `conclusion: success` ＋ `head_sha` 대조**. ⛔사이트를 열어보려 하지 말 것(프록시 403).
👉 ⛔**「푸시했다」로 끝내지 말 것.** 오늘 그렇게 넘어갔다가 v9.91 이 안 나간 걸 한참 뒤에 알았다.

## 🅴 패턴 E — 창업자 판정 자리를 내가 대신 정한다  ⭐제일 비싸다

취향·방향은 창업자 것인데(규칙 11) 내가 미리 쳐내거나 굳힌다.

**증거**
- 「표지 밖 버튼」 안을 *"찾기 어려워진다"* 며 **내 판단으로 미리 쳐냈다** → 창업자가 다시 물어 되살아났고, 그게 답이었다
- 창업자 기준 셋을 듣자마자 **내 후보였던 꼬막까지 스스로 쳐냈다** → *"꼬막은 괜찮아."*
- 어두운 배경의 흰 원을 v8.5 에 **판정 없이** 넣어 굳혔다 → 나중에 그게 버그의 뿌리가 됐다
- 모션 배분 초안을 확정으로 (위 C)
- 오늘도 — 「글씨체를 빼자」에 **빼는 코드를 먼저 쓰기 시작**했다. 창업자가 되돌렸다(*"펜글씨빼지말자 ㅋ"*)

**지금 막는 것** — 규칙 13(검수 통과해야 배포) · `hold/*` 브랜치 · 검수판 보내기

**구멍** — *«쳐내는 것»은 아무 흔적을 안 남긴다.* 게이트가 볼 게 없다.
👉 **기준은 「어디를 볼지」를 정하는 것이지 「되나 안 되나」를 정하는 게 아니다.**
   후보로 올려 판정을 받는다. ⛔내가 대신 적용해 미리 빼지 않는다.

## 🅶 패턴 G — JSX 주석을 «표현식 여는 자리»에  ⭐네 번 밟았다

`{/* */}` 는 «자식» 자리에서만 된다. `=> (` · `return (` 바로 뒤는 객체 리터럴로 파싱돼 `Expected ")"` 로 죽는다.
**경고를 바로 윗줄에 적어놓고도 또 밟았다** (2026-08-04 · 08-06 · 08-07 ×2).

**지금 막는 것** — `npm run 실수` 의 ① (빌드도 잡지만 **빌드는 30초, 이건 0.2초**)
👉 함수 «바깥»으로 빼고 `//` 주석으로.

## 🅷 패턴 H — 「전부 담기」식 설계가 개수 늘면 스스로 무너진다

**증거**
- PWA precache 가 그림을 «전부» 담아 첫 실행에 **215MB** → 「쓸 때만 받기」로 4.1MB
- 공유 카드 글꼴 꾸러미가 «우리 글꼴 전부» — 넷일 땐 1.7MB, **열둘이면 4.7MB**
- 글씨체 고르는 칸이 이름을 그 글씨체로 그려서 **탭 한 번에 4.45MB** → 칩 벌 80KB
- 캐시 `maxEntries` 를 개수에 «딱 맞게» 잡으면 하나만 더 들어와도 쓰던 게 사라진다

**지금 막는 것** — `check-precache.mjs`(8MB 상한) · `check-fontchip.mjs`(칩 벌) · `check-packleak.mjs`

**구멍** — *새로 만드는 「전부 담기」는 아무도 안 본다.*
👉 **「N 이 열 배가 되면?」을 설계할 때 한 번 묻는다.** 창업자가 오늘 *"무거워진다며"* 로 물어서 잡았다 —
   **묻지 않았으면 4.45MB 가 그대로 나갔다.**

## ✅ 쓰는 법

```bash
npm run 실수      # 기계가 잡는 것만 (스모크에도 물려 있어 배포를 막는다)
npm run assets    # 개수·정원·자산 현황 (손으로 세지 말 것)
npm run smoke     # 전체 (실수 게이트 포함)
```

**말하기 전에 스스로 묻는 셋** — 기계가 못 잡는 자리다.
1. 이 검사는 «무엇을» 보나? 틀린 값을 넣으면 걸리나? (A)
2. 「없다」인가, 「내가 아직 못 찾았다」인가? 확인 방식부터 의심했나? (B·C)
3. 이건 «내가» 정할 자리인가, 창업자가 정할 자리인가? (E)
