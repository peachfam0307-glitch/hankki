# 한끼 캐릭터 설정집 (IP 바이블) · 초안 2026-07-18

> 목적: 이모티콘·앱·굿즈에서 계속 꺼내 쓸 캐릭터 성격·역할 정리. 성격이 곧 IP의 힘(라이언=갈기없음, 푸쉰=게으름처럼 "약점/성격"이 판매요인).
> ⚠️ 마스코트 이름 개명 진행 중: **곰곰이 → 꼬르곰(후보)** (사유: 쿠팡 식품PB "곰곰"과 충돌 → `docs/법적리스크-조사-2026-07-18.md`). "-식이" 계열(곰식이·뚱식이)은 카카오 춘식이 연상 리스크로 제외.

## 세계관 한 줄
> 작은 부엌에서 요리하며 사는 동물 친구들. 각자 성격대로 요리를 대하는 "한끼 부엌 식구들".

## 주인공
### 🐻 꼬르곰 (곰) — ✅ 확정 성격
- **한 줄**: 순하고 어리숙한데 **맨날 배고픈** 먹보 순둥이.
- 이름 = 꼬르륵(배꼽시계) + 곰 → 성격이 이름에 박힘.
- 셰프모자 착용(정체성 앵커). 요리 완성하면 세상 다 가진 표정.
- 이모티콘 상황: 배고파 쓰러짐 / 냄비 앞에서 침 흘림 / 완성하고 감동 / 냉장고 열고 실망 등 무한.

### 🐧 펭펭이 (펭귄) — ✅ 확정 성격
- **한 줄**: 좀 **심술궂고 까칠한** 츤데레.
- 순둥 꼬르곰이랑 **순둥×까칠 콤비** = 케미·상황극 무한 (라이언×춘식 포지션).
- (여름·시원한 담당 톤과도 연결 가능 — 튜브·아이스)

## 친구들 (제안 — 성격 + 앱 기능 매핑, 반응 보고 확정)
> 조사 팁: 사이드 캐릭터를 앱 기능에 매핑하면 자연스럽고 앱 안에서 활약처가 생김.
| 캐릭터 | 제안 성격 | 앱 역할(제안) |
|---|---|---|
| 🐹 햄스터 | 볼에 잔뜩 쟁여두는 욕심쟁이 | **냉장고(재고) 담당** — 쟁여두기 |
| 🐕 강아지 | 신나서 팔랑팔랑 뛰어다님 | **장보기 담당** — 사러가기 |
| 🐰 토끼 | 깔끔·정리쟁이 | **모아보기/정리 담당** |
| 🐱 고양이 | 도도한 미식가·입맛 까다로움 | **별점·평가 담당** |
| 🐤 병아리 | 요리 초보·서툴지만 열심 | **초보 응원·요리기록 담당** |
| 🦎 도마뱀 | 느긋 마이페이스 | **타이머·기다림 담당**? |

## 활용
- **이모티콘**: 꼬르곰 단독 세트(24~32컷) 먼저 → 꼬르곰×펭펭이 콤비 세트 → 친구들 확장.
- **앱**: 로딩·빈화면·푸시·코치마크·공유카드에 성격 살린 곰 재사용(단색·단순 실루엣 유지).
- **굿즈/시즌**: 시즌·상황 변형(명절 꼬르곰·다이어트 꼬르곰·야식 꼬르곰…) = 무한 콘텐츠.
