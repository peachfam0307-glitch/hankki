# 한끼 캐릭터 설정집 (IP 바이블) · 초안 2026-07-18

## ✅ 공식 기준컷 확정 (2026-07-18 밤) — ChatGPT 생성 + 창업자 큐레이션
> 이모티콘용 공식 비주얼 확정. 기준 이미지 2장은 창업자 폰에 보관(모든 신규 컷 생성 시 반드시 첨부 + "이 캐릭터들 그대로").
- **꼬르곰**: 진한 꿀 카라멜 브라운 몸 + 크림 주둥이·배 + 흰 셰프모자 + **크림 스트라이프 앞치마(허리 리본·주머니)** + **나무 숟가락**(시그니처) + 콩눈·걱정눈썹·발바닥 젤리. (v1 연한 크림 버전은 "약해서" 폐기 — 진한 몸색 대비가 핵심)
- **펭펭이**: 블루그레이 몸 + 흰 배 + **블랙 베레(삐딱) + 슬림 선글라스(위로 반감긴 눈 빼꼼 = 하찮음 포인트) + 블랙 가죽자켓 + 은색 체인** + 팔짱 + "…". 
- **대칭 구조**: 곰=앞치마(부엌·F) vs 펭귄=가죽자켓(패션·쌉T) — 옷으로 성격 대비.
- **📏 크기 관계(확정 2026-07-18)**: 펭펭이는 꼬르곰의 **2/3 크기**(곰 가슴 높이). 큰 순둥이 형 × 작은 시크 동생 구도(라이언×춘식 공식). 작은 쪽이 팩폭하는 게 포인트.
- 제작 파이프라인: 클로드 프롬프트(`캐릭터-그림-프롬프트.md`) → 창업자 ChatGPT 생성·큐레이션 → 클로드 판정·세트구성·자막.

> 목적: 이모티콘·앱·굿즈에서 계속 꺼내 쓸 캐릭터 성격·역할 정리. 성격이 곧 IP의 힘(라이언=갈기없음, 푸쉰=게으름처럼 "약점/성격"이 판매요인).
> ⚠️ 마스코트 이름 개명 진행 중: **곰곰이 → 꼬르곰(후보)** (사유: 쿠팡 식품PB "곰곰"과 충돌 → `docs/법적리스크-조사-2026-07-18.md`). "-식이" 계열(곰식이·뚱식이)은 카카오 춘식이 연상 리스크로 제외.

## 세계관 한 줄
> 작은 부엌에서 요리하며 사는 동물 친구들. 각자 성격대로 요리를 대하는 "한끼 부엌 식구들".

## ⭐ 핵심 콤비 컨셉 — F × 쌉T (밈 엔진)
> **꼬르곰(감성 F) × 펭펭이(팩폭 쌉T)** = 한국 MBTI "F vs T 반응 차이" 밈 포맷.
> "상황별 F/T 반응"으로 이모티콘·스티커 **무한 생산 + 극공감 바이럴**. (조사: 밈 네이티브 + 상황 시리즈 = 무한 콘텐츠)
> 예시 — 요리 망함: F "흑 나 요리 못하나봐😭" / T "응 계량을 안 했잖아." · 배고픔: F "배고파서 힘이 없어🥺" / T "냉장고에 계란 있어."

## 주인공
### 🐻 꼬르곰 (곰) — ✅ 확정 성격
- **한 줄**: 순하고 어리숙한데 **맨날 배고픈** 먹보 순둥이.
- 이름 = 꼬르륵(배꼽시계) + 곰 → 성격이 이름에 박힘.
- 셰프모자 착용(정체성 앵커). 요리 완성하면 세상 다 가진 표정.
- 이모티콘 상황: 배고파 쓰러짐 / 냄비 앞에서 침 흘림 / 완성하고 감동 / 냉장고 열고 실망 등 무한.

### 🐧 펭펭이 (펭귄) — ✅ 확정 성격
- **한 줄**: **쌉T 시니컬 + 겁나 패셔니스타** 😎👜. 패션엔 진심, 말투는 팩폭.
- **⭐ 전략적 역할 = "꾸미기 기능의 마스코트".** 패셔니스타라 안경·썬글·목도리·베레모·가방 등 **소품/옷 무한** → 꾸미기 아이템 콘텐츠 무한 + 앱의 꾸미기·테마·스티커를 펭펭이가 자랑하며 소개(캐릭터=판매엔진, 제페토식 패션아이템 전략).
- 예: 꼬르곰 "그 목도리 예쁘다!" → 펭펭이 "이거 한정판이야. 넌 몰라."
- 순둥 꼬르곰이랑 **순둥×시니컬 콤비** = 티키타카 상황극 무한 (라이언×춘식 포지션). 잔망루피식 "대변인 밈" 결.
- **시그니처 소품: 안경 🤓 / 썬글 😎** (예정) — 안경=평소 지적 시크 / 썬글=여름 쿨(튜브와 세트). 소품 변주 = **스티커·이모티콘 콘텐츠 무한 + 시즌팩(여름 썬글) 연결.** + **펭수·뽀로로와 확실히 구별**(둘 다 안경류 X)되는 법적 차별화까지 일석이조.
- 티키타카 예: 꼬르곰 "배고파 쓰러짐" → 펭펭이 "…또?" / 꼬르곰 "완성! 감동" → 펭펭이 "…탄내 나는데."
- (여름·시원한 담당 톤 연결 가능 — 튜브·아이스)
