## ⭐ 핵심 콤비 컨셉 — F × 쌉T (밈 엔진)
> **꼬르곰(감성 F) × 펭펭이(팩폭 쌉T)** = 한국 MBTI "F vs T 반응 차이" 밈 포맷.
> "상황별 F/T 반응"으로 이모티콘·스티커 **무한 생산 + 극공감 바이럴**. (조사: 밈 네이티브 + 상황 시리즈 = 무한 콘텐츠)
> 예시 — 요리 망함: F "흑 나 요리 못하나봐😭" / T "응 계량을 안 했잖아." · 배고픔: F "배고파서 힘이 없어🥺" / T "냉장고에 계란 있어."

## 주인공
### 🐻 꼬르곰 (곰) — ✅ 확정 성격
- **한 줄**: 순하고 어리숙한데 **맨날 배고픈** 먹보 순둥이.
- 이름 = 꼬르륵(배꼽시계) + 곰 → 성격이 이름에 박힘.
- 셰프모자 착용(정체성 앵커). 요리 완성하면 세상 다 가진 표정.
- 이모티콘 상황: 배고파 쓰러짐 / 냄비 앞에서 침 흘림 / 완성하고 감동 / 냉장고 열고 실망 등 무한.

### 🐧 펭펭이 (펭귄) — ✅ 확정 성격
- **한 줄**: **쌉T 시니컬 + 겁나 패셔니스타** 😎👜. 패션엔 진심, 말투는 팩폭.
- **⭐ 전략적 역할 = "꾸미기 기능의 마스코트".** 패셔니스타라 안경·썬글·목도리·베레모·가방 등 **소품/옷 무한** → 꾸미기 아이템 콘텐츠 무한 + 앱의 꾸미기·테마·스티커를 펭펭이가 자랑하며 소개(캐릭터=판매엔진, 제페토식 패션아이템 전략).
- 예: 꼬르곰 "그 목도리 예쁘다!" → 펭펭이 "이거 한정판이야. 넌 몰라."
- 순둥 꼬르곰이랑 **순둥×시니컬 콤비** = 티키타카 상황극 무한 (라이언×춘식 포지션). 잔망루피식 "대변인 밈" 결.
- **시그니처 소품: 안경 🤓 / 썬글 😎** (예정) — 안경=평소 지적 시크 / 썬글=여름 쿨(튜브와 세트). 소품 변주 = **스티커·이모티콘 콘텐츠 무한 + 시즌팩(여름 썬글) 연결.** + **펭수·뽀로로와 확실히 구별**(둘 다 안경류 X)되는 법적 차별화까지 일석이조.
- 티키타카 예: 꼬르곰 "배고파 쓰러짐" → 펭펭이 "…또?" / 꼬르곰 "완성! 감동" → 펭펭이 "…탄내 나는데."
- (여름·시원한 담당 톤 연결 가능 — 튜브·아이스)
