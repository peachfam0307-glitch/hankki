📮 *"굳이 하나 더 만든다면 딱 1장만 추가하면 돼요. … 더 만들면 오히려 릴스가 **광고 전단처럼** 보여요."*
📮 → *"저는 새 시안 한 장을 만드는 것보다 **실제 UI 위에 훅 자막을 얹는 쪽을 1순위로 추천**해요."*

⭐⭐ **왜 1순위인가**(창업자 설명) — *"별도 광고 이미지가 한 장 더 끼는 느낌이 없거든요."*
   첫 화면이 홍보 이미지면 *"앱 설명 광고네"* 를 **순간적으로 알아버린다.**
   훅으로 시작하면 *"무슨 얘기지?"* 하고 **다음 화면을 한 번 더 보게 된다.**

| 시각 | 화면 | 자막 |
|---|---|---|
| 0.00 | 레꾸자랑 UI **살짝 어둡게/블러** | **「레시피 저장했는데…」** |

| 1.10 | **블러가 확 풀리며** 실제 UI | → 콩국수 콕 👆 |

⛔ **꾸미지 않는다** — 창업자 = *"꼬르곰 전신, 카드 여러 장, 별 팡팡, 말풍선 등은 안 넣는 게 좋아요."*
