# 🎃 「한끼 레꾸자랑」 코너 ＋ 10월 할로윈 — 설계 (2026-09-13 · ⭐현행)

> 📮 창업자 = *"매달 한끼 레꾸자랑을 실을까.."* ← ⭐**일회성 이벤트가 아니라 «매달 도는 코너»**

## 1️⃣ 한 장으로

```
10/1   🎃 할로윈 팩 62컷을 «모두에게» 연다  ← 재료를 먼저 쥐여준다
       📱 앱 «안» 소식으로 알린다           ← 도달 100% · 광고비 0원
10/15  📮 DM 접수 마감
10/20  📸 인스타에 «보낸 사람 전원» (클로드가 캐러셀로 조립)
       📱 그중 뽑힌 사람 = 앱 「이번 달 레꾸」
11월~  🔁 매달 반복
```

## 2️⃣ ⭐ 왜 이 모양인가 — 실측 셋이 정했다

| 실측 | 그래서 |
|---|---|
| 팔로워 **80명대** · 자연 확산 거의 0 | ⛔인스타에서 시작하면 **볼 사람이 80명뿐** |
| 앱 유저 **100명** · 매일 **17명**이 연다 | ⭐**앱 안에서 시작한다** — 도달 100% · 돈 0원 |
| 광고 소재 ①「꾸민 요리책」 1,562 vs ②③ 29·1 = **54배** | ⭐소재는 **「꾸민 결과물」** — 기능 설명은 두 번 죽었다 |

📌 **확산 방향을 뒤집었다** — ~~인스타 → 앱~~ 이 아니라 **앱 → 인스타**.
   창업자 목표 순서(①설치 ②레꾸자랑 ③리포스트)에서 **설치가 «맨 앞»이 아니라 «결과»**가 된다.

## 3️⃣ ⭐⭐ 「다 주면 이벤트가 되나」 — 창업자 지적이 푼 것

📮 창업자 = *"근데... 다주면 그게 이벤트가 될까?"* → **맞는 지적이었다.**
✅ **보상이 팩이 아니다. 팩은 «재료»고, 보상은 «뽑혀서 실리는 것»이다.**
   · 꾸미는 건 **문턱 0** — 받고 그냥 놀아도 된다
   · DM은 **하고 싶은 사람만** — 「참여하세요」보다 「갖고 놀아요」가 먼저다

## 4️⃣ 몇 명 뽑나 — ⛔「뽑기」가 성립 안 할 수도 있다

🔢 레꾸자랑 = 엿새 7명 · 꾸미기 저장 3명 → **DM까지 보내는 건 3~10명 짐작**(⛔실측 아님)
⛔ **3명 보냈는데 1명만 뽑으면 나머지 2명은 «떨어진 사람»**이 된다. 첫 유저들에게 그건 안 좋다.

| 어디 | 몇 명 | 자리 |
|---|---|---|
| 📸 인스타 | **보낸 사람 전원** | 캐러셀 1장에 격자 4~9명 × **10장 = 90명까지** · 릴스면 30명이 15초 |
| 📱 앱 | **한 달에 한 명** | 자리가 1~2장뿐(창업자 지적) → 매달 교체 = **앱 열 이유**가 된다 |

⭐ 조립은 **클로드가 한다**(규칙 8). 창업자 손 = 그림 모으기 ＋ 고르기까지.

## 5️⃣ 🎁 개별 선물 — ✅ **나중엔 된다** (구글 프로모션 코드)

📖 공식(Play Console 고객센터) = *"프로모션 코드로 유료 앱, **인앱 상품**, 정기 결제를 **무료 제공**"*

| | 일회용 코드 | 맞춤 코드 |
|---|---|---|
| 인앱 상품(우리 팩) | ✅ **된다** | ⛔ 안 된다 — **정기 결제용만** |
| 몇 번 | 1인 1회 | 여러 번 |
| 한도 | **한 앱에 분기당 500개** (⚠️안 쓰면 다음 분기로 **이월 안 됨**) | 2,000~99,999 |

⭐ **개발 0** — 콘솔에서 만들어 DM으로 보내면 끝. 앱 코드를 안 건드린다.
⛔ **전제 둘** — ①인앱 상품이 콘솔에 등록돼 있나 ②결제가 붙어 있나. **둘 다 [모름] — 콘솔은 클로드가 못 본다.**
📌 그래서 **10월엔 코드를 안 쓴다**(팩을 이미 다 풀어서 줄 게 겹친다). **12월 크리스마스 팩부터**가 제 자리다.

## 6️⃣ ⚖️ 법 — 확인한 것

- ⭐ **경품 «가액 한도»가 없다** — 「경품고시」가 **2016년 폐지**(옛 한도 = 단일 2,000만원 · 총액 매출 3%)
- ⛔ 남는 의무 셋 — ①**표시광고법**(당첨자 수·확률·발표일·분쟁처리를 미리 적기 · 과태료 최대 5천만원)
  ②개인정보 수집·이용 동의 ③「혜택 알림」으로 광고 수신 동의를 끼워 받지 않기
- ⭐ **추첨이 아니라 「보낸 사람 전원 게재」면 ①의 무게가 크게 준다**

## 7️⃣ ⚠️ 안 풀린 것 · 모르는 것

- ❓ **앱 「이번 달 레꾸」 자리를 만들까** — ⛔그런 자리가 **아직 없다**(검색 0건). 만들면:
  · 상이 세지고 **10월이 끝나도 계속 쓰는 칸**이 된다 · 대신 화면 한 칸 ＋ **매달 배포**
  · ⚠️ 아이디를 앱에 박으니 **개인정보** — 동의 필요 · *"내려주세요"* 하면 배포를 한 번 더
  · ⚠️ **Play 「사용자 제작 콘텐츠」 정책**에 걸리는지 **[모름]** — 콘솔·정책을 못 본다
- ❓ **코너 이름** — 「한끼 레꾸자랑」? 「이번 달 레꾸」?
- ❓ 11월에 팩을 다시 잠그나 → **잠그지 않는다**(뺏는 게 된다). 한 번 연 사람은 계속 가짐
