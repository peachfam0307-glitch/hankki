# 🎨 한끼 곰 로고마크 — AI 생성 프롬프트 (Recraft·Ideogram) · 2026-07-22

> 목적: **미니멀·플랫 벡터 곰 마크**(상표·앱아이콘용)를 AI로. 내(클로드)·GPT 손그림 대신 **Recraft(네이티브 SVG)** 사용.
> 근거: `docs/로고-상표-디자인-학습-2026-07-22.md`(미니멀 원칙·흑백 상표 유리·요부 유지) · 물결곰 정본 스펙.

## 🧭 사용 순서
1. **Recraft**(recraft.ai) 접속 → **Style = "Vector Illustration"** 또는 **"Icon"** 선택.
2. 가능하면 **물결곰 정본 이미지를 레퍼런스로 첨부**(스타일 가이드) → "same character as reference, simplified flat version".
3. 아래 **프롬프트 A(컬러)** 붙여넣고 여러 장 생성 → 요부 잘 살린 것 고르기.
4. **프롬프트 B(흑백)**로 상표용 흑백 버전도.
5. 글자 "한끼"는 **Ideogram**(ideogram.ai)에서 **프롬프트 C**로 따로.
6. 마크 + 글자 = Recraft/Illustrator에서 합치기. (SVG라 무한 확대·편집 OK)

## ✅ 요부 체크리스트 (이거 다 있어야 "우리 꼬르곰")
셰프모자 · 계란후라이 앞치마 포켓 · **하트 머리 나무 주걱** · 콩눈(까만 점) · 살구코랄 볼터치 · 밀크카라멜 몸색. (복슬털은 뺌 = 미니멀)

## 🅰️ 프롬프트 A — 컬러 마크 (Recraft, Vector/Flat)
```
Flat minimal vector logo mark of a cute chibi baby bear chef, front-facing, simple upper body. The bear wears a tall soft white chef's toque and a cream apron with a fried-egg-shaped pocket (white with a soft yellow yolk). One paw holds up a wooden spoon with a HEART-shaped head. Face: two small round black bean eyes, a small rounded cream muzzle with a tiny nose and a subtle smile, soft coral cheek blush, small round ears. Colors: warm milk-caramel brown body (#E6B98C), cream (#FBF3E9), coral cheeks (#F0AE9C), soft yellow egg yolk. Clean smooth even outlines, only 2–3 flat colors, no gradient, no shading, NO fur texture, generous negative space, plain/transparent background. Modern warm minimal Korean cute-brand mascot logo. Must stay clear and recognizable at very small sizes (app icon, favicon).
```

## 🅱️ 프롬프트 B — 흑백 마크 (상표 출원용 · 넓은 보호)
```
Same cute chibi baby bear chef mascot as above (tall chef toque, cream apron with fried-egg pocket, holding a heart-headed wooden spoon, bean eyes, round muzzle, small ears). Render as a single-color logo: clean BLACK line art on white, even line weight, minimal flat shapes, no color, no gradient, no shading, no texture. Designed as a black-and-white trademark mark that reproduces perfectly at any size, from tiny favicon to large print.
```

## 🅲 프롬프트 C — "한끼" 글자 (Ideogram)
```
Korean logo wordmark of the word "한끼", rounded friendly bold Korean lettering (similar to Jua typeface), warm dark brown color (#5B4436), clean modern minimal, balanced spacing, high legibility, plain transparent background. No mascot, text only.
```

## 💡 팁
- **여러 장 뽑아 비교** — AI는 캐릭터 일관성이 들쭉날쭉. 요부 다 살고 제일 우리곰 같은 걸 고름.
- 안 나오면 프롬프트에 **"same character as the reference image"** 강조 + 물결곰 첨부.
- 그래도 별로면 → **디자이너(크몽·숨고 ~2~5만원)** + 이 문서 브리프로 발주.
- **흑백(B)로 상표 출원** = 색 자유 + 넓은 보호. 컬러(A)는 앱·브랜딩용.
