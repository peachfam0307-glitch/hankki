## ✅ 어떻게 채우나 — 둘 중 아무거나

**ⓐ 쿠팡 링크를 주면** → `curation.js` 의 그 재료 칸에 **한 줄 더** 넣는다(한살림은 «그대로 둔다»).
　　📮 창업자 확정 = *"큐레이션에 한살림추천템은 그대로 두고 쿠팡을 추가로 더 올려야 할 것 같아."*
**ⓑ 컬리·오아시스 같은 데도 된다** — 파트너스 링크만 있으면 몰은 안 가린다.

⛔ **한살림을 빼지 않는다** — 창업자가 즐겨 쓰는 곳이고, 화면엔 그대로 보여야 한다.

## 🔢 어떻게 이 여덟을 골랐나 (⛔글자로 세지 않았다 · 함수를 돌렸다)

날짜를 **2027-03-20**(모든 제품이 열린 뒤)으로 돌려놓고 `ingLink()` 를 전수로 돌렸다:

```
✅ 링크가 붙는 말  91개 / 99개
⛔ 그래도 안 붙는 말  8개   ← 이 문서
```

📌 즉 **「지금 안 붙는 것」과 「영영 안 붙는 것」은 다르다.**
   지금 안 붙는 말 50개는 대부분 **`from` 날짜가 미래**라서다 — 그날 되면 저절로 붙는다(고장이 아니다).

## 🚨 내가 두 번 잘못 셌다 — 그 기록

⛔ 처음 = *"55개가 막혔다"* → `matches` 를 **글자로만 세어서** 나온 값.
⛔ 두 번째 = *"45개가 한살림 탓"* → **열린 날짜와 낱말 시작 규칙을 안 봐서** 나온 값.
✅ 세 번째 = `picksForIngredients()` 와 `ingLink()` 를 **실제로 돌려서** 8개로 확정.

📌 **배운 것 = 개수를 말하기 전에 «앱과 같은 함수»를 돌린다.** grep 개수는 근거가 아니다(규칙 30).
