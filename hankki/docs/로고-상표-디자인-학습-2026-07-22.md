## 1. 미니멀 로고 원칙 (핵심)
- **단순할수록 기억·인지 쉽다.** 복잡하면 뇌가 처리·기억하기 어려움. → 심플 = 각인.
- **여백(negative space)이 세련을 만든다.** 중요한 것만 남기고 나머지 삭제. 정(positive)/부(negative) 공간 균형 → 꽉 차면 지저분, 너무 비면 미완성.
- **색 1~2가지.** 색 많으면 복잡. 중성·파스텔 톤 = 전문성·프리미엄.
- **타이포그래피 자체가 디자인.** 글자만으로도 강력한 로고 가능(워드마크).
- **그리드로 구성** = 균형·완성도.

## 2. ⭐ 마스코트 미니멀화 (우리 핵심 이슈)
- **상세 마스코트는 큰 데선 좋지만 작은 데(앱아이콘·파비콘·아바타)선 디테일이 뭉개짐** → 미니멀 접근 필수.
- **마스코트 아이콘 = 단순화 버전**(보통 머리만 or 단순 전신). 작은 포맷 전용.
- 로고는 **그라데이션·텍스처·색 없이도** 알아봐야 함. **풀컬러·플랫·모노크롬·자수·인쇄** 다 돼야.
- **작은 크기에선 일러스트 억제하고 글자(브랜드)만 남기게 설계.**
- → 우리 물결곰(복슬털·침·음영)은 **디테일 과다** = 그대로는 미니멀 로고에 안 맞음. **단순화한 곰 "마크"가 정석.**

## 3. ⭐ 상표 색채 — 흑백 vs 컬러 (색 질문 답)
> 한국 자료(ditoday·ip-lab·brandpro) 일치:
- **흑백(무채색)으로 출원 = 색 지정 안 함** → 등록 후 **어떤 색으로 써도 다 그 상표 사용으로 인정**(넓은 보호 + 색 자유).
- **컬러로 출원 = 지정색** → 등록시 그 색과 **일치해야만** 사용, 색 바꾸면 안 됨(좁은 보호).
- **검은색 표장 출원이 더 넓게 보호받음.** 전반적으로 **색 지정 안 하는 게 우세.**
- → **결론: 한끼 로고는 흑백(무채색)으로 출원이 유리.** 실제 앱·브랜딩은 캐러멜+크림 컬러로 쓰면 됨(흑백 등록이 컬러 사용까지 다 보호). ※ 최종은 출원 직전 KIPRIS/변리사 재확인.

## 4. 도형·결합 상표 식별력 (헬프미·유레카)
- 식별력 = **소비자가 하나의 브랜드로 인식하는지.** 품질·용도 등 서술적 표현은 식별력 부족.
- 도형상표는 등록 가능성 비교적 높음.
- **문자+도형 결합에서 도형(곰)에 독자적 식별력 있으면 결합마크가 강함.** (곰이 요부) — 우리 전략(한끼는 보통명사라 곰으로 식별력 보강)과 정확히 일치.

## 5. 한글 레터링 (세련되게)
- 감성적이되 **과하지 않게.** 단순 장식이 아니라 **설계된 형태**(자음·모음 구조·속공간 균형 분석 후).
- 주아체 그대로는 귀엽지만 흔할 수 있음 → **살짝 커스텀·조정**하면 세련도↑ (획 끝·자간·비율).

## 6. 세련 큐트 브랜드 트렌드 (2026)
- **파스텔 팔레트 + 둥근 모서리** = 세련 미니멀.
- 커스텀 폰트 + 절제된 귀여운 요소 = 따뜻하되 고급.
- **미니멀 워드마크 + 클린 타이포 = 프리미엄.** (라인/카카오프렌즈: 캐릭터 심볼 + 심플 워드마크 결합형)

## 🎯 한끼 적용 전략 (위 원칙 → 우리 로고)
1. **구조 = 결합형**: 단순화 곰 심볼 + "한끼" 한글 워드마크.
2. **곰 = 미니멀 마크로 단순화** — 특징 최소(귀·눈·셰프모자 정도), 복슬·침·음영 제거, 플랫 2색, 흑백OK. **상세 물결곰은 스티커·콘텐츠용으로 유지**(정본 안 버림). = 상세 마스코트 + 심플 로고마크 병행(브랜드 표준).
3. **색 = 상표는 흑백 출원**(넓은 보호), 앱/브랜딩은 캐러멜+크림.
4. **여백 넉넉 + 절제** — 하트·별 데코 **로고엔 X**(작을 때 지저분). 귀여운 이모지는 앱 꾸미기·키비주얼 자리.
5. **세트로**: 가로/세로 대표 로고 + **아이콘판(곰 머리, 파비콘·앱아이콘)** + 흑백판.

## 7. ⭐ 등록마크 ↔ 물결곰 = "같은 캐릭터"로 묶기 (유사·요부) — [2026-07-22 추가검증]
> 창업자 제공 법률분석(특허청 FAQ·상표법·판례) 검토 결과 = 내 리서치와 일치. 핵심:
- **흑백 미니멀 마크로 등록해두면, 물결곰이 같은 얼굴 구조·비례·요부(셰프모자·계란 앞치마)를 유지하는 한 "상표의 사용"으로 인정될 여지 큼.** (등록도안과 유사한 사용도 상표 사용에 포함)
- **도형상표 유사 판단 = 외관의 지배적 전체 인상**(모양·비율·선·요부). **요부가 비슷하면 유사 인정 쉬움.**
- → **설계 원칙(중요)**: 미니멀 마크와 물결곰의 **형태 차이를 너무 벌리지 말 것.** 미니멀 마크에도 **같은 얼굴 구조 + 셰프모자(+계란 앞치마)**를 담아 "물결곰의 미니멀 쌍둥이"로. 앱 아이콘 = 등록 도안과 거의 동일 버전.
- ⚠️ **정확히 어디까지 유사로 보는지는 개별 심사·분쟁 판단** — 최종은 변리사·심사관·법원. (여기서 확정 불가, 중요 상표면 실제 도안으로 변리사 개별상담)

## ⚠️ 리스크 (정직)
- **GPT는 상세 일러스트를 잘 뽑지, 진짜 미니멀 벡터 마크는 약함.** → 미니멀 곰 마크 만드는 법 3가지:
  - (a) 클로드가 **기하학적 곰 마크**를 코드/벡터로 구성(플랫·정밀 제어)
  - (b) GPT에 "플랫·단순·텍스처 없는 곰 아이콘" 프롬프트(근사치)
  - (c) 나중에 디자이너 외주(비용, 수익 후)
