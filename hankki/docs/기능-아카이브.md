## 1. 레시피 저장·정리
- **레시피 저장**: 제목·재료·만드는 법·메모·조리시간·인분·난이도·태그·폴더·원본 링크.
- **썸네일 4종**: 아이콘(제목에 맞춰 자동 추천) · 이모지 · 글자 타일 · 사진(정사각 자동 크롭). 음식 사진과 아이콘을 섞어 써도 됨.
- **직접 작성 화면(EditorScreen)**: 모든 항목을 손으로 채우거나, 사진에서 자동으로 채움.
- **레시피 상세(RecipeDetailScreen)**: 재료·만드는 법·기록을 한 화면에서. 상단에 편집(✏️)·북마크(🔖)·더보기(⋯) 버튼.
- **편집 노출**: 사진·아이콘 바꾸는 편집 버튼을 ⋯ 안에 숨기지 않고 상단에 바로 노출.
- **폴더 분류**: 한식/양식 등 기본 폴더 + "새 폴더" 직접 추가.
- **카테고리 자동 추정**: 제목·메모로 한식/양식/일식 등 자동 분류.
- **즐겨찾기(북마크)** + 자주 해먹는 요리 집계(cooked 횟수).
- **저장 날짜 자동 기록·표시**.
- **내 레시피 목록(MyRecipesScreen)** · 즐겨찾기(FavoritesScreen) · 자주 해먹는(CookedScreen).

## 2. 레시피 가져오기 (OCR·공유·링크)
- **사진에서 글자 가져오기(OCR)**: 레시피가 적힌 사진·캡처를 골라 **재료·순서를 자동 분리**해 채움.
- **재료/만드는 법 각 칸 개별 사진** _(v1.5)_: 각 칸의 📷 버튼으로 그 사진을 **지정한 칸에만** 채움. 여러 번 누르면 **여러 장(2~3장)** 이어붙임 → 2단 레이아웃·긴 레시피 대응.
- **사진 자르기(CropSheet)**: OCR 전에 광고·그림 빼고 글자 부분만 선택. 모서리 드래그. 상황별 안내(레시피/영수증/일지).
- **공유받기(Web Share Target)**: 인스타·갤러리 등에서 "공유 → 한끼"로 링크·사진·캡션을 받아 Inbox에 저장. 캡션에 레시피가 있으면 파싱.
- **링크 자동 읽기**: 유튜브·블로그 링크의 제목/설명 가져오기.
- **보면서 쓰기**: 유튜브 영상·인스타 미리보기·캡처 원본을 화면 위에 고정하고 아래에서 받아적기. (인스타로 이탈 안 되게 iframe sandbox 제한)
- **Inbox(미분류함)**: 공유·사진으로 급히 담은 레시피 임시 보관 → 나중에 정리.
- **출처 배지(SourceBadge)**: 인스타/유튜브/링크/사진/직접작성 표시.

## 3. 요리하기
- **요리 모드(CookScreen)**: 단계별 풀스크린, 큰 글씨, 요리사 친구(CookBuddy) 응원.
- **화면 꺼짐 방지(Wake Lock)**: 요리 모드 + **레시피 상세 화면**에서도 화면이 안 꺼짐 _(v1.8, 레시피 화면까지 확장)_.
- **요리 타이머**: 단계별 타이머, 소리 알람, 하단 타이머 바(여러 화면에서 유지).
- **인분 조절**: 인분을 바꾸면 재료 수량이 자동 환산(scaleIngredient).
- **재료 담기**: 레시피 재료를 장보기 리스트로 바로 담기.

## 4. 냉장고·장보기
- **냉장고 재료함(PantryView)**: 집에 있는 재료 + **유통기한** 관리. 임박 순 정렬, D-day 칩(지남/오늘/D-n).
- **영수증 스캔** _(핵심 기능)_: 영수증/주문내역 캡처를 찍으면 **식재료만 골라 냉장고에 자동 담기**. 확인 화면에서 체크로 걸러냄. 버튼을 크고 진하게 강조 _(v1.9)_.
- **냉장고 파먹기**: 가진 재료로 만들 수 있는 레시피를 매칭 개수 순 추천. 없으면 "한끼 추천"(기본 레시피).
- **장보기 리스트**: 살 재료 체크리스트. 체크하면 "냉장고에 넣어뒀어요" → 재료함 자동 이동. 항목에 사러가기 링크(url)가 있으면 '사러가기', 없으면 '검색'. _(v1.95: 옛 '사고 싶은 재료' 위시를 이 리스트로 통합)_
- **주부의 장바구니**: 18년차 큐레이션 카드. '이번 주 픽' 기본 + 카테고리 칩 필터. '담기'→장보기 리스트(사러가기 링크 보존) _(v2.1)_.
- **쇼핑몰 바로가기**: 마켓컬리 등 자주 쓰는 쇼핑몰 아이콘 등록 → 로그인 세션 유지되는 브라우저로 열기·검색.
- **장보기 탭 순서** _(v2.1)_: 주부의 장바구니 → 장보기 리스트 → 쇼핑몰 바로가기(둘러보기→담기→사러가기 퍼널). 냉장고는 옆 토글(2군).
- **냉장고/장보기 하위 화면 기억** _(v1.3)_: 냉장고에서 추천 레시피 보고 돌아와도 장보기로 안 튕김.

## 5. 요리 기록
- **요리 일지**: "만들었어요!" 기록 — 별점, 나만의 팁, 사진.
- **레시피 탭에 통합** _(v1.x)_: 별도 '일지' 탭을 없애고 레시피 상세의 "내 요리 기록" 카드로 합침(레시피와 기록이 한 곳).
- **최근 기록 요약**: 마지막으로 만든 날, 총 만든 횟수.

## 6. 표지 꾸미기
- **꾸미기(DecorEditor/DecorLayer)**: 레시피 표지 사진 위에 스티커·포스트잇·글자를 얹기. 드래그 이동, 손잡이로 크기·회전.
- **스티커 라이브러리(Stickers)**: 손그림 표정(스마일·하트눈·윙크 등), 요리사 친구, 재료·조리도구, 소스병, 디저트, 엄지척·왕관 등.
- **포스트잇·팁 메모**: 색상별 포스트잇에 글쓰기.
- **글자 스티커**: 색상별 직접 글쓰기(고운돋움 손글씨체, 사진 위에서도 읽히게 외곽선).
- **크기 비례** _(v1.5)_: 스티커·포스트잇 크기를 줄이면 **글자도 정확히 같은 비율로** 작아짐(CSS 컨테이너 단위 cqw).
- **세로 그리드 서랍**: 가로 스크롤 없이 종류별로 쌓아 보여줌.

## 7. 홈·추천
- **오늘 뭐 해먹지?**: 냉장고 재료로 만들 수 있는 요리 우선 추천, "다른 추천"으로 넘기기.
- **자주 해먹는 요리** · **최근 저장** · **내 레시피 전체 보기 버튼**. _(v1.99: 홈의 '전체 레시피' 그리드는 레시피 탭과 중복이라 제거 — 홈은 깔끔한 대시보드로)_
- **상단 가져오기 버튼**: 제일 자주 쓰는 기능이라 홈 상단에 배치.

## 8. 검색
- 레시피·재료·태그 검색(SearchScreen). 홈 상단 검색창에서 바로 진입.

## 9. 백업·데이터
- **백업 내보내기**: 공유 시트로 카톡 「나에게」·드라이브에 저장, 또는 **백업 코드 복사**(공유 안 되는 폰 대비).
- **백업 불러오기**: 파일 열기 또는 코드 붙여넣기로 복원.
- **예시 데이터**: 처음 사용자를 위한 예시 레시피(실제 음식 사진 포함). 비우기/되돌리기 가능.

## 10. 테마·디자인
- **테마 3종** _(설정에서 전환)_: 크림(기본)·세이지·다크.
- **다크 모드**: 색을 서로 전환, 상단 버튼 가시성 보정.
- **CSS 변수 기반**: `--brown` 등 토큰으로 전체 테마 일괄 적용, 상태바 색까지 동기화.
- **앱 아이콘**: **곰곰 셰프(곰돌이) 단독** — 크림 배경 + 하얀 요리사 모자 쓴 곰, B프레이밍(여백 넉넉·머리 작게) v6. `public/icons/icon-512-v6.png`. (옛 '딥 차콜그린+은수저 한끼'·곰=ㅎ v4·곰 크게 v5는 보존.)
- **글씨체**: Pretendard(본문) + 고운돋움(손글씨 톤).

## 11. 앱 기반
- **PWA**: 홈 화면 설치, 오프라인 동작(서비스워커 프리캐시), 새 버전 자동 반영(업데이트 후 "최신 버전" 안내 토스트).
- **버전 표시** _(v1.3)_: 설정 맨 아래 버전(v1.9) 표시 — 캐시 문제 진단·확인용.
- **뒤로가기 종료 확인 팝업** _(v1.4~v1.7)_: 홈에서 뒤로가기 시 "한끼를 나갈까요?" 팝업으로 **실수 종료 방지**. React 로딩 전 히스토리 트랩(index.html) + 앱 복귀 시 재설치.

- **안전영역·키보드 대응**: safe-area, 키보드 올라오면 화면 리사이즈.

## 12. OCR 엔진 상세
> `src/ocr.js` · `src/ocrCorrect.js` · `src/parseRecipe.js` · `src/receipt.js`

- **폰 내장 OCR 우선**: TextDetector(안드로이드 크롬)로 한국어 인식률↑, 없으면 tesseract.js.
- **적응형 이진화(Bradley–Roth)** _(v1.x)_: 이미지 전체가 아닌 **국소 영역별 밝기**로 글자/배경 분리 → 그림자·구김·불균일 조명에 강함. (합성 검증: 조명 얼룩에서 전역 60.7% → 적응형 100%)
- **자동 반전**: 다크모드 캡처(흰 글씨) 자동 반전. 중앙값 기준이라 밝은 음식 사진 섞여도 안 속음.
- **신뢰도 필터**: tesseract가 지어낸 저신뢰 단어/줄 제거(외계어 방지).
- **영수증 전용 처리**: 적응형+컬럼 모드(PSM 4) 1순위, 약하면 전역으로 재시도.
- **오독 교정(ocrCorrect)**: 유니코드 분수(½→1/2), 전각→반각(２ｇ→2g), 숫자 오독(O→0·l/I/|→1), 작은술('2+'→'2t'), 범위(900g-1kg→900g~1kg), 크기(2cm x 2cm→2cm×2cm).
- **재료/만드는 법 분리(parseRecipe)**: 조리 동사·평서형 종결('볶는다·끓인다·푼다')로 순서 문장 판별. 섹션 헤더 없이도 자동 분리. 팁은 메모로. 잡음 제목 거부.
- **영수증 품목 추출(receipt)**: 번호 품목줄(2줄 구조) 인식, 띄어쓴 헤더 필터, 아는 식재료 사전 + 편집거리 1 스냅('고주장'→'고추장'), 할인·비식품·가전·초고가(10만원↑) 제외.

## 13. 변경 이력 (버전별)

## 14. 앞으로의 기록 방식
매일 작업이 끝나면 **[13. 변경 이력]** 맨 위에 새 버전 블록을 추가해:

```
### vX.Y — YYYY-MM-DD
- (큰 변화) …
- (작은 수정) …
- (버그 수정) …
```

그리고 새 기능이 하나의 "영역"으로 커지면 위쪽 해당 섹션(1~12)에도 한 줄 요약을 넣어두면 나중에 찾기 쉬워.
문서 맨 위 `마지막 업데이트`와 `현재 버전`도 같이 갱신하기.
