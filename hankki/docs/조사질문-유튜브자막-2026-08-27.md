# 🎥 조사 질문 ① — 유튜브 자막 (붙여넣기용)

> 📮 창업자 2026-08-27 = *"1.번 다 붙여서 줬어."* → *"질문을 다시줘야할 것 같은데 그럼"*
> ⛔ **답이 안 왔다** — AI 다섯이 전부 ②(유명인 이름)로 답했다. 질문을 다시 던진다.

## ⛔ 왜 ②로 샜나 (내 추정)

한 번에 둘을 주면 AI가 **뒤엣것·긴 것 하나만** 붙잡는다. ②가 판례·조문이 많아 더 「답하기 좋은」 질문이었다.
✅ **그래서 이번엔 «①만» 준다** ＋ 맨 앞에 **「②는 답하지 말라」**를 박았다.

## 📋 이거 하나만 통째로 복사해서 붙여넣기

```
⛔ 이 질문은 「유튜브 자막」에 대한 것만 묻습니다.
   부정경쟁방지법·퍼블리시티권·유명인 이름 이야기는 하지 마세요. 그건 이미 답을 받았습니다.

저는 한국에서 요리 레시피 앱을 운영합니다(구글 플레이 정식 출시 상태, 유료 아이템 판매 예정).

유저가 유튜브 요리 영상 URL을 붙여넣으면, 그 영상의 자막(transcript)을 가져와
LLM으로 재료·조리순서를 정리해 주는 기능을 만들고 싶습니다.

경쟁 앱(해먹으리/Hemogry)은 이미 이 기능을 제공하고 있고,
결과 화면에서 조리 단계마다 영상 타임스탬프(00:19, 00:27 …)가 붙어
누르면 그 장면으로 점프합니다. 자막 기반으로 보입니다.

아래 7개를 "공식 문서 원문 인용 + 출처 URL"과 함께 알려주세요.
추측이면 추측이라고 명시해 주세요. 확인 못 한 것은 "확인 못 함"이라고 적어 주세요.

1. YouTube Data API v3 의 captions.download 로
   "내가 소유하지 않은 제3자 영상"의 자막을 받을 수 있습니까?
   → 공식 문서의 해당 문장을 그대로 인용해 주세요.

2. 안 된다면, 상용 앱들이 쓰는 "약관에 어긋나지 않는" 자막 취득 경로가 존재합니까?
   존재한다면 구체적으로 무엇이고, 어떤 조항이 그것을 허용합니까?

3. youtube.com/api/timedtext 같은 비공식 엔드포인트나
   yt-dlp 계열 라이브러리로 자막을 받는 것은
   YouTube 서비스 약관 / YouTube API 서비스 약관 위반입니까?
   → 위반이라면 해당 조항 번호와 원문을 인용해 주세요.

4. 영상 "설명란(description)"을 videos.list(part=snippet) 로 받아
   레시피 추출에 쓰는 것은 약관상 허용됩니까?
   그 설명란 글 자체는 영상 제작자의 저작물입니까?
   (우리는 원문을 그대로 싣지 않고 재료·순서만 뽑아 우리 문장으로 다시 씁니다)

5. YouTube Data API v3 의 2026년 현재 무료 할당량(quota)은 얼마이고,
   videos.list 는 몇 유닛을 소모합니까?

6. 이 기능이 Google Play 정책상 문제가 될 소지가 있습니까?
   (예: 제3자 콘텐츠 무단 이용 관련 조항)

7. 마지막으로 — 위 1~6을 종합해서
   "법적/약관적으로 가장 안전한 구현 방식" 하나를 추천해 주세요.
```

## 🎯 이 답으로 우리가 무엇을 정하나

- **1~3 이 「전부 안 된다」로 닫히면** → 자막 길은 죽고, **④ 설명란 ＋ 유저가 직접 붙여넣기**로 간다
- **2 에 «되는 길»이 하나라도 있으면** → 그 길로 원가를 재고 → **열쇠 몇 개인지 창업자 판정**
- ⛔ **①이 닫히기 전엔 만들기를 시작하지 않는다** (해먹으리 조사 문서 맨 아래 · 창업자 확정 순서)

## ⚠️ 답을 받으면 내가 걸러낼 것

- **「해먹으리가 하니까 된다」류의 답은 근거가 아니다** — ②에서 다섯 AI가 전부 짚은 그 함정
- **조항 «번호»만 있고 원문이 없으면** 다시 확인해야 한다(②에서 판례 인용이 섞인 답이 하나 있었다)
- **할당량 숫자는 해마다 바뀐다** — 2026년 값인지 확인
