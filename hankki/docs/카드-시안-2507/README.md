# 🃏 레시피 공유 카드 시안 — 2026-07 (바이럴 획득 무기)

> 인스타 피드에서 **스크롤을 멈추게 하는** 공유 카드. 캐릭터(꼬르곰·펭펭) 다이컷 + 컬러팝 + 볼드타이포.
> 원칙: **여백·절제**(다꾸 감성) + **디자인 한 방**(스티커 개수로 승부 X). 관련: `../작업복기-2026-07-19-캐릭터카드-대장정.md`

## 레이아웃 4종 (다양성 = 지루하지 않은 세트)
- **A 컬러팝 다이컷**: 컬러 팝 패널을 캐릭터가 스티커처럼 뚫고 나옴. 흰 테두리 다이컷. 캐릭터가 주인공. (`c1a`, `c5a`)
- **B 볼드 타이포**: 거대 글씨가 주인공(썸네일에서도 읽힘). 캐릭터는 코너 원형에 다이컷. (`c2b`, `c4b`)
- **C 폴라로이드(다꾸)**: 폴꾸 감성 — 사진 프레임 + 마테 + 손글씨 캡션. (`c3c`)
- **D 매거진**: 잡지 표지 마스트헤드 + 커버라인. (`c6d`, 진행 예정)

## 폴더
- `heroes/` — 카드용 고화질 캐릭터 컷 (hero1 곰스파게티 · hero2 곰라면 · hero3 펭케이크 · hero4 펭하트 · hero5 콤비팬케이크 · hero6 곰장보기)
- `이모지/` — 손그림 이모지 세트(음식·도구에서 2x 업스케일): 딸기·케이크·하트머그·달·라면·하트말풍선·아이스커피·파스타·허브·YUM·나무숟
- `html/` — 카드 HTML 소스 (파일:// 폰트·PNG). 렌더: `scratchpad/render.sh`(headless chromium, 1080×1350, scale2)
- `렌더/` — 렌더된 PNG (2160×2700). `set_4.png` = ①②④⑤ 세트 모아보기

## 렌더 방법

```
bash render.sh /abs/path/cN.html /abs/path/out.png   # chromium --screenshot, scale2, 투명배경
```
