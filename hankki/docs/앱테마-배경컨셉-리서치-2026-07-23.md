# 🎨 한끼 앱 테마·배경 컨셉 리서치 (2026-07-23)

> 창업자 지시("앱 전체테마 배경컨셉 서치 공부하고 와")로 3갈래 병렬 리서치(트렌드·문서·배경) + 현재 코드 대조. task#20(웜→뮤트/뉴트럴 개편) 기반.

## 0. 한 줄 결론
**"차가운 greige"가 아니라 "따뜻한 greige"** — 지금 배경(#fdfbf7)에서 **노란기만 살짝 빼고 온기는 유지**. 배경은 뉴트럴 캔버스로 빼고 **색은 곰펭이 짊어진다**(웜 곰 + 쿨 펭 = 악센트). 배경지는 「저대비 캔버스 → 뮤트 브릿지 → 딥무드」 3단 + 시즌 롤아웃.

---

## 1. 트렌드 리서치 (2025–2026 근거)
- **Elevated Neutrals / Neo Earth Tones**: 순백 대신 greige·sand·clay·sage. "calm tech" 저채도 뉴트럴이 표준. 테라코타는 *채도 낮춘* 형태로 생존.
- **Korean Cozy Beige (명명된 미감)**: 배경=뉴트럴, **색은 캐릭터가 짊어짐**. 라인프렌즈·리락쿠마 계열. 실례 = **컬러그램 × 잔망루피**(땅콩톤 베이지 + 잔망핑크 악센트).
- **Headspace = 우리 곰펭 문제의 검증된 선례**: warm orange + cool blue를 *의도적 공존*. → 웜 곰 + 쿨 펭이 트렌디하고 정합함을 입증.
- **음식앱(만개·우리의식탁·NYT Cooking·Kurashiru)**: 배경을 뉴트럴로 죽여 **음식이 주인공**. 밝은 음식↔어두운 배경 / 어두운 음식↔밝은 배경. 채도 팝은 CTA에만.
- **다꾸/폴꾸 2025-26**: 모눈·깅엄체크·도트·크래프트지 = **저대비 캔버스**(캐릭터·음식과 안 싸움). 딥배경 + 글리터·홀로·포일 스티커가 하이라이트.

## 2. 우리가 이미 정한 것 (지켜야 할 원칙 — 문서 근거)
- **표지/공유카드 톤 `#f4f2ee` 확정**(웜기 살짝 남긴 중립, 곰·펭 둘 다). ※ 이건 **표지**지 앱 전체 배경(`--bg`) 아님.
- **앱 테마 3종 이미 구현**: 기본(웜크림 `#fdfbf7`)·블루(더스티 `#f4f7fb`, 사실상 펭 라인)·다크(웜 에스프레소 `#17120d`). → "곰웜+펭쿨" 고민이 테마 구조에 일부 반영돼 있음.
- **딥 배경지 = 무조건**(확정·구현): `딥플럼 #3e3442`·`미드나잇 #2d3340`. 순검정 금지 → 따뜻한 딥톤("밤하늘 다꾸").
- **캐릭터색**: 꼬르곰 `#EBAB73`(웜 캐러멜) · 펭펭 = 쿨/중성 회색계열(잠정 `#454B54`, 최종 대기).
- **⚠️ 절대 원칙**: **"뮤트하되 회색빛 없이 따뜻하게, 저채도 아님"**(mute ≠ 무채색). 이모티콘 발주도 "회색빛 없이, 채도 너무 낮지 않게." → **트렌드의 '차가운 greige'로 가면 우리 원칙 위반.**

## 3. 핵심 긴장 → 해소
| | 트렌드가 미는 것 | 우리 원칙 |
|---|---|---|
| 배경 | greige 뉴트럴(회색 섞인 베이지) | 회색빛 없이 따뜻하게 |

**해소법 = "따뜻한 greige"**: `#fdfbf7`의 **노란 기운만** 덜어내되(→ 더 중립·차분), **온기(웜)는 유지**. 완전 회색 아님.
- 펭(쿨)은 **배경을 식혀서가 아니라** 캐릭터·악센트·(옵션)쿨테마로 담는다 → Korean Cozy Beige + Headspace 원리.

## 4. 제안 A — 앱 테마(라이트) 미세조정
> 갈아엎기 X. 노란기만 빼는 **미세 이동**. (실제 적용은 목업 보고 `/픽스` 때)

| 변수 | 현재 | 제안(따뜻한 greige) | 이유 |
|---|---|---|---|
| `--bg` | `#fdfbf7` | **`#f6f2ea`** | 노란기↓ 온기 유지 = 곰·펭 공존 캔버스 |
| `--surface` | `#ffffff` | **`#fdfaf5`** | 순백 대신 웜오프화이트(덜 차갑고 음식 돋보임) |
| `--cream` | `#f2ede3` | `#efe9de` | 살짝 중립 |
| `--brown`(포인트) | `#cd7c50` | 유지(=뮤트 테라코타, 트렌드 부합) | 곰 웜 히어로 |
| `--text` | `#3d3830` | 유지(웜차콜) | |
| **쿨 카운터(신규)** | — | **`#3E4C5E`~`#454B54`(펭 슬레이트)** | 60-30-10의 10% 악센트(태그·선택상태 등) |

- **운영 = 60(웜뉴트럴 배경)·30(웜 히어로/곰·테라코타)·10(쿨 악센트/펭 슬레이트).**
- 옵션: 더 밀고 싶으면 `--bg #f3f1ec`(살짝 더 뉴트럴). 표지 백업 `#f3f4f4`(더 쿨)와 결이 같음.

## 5. 제안 B — 배경 컨셉(2종 구분)
**(1) 앱 서피스** = **웜크림 뉴트럴 하나로 고정**(음식이 주인공). + **다크 서피스 옵션**(`#17171B` 카드 `#1F1F24`)으로 "밤의 자기돌봄" 무드.
**(2) 배경지(꾸미기)** = 3단 구조로 정리 (현재 17종 점검):
- **① 저대비 캔버스**(상시): 크림·모눈·크래프트·깅엄체크·도트 — 캐릭터·음식이 주인공.
- **② 뮤트 브릿지**: 세이지 `#7E9484`·클레이 `#B08466`·노을 그라데 — 웜/쿨 잇는 중간톤.
- **③ 딥 무드**(반짝이 페어링): 현재 딥플럼·미드나잇 + 후보 **딥그린 `#1F2E27`·잉크네이비 `#16233A`·버건디 `#3A1622`**. 딥엔 웜화이트·골드 글자.
- **시즌 롤아웃**: 코어(위)는 상시 무료 + **월간 시즌팩**(봄 벚꽃 `#F7D9DE→#FBEFE6` / 여름 자개 `#DCEBE8` / 가을 웜딥 `#B8520A` / 겨울 무드등 `#1E2A3A`+골드). 종료 후 아카이브→이듬해 재등장(수집 동기). ※ 너무 빠른 완판 소외감 주의 → 코어는 항상 열어둠.

## 6. 다음 액션 (최소 작업·순서 — 확정 후)
