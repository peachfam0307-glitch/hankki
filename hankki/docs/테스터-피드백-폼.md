# 테스터 피드백 — 익명 구글 폼 (14일 클로즈 테스트용)

> 목적: 지인이 아닌 테스터도, 나한테 직접 말하기 부담스러운 사람도 **익명으로** 편하게 의견 주게.
> 앱 안 `설정 → 의견 보내기 [익명]` 이 이 폼을 연다. 폼 URL을 `src/version.js`의 `FEEDBACK_URL`에 넣으면 버튼이 켜진다.

## 만드는 법 (2분, 익명 보장이 핵심)
1. **forms.google.com** → 빈 양식 새로 만들기
2. 오른쪽 위 **설정(톱니바퀴)** →
   - **‘이메일 주소 수집’ = 수집 안 함** ✅ (이게 익명의 핵심)
   - **‘응답 1개로 제한’ 끄기** (로그인 강제 안 되게)
3. 아래 질문들 추가
4. 오른쪽 위 **보내기 → 링크(🔗) 아이콘 → URL 복사**
5. 그 URL을 클로드에게 주기 → `FEEDBACK_URL`에 넣어 버튼 활성화

## 질문 (짧게 · 대부분 선택식이라 1분이면 응답)
1. **한끼를 얼마나 자주 쓰나요?** (객관식) — 거의 매일 / 가끔 / 몇 번 써봄 / 깔고 거의 안 씀
2. **레시피를 저장(담기)해 봤나요?** (객관식) — 예 / 아니오
   - 예라면, 대략 몇 개? (단답) ___
3. **써본 기능을 골라주세요** (체크박스·복수) — 레시피 저장·가져오기 / 표지 꾸미기 / 주부의 장바구니 / 영수증 스캔 / 오늘 뭐 해먹지 / 장보기·냉장고 / 요리 모드
4. **전반적으로 얼마나 만족했나요?** (별점 1~5)
5. **제일 좋았던 점** (단답/장문)
6. **불편했거나 안 됐던 점 · 버그** (장문) — 가감 없이 솔직하게!
7. **이런 기능 있으면 좋겠다** (장문, 선택)
8. **주변에 추천할 의향?** (선택 1~5)
9. (선택) 기기 — 아이폰 / 갤럭시·안드로이드

## 톤 안내문 (폼 상단 설명에 넣기)
> 한끼를 써봐 주셔서 정말 감사해요. 이 의견은 **완전 익명**이에요.
> 좋았던 점보다 **불편했던 점·안 됐던 점**이 훨씬 도움이 돼요. 편하게 가감 없이 남겨주세요 🙏
