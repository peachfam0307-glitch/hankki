> → *"**테스터 의견을 넣고 수정한걸 반영해야 구글에서 알지**"*

## ⭐⭐ 왜 이 문서가 있나 — 출시 노트가 「증거」다

⛔ **2026-08-02 반려 사유 ② = *"앱 업데이트를 통해 의견을 수집·조치하지 않았습니다"***

재신청 답변(설문)에만 「의견 → 고침」을 쓰고 **출시 노트를 기능 나열로 내면 앞뒤가 안 맞는다.**
심사자가 보는 자리가 **둘**이기 때문이다 —

| 심사자가 보는 곳 | 무엇이 보이나 |
|---|---|
| 재신청 답변(설문) | 우리가 **말한** 것 |
| **출시 내역의 출시 노트** | 우리가 **한** 것 (버전마다 남는다) |

📌 **둘이 같은 말을 해야 한다.** 그래서 이 판의 노트는 **테스터 의견을 맨 앞에** 둔다.

⛔⛔ **클로드가 여기서 한 번 틀렸다** — 처음엔 «오늘(8/5) 고친 것»만으로 노트를 썼다.
실제로 이 판에 실리는 건 **v9.50 ~ v9.79 = 30판**이다(콘솔 최신 = versionCode 11 = **v9.49**).
어제 고친 것(자랑카드 먹통·요리 모드 버튼·장바구니 길이·상표 곰)이 통째로 빠져 있었다.
**창업자가 잡았다.** 📌 **「오늘 한 것」이 아니라 「지난 판 이후 한 것 전부」다.**

```
직접 써보며 찾은 것도 고쳤어요.
· 레시피를 지우면 앱이 멈추던 문제
· 자랑 카드가 공유되지 않던 문제 (20초 넘게 걸리던 것도 빨라졌어요)

· 장보기 목록이 너무 길던 것 (접기·더보기)
· 어두운 배경에서 음식 아이콘이 하얗게 보이던 것

새로 들어간 것
· 음식 아이콘 16종 추가 (총 236종)
· 8월 주간 레시피, '비 오는 창' 배경
· 처음 켤 때 받는 양을 크게 줄여 설치·실행이 빨라졌어요
```

📌 **순서가 핵심이다** — 테스터 의견 → 직접 찾은 것 → 새 기능.
⛔ 새 기능을 앞에 두면 「기능만 늘리는 앱」으로 읽힌다. 반려 사유 ②가 정확히 그 지점이다.
