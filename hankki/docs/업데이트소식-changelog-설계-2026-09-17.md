# 📣 업데이트 소식(changelog) — 설계·실측 (2026-09-17)

📮 창업자 = *"우리 업데이트 일지 유저들에게 알려줘야하는거 아닐까? 어떤 기능이 업데이트가 되었는지.."*
   → 길 셋 중 **②「배포할 때 유저 문장 한 줄을 안 적으면 배포가 죽는 게이트」** 확정 = *"②로 가자"* · *"다 ㄱ. 나중에 셋은 두고"*
📮 아이폰 세션(창업자 전달) = *"ASC용 「이 버전의 새로운 기능」 문구도 같은 changelog에서 뽑을 수 있게 버전별로 유저 말 한 줄씩"*

## 1. 실물로 본 것 (설계 전)
- 「한끼 소식」(홈 카드 · 설정 줄)은 **날짜로 열리는 것**(레시피·꾸미기·카드·장바구니)을 저절로 띄운다 — 잘 돈다.
- **배포로 바뀐 기능**은 `whatsnew.js` `APP_FEATURES` 에 손으로 적어야 했고, 거기엔 **8/29 살구 배경 1줄**뿐. 그 칸은 `theme` 키만 받는다.
- 🔢 8/29 v11.80 → 9/17 v13.65 = **185판** 배포 · 유저에게 닿은 소식 = 살구 1줄.
- 「패드·폴드에서도 써요」 카드는 날짜가 없어 영영 남고, 「나중에」 셋(레꾸상점·PDF·커뮤니티)은 창업자 판정 = 그대로 둔다.

| 파일 | 무엇 |

| `scripts/changelog.mjs` | `--asc --from vX [--to vY]` ASC 복붙 덩이 · `--보관` 90일 지난 줄을 `docs/changelog-보관.md` 로 |

## 4. 세 각도에서 바뀐 것 (design-gate 통과 2026-09-17)
- **사람** — 홈 「새로」 알약·팝업 안 켬(살구와 같은 층) · 여러 줄은 한 카드로 접기 · ASC 뽑기 명령 · 아이폰은 앱 안 소식이 다음 빌드에야 실리니 ASC 줄이 먼저
- **사고** — 번호 올렸는데 줄 없음/중복/UTC 날짜/클로드 문장 → 전부 exit 1
- **규모** — 연 3,400줄 → 90일 지난 줄은 보관 문서로(번들을 안 키운다) · 소식은 폰 안에서만 그려 서버 0

## 5. 한계 — 못 잡는 것 (정직하게)
- `user: null` 남용(유저 눈에 보이는데 null 로 넘기기)은 기계가 못 잡는다.
- ASC 「새로운 기능」 글자 한도는 **모른다** — 아이폰 세션이 ASC 실물에서 본다(`--asc` 가 글자 수를 같이 찍는다).
- 문장의 «성의»는 못 잡는다 — `who:'창업자'` 는 «누가 확정했나»만 본다.

## 6. 앞으로 배포할 때 (⭐매 판)
```
① src/version.js 올림
② src/data/changelog.js 맨 위에 한 줄
   { v: 'v13.xx', when: 'YYYY-MM-DD', user: '유저 문장', who: '창업자', asc: true }   ← 창업자가 문장 확정
   { v: 'v13.xx', when: 'YYYY-MM-DD', user: null }                                    ← 유저 눈에 안 보이는 판
③ npm run smoke (check-changelog 가 본다)
```
🍎 아이폰 빌드 전 = `node scripts/changelog.mjs --asc --from <지난 빌드 버전>` → 그대로 ASC 에 붙여넣기.
