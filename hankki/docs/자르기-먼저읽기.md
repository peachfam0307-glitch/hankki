# ✂️ 자르기 전에 무조건 읽는 문서

> 창업자 2026-07-31: *"이미지컷 자르기전에 읽을 문서 만들어. 규칙이랑 최우선 고려사항. 도구.
> 검토할 때 중요한 것들."* · *"왜 네 기억에 맡기냐고 우리 규칙이 있는데. 그럼 규칙을 왜 정한거야?"*

**규칙은 있었는데 «지킬 장치»가 없었다.** 그래서 사고가 났다 —
큰 4컷 프레임 시트가 저장소에 있는데 못 찾고 **옛 16종 격자 시트**로 잘랐다.
컷이 272px라 2.3배로 늘려 쓰다 톱니가 됐고, 창업자가 네 번을 다시 봐야 했다.

📌 **그래서 이 문서는 「읽어야 하는 문서」가 아니라 「기계가 읽히는 문서」다.**
`/자르기` 명령어가 이 문서를 띄우고, **훅이 `cut.py` 실행을 막는다**(아래 5️⃣).

---

## 0️⃣ 순서 — 이 순서를 벗어나지 않는다

```
① 시트 고르기      python3 tools/sheet-index.py            # 표 갱신
                   → docs/stickers/_원본-우선순위.md 에서 «최신 팩» 확인
② 시트 검사        python3 tools/sheet-index.py --check <시트>
                   → 격자 / 컷 크기 / 흰 다이컷 세 가지를 한 줄로
③ 자르기           python3 tools/cut.py <시트> <폴더> <접두어> [옵션]
④ 눈으로 검수      자동으로 tools/cut-check.py 가 돈다 (진한·빨간·밝은·실제크기)
⑤ 앱에 넣기        python3 tools/recut.py <시트…> --panel <확인표>   # 먼저 눈으로
                   python3 tools/recut.py <시트…> --apply            # 맞으면 덮어쓰기
⑥ 게이트           npm run smoke
```

---

## 1️⃣ ⭐ 최우선 고려사항 — 여기서 틀리면 나머지가 다 헛일

### ⓵ **원본은 「가장 최근에 받은 것」을 쓴다**

⛔ 옛날 시트 뒤져서 쓰지 말 것. 같은 그림이 여러 팩에 있으면
**`docs/stickers/_원본-우선순위.md` 에서 위에 있는(최신) 팩**이 무조건 우선.

⚠️ **폴더 이름을 믿지 말 것.** 실제로 `신규-2607-재료도구` 폴더 안에 **프레임**이 있었다.
이름이 내용을 안 말해서 못 찾았다. → 표를 보고 **컷 크기**로 고른다.

### ⓶ **크게 쓰는 것은 컷이 커야 한다 — 늘려 쓰면 반드시 톱니가 난다**

| 쓰임 | 앱 표시 | 원본 컷 긴변 |
|---|---:|---:|
| 프레임·표지 | 626px | **600px 이상** (한 장에 4컷) |
| 데코·소품·글자 | 84~240px | 250px 이상 (한 장에 12~20컷) |

⚠️ **늘려서 자르면 요철도 같이 늘어난다.** 흐림은 `긴변 × 0.007` 고정이라 못 뭉갠다.
어쩔 수 없이 늘려 쓸 땐 **`--smooth <배율>`** 로 흐림도 같이 키운다.

### ⓷ **흰 테두리 = 스타일이 아니라 「보호막」**

흰 배경에서 자를 때 **진갈색 외곽선이 파먹히는 걸 막는 게 목적**이다.

- 그림에 흰 다이컷이 **없으면** → `--diecut auto` (긴변 1.2%, 바닥 3px)
- 그림에 흰 다이컷이 **이미 있으면** → `--diecut keep` ⛔`auto` 면 **두 겹**이 된다
- 진짜 띠부씰 팩으로 낼 것만 → `--diecut 10`

### ⓸ **`--apply` 전에 `--panel` 로 짝을 눈으로 본다**

짝은 이름이 아니라 **픽셀**로 짓는다. 그런데 실제로 **숫자 「2」가 「오늘도 해냄」 자리**를 차지했다.
확인표를 안 봤으면 앱에 숫자가 떴을 것이다.
→ 시트마다 **`--only` 를 따로** 주고, 헷갈리면 **`--near 0.02` + `--pair` 로 손으로 못 박는다.**

## 2️⃣ 🛠 도구 — 이 다섯 개만 쓴다

| 도구 | 언제 | 한 줄 |
|---|---|---|
| **`tools/sheet-index.py`** | 자르기 **전** | 원본 우선순위 표 만들기 · `--check` 로 시트 한 장 검사 |
| **`tools/cut.py`** | 자를 때 | **표준 컷 도구.** ⛔다른 컷 도구는 쓰지 않는다 |
| **`tools/cut-check.py`** | 자른 **직후** | 3단계 검수(진한·빨간·밝은·실제크기) — `cut.py` 가 자동으로 부른다 |
| **`tools/recut.py`** | 앱에 넣을 때 | 픽셀 지문으로 옛 key에 덮어쓰기 · 백업·비율 갱신 자동 |
| **`tools/outline-check.py`** | 의심될 때 | 끊긴 외곽선 전수 조사(어디를 볼지만 정해준다) |

### `cut.py` 옵션

| 옵션 | 기본 | 언제 손대나 |
|---|---|---|
| `--diecut auto\|keep\|N` | 없음 | ⭐**항상 켠다.** 위 ⓷ 참고 |
| `--frame` | 꺼짐 | 프레임(가운데 창 뚫기 + 창 안쪽 라인) |
| `--grid RxC` | 꺼짐 | 한 칸에 그림＋떨어진 소품이 흩어진 시트. **칸으로 묶기만** 함 |
| `--drop R` | **0.12** | 하트·반짝·물방울을 **떼는 게 기본**. 남기려면 `--drop 0` |
| `--punch R` | 꺼짐 | 바구니 손잡이처럼 그림 «안»에 갇힌 흰 구멍 뚫기(`0.004`) |
| `--join N` | 5 | 쪼리처럼 **한 그림이 두 조각**일 때만 키운다(25) |
| `--min N` | 8000 | 속도선·반짝까지 살리려면 낮춘다(60) |
| `--smooth K` | 1 | **늘려서 자를 때만** 그 배율만큼 |

## 3️⃣ 👁 검수할 때 중요한 것

📌 **숫자는 「어디를 볼지」만 정하고, 「맞나 틀리나」는 눈이 정한다.**

| 판 | 여기서만 보이는 것 |
|---|---|
| **진한 판** `#22263A` | 흰 잔재 · 투명 안 된 곳 |
| 🟥 **빨간 판** | **그림 안에 갇힌 흰 판**(바구니 손잡이 속) — 진한 판으론 안 보였다 |
| **밝은 판** | 어두운 잔재 · 끊긴 외곽선 · 갈색 후광 |
| **실제 크기** | 유저가 보는 크기. 원본만 보면 «괜찮은데 화면은 지저분» 해진다 |
| **서랍 크림색** `#E9E3D8` | 흰 테가 두꺼워 «부어» 보이는지 |

### 자주 나온 사고 (같은 걸 또 내지 말 것)

| 증상 | 진짜 원인 |
|---|---|
| 솜뭉치 테두리 | 칼선을 «그림»이 아니라 **시트에 칠해진 옅은 그림자**에서 쟀다 |
| 톱니(쥐가 파먹은 듯) | 시트를 **늘려서** 잘랐는데 흐림은 그대로 |
| 흰 테가 두 겹 | 그림에 이미 흰 다이컷이 있는데 `auto` 를 또 둘렀다 |
| 각진 흰 조각 | `--drop` 이 마테·별·꽃을 떼면서 **이어주던 다리**를 남겼다 |
| 엉뚱한 그림이 뜸 | 시트를 묶어 돌려서 `--only` 가 넓었다 |
| 알맹이가 사라짐 | `--frame` 창 뚫기가 조개 **진주**를 먹었다 |
| 검은 점선 | 원본에 **가짜 투명 격자**가 그려져 있었다 |

## 4️⃣ ⛔ 절대 규칙

1. **자르기 전에 `sheet-index.py --check` 를 돌린다.** 안 돌렸으면 훅이 막는다.
2. **원본은 지우지 않는다** — 옛 파일은 `docs/stickers/_옛컷-백업-<날짜>/` 에 자동 보관.
3. **덮어쓰기는 옛 key에 같은 이름으로** — 그래야 이미 그걸로 꾸며 저장한 레꾸가 안 깨진다.
4. **PNG 를 바꾸면 `PHOTO_RATIO` 도 같이** (`recut.py` 가 자동으로 한다).
5. **자른 뒤 `npm run smoke`** — 잘림·잡조각·계단이 있으면 배포가 막힌다.
6. **새 시트를 받으면 그날 바로** 저장 + `sheet-index.py` 갱신 + `docs/stickers/README.md` 등록.
7. **폴더 이름은 내용을 말해야 한다** — 「석 달 뒤 처음 보는 사람」 기준으로 읽어볼 것.

## 5️⃣ 🔒 지킬 장치 — **내 기억에 안 맡긴다**

창업자 질문: *"그러면 네가 지킬 장치를 만드는 거야?? 다른 방법있어??"*
→ **있다. 세 겹으로 걸어놨다.**

| 겹 | 무엇이 강제하나 | 안 지키면 |
|---|---|---|
| ① **훅** `.claude/hooks/cut-guard.sh` | **하네스**가 `cut.py`·`recut.py` 실행을 가로챈다 | **명령이 아예 안 돌아간다** |
| ② **도구** `cut.py` 자체 검사 | 가짜 격자 시트면 스스로 멈춘다 | 자르기가 중단된다 |
| ③ **게이트** `npm run smoke` | 잘림·잡조각·계단·해상도 | **배포가 막힌다** |

⭐ ①이 핵심이다. 문서를 «읽기로 약속»하는 건 결국 내 기억이지만,
**훅은 내가 잊어도 하네스가 대신 막는다.**
