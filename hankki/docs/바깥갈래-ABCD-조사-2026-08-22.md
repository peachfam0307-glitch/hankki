## 【A】 스토어에서 「레시피」로 검색하면 안 나온다

📮 창업자 = *"한끼로 검색하면 나오는데 레시피로 검색하면 안나와."*

### ⭐ 제일 큰 것 — **「레시피」는 이미 앱 «제목»에 들어 있다**
앱 이름 = **「한끼 — 나만의 레시피, 레꾸해요」** (2026-08-21 창업자 웹스토어 캡처 · `CLAUDE.md:29`)
＋ 구글 플레이는 **제목·짧은 설명·긴 설명을 «전부» 색인한다**(애플과 다른 점).

👉 그러니 **「낱말이 없어서 안 나오는 것」이 아니다.** 그럼 남는 갈래는 둘뿐이다.

| | 갈래 | 어떻게 가르나 |
|---|---|---|
| **ⓐ** | **순위가 낮아서 «안 보이는» 것** (색인은 됐다) | 검색 결과를 **끝까지 내려본다** — 20~30번째에라도 있으면 ⓐ다 |
| **ⓑ** | **아직 색인이 «덜 된» 것** (출시 1일차) | 며칠 뒤 다시 검색해서 뜨면 ⓑ였다 |

### 🔢 ⓐ가 훨씬 그럴듯한 이유 — 숫자가 그렇게 말한다
· **출시 «1일차»** (8/21 라이브) · 다운로드 **10+**
· 「레시피」는 **경쟁이 제일 심한 머리 낱말**이다 — 만개의레시피·해먹으리·레시피브로가 다 그 자리를 놓고 싸운다
· 2026 기준 플레이 순위는 **메타데이터보다 «설치 속도·유지율»이 더 무겁다**(검색 요약)
· 새 앱엔 **「신뢰 신호 지연(trust signal delay)」** 이 있다 — 알고리즘이 «꾸준한 설치·낮은 삭제율»을 볼 때까지 검색에 잘 안 띄운다
· 메타데이터를 고쳐도 **반영에 7~9일**

📌 **즉 「고장」이 아니라 「아직 어린 앱」이다.** 「한끼」가 바로 나오는 건 **고유명사라 경쟁자가 0**이기 때문이다.

### ⛔ 그래서 «지금» 제목·설명을 뜯어고치지 않는다
· 고쳐도 반영에 7~9일 · 그 사이 비교 대상이 사라져 **뭐가 효과였는지 영영 모른다**
· 2026 변화 = **긴 설명에 낱말을 쑤셔 넣으면 품질 분류기가 «눌러버린다»**(역효과)

### 📸 창업자에게 필요한 것 — 캡처 셋 (⛔이거 오기 전엔 더 안 판다)
1. **폰 플레이스토어에서 「레시피」 검색 → 끝까지 내린 화면** (우리 앱이 «어디쯤» 있나 / 정말 없나)
2. **Play Console → 스토어 등록정보 → 「짧은 설명」 80자 전문** (여기 「레시피」가 들어 있나)
3. **「한끼 레시피」·「집밥 레시피」로 검색한 결과** (⭐꼬리 낱말에선 뜨는지 = 색인 여부가 여기서 갈린다)

⭐ **3번이 제일 값싸고 결정적이다** — 꼬리 낱말에서 뜨면 **색인은 됐고 순위 문제**로 확정된다.

### ⑵ 🚨🚨 **전역 월 900 상한과 «정면으로» 부딪힌다 — 이게 진짜 관문이다**

## 【D】 꾸미기 팩 가격 — **1,490 vs 1,290**

📮 창업자 = *"1500원보다 1490이, 1300원보다 1290원이 좋을 것 같은데 … 못정했어."*

### ⭐⭐ 결정적인 것 — **왼쪽자리 효과는 「맨 앞 숫자가 바뀔 때만」 먹힌다**
검색 원문 = *"The left-digit bias effect **doesn't work if the leftmost digit is unchanged** (e.g., $3.50 vs $3.49)."*

| 값 | 맨 앞 숫자 | 효과 |
|---|---|---|
| **1,000 → 990** | **1 → 9** (「천원」이 「몇백원」이 된다) | ⭐**크다** — 우리 990 이 잘 고른 값인 이유 |
| **1,500 → 1,490** | **1 → 1** (안 바뀐다) | ⚠️**거의 없다** |
| **1,300 → 1,290** | **1 → 1** | ⚠️**거의 없다** |

📌 **창업자 감은 방향이 맞다**(90 이 붙으면 «계산된 값»으로 보여 살짝 낫다).
   ⛔ **다만 얻는 게 「살짝」이다.** 990 에서 본 그 효과를 기대하면 안 된다.

### 🔢 그럼 남는 건 «순수한 값 차이»다
```
1,490 − 1,290 = 200원  (＝ 15.5%)
구글 15% 뗀 실수령   1,266.5원  vs  1,096.5원   → 팩당 170원
1,000팩 팔면          127만원   vs   110만원    → 17만원
```

### ✅ 추천 = **₩1,490** — 근거 넷
1. **왼쪽자리 효과가 어차피 «안» 먹는다** → 1,290 으로 내려서 «심리적으로» 버는 게 거의 없다. **그냥 200원을 버리는 것에 가깝다.**
2. **꾸미기 팩은 「영구 소장 · 원가 0 · 재구매 압력 0」** → 2026-08-20 에 이미 *"재구매 압력이 없으니 값을 받는다"* 로 갈라 놨다. 그 판정이 그대로 여기 적용된다.
3. **두 층이 뚜렷해진다** — 🔑990(소모품) ↔ 🎨1,490(영구). 1,290 이면 990 과 붙어 **층이 흐려진다.**
4. **가격은 내리긴 쉽고 올리긴 어렵다**(2026-08-20 에 적어둔 비대칭). 1,490 으로 열고 안 팔리면 **「출시 기념 990」** 을 쓸 수 있다. 반대는 리뷰에 *"올랐네"* 가 박힌다.

⚠️ **정직하게 — 한국 앱 인앱결제에서 1,490 vs 1,290 을 비교한 «연구»는 못 찾았다.**
   위 넷은 ⑴일반 가격심리 원문 ⑵우리가 이미 내린 판정 ⑶산수다. **실험값이 아니다.**
✅ 값은 자유롭다 — 구글 담당자 확인 = 한국은 **70원 ~ 600,000원** 설정 가능(2026-08-17).

### ⛔ 그리고 «지금은 등록하지 않는다» — 그대로다
· `sellable` 5개 전부 **false** · BILLING 권한 AAB **미출시** · 결제 스위치 **9월 판정**
· ⭐ 여기 적은 건 **「정해졌다」는 기록**이지 실행이 아니다.
