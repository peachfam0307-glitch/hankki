# 주부의 장바구니 — 건강 식재료 큐레이션 (원본 보존)

> 18년차 주부가 수년간 직접 쓰며 고른 첨가물 적은 건강 재료들.
> 앱 '주부의 장바구니'에 성분·설명과 함께 소개 → 구매처 링크(제휴 수수료).
> _출처: 창업자가 직접 정리(2026-07-14). 계속 추가 예정._

## 표기 규칙 (창업자 지정)
- 제품명 옆 괄호 구매처는 정리해서 표기 (예: 데리야끼소스 → 오아시스, 무무덕 → 산지톡, 명태살 어묵/초당옥수수피자/고구마부리또 → 한살림)
- 띄어쓰기 교정: "명태살 가득 참 어묵", "문어 비엔나", "이리아다 칼라마타 엑스트라버진 올리브유 실버틴"
- 설명은 사용 팁 스타일로 (예: 자연누리 훈제오리 → "마지막에 깻잎 듬뿍 찢어 살짝 볶으면 굿!!", 고구마부리또 → "달달 고소, 아이들 간식으로 최고")
