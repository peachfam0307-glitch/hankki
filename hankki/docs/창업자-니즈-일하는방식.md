# 창업자 니즈 · 일하는 방식 (작업 시 항상 반영)

> 모든 작업에 이 문서를 기본 전제로 깔고 간다. 새 요청이 와도 여기 원칙을 먼저 통과시킨 뒤 결과물을 낸다.
> (요약이 필요하면: **디테일·미감 최우선 / 이모지 금지 / 완성본만 / 판단 먼저 말하고 실행 / 정직**)

## 1. 미감 (가장 민감한 부분)
- **디테일에 매우 민감하다.** 아이콘 하나, 곡선 하나, 자간 하나까지 본다. "대충"은 바로 알아챈다.
- **이모지는 촌스럽다.** 홍보물·UI에서 이모지 대신 **커스텀 라인/플랫 SVG 아이콘**을 쓴다.
- **따뜻한 폰트.** 시스템 한글 폰트(각지고 딱딱)를 싫어한다. 둥근·손글씨 계열(Jua·Gaegu·GowunDodum)로 감성을 낸다.
- **에디토리얼한 여백.** 요소를 꽉 채우면 "정신없다"고 느낀다. 숨 쉬는 레이아웃, 정돈된 톤.
- 톤앤매너: 크림/베이지 배경 + 먹색 글자 + clay/coral 포인트. 따뜻하고 사랑스럽게.
- 아이콘·그림은 실제 앱 아트(StickerArt 하트·별·리본, FoodIcon)와 **브랜드 결을 맞춘다.**

## 2. 정직 (신뢰의 문제)
- **아직 없는 기능을 광고하지 않는다.** (예: 공유 "링크" 기능 미출시 → 홍보 문구에서 삭제)
- 테스트 실패·건너뜀·미완은 그대로 보고한다. 되는 척하지 않는다.

## 3. 일하는 방식
- **완성본만 보여준다.** 잘리거나 반쯤 된 시안을 내밀면 실망한다. 렌더해서 내 눈으로 검수한 뒤 전달.
- **판단을 먼저 간단히 말하고 실행한다.** ("내 요청에 대한 너의 생각이나 판단도 간단히 정리 후 말하고 실행해줘")
- **쉽게 설명한다.** 뭘 어떻게 하라는지 모르겠다는 피드백이 나오면 곧장 눈높이를 낮춘다.
- 심혈을 기울인다. 첫 홍보 시안 같은 "얼굴" 작업은 특히 정성껏.
- 반복 수정을 마다하지 않되(닭다리 아이콘 여러 차례처럼), 매 라운드 **원인을 짚고** 고친다.

## 4. 제품 방향 (제품 결정 시 참고)
- **꾸미기(다꾸 감성)가 핵심 셀링포인트.** MZ·다꾸 트렌드를 계속 흡수해 "무한증식" 아이템으로 확장.
- **공유의 확장**이 큰 방향. 내가 꾸민 표지/레시피를 친구와 나누기 → 나중엔 본인 영상까지.
- 남성·운동러 타깃도 의식(심플·깔끔 아이템, 카테고리 맞춤: 다이어트/건강식 등).
- "써보고 매력이 있어야 남는다" — 출시 후에도 질리지 않게 계속 다듬는다.
- 창업자 자산: **주부 18년 안목**(살림템 큐레이션)이 차별점.

## 5. 실무 메모
- 폰트는 매번 새로 받지 않는다 → `design/promo/`(woff2 + fonts-embed.css)에서 재사용.
- 홍보 렌더 워크플로: `design/promo/README.md` 참고.
