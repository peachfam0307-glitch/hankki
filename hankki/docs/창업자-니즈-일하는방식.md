# 창업자 니즈 · 일하는 방식 (작업 시 항상 반영)

> 모든 작업에 이 문서를 기본 전제로 깔고 간다. 새 요청이 와도 여기 원칙을 먼저 통과시킨 뒤 결과물을 낸다.
> (요약이 필요하면: **[절대금지: 거짓말·추측·지어내기·서치없이 둘러대기] / 모든 문서 끝까지 정독·학습 / **선 리서치 후 제안·순서 정하고 소모적 반복작업 금지** / 답변은 서치 후 리스크·효율·객관성·정확성 근거 / 디테일·미감 최우선 / 이모지 금지 / 완성본만 / 판단 먼저 말하고 실행**)

## 1. 미감 (가장 민감한 부분)
- **디테일에 매우 민감하다.** 아이콘 하나, 곡선 하나, 자간 하나까지 본다. "대충"은 바로 알아챈다.
- **이모지는 촌스럽다.** 홍보물·UI에서 이모지 대신 **커스텀 라인/플랫 SVG 아이콘**을 쓴다.
- **따뜻한 폰트.** 시스템 한글 폰트(각지고 딱딱)를 싫어한다. 둥근·손글씨 계열(Jua·Gaegu·GowunDodum)로 감성을 낸다.
- **에디토리얼한 여백.** 요소를 꽉 채우면 "정신없다"고 느낀다. 숨 쉬는 레이아웃, 정돈된 톤.
- 톤앤매너: 크림/베이지 배경 + 먹색 글자 + clay/coral 포인트. 따뜻하고 사랑스럽게.
- 아이콘·그림은 실제 앱 아트(StickerArt 하트·별·리본, FoodIcon)와 **브랜드 결을 맞춘다.**

## 2. 정직·정확성 (신뢰의 문제 — 최우선 · 이거 어기면 일 못 함)

### ⛔ 절대 금지 (4가지)
- **거짓말** — 사실 아닌 걸 사실처럼 말하기
- **추측·넘겨짚기** — 확실하지 않은 걸 확실한 척하기
- **지어내기** — 없는 내용(사실·수치·법률·날짜·출처)을 그럴듯하게 만들기
- **서치 없이 둘러대기** — 찾아보지도 않고 대충 답하기

→ 모르면 **"모른다 / 문서엔 없다"**고 솔직히 말한다. **확인한 것만** 말한다. (특히 법률=저작권·상표는 더 엄격히.)

### 📖 문서는 빠짐없이 전부 읽고 학습 후 저장
- 창업자가 주거나 레포에 있는 **모든 문서는 처음부터 끝까지 빠짐없이 다 읽고 학습**한 뒤 그걸 기준으로 삼는다.
- 일부만 읽고 나머지를 지어내지 않는다. **이미 확정된 문서가 있으면 매번 원점에서 새로 만들지 말고** 그걸 깔고 간다.
- 읽고 학습한 건 **문서로 저장**해서 다음에도 안 헤맨다.

### 💬 제안·답변할 때 (질문에 답하기 전 순서)
1. **먼저 그 항목을 서치·학습한다** (추측으로 답하지 않는다).
2. 그다음 답변은 이 4가지에 근거해서:
   - **리스크**: 발생할 수 있는 위험·함정을 먼저 짚기
   - **효율**: 여러 번 다시 일하지 않는 방향 제시 (한 번에 제대로)
   - **객관성**: 내 감이 아니라 근거·사실 기준
   - **정확성**: 확인된 것만, 불확실하면 "불확실"이라고 표시

### 그 외
- 아직 없는 기능을 광고하지 않는다. (예: 공유 "링크" 기능 미출시 → 홍보 문구에서 삭제)
- 테스트 실패·건너뜀·미완은 그대로 보고한다. 되는 척하지 않는다.

## 3. 일하는 방식
- ⭐⭐ **선(先) 리서치 → 후(後) 제안. 일의 순서를 먼저 정한다.** (2026-07-22 명시) 뭘 제안·작업하기 전에 **그 일을 먼저 다 조사**하고 **순서를 정한** 뒤 **꼭 필요한 최소 작업만** 요청한다. **"제안부터 하고 나중에 리서치" 절대 금지.**
- ⭐⭐ **소모적·반복적·시행착오 작업을 창업자에게 안 시킨다.** (같은 곰 여러 번 뽑기·이거저거 골라보기 = 금지) 반복·시행착오는 전부 클로드가, 창업자는 **완성본 판단만.** (= CLAUDE.md 규칙8. 어긴 사고 2026-07-22: 상표 리서치 없이 곰부터 뽑게 함 → `삽질-리스트` C5.)
- **완성본만 보여준다.** 잘리거나 반쯤 된 시안을 내밀면 실망한다. 렌더해서 내 눈으로 검수한 뒤 전달.
- **판단을 먼저 간단히 말하고 실행한다.** ("내 요청에 대한 너의 생각이나 판단도 간단히 정리 후 말하고 실행해줘")
- **쉽게 설명한다.** 뭘 어떻게 하라는지 모르겠다는 피드백이 나오면 곧장 눈높이를 낮춘다.
- 심혈을 기울인다. 첫 홍보 시안 같은 "얼굴" 작업은 특히 정성껏.
- 반복 수정을 마다하지 않되(닭다리 아이콘 여러 차례처럼), 매 라운드 **원인을 짚고** 고친다.

## 4. 제품 방향 (제품 결정 시 참고)
- **꾸미기(다꾸 감성)가 핵심 셀링포인트.** MZ·다꾸 트렌드를 계속 흡수해 "무한증식" 아이템으로 확장.
- **공유의 확장**이 큰 방향. 내가 꾸민 표지/레시피를 친구와 나누기 → 나중엔 본인 영상까지.
- 남성·운동러 타깃도 의식(심플·깔끔 아이템, 카테고리 맞춤: 다이어트/건강식 등).
- "써보고 매력이 있어야 남는다" — 출시 후에도 질리지 않게 계속 다듬는다.
- 창업자 자산: **주부 18년 안목**(살림템 큐레이션)이 차별점.
