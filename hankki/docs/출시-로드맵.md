## Q1. 지금까지 만든 거 대대적으로 다시 해야 할까?

**아니.** 지금 한끼(PWA)는 **그대로 구글 플레이 앱이 된다.**
- 플레이 스토어의 수많은 앱이 우리 같은 웹앱을 **TWA**(Trusted Web Activity)라는 공식 방식으로 감싸서 출시한 것.
- 감싸는 도구(PWABuilder)는 무료고, 하루면 된다. **코드 재사용 100%.**
- 지금 열심히 다듬는 게 전부 출시 준비 그 자체다. 버리는 작업이 하나도 없다.

| **3. 수익화** | 사용자 반응 본 뒤에 붙인다 (아래) | 출시 후 | 0원~ |

- 구글 개인 개발자 계정은 **신규 등록 시 비공개 테스트 요건**(테스터 모아 2주 테스트)이 있어서 심사 기간이 걸린다 — 어차피 우리 베타 테스트랑 똑같은 거라 자연스럽게 통과.
- **개인정보처리방침 페이지 필수** — 우리 앱은 데이터가 전부 폰 안(localStorage)이라 쓸 내용이 간단. 내가 만들어줌.

## Q3. 사업자 등록? 절차 어렵지 않나?

**출시만 할 거면(무료 앱) 사업자 필요 없다.** 개인 계정으로 출시 가능.
수익이 **실제로 나기 시작할 때** 순서대로 하면 된다:

1. **사업자등록** — 홈택스에서 온라인 신청, **비용 0원**, 반나절. '간이과세자'로 시작.
2. **통신판매업 신고** — 정부24에서 온라인, 등록면허세 **연 1.2만~4만원**(지역별). 인앱 판매 시작할 때.
3. **쿠팡 파트너스**(제휴 수수료) — **사업자 없이 개인으로 가입 가능.** 수익 나면 세금은 원천징수로 알아서 처리됨. 나중에 사업자 달면 전환.

→ 즉 "미리 준비할 서류 산더미" 같은 건 없어. **필요해지는 시점에 하나씩**, 각각 반나절짜리.

## Q5. 수익은 얼마나? (솔직 버전)

앱 수익 = **사용자 수 게임**이라, 처음 몇 달은 0원~용돈 수준이 현실이야. 대신 우리는 유지비도 거의 0이라 **리스크가 없다.**

한끼에 어울리는 수익 구조 3개:
1. **쿠팡 파트너스** (제일 먼저) — 장보기 탭 '사러가기'가 이미 있잖아. 그 링크가 파트너스 링크가 되면 구매액의 ~3%가 수수료. *예: 월 100명이 평균 3만원어치 구매 → 월 9만원.*
2. **프리미엄** (인앱/웹 결제) — 꾸미기 스티커 팩, AI 인식 무제한 같은 것. *예: MAU 1,000명 중 2%가 월 4,900원 → 월 10만원.* (구글 수수료 15% 제외)
3. **광고** — 마지막 수단. 앱 감성 해쳐서 비추.

→ 감 잡히지? **MAU 수천 명은 돼야 월 수십만원**이 보이는 구조. 그러니 순서는 무조건: **좋은 앱 → 사용자 → 수익화.** 수익화를 먼저 고민하느라 출시가 늦어지는 게 최악.

## 부록 A. AI 자동인식 (사진·인스타·유튜브) — 비용·구조·안전장치

> 2026-07-14 추가. "비용 폭탄 나는 거 아냐?"에 대한 결론: **구조적으로 폭탄이 불가능하게 만들 수 있다.** 진짜 과제는 비용이 아니라 "키 숨길 작은 서버 1개"뿐.

### A-1. 사진 1장당 실제 비용 (2026-07 기준)
- 레시피 사진(≈1080px) → 이미지 토큰 ≈ (가로×세로)÷750 ≈ 1,000~1,600토큰 + 출력 몇백 토큰.
- **Haiku 4.5** (입력 $1 / 출력 $5 per 100만 토큰) 기준: **사진 1장 ≈ 2~3원**.
- 레시피 100장 ≈ 200~300원, 500장 ≈ 1,000~1,500원. **아무리 많아도 껌값.**
- 더 아끼기: **Batch(배치) API = 50% 할인** (몰아서 처리), **프롬프트 캐싱** (반복 지시문 90% 절감).
- OCR·재료추출은 Haiku 4.5로 충분. 정확도 더 필요하면 Sonnet(3~5배 비쌈, 그래도 저렴).

### A-2. 인스타/유튜브 링크 자동등록 구조
```
유저가 링크 붙여넣기
  → 내 작은 서버가 "캡션(글)" 가져옴  ← 핵심은 이 스크래핑 층
  → Claude Haiku가 재료·순서로 정리
  → 자동 등록
```
- **핵심은 AI가 아니라 "캡션 긁어오는 층".** 대부분 레시피 릴스는 **캡션 글에 재료·순서가 다 있음** → 글만 읽으면 **거의 공짜(0.1~1원)**. 비싼 영상분석 불필요.
- 캡션 가져오는 법 2가지:
  - **A. 스크래핑 API 사서 쓰기**(Apify·RapidAPI 등) — 인스타 차단을 걔네가 대신 뚫어줌. 링크당 ≈1~15원, **무료 티어(월 100~500건)** 있음. ← 추천
  - B. 직접 크롤러 — 서버비만 들지만 인스타가 구조 바꾸면 자주 깨져서 유지보수 지옥.
- **유튜브는 더 쉬움** — 공식 자막(script)을 가져올 수 있어 스크래핑 API도 거의 불필요, 더 안정적.
- 유일한 약점: 스크래핑 방식은 인스타가 막으면 **가끔 며칠 안 될 수 있음**(그런 앱 리뷰에 "가끔 링크 안 먹혀요"가 그 이유).

### A-3. "폭탄" 막는 안전장치 (이거 하나면 걱정 끝)
1. **선불(Prepaid) 결제** — console.anthropic.com에서 카드로 **미리 $5(약 7천원) 충전** → 그만큼만 쓰고 소진되면 자동 정지. 통신사 선불폰처럼 **충전액 이상 절대 안 나감.** ← 초보 강추.
2. **월 한도(spend limit)** — "월 5만원 넘으면 API 자동 정지" 설정. 후불(auto-reload) 쓸 땐 필수.
3. **사용량 알림** — 50%·80% 도달 시 이메일.
4. **유저별 횟수 제한** — 내 서버에서 "무료=하루 3장, 프리미엄=하루 30장" 코드로 제한. 어뷰징 방지.
- → **1번(선불)만 켜도 폭탄은 물리적으로 불가능.** $5 = 사진 2,000장 넘게 처리됨.

### A-4. 결제 세팅 순서
1. console.anthropic.com 로그인 → Billing에 해외결제 카드(비자/마스터) 등록
2. **$5부터 충전**(처음엔 이거면 충분) → Limits에서 월 한도 설정
3. 실제 사용 데이터 보고 프리미엄 가격·한도 조정

### A-5. 지금 앱 상태
- 캡쳐 OCR은 **이미 폰 안에서 도는 무료 tesseract** 사용 중 → API 비용 0원.
- AI 비전 API는 **정확도 업그레이드용(프리미엄)** 이라 서버 붙일 때만 필요. **출시엔 지금 무료 OCR로 충분.**
