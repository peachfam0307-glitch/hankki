## 🗄 KV 저장 칸 — 세 가지를 한꺼번에 푼다

⭐ 아래 한 벌이 **①플랫폼 나누기(아이폰 세션 제안) ②50개 묶음(규모) ③두 번 보내기 막기(사고) ④계측**을 다 푼다.

```
push:web:<묶음번호>     = [구독 …최대 50개]   ← 안드로이드·PC
push:ios:<묶음번호>     = [구독 …최대 50개]   ← 아이폰이 네이티브로 가면 (APNs)
push:n                  = { web: 2, ios: 0 }  ← 묶음이 몇 개인가
push:sent:<YYYY-MM-DD>  = '1'                 ← ⛔보내기 «전»에 먼저 박는다(두 번 막기)
push:log:<YYYY-MM>      = { 보냄, 성공, 만료삭제 }  ← 조용한 실패를 보이게
```

🔢 **KV 쓰기 무료 한도 1,000/일**을 이 꼴이면 안 건드린다 —
　 하루에 쓰는 것 = `push:sent` **1번** ＋ `push:log` **1번** ＋ 새 구독이 생길 때만 그 묶음 1번.
　 ⛔ 「보낼 때마다 쓰기」로 짜면 91명이면 하루 91번 → 열 명만 늘어도 한도가 보인다.

### 보내는 차례 (cron 이 이 순서로)
1. `push:sent:<오늘>` 이 있나? → 있으면 **끝**(두 번 방지)
2. 없으면 **먼저 박는다** → 그다음 보낸다 (⛔순서를 바꾸면 겹칠 수 있다)
3. `push:n` 을 읽어 묶음 수만큼 «따로» 깨어나 보낸다 (한 번에 50개까지)
4. 410/404 가 온 구독은 그 묶음에서 **뺀다**
5. `push:log` 에 보냄·성공·만료삭제를 더한다

### ⛔⛔ 설계가 «또» 바뀐 곳 둘 — 만들면서 나왔다
1. **글자를 실어 보내지 않는다(빈 푸시).** 글자를 실으려면 RFC 8291 암호화(aes128gcm·HKDF·ECDH)를 손으로 짜야 하고, 대시보드 워커는 라이브러리를 못 쓴다. 틀리면 «조용히» 안 온다.
   ✅ 빈 푸시 = 암호화 0줄. 필요한 건 VAPID 서명 40줄뿐. 문구는 폰이 `/today` 로 가져온다 → **문구 고치기 = 앱 배포(저절로)**, 워커 붙여넣기가 아니다.
2. **묶음 = 50 이 아니라 40.** 무료 상한 50 에는 KV 읽기·쓰기도 «다 센다». 재현판 실측 = 한 번 깨어날 때 fetch＋KV **48**. 50 으로 잡았으면 넘었다.

### 🔑 VAPID 열쇠는 «아무도 안 만진다»
워커가 첫 `/vapid` 호출 때 스스로 만들어 KV(`push:vapid`)에 둔다. 공개 열쇠만 응답에 나간다. 채팅·저장소·대시보드 비밀 칸 어디에도 적을 게 없다.
