## 2. 🎭 조연 캐릭터 방향 결정 (진행 중)

창업자가 조연 캐릭터 두 세트를 보여주고 의견 요청 — "흔한 동물 말고 애들이랑 잘 어울리는 걸로 만들었는데 뭐가 더 좋아?"

| | 첫 시안 | 재개발 |
|---|---|---|
| 조연 3인 | 강아지(멍멍이)·토끼(토리)·햄스터(햄찌) | 🦫카피바라·🐭친칠라·🦊사막여우 |
| 성격 | 예쁘고 안정적·누구나 앎 | 안 흔함·신선 |

**클로드 판단 = 재개발(카피바라·친칠라·사막여우) 방향 추천:**
1. **안 흔해서 각인** — 토끼·강아지·햄스터는 라인프렌즈·카카오부터 넘쳐서 묻힘. 독특한 조합은 "이 조합 뭐지?" 하고 한 번 더 보게 됨.
2. **컨셉 결** — 카피바라 = 느긋·힐링 아이콘 = 한끼 북극성("오늘 한 끼 해낸 나 위로") / 친칠라 = 복슬 = 우리 물결 곰펭 스타일과 질감 통일.
3. **IP 유리** — 독특한 캐스트가 상표·저작권 보호에 유리 (특허청도 "다양한 캐릭터 노출이 저작권에 유리" 언급).

**손질 필요(방향 확정 후)**: 사막여우 귀 강조(코기와 실루엣 구분)·조연 3인 이름 재정리(멍멍이·햄찌·토리 → 새 이름)·앱 친구들 탭 이름표(카피바라·친칠라 인지도 낮음 보완).

**보관**: `docs/stickers/캐릭터-세계관-확장-2507/한끼-조연개발-카피바라친칠라사막여우-생활씬{A,B}.png` (요리·피크닉·쇼핑·운동·TV 씬).
