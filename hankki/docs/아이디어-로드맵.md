# 한끼 아이디어 · 로드맵 (백로그)

> _창업자가 적은 아이디어 원본을 보존하고, 단계별로 정리한다._
> 방향을 정할 땐 `기획-노트.md`(왜·누구)와 이 문서(무엇을·언제)를 함께 본다.
> **원문은 그대로 보존** — 정리/우선순위는 참고용, 최종 결정은 창업자.

---

## 원문 (어제 적은 것, 그대로)
- **아바타**: 심플·깔끔 버전 / 뾰루퉁한 캐릭터 버전 추후 추가 / 요리하는 남성들을 위한 심플한 아바타 추가
- **꾸미기**: 표정·도구·글자·포스트잇(모양) 등 — **남자ver**: 알통, 단백질 파우더, 아령, 물병 등
- **배경**: 심플 버전 (남성 사용자 위한)
- **로그인**: 카톡·네이버 등 연동 — 레시피카드 편하게 보내기, 내 파일 내보내기
- **가계부 기능**: 영수증이나 쇼핑몰 쇼핑 내역으로 정리…? (복잡할 것 같아 고민)
- **장보기**: 첨가물 없는 식재료 소개 — 18년차 주부가 아끼고 수년간 쓰던 건강한 재료들(간장·고추장·액젓·소금·설탕·어묵 등 매우 많음) 성분과 함께 소개 → 링크(수수료 발생)
- **레시피 추천 (AI)**: 요즘 뜨는 레시피, 자취요리, 초간단, 한그릇, 식사대용 스무디, 포케, 샌드위치, 00프로그램 레시피 등 — 타겟층에 맞게 추천
- **커뮤니티**: 유저 모이면 레시피 공유 / 가져오기 하면 그 유저에게 **한끼 전용 머니** 적립 → 나만의 레시피북 PDF 다운, 다양한 꾸미기·기능 구입 / 유저 늘면 **살림도구**까지 확장, 유저끼리 소개, 가장 많이 가져온 물건·재료는 한끼가 대표링크 제공(수수료)
- **영어 ver**: 한식에 관심 많은 외국인·영어가 편한 사람들을 위한
- **설정에 문의 채널**
- **작업한 코드 도용 방지**
- **주간 식단표 짜기**: 장보기 기반 — 내가 있는/장본 재료로 재료 다 소진할 수 있는 레시피 추천
- **친구와 공유하기**: 레시피카드에 링크 넣기
- **앱 홍보**: 카드 형태로 링크 넣고 맘카페에 홍보할 수 있는 카드 이미지 제작
- **앱스토어 소개 페이지**: 기능 소개·슬로건 매력적으로 어필, 다운로드 유도
- **연구실 기능**: 유저 니즈·피드백 반영("이런 기능 만들어주세요"), 버그·오류 신고, "다음 기능은 이거다" 예고 팝업
- **출시 시 AI 가져오기 기능 제일 중요!!** — 가져오기 할 때 **로딩 안내 화면** 만들기
- **수수료·유료기능 고민**: AI를 무료로 조금이라도 줄지, 아예 유료로 할지 — 무료면 OCR을 스트레스 안 받게 해야 함

## 단계별 정리 (참고안)

### 🟢 지금 / 출시 직전 (가벼움, 바로)
- **AI 가져오기 로딩 안내 화면** — 가져오기 중 기다리는 UX (출시 시 제일 중요 기능의 완성도)
- **설정에 문의 채널** — 이미 이메일 있음, 눈에 잘 띄게
- **앱스토어 소개 페이지 문구** — 슬로건·기능 어필 (이미 `출시-가이드.md`에 소개글 초안 있음)
- **앱 홍보 카드 이미지** — 맘카페·SNS용 (친구초대 카드와 같은 방식으로 제작 가능)
- **친구와 공유 / 레시피카드 링크** — 꾸미기 카드에 링크 = 바이럴 루프 ⭐

### 🟡 출시 후 (반응 보고, 로컬로 가능한 것)
- **아바타·꾸미기·배경 남성 ver** — 알통·단백질·아령 스티커, 심플 배경 → 남성 유저 확장(자취남·혼밥남). 로컬이라 비용 없음, 확장 효과 큼
- **주간 식단표** — 장보기·냉장고 재료 소진 기반 추천 (기존 '오늘 뭐 해먹지' 확장)
- **연구실 기능** — 피드백·버그 신고·다음 기능 예고 (커뮤니티 라이트, 애착 유저 만들기)
- **장보기 건강 재료 소개 확장** — 18년차 주부 큐레이션(간장·고추장·액젓·소금·어묵…) 성분과 함께 → 제휴 링크(수수료). **현실적 1순위 수익 레버**

### 🟠 계정·수익 (구조 바뀌는 것 — 신중히)
- **로그인(카톡·네이버 연동)** — 레시피카드 전송·파일 내보내기 편해짐. ⚠️ 서버·개인정보 부담 시작점
- **수수료·유료기능 결정** — 핵심 갈림길:
  - AI를 **무료로 조금**? → OCR 스트레스 최소화가 전제 (무료 AI = 비용 발생)
  - **완전 유료(프리미엄)**? → AI·PDF·프리미엄 꾸미기를 페이월 뒤로
  - → `기획-노트.md`의 "AI는 페이월 뒤에서만" 원칙과 연결
- **가계부 기능** — 복잡도 높음, 창업자도 고민 표시. 후순위/보류 검토

### 🔵 커뮤니티 · 확장 (유저 수백~1,000명+ 모인 뒤)
- **커뮤니티**: 레시피 공유 + **한끼 머니**(가져오기 시 적립 → PDF 레시피북·꾸미기·기능 구입) = 리텐션+바이럴 동력
- **살림도구 확장 + 대표링크(수수료)** — 가장 많이 가져온 재료·도구를 한끼가 큐레이션
- ⚠️ 유저 적을 때 열면 "유령 도시" 위험 → 활성 수백 명+ 뒤, 초반 불씨는 창업자가 직접
- **AI 레시피 추천** — 뜨는/자취/한그릇/포케 등 타겟 맞춤 (AI라 비용 → 유료 or 신중)
- **영어 ver** — 한식 관심 외국인·영어권. 시장 확 넓어지지만 번역·현지화 공수

### 🛡️ 상시
- **코드 도용 방지** — 저장소 관리, 라이선스·민감정보 분리 (지금도 상대경로·로컬 저장으로 리스크 낮음)

## 핵심 관찰 (전략 메모)
1. **출시 최우선 = AI 가져오기 완성도 + 로딩 UX.** 이게 타겟(헤비 세이버)의 첫인상이자 핵심 가치.
2. **남성 유저 확장(아바타·꾸미기·배경)** 은 저비용 고효과 — 로컬이라 돈 안 들고 시장이 넓어짐. 출시 후 빠른 카드.
3. **수익 1순위 = 장보기 건강재료 제휴.** 자연스럽고 비용 없음. AI·커뮤니티보다 먼저.
4. **한끼 머니 + 커뮤니티** 는 리텐션·바이럴의 진짜 엔진이지만 **유저 규모 + 서버 비용**이 전제. 2단계.
5. **AI 무료/유료 결정**이 비용 구조를 가르는 제일 큰 갈림길. 무료로 풀면 오답끝식 함정. 페이월 권장.
