## 4️⃣ 방법 다섯 · 장단점 · 추천 순서

| | 무엇 | 좋은 점 | ⚠️ |
|---|---|---|---|
| **①** | **「최근 쓴 것」 맨 위** | ⭐**제일 싸고 효과가 크다** — 코드가 이미 있다(음식 픽커). 사람은 자기가 쓰는 20~30개를 반복해 쓴다 | 처음 쓰는 사람에겐 비어 있다 |
| **②** | **검색 (초성 포함)** | 850컷이 돼도 **한 번에 꺼낸다.** 이것도 코드가 있다 | ⚠️**스티커에 이름표가 없다**(`dp_01`…) → 394개에 이름 붙이는 노가다 필요 (⭐노가다는 클로드가 · 규칙8) |
| **③** | **그룹 접기** (창업자 제안) | 스크롤이 확 준다. 상태를 기억하면 한 번만 하면 된다 | 접어두면 **새로 산 팩도 안 보인다** → *"샀는데 어디 있지?"* |
| **④** | **숨기기 / 서랍으로 빼기** (창업자 제안) | 안 쓰는 걸 아예 치운다 | ⚠️⚠️ **돈 주고 산 걸 숨기면 「산 게 없어졌다」가 된다.** 되돌리는 길이 확실해야 하고, 되돌리는 자리를 유저가 찾을 수 있어야 한다 |
| **⑤** | **「내 팩」으로 묶어 보기** | ⭐**팔 때도 좋다** — 산 것이 한 덩어리로 보이면 소유감이 생긴다. 팩 단위로 접기·펴기도 자연스럽다 | 새 화면이 하나 늘어난다 |

### ⭐ 추천 순서 = **① → ② → ⑤ → ③ → ④**

**왜 이 순서인가**
1. **①②는 유저가 아무것도 안 해도 된다.** ③④는 **유저에게 「정리」를 시키는 일**이다.
   → **유저에게 관리를 시키는 건 마지막 수단**이다. 다꾸는 노는 것이지 파일 정리가 아니다.
2. ①②는 **코드가 이미 있다**(음식 픽커). ③④는 새로 만들어야 한다.
3. ⑤는 **돈이 되는 쪽**이라 결제(#54)와 같이 하면 값이 두 배다.

## 5️⃣ 언제 해야 하나

- ⚠️ **단 무료 계절만으로도 1년에 248컷이 는다** → **6개월 안엔 ①②가 필요하다.**
- 📌 ⑤는 **결제 붙일 때 같이** (그때 「산 것」이라는 개념이 처음 생긴다).

## 6️⃣ ⛔ 하지 말 것

- **자동으로 숨기지 않는다.** *"안 쓰는 것 같아서 치웠어요"* 는 **뺏은 것**으로 읽힌다.
