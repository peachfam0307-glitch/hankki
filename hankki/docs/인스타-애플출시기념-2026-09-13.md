# ✅ [19:22 확정] 캐러셀 6장 — 문구·자리 다 정했다

📮 창업자 = *"잘보이게 적어줘 **이 캐러셀은 아이폰출시가 제일 중요하니까**"*
📮 ＋ *"아! **로그인화면도 하나 캐러셀에 넣자**"*

## ⭐⭐ 이 판의 «주인공» = 아이폰 출시
⛔ 그래서 **1장·6장에서 「아이폰」이 제일 크게** 보여야 한다.
   기능 소개(2~5장)는 «곁들이»다 — 거기서 글씨를 키우면 주인공이 묻힌다.

| 장 | 큰 글씨 | 작은 글씨 | 그림 |
|---|---|---|---|
| **1 훅** | **아이폰 유저분들<br>많이 기다리셨죠?** | 이제 아이폰에서도 | 꼬르곰 만세(`낱개-콤비축하/01`) ＋ 폭죽(`02`) |
| **2 뭐가 되나** | 이제 어느 폰이든 한끼 | 흩어진 레시피를, 한곳에 | 레시피 화면 |
| **3 저장** | 인스타에서 본 레시피,<br>담아두면 사라지지 않아요 | | 저장 화면 |
| **4 꾸미기** | 내가 한 끼를 기록해요 | | 레꾸 한 장 |
| **5 로그인** | 폰이 바뀌어도<br>그대로 있어요 | 로그인하면 레시피가 따라와요 | 로그인 화면 |
| **6 끝** | **아이폰에서도,<br>오늘도 한끼하세요** | 구글 플레이 · 앱스토어에서 **한끼** | 꼬르곰·펭펭 건배(`03`) ＋ 폭죽 |

⭐ **5장(로그인)을 넣은 이유** = 아이폰 유저는 «안드로이드에서 옮겨오는» 사람이 아니라
   **새로 까는 사람**이다. 「기록이 사라지지 않는다」가 그 사람에게 제일 큰 걱정이다.
