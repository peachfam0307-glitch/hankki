## 2. ⭐ 레시피 양념 → "주부의 장바구니" 제품으로 + 메모 자동 채우기 (퍼널)

### 메모 자동 채우기 형식 (예: 돼지고기 김치찌개)
> "이 레시피엔 **주부의 장바구니**의 *올바른가 요리의정수 해물맛*, *홍영의 붉은대게 백간장*, *복이네 고춧가루*를 사용했어요. 🛒 재료 사러가기"
- 톤: 옆집 언니("~썼어요"), 과장 X. 재료 리스트엔 일반명, 메모에 제품+사러가기.

### ⭐ 창업자 확정 방향 = "무조건 내 제품으로 아예 바뀌게" + 자동화
> 창업자: "계속 추가될 예정이니 **내가 재료 올리면 자동으로 바뀌면** 좋겠어. 레시피 올릴 때 간장·된장·국간장 등은 **무조건 내 재료로 아예 바뀌게.**"
- **재료 리스트 자체를 장바구니 제품으로 치환**(메모만 X → 재료에 직접). 요리 가능성 위해 일반명 병기: `진간장(성가정 우리콩 진간장) 1큰술` 형태.
- **표준 규칙화**: 레시피 작성·수정 시 양념은 **항상** 매핑표대로 치환 → CLAUDE.md 핀에 규칙 추가.
- **살아있는 매핑표**: 창업자가 장바구니에 제품 추가 → 클로드가 매핑표 갱신 + **그 재료 쓰는 모든 레시피 재스캔·치환**(창업자=큐레이터, 클로드=전파). = "자동으로 바뀜".

### 실행안 (클로드=반복, 창업자=확인)
1. **매핑표 확정**(위 표) + 애매한 것 창업자 확인(예: **국간장** → 백간장(홍영)? 초피액젓? 요리별로).
2. 클로드 **36개 레시피 스캔** → 양념 치환 + 메모에 "주부의 장바구니 ○○ 사용 · 사러가기".
3. 창업자 확인 → basics.js 반영 → **`/픽스` 때 배포**(규칙9).
4. 이후 신규 제품/레시피는 규칙 따라 자동 적용.
- **주의**: 나쁜 대체품 강매 X · 쿠팡 없으면 원래 링크(정직) · 맛 해치는 교체 X · 일반명 병기(누구나 요리 가능).
