■ 제목을 바꾸라는 것 둘
  · 「파절이 소스」 → **「파절이」**        (창업자 "파절이로 바꾸고.(제목)")
    ⭐ 소스가 아니라 «요리»가 됐다 — 파를 썰고 담그고 무치는 순서가 다 왔다.
  · 「비냉 양념장」 → **「비빔냉면+고기를 곁들인」**  (창업자 "제목 (비빔냉면+고기를 곁들인)")
    ⚠️ 이건 제목이라기엔 길다 — 넣을 때 창업자에게 한 번 더 물을 것.

■ 원문을 고치라는 것
  · 마늘간장 계란장 — 백업 원문 재료가 「계란 반죽에 간장 크게 1」인데
    창업자 = **"계란 반죽 아니고 반숙."** → 「반숙 계란에 간장 크게 1」
    ⛔ 백업 파일에 «잘못 적힌» 것을 창업자가 잡은 것이다. 원문을 그대로 옮기면 틀린 채로 나간다.
  · 차돌된장 — 「국간장 1큰술」 → **초피액젓**(창업자 "국간장-초피로") · 「꿀 0.5큰술」 → **꿀 1작은술**

■ 안 적은 것
  · 참깨 소스 = 시간·인분을 안 적었다 → 넣을 때 물어볼 것
  · 「초무침 소스」·「마요간장 (웨지감자/샐러드 소스)」 = **나중에** (다음 판에 다시 올린다)

# 🍳 [2026-08-19 확정] 「마늘간장 계란장」 → **마늘간장계란밥**

📮 창업자 = *"계란장은 뭐야??"* → 물음이 맞았다. **이건 계란장이 아니었다.**

⛔ **왜 이런 일이 났나** — 백업 원본이 이 꼴이었다:
```
제목 = 마늘간장 계란장
time = 0 · servings = 0
[재료] 오일·들기름 1큰술 / 마늘 1큰술 / 계란 2 / 계란 반죽에 간장 크게 1 /
       팬 돌려가며 바삭하게 / 밥 위에 (버터)
[만드는 법] (0걸음)
```
📌 **만드는 법이 0걸음이고 재료 칸에 메모가 통째로 들어가 있었다** — 창업자가 앱에 급히 적어둔 그대로다.

⭐ ＋ **이름도 안 맞았다** — 「계란장」은 삶은 계란을 «간장에 담가 절이는» 것인데
   이 레시피는 «기름·마늘에 계란을 부쳐 밥 위에» 얹는 것이다.
