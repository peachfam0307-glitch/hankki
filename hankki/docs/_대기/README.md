## ⛔ 여기 두면 «안 되는» 것

- **끝난 일의 재료** (반영 완료된 초안·이미 적용한 patch·지난 검수판)
  → `docs/_archive/` 로 보낸다. **거기 들어가면 `archive-guard` 가 막는다**(창업자 허락 때만 열림).

📌 **왜 이 규칙이 생겼나 (2026-08-15)** — `레시피-정리-초안-2026-08-10.json` 이 여기 있었다.
   반영은 «코드»에 끝났는데 이 파일은 8/10 상태로 얼어 있었고, 나는 그걸 보고
   **「창업자 확인을 못 받은 여섯 자리가 있다」** 고 잘못 보고했다(전부 이미 반영돼 있었다).
   ⭐ 뿌리 = **「대기」라는 이름이 「아직 안 한 것」으로 읽힌다.** 그런데 안엔 «끝난 재료»가 섞여 있었다.
