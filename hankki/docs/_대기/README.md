# `_대기/` — 창업자 확인 전이라 **아직 앱에 안 올린** 변경분

> ⚠️ 여기 있는 `.patch`는 **적용하면 안 되는 게 아니라, 아직 적용 안 한 것**이다.
> 우리 구조상 배포 브랜치에 `hankki/**`를 푸시하면 **곧바로 배포**된다(규칙 9).
> 그래서 창업자가 "배포해 / ㄱㄱ / 픽스" 하기 전엔 앱 코드를 커밋·푸시하지 않는데,
> 그러면 **컨테이너가 날아갈 때 작업이 통째로 사라진다.**
> → 코드 변경분을 patch로 떠서 문서 폴더에 보관한다. 문서 저장은 배포와 무관.

## 적용법

```bash
cd hankki && git apply docs/_대기/<파일>.patch
```

패치가 안 맞으면(그 사이 파일이 바뀌었으면) `git apply --3way` 로.
**적용해서 배포까지 끝났으면 그 patch는 지운다.**

## 목록

### `레꾸자랑-뒤로가기-2026-07-29.patch` — 창업자 확인 대기

**증상** (창업자 제보): "레꾸자랑 끝내고 뒤로가기하면 바로 홈으로 가. 레꾸자랑 추가하려면 또 이동해야 함."

**원인**: `BragScreen`만 `useLayerBack`을 안 쓴다. 다른 화면·시트 **18개는 전부** 쓰는데
v8.53에서 이 탭을 새로 만들 때 빠졌다. 같은 카드 모달을 쓰는 `RecipeDetailScreen`은 제대로 쓰고 있다.
→ 시트·모달이 히스토리 칸을 안 쌓아서, 뒤로가기가 모달을 건너뛰고 App 의 "탭≠홈 → 홈으로" 규칙에
곧바로 떨어진다 = **한 번에 카드도 닫히고 홈으로도 튕긴다.**

**수정**: 2줄
```js
useLayerBack(!!pick,  () => setPick(null))    // 선택 시트
useLayerBack(!!share, () => setShare(null))   // 카드 모달
```

**검증 (재현 스크립트 `hankki/_bk.mjs` 전후 비교)**

| 카드 모달 열기 | history 4 (안 쌓임) | history 6 ✅ |
| **뒤로가기 1번** | **탭=홈** ❌ | **탭=레꾸자랑** ✅ |
| 뒤로가기 2·3번 | — | 홈 → 종료 확인 (정상) |
