# `_대기/` — 창업자 확인 전이라 **아직 앱에 안 올린** 변경분

> ⚠️ 여기 있는 `.patch`는 **적용하면 안 되는 게 아니라, 아직 적용 안 한 것**이다.
> 우리 구조상 배포 브랜치에 `hankki/**`를 푸시하면 **곧바로 배포**된다(규칙 9).
> 그래서 창업자가 "배포해 / ㄱㄱ / 픽스" 하기 전엔 앱 코드를 커밋·푸시하지 않는데,
> 그러면 **컨테이너가 날아갈 때 작업이 통째로 사라진다.**
> → 코드 변경분을 patch로 떠서 문서 폴더에 보관한다. 문서 저장은 배포와 무관.

## 적용법

```bash
cd hankki && git apply docs/_대기/<파일>.patch
```

패치가 안 맞으면(그 사이 파일이 바뀌었으면) `git apply --3way` 로.
**적용해서 배포까지 끝났으면 그 patch는 지운다.**
