## ⏱ 따라만 하면 되는 순서 (폼 하나에 5분 · 2026-07-31 추가)

> 창업자 *"한끼연구소 구글폼도 까먹은거 같고.."* → **문항은 아래에 다 써놨다. 만드는 순서만 없었다.**

1. **`forms.google.com`** 접속 → ⚠️**초록 "한끼"(안녕한끼) 계정**인지 먼저 확인 (의견 폼이 거기 있다)
2. **`+ 빈 양식`** 누르기
3. 아래 **② 설문 폼** 칸의 **제목 → 설명 → 문1 → 문2 → 문3** 을 **위에서부터 그대로 복붙**
   - 문항 종류(객관식/장문)는 각 문항 오른쪽 드롭다운에서 고른다
   - `필수` 표시된 것만 오른쪽 아래 **필수 토글 ON**
4. 오른쪽 위 **⚙️ 설정** → **`이메일 주소 수집` = 수집 안 함** ⚠️**이거 안 하면 약속이 깨진다**
   - 같은 화면에서 `응답 사본 보내기` = **안 함**, `로그인 필요` = **끔**
5. 오른쪽 위 **보내기 → 🔗(링크) → 링크 복사**
6. **③ 오류 폼**도 2~5번 똑같이 한 번 더
7. 나온 주소 **2개를 나한테 붙여넣기** → 내가 앱에 넣고 배포하면 그 순간 칸이 생긴다

💡 **한 번에 다 안 해도 된다.** 하나만 만들어 줘도 그 칸부터 켜진다.
💡 **문3 자동 버전 채우기**(아래 ⭐ 절)는 **안 해도 된다** — 안 하면 유저가 직접 적는 것뿐이다.

## ⚠️ 세 폼 공통 설정 — 이거 안 하면 약속이 깨진다
1. **설정 → 응답 → `이메일 주소 수집` = 수집 안 함**
   `public/privacy.html` 에 *"개인정보를 수집·저장·전송하지 않습니다"* 라고 써놨고 Play 데이터 보안 신고도
   **'수집 안 함'** 으로 이미 제출했다. 폼이 이메일을 모으면 그 약속이 깨진다.
   (⛔ 로그인 필수 · ⛔ 이메일 필수 항목 · ⛔ "연락처 남겨주세요" 금지)
2. **로그인 없이 아무나 답할 수 있게** (조직 제한 끄기)
3. **필수 항목은 하나만** — 나머지는 다 선택. 필수가 많으면 안 낸다.
4. 설정 → **응답 사본 받기 = 안 함** (유저에게 메일을 보내려면 이메일이 필요해진다)
5. 폼 제목·설명에 **답장을 약속하지 않는다.** "읽고 있어요" 까지만.
   (`docs/리텐션-설계원칙-2026-07-30.md` — 주기·답장 약속 금지)

## ③ 오류 폼 — "안 되는 것 알려주기"

**폼 제목**
```
한끼 · 안 되는 것 알려주기
```
**폼 설명**
```
불편하게 해서 미안해요. 어디서 어떻게 안 됐는지만 알려주시면 고쳐요.
```

**문1 (필수 · 단답)** — `어디서 그랬어요?`
```
예: 레시피 꾸미기 / 사진으로 가져오기 / 장보기
```
**문2 (필수 · 장문)** — `어떻게 하면 그렇게 돼요?`
```
"이걸 누르니까 이렇게 됐어요" 정도면 충분해요.
```
**문3 (선택 · 단답)** — `앱 버전`
```
설정 맨 아래에 적혀 있어요
```
⛔ **「화면 사진」 칸은 없앴다** (창업자 2026-07-31 *"사진을 안보내는게 저건 왜 물어봐?"* — **맞는 지적**)
   원래 이 문서엔 *"장문으로 두고 «사진은 안 보내셔도 돼요» 라고 쓰자"* 는 절충안이 적혀 있었는데,
   **글 쓰는 칸엔 사진을 붙일 방법이 아예 없다.** 넣을 수 없는 걸 물어보는 칸이었다.
   ⚠️ 파일 업로드로 만들면 **구글 로그인이 강제되어 익명이 깨진다** → 그래서 켤 수도 없다.
   📌 **오류 신고는 짜증 난 상태에서 쓰는 거라 짧을수록 실제로 낸다.** 3문항으로 끝낸다.
   📌 교훈 = **어정쩡한 절충안은 답이 아니다.** 못 하는 거면 칸을 없앤다.

### ⭐ 문3(앱 버전)을 자동으로 채우는 법 — 유저가 안 적어도 되게
1. 폼 편집 화면 오른쪽 위 **⋮ → `미리 채워진 링크 가져오기`**
2. **앱 버전 칸에 `__VER__` 라고 입력**하고 나머지는 비운 채 **링크 가져오기**
3. 나온 주소를 그대로 나한테 주면 된다 → 앱이 열 때 `__VER__` 를 **지금 버전(`v9.02` 같은)** 으로 바꿔서 연다
   (`LabSheet.jsx` 가 처리. 안 해도 되고, 안 하면 유저가 직접 적는다)
