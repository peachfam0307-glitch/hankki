# 대기 — 아바타에 우리 5인 넣기 (#74) · 2026-07-29 KST

## 뭘 했나
프로필 아이콘 고르는 곳(설정 → 아바타)에 **「우리 애들」 그룹을 맨 위**에 신설.
꼬르곰 · 펭펭 · 카롱 · 모아 · 꼬비 5명 전부.

- 소스 = 창업자가 준 `⭐정본-5인-얼굴.png`(1536×1024)
- 낱개 = `docs/stickers/캐릭터-세계관-확장-2507/5인-라인업-확정-2507/낱개-얼굴/av_*.png`
- 앱 사본 = `src/assets/avatars/av_*.png` (patch엔 안 들어감 — **낱개-얼굴/ 에서 복사하면 된다**)
- 코드 = `src/components/Buddies.jsx` (patch 파일)

## 왜 얼굴 컷인가 (전신·상반신이 아니라)
아바타 자리는 **설정 56px · 홈 상단바 32px**이다.
상반신을 넣으면 그 안에서 얼굴이 12~14px밖에 안 돼 **누가 누군지 구분이 안 된다.**
얼굴 컷은 56px에서도 다섯이 다 구분된다(검증 스크린샷으로 확인).

## 자를 때 쓴 방법
동그란 아바타에서 **귀·모자·리본이 잘리지 않게 외접원 기준**으로 잘랐다 —
머리의 중심에서 가장 먼 불투명 픽셀까지 거리를 재고 **+10% 여유**를 준 정사각으로 크롭.
그래서 원형 마스크를 씌워도 안 잘린다(실제 렌더로 확인).

## 검수 (`docs/스티커-검수-절대원칙.md` 5가지)
| | 결과 |
|---|---|
| ①투명판 | 통과 — 체커보드 렌더, 배경 자국 없음 (알파 0~255) |
| ②잘림 | 통과 — 테두리 1px 불투명 픽셀 **0개** / 자동 컷에서 버린 조각 최대 23px(안티에일리어싱뿐) |
| ③해상도 | 통과 — 소스 334~555px vs 표시 56px = **6~10배 축소** |

| ⑤앱 렌더 | 통과 — `_av.mjs`: 그룹 라벨 노출 · 이름표 5개 다 뜸 · 깨진 이미지 0 · **pageerror 0** · 꼬르곰 고르면 홈 상단바까지 반영 |

`npm run build` + `npm run smoke`(해상도·카드제목·링크·파서·e2e) **전부 통과.**
