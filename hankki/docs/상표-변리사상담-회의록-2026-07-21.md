## 안건 1. 상표권 등록 가능성 및 전략

**1-1. 기존 '한끼' 상표와의 유사성·거절 가능성**
- 동일/유사 명칭 선등록 상표가 있을 수 있음 → 출원 전 **선행상표 조사** 필수.
- 단순 문자상표만으론 차별화 어려워 거절 위험 → 추가 전략 필요.
- *(우리 조회로 이미 예비확인: 오팬=전자서적 G5206 ≠ 우리 앱 G390802 → 유사군 다름)*

**1-2. 캐릭터 결합 디자인으로 식별력 ↑ (반복 강조된 핵심)**
- 문자만으론 식별력 약함 → **독창 캐릭터 결합 시 시각적 차별화 → 식별력 크게 향상.**
- 캐릭터 결합하면 문자 요소 같아도 전체 외관·개념이 달라져 유사판단에서 유리.

**1-3. 유사군 코드 상품분류 전략**
- 레시피 앱 = 09류 SW(+필요시 42류 서비스). 캐릭터 상품화 대비 부가분류(문구·잡화·의류=16·25류 등)까지 폭넓게 검토.
- 지정상품 범위 설정에 따라 충돌·등록 가능성 달라짐 → 사업확장(굿즈·라이선싱) 고려한 사전 분류.

**1-4. 등록 후 실사용 + 불사용 취소심판 리스크**
- 상표는 등록만으로 끝 아님 → **지정상품에 실제 사용**이 중요.
- 정당한 이유 없이 **3년 이상 미사용** 시 제3자가 취소심판 청구 가능 → 사용 증빙(앱 노출·마케팅·매출·날짜) 지속 관리.

**⇒ 결론: 독창적 캐릭터+디자인 결합해 식별력 확보하면 상표 등록 가능성 있음.**

**체크포인트**: ①한끼·유사명 선행상표 조사(KIPRIS) ②캐릭터+문자 결합상표 출원 검토 ③굿즈·라이선싱 대비 유사군 폭넓게 ④등록 후 사용 증빙 정기 보관.

## 안건 2. AI 생성 캐릭터의 저작권·디자인권

**2-1. AI 생성물 자체 저작권**
- 인간 창작 기여 없으면 저작물 인정 어려움(저작권=인간의 창작적 표현 보호). AI 초안 단독은 등록·침해주장 근거로 약함.
- **인간이 창작적으로 수정·편집한 부분**이 있어야 보호 여지 생김.

**2-2. 인간 창작 기여 증빙 관리**
- AI 초안 이후 **레이어별 수정 작업물 보관** 권장.
- 색보정·선 다듬기·구도 변경·디테일 추가 등 **단계별 수정 기록을 시간순**으로 → 창작 개입 입증 근거.
- 레이어 파일·버전별 저장·수정 전후 비교 = 분쟁·등록심사 시 창작성 소명 핵심 증거.

**2-3. 디자인권으로 캐릭터 별도 보호**
- 상표권(브랜드 식별력) vs 디자인권(형상·모양·색채) = 보호대상·요건 다름 → **병행 확보 전략** 유효.
- 디자인권도 창작성·신규성 요구 → 2-2 수정기록이 디자인권 확보에도 활용.

**⇒ 결론: AI 초안 바탕으로 직접 수정·편집한 과정을 기록해 증빙 자료로 활용.**

**체크포인트**: ①AI 초안·최종본 구분 보관 ②레이어 병합 말고 단계별 파일 저장 ③수정일자·내용·작업자 로그 작성 ④최종 디자인 확정 시 디자인권 출원(상표와 함께/순차).
