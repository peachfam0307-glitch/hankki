## ⛔ 오늘 밟은 함정 (다시 밟지 말 것)

1. **`deviceScaleFactor` ＋ `recordVideo.size`** 를 다르게 주면 **녹화가 잘린다**(왼쪽 위만 앱, 나머지 회색)
2. 장면마다 **`page.goto`** 하면 흰 화면이 번쩍인다 → 탭·뒤로가기로만 옮긴다
3. **`boundingBox()` 는 타임아웃 옵션이 없다** — 없는 요소를 30초씩 기다려 한 판이 211초가 됐다
4. **커서가 0×0** — 앱 CSS `img{max-width:100%}` 가 부모(width:0)에 걸려 깎았다 → `max-width:none` 못 박기
5. **템플릿 문자열 안 주석에 백틱** 쓰면 문자열이 끊겨 죽는다(CLAUDE.md 에 이미 적힌 함정)
6. 레꾸에서 **「취소」** 를 누르면 *"저장하고 나가기…"* 를 한 번 더 묻는다 → **뒤로가기**는 안 묻는다(`DecorEditor.jsx:516`)
7. **내가 만든 자동 검사가 틀렸다** — 하단바의 파란 아이콘을 「타이머 막대」로 셌다. 실물 프레임을 열어봐야 안다(규칙 21)
