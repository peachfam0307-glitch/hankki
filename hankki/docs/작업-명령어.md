# 한끼 작업 명령어 (지시어)

> 창업자가 이 단어를 말하면 클로드가 정해진 절차를 실행한다. **언제든 "명령어"라고 하면 이 목록을 보여준다.**
> 확정 10개. 필요하면 추가·수정.

---

## ✅ 확정 명령어 (10)

| # | 명령어 | 하는 일 |
|---|---|---|
| 1 | **doc저장** | 복기 → 검토 → 수정 → 정리 → 문서 저장 → 창업자에게 보여주기 |
| 2 | **점검** (전수점검) | 빌드 오류 + 주요 화면 런타임 스모크 + 버그 사냥 → 요약 보고 |
| 3 | **청소** | 죽은 코드·미사용 import·찌꺼기 파일 정리 후 빌드 확인·커밋 |
| 4 | **배포확인** | 방금 푸시가 실제 배포됐는지(GitHub Actions→Pages) 확인, 실패 시 원인 |
| 5 | **복기** | 저장 없이 지금까지 한 것만 요약 보고 |
| 6 | **아카이브** | 기능-아카이브 내용을 채팅에 요약해 보여줌(필요시 최신화) |
| 7 | **릴리즈** (배포) | 버전↑ → 빌드 → 커밋 → 푸시 (기능 완성 시 표준 출고) |
| 8 | **마무리** (쉬자) | 세션 정리: 남은 변경 커밋·푸시 + 문서 최신화 + 요약 + 대기 항목 |
| 9 | **문구점검** | 오타·맞춤법·톤(과장 말투) 전수 점검 후 수정 |
| 10 | **스샷** | 특정 화면 렌더 캡처해서 보여주기(디자인 확인용) |

> 부가: **"명령어"** = 이 목록 보여주기.
