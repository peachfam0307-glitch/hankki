# 한끼 작업 명령어 (지시어)

> 창업자가 이 단어를 말하면(또는 `/명령어`로) 클로드가 정해진 절차를 실행한다.
> 언제든 **`명령어`** 라고 하면 이 목록을 보여준다. (파일: `.claude/commands/*.md` — `/명령어`가 폴더를 자동 스캔)
>
> 📁 명령 파일 위치: `hankki/.claude/commands/`. 레포 루트(`.claude/commands`)에 심링크가 있어 `/`로도 로드된다.
> 🧹 **2026-07-26 정리**: 21개 → **18개** (중복 통합). 아래 "정리 내역" 참고.

## ✅ 명령어 18개 (그룹별)

각 명령어는 **한 단어**만 말해도 아래 절차가 그대로 실행된다. 전부 반말·한국어.

### 🌅 시작 · 마감 · 저장
| 명령 | 하는 일 |
|---|---|
| `안녕` | 새 세션 인사 — `CLAUDE.md`·`docs`·스티커 인덱스를 **먼저 자동으로 읽고** 현황 파악 후 반갑게 브리핑. (시작 = 안녕) |
| `복기` | 저장 없이, 지금까지 한 것만 **빠짐없이** 읽어 요약 보고. |
| `정리` | 작업 도중 아무 때나 **중간 정리** — 결정·자산·바뀐 것 정돈 + 문서 최신화 + 커밋·푸시 + 대기 항목 짚기. |
| `잘자` | 하루 마감 **풀 시퀀스** — 전체복기 → 정리 → 점검 → 청소 → 아카이브저장 → doc저장 (전부 커밋·푸시) + 굿나잇. |
| `doc저장` | 지금까지 작업을 복기→검토→정리해 **문서로 저장**(덮어쓰기 금지, `-2`·`-3`…) → 보여주기. |

### 🔍 품질 · 점검
| 명령 | 하는 일 |
|---|---|
| `점검` | 빌드 오류 + 주요 화면 **런타임 스모크 테스트** + 버그 사냥 → 요약 보고. *(CI 자동판 = `scripts/smoke.mjs`, v8.69부터 배포 전 자동 실행)* |
| `청소` | 죽은 코드·안 쓰는 import·찌꺼기 파일 정리 → 빌드 확인 → 커밋. |
| `문구점검` | 오타·맞춤법·톤(과장된 말투) 전수 점검 후 수정. |
| `배포확인` | 방금 푸시가 실제로 배포됐는지(GitHub Actions → Pages) 확인, 실패 시 원인까지. |

### 📋 할일 · 출고
| 명령 | 하는 일 |
|---|---|
| `할일` | 지금 기준 **오늘 할 일**을 우선순위로 (🔴지금/🎨병행/🔴출시게이트/🟢선점/✅완료/🔵나중). 전체 백로그 다 훑어서, "오늘 딱 하나"까지. 창업자 할 일 vs 클로드 할 일 구분. |
| `릴리즈` | 버전 올림 → 빌드 → 커밋 → 푸시 (기능 완성 시 표준 출고 절차). |
| `확정` | 지금 보는 산출물(로고·이미지·문구·화면)을 **확정본으로 명시적 교체**. 이전 확정본은 **절대 지우지 않고** 새 이름으로 보존. 창업자가 `확정`이라 말하기 전엔 확정본을 건드리지 않는다. |

### 📸 참고 · 소환
| 명령 | 하는 일 |
|---|---|
| `스샷` | 특정 화면을 렌더·캡처해서 보여줌(디자인 확인용). |
| `아카이브` | 기능-아카이브 문서 내용을 채팅에 요약(필요하면 최신화). |
| `메모` | `CLAUDE.md`의 **📌 고정 메모(핀)** 소환 — 출시 일정 D-day·버전·링크. |
| `업뎃테스트` | 최근 업뎃 기준, 창업자가 폰에서 직접 확인할 **테스트 체크리스트**. |
| `필살` | 꾸미기 **필살기** 방향 소환(본체=곰펭 스티커·확산=프레임·양념=효과·다음 순서). 기준: `docs/꾸미기-필살기-2026-07-18.md`. |

### 🧭 메타

|---|---|
| `명령어` | 이 목록 전체를 보여줌 (`.claude/commands/` 폴더를 자동 스캔). |

## 🧹 2026-07-26 정리 내역 (21 → 18)
- **시작류 3→1**: `시작`·`docs읽고시작` 삭제 → **`안녕`** 이 다 함(문서 읽기+인사).
- **할일류 2→1**: `리스트업` 삭제 → **`할일`** 이 상위호환(전체 백로그·우선순위·오늘 하나).
- **마감류 정돈**: `마무리` 삭제 → 가벼운 중간정리는 **`정리`**, 하루 마감 풀세트는 **`잘자`** 로 이원화.
- **`필살` 파일 신규 생성**: 마스터 문서엔 있었는데 파일이 없던 것 → `.claude/commands/필살.md` 추가.
- 결과: 파일 18개 = 이 문서 18개 **1:1 일치**.
