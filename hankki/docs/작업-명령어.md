# 한끼 작업 명령어 (지시어)

> 효율적으로 일하기 위해 정한 짧은 명령어. 창업자가 이 단어를 말하면 클로드가 정해진 절차를 실행한다.
> 새 명령어가 필요하면 추가한다.

---

## 📌 확정 명령어

### `doc저장`
지금까지 한 내용을 **복기 → 검토 → 수정 → 정리 → 문서 저장 → 창업자에게 보여주기**.
- 복기: 이번 세션/구간에 무엇을 했는지 훑음
- 검토: 빠진 것·틀린 것·미완 없는지 확인
- 수정: 발견 시 바로 고침
- 정리: 아카이브·로드맵 등 해당 문서에 반영
- 보여주기: 저장한 요약을 채팅에 정리해 보고

### `점검` (또는 `전수점검`)
앱이 제대로 도는지 **전수 품질 점검**.
- 빌드·정적 오류 확인 (`npm run build`)
- 주요 화면 런타임 스모크 테스트(Playwright로 홈·레시피·장보기·상세·요리모드 등)
- 최근 변경 관련 버그 사냥 + 발견 시 수정·재검증
- 결과를 요약 보고(문제 없으면 "이상 무", 있으면 목록+수정)

### `청소` (또는 `정리찌꺼기`)
**죽은 코드·찌꺼기 파일 정리**.
- 미사용 컴포넌트·함수·import 스캔·삭제
- 안 쓰는 파일(임시·중복) 정리
- 삭제 후 빌드로 안전 확인. 커밋

### `배포확인`
방금 푸시가 **실제 배포됐는지** 확인(GitHub Actions → Pages). 실패 시 원인 보고.

### `복기`
저장 없이 **지금까지 한 것만 요약**해서 보고(가벼운 리캡).

### `아카이브`
`기능-아카이브.md` 내용을 **채팅에 요약**해서 보여줌(파일 안 열어도 됨). 필요하면 최신화.

### `릴리즈` (또는 `배포`)
표준 출고 절차: **버전 올리기 → 빌드 → 커밋 → 푸시**. (기능 완성 시)

### `마무리` (또는 `쉬자`)
세션 정리: 남은 변경 커밋·푸시 + 관련 문서 최신화 + 오늘 요약 + 대기 항목 정리.

## 🧭 판단 관련 (참고)
- 큰 결정은 **`결정-원칙.md`** 기준으로 클로드가 판단, 애매한 갈림길만 확인.
- 레시피 관련은 **`레시피-작성-규격.md`** 따름.

## ➕ 추가하면 좋을 후보 (창업자 골라서 확정)
- `문구점검` — 오타·맞춤법·톤(과장 말투) 전수 점검
- `스샷` — 특정 화면 렌더 캡처해서 보여주기(디자인 확인용)
- `되돌려` — 방금 변경 되돌리기(직전 커밋 revert)
- `제철` — 지금 달 기준 제철 재료·레시피 제안
- `수익체크` — 제휴/수익 동선 점검(파트너스 링크 등)

> 필요 없다 싶은 건 빼고, 원하는 것만 확정하면 그걸로 굳힌다.
