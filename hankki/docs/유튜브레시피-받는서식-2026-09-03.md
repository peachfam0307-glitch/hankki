## 0️⃣ 왜 이 서식이 필요한가 — 한 줄

⭐⭐ **그런데 그 「본다」를 클로드가 못 한다** — 유튜브가 이 컨테이너에서 막혀 있다(EGRESS_BLOCKED · 실측).

## 1️⃣ 📝 채우는 칸 — **한 편에 이만큼**

⭐ 굵은 것 **넷만 꼭** 채우면 된다. 나머지는 비워도 내가 채운다.

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 영상주소   https://www.youtube.com/watch?v=????
■ 채널이름   일등감의 쉬운 레시피
■ 제목       감자채전
■ 시간       5      (분 · 숫자만)

  인분       2      (모르면 비움)
  난이도     쉬움 / 보통 / 어려움   (모르면 비움)

■ 재료
   감자 큰 것 2~3개
   모짜렐라 치즈 1~2줌
   체다치즈 1~2줌
   감자전분 듬뿍 1큰술
   소금 적당량
   후추 적당량

■ 순서
   1. 팬 위에 감자를 채 썰어요.
   2. 나머지 재료를 모두 올리고 골고루 섞어 동그란 모양을 잡아요.
   3. 올리브오일을 두르고 앞뒤로 노릇하게 부쳐 완성해요.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 칸 설명 (짧게)
| 칸 | 어떻게 | 왜 |
|---|---|---|
| **영상주소** | 주소창 그대로. `youtu.be/…` 도 된다 | 이게 있어야 ▶ 표·「영상」 칩·플레이어가 붙는다 |
| **채널이름** | 화면에 보이는 채널명 **그대로** | ⭐⭐ **출처 표시 = 창업자 확정의 «절반»이다. 비우면 안 된다** (`sourceName`) |
| **제목** | ⭐ **영상 제목을 그대로 쓰지 말고 요리 이름으로** | 「감튀보다 맛있어! 원팬 5분컷」 = **광고 문구**다. v12.34 가 고친 그 자리 |
| **시간** | 숫자만(분) | 목록에 「5분」으로 뜬다 |
| **재료** | 한 줄에 하나 · **이름 + 분량** | 「감자 큰 것 2~3개」처럼 붙여 쓴다 |
| **순서** | 한 줄에 한 걸음 | ⛔말투는 내가 앱 말투로 맞춘다 |

## 2️⃣ ⛔⛔ 채울 때 «하면 안 되는» 것 — 이게 서식의 핵심이다

1. ⛔⛔ **원문(자막·설명란)을 «저장소·커밋·문서·앱»에 남기지 않는다.**
   ✅ **창업자가 채팅에 붙여 주는 것은 된다** — 나는 읽고 **재료·분량·순서만 뽑아 우리 문장으로** 쓴다.
   ⭐⭐ **여기가 진짜 선이다** — 우리 저장소는 **public** 이라, 원문이 새면 **그건 실제로 남는 흔적**이다.
   📮 창업자 = *"내가 손으로 쓴지 뭐 어떻게 찾아낼건데"* — **맞다. 결과물로는 아무도 못 찾는다.**
   　 찾을 수 있는 건 **원문이 저장소에 남았을 때**뿐이다. 그래서 막는 건 **저장 한 곳**이면 된다.
2. ⛔ **말·설명·비유를 옮기지 않는다.** 옮기는 건 **재료·분량·순서**뿐이다.
   (「이게 진짜 미쳤어요」 같은 표현은 그 사람 것이다)
3. ⛔ **영상 제목을 제목 칸에 그대로 넣지 않는다** — 광고 문구가 들어온다.
4. ⛔ **조회수는 안 적는다** — ✅ **창업자 확정 2026-09-03 = *"조회수 나도 굳이..야"***
   📌 이유 = 영상 페이지를 봐야 아는 숫자라 **손으로 적어야 하고 반드시 낡는다.**
   ⛔ 다시 꺼내지 말 것.
5. ⛔ **채널명을 유튜브 API 로 받아오지 않는다**(III.E.4 derived data) — **손으로 적는다.**
6. ⛔ **「○○○ 표 레시피」로 우리를 팔지 않는다** — 출처 표시는 되지만 홍보로 쓰는 건 다른 문제다
   (퍼블리시티권 · ⛔확인 안 됐다).

## 3️⃣ 🤖 클로드가 «묻지 않고» 채우는 칸

⛔ 창업자에게 다시 안 묻는다. 아래는 내가 정한다.

| 칸 | 어떻게 정하나 |
|---|---|
| `id` | `basic-<영문>` |
| `icon` | 우리 음식 컷에서 고른다 (⛔없으면 「없다」고 말하고 새로 안 지어낸다) |
| `category` · `folder` | 한식/양식/… 우리 갈래 그대로 |
| `tags` | 재료·상황에서 뽑는다 |
| `from` | ⛔⛔ **열릴 날짜는 내가 «절대» 안 정한다**(규칙 11 · 절대원칙 28) — 창업자가 정한다 |
| `sourceUrl` · `sourceName` | 위 서식의 영상주소·채널이름 그대로 |
