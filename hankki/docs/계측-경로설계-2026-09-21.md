## 1. 🗺 경로 전부 — 사람이 지나는 길

```
① 밖        광고 → 받기 페이지 → 스토어
② 입구      설치 → 첫 실행 → 소개 → 로그인
③ 안        홈 → 레시피 보기 → 레꾸 → 요리 → 일기 → 장보기
④ 돌아옴    알림 · 재방문
⑤ 돈        쿠팡 · 열쇠 · 결제(아직 안 켬)
```

## 2. 👥 사람 갈래 넷 — 창업자가 짚은 그대로

⭐ **갈래는 «따로 재는 것»이 아니라 위 관문들의 «조합»으로 나온다.** 새 이름을 만들지 않는다.

| 갈래 | 어떻게 가려내나 | 무엇을 알게 되나 |

- 이벤트 이름 **500개 상한** · **40자** 상한
- ⛔ **이름에 «값»을 섞으면 이름 수가 터진다** (`product_view_12345` 같은 꼴)

⛔ **우리도 이미 그 꼴이 하나 있다** = `foodcost_shop_open_<가게아이디>`.

✅ **규칙 넷**
1. **관문 이름은 고정** — 값을 이름에 안 섞는다

## 8. 🔁 세 각도 (절대원칙 33)

**1차 · 사람** — 갤럭시 새 사람 · 아이폰 새 사람 · 웹으로 직접 온 사람 · 기존 사람 넷을 세워 따라가니
입구 세 칸이 비었고, **기존 사람은 게이트가 안 떠서 `first_open` 뺄셈이 틀린다**(`App.jsx:113`).
＋ 레꾸자랑에서 **고르고 돌아선 사람**이 안 보인다 → `brag_pick` 을 더한다.

**2차 · 사고** — 일부러 잘못 굴리니
ⓐ §0 의 이름 겹침 — `catch` 가 삼켜 **몇 주 동안 아무도 몰랐다**
ⓑ `행동보내기` 는 gtag 가 없으면 **버린다**(`stats.js:560`). 소개·로그인은 **앱 켜자마자**라 그냥 쓰면 샌다.
　 그렇다고 `보내기()` 를 쓰면 「못보낸화면」 한 칸을 덮어 **첫 화면 기록이 사라진다**(`stats.js:365` · 9/12 사고 자리).
　 ✅ 그래서 **아이폰(직접모드)은 즉시 나가고, 갤럭시는 gtag 가 붙은 뒤로 미루는 작은 칸**이 따로 필요하다.
ⓒ 탈출구는 아이폰에 없다 → `gate_escape` 0 이 정상. 장부에 적지 않으면 「안 샜다」로 오해한다.

**3차 · 규모** — 관문 16개 × 하루 새 사람 10명 ＝ 160건/일. 1만 명이면 **16만 건/일**.
이름은 44종이라 상한 500 에서 멀다. ⛔ 다만 **이름에 값을 섞으면** 그 자리가 먼저 터진다
(`foodcost_shop_open_<id>` 가 이미 그 꼴이다).
＋ 조회수 섞임이 16개만큼 더 심해진다 → §7 ①.

## 9. 💔 실패의 모양 (절대원칙 34)

| | |
|---|---|
| **지금** | 새 사람이 어디서 돌아섰는지 모른다. 뺄셈으로 짐작하고 「안 했다」와 「못 했다」를 못 가른다. 자랑은 0으로 보여서 「인기가 없다」로 읽는다. 알림 효과를 못 잰다. **→ 고칠 데를 못 정하고 광고비만 쓴다** |
| **고친 뒤** | 관문마다 숫자가 남는다. 못 재는 건 둘뿐이고(스토어 안 · 쿠팡 구매) **둘 다 「우리가 못 잰다」고 적혀 있다.** 대신 조회수가 더 섞여서 장부에 가르는 법을 같이 적어야 한다 |

⭐ **모양이 바뀐 자리** = 「숫자가 없다」 → 「숫자가 있고, 없는 것은 없다고 적혀 있다」.
⛔ 숫자를 늘린 게 아니라 **「모른다」를 없앤 것**이다.

## 9.5 🔬 **«눌러서» 잰 실측** (2026-09-21 · `scripts/_판-관문전수-0921.mjs` · 같은 길 3판)

⛔ 위 §3 표는 **코드를 읽어서** 만든 것이다. 그런데 레꾸자랑 버그(§0)가 보여주듯
　 **코드에 호출이 있어도 실제로는 안 나갈 수 있다.** 그래서 앱을 띄워 «눌러» 다시 쟀다.

📮 창업자 = *"주부의 장바구니도 몇명이 눌러봤는지 사러가기 눌러본 사람은 몇명인지"*
　 → **사러가기는 세는데 «펼친 사람»을 안 센다.** 그래서 **「본 사람 중 몇 %가 눌렀나」가 안 나온다.**
　 ＝ 「이 기능을 살릴까 없앨까」를 판단할 값이 **딱 그 한 칸 때문에** 안 나온다.

### 🩹 판이 «세 번» 고장 났고, 그때마다 「앱이 안 센다」로 보였다

| 내 고장 | 어떻게 보였나 |
|---|---|
| 브라우저 안 함수에서 Node 변수를 썼다 | 모든 걸음 «관문 0개» |
| 코치마크를 안 껐다(화면 전체를 덮는다 · `inset:0` · `z-index:500`) | 모든 걸음 «못 눌렀다» |
| 앱이 자기 `gtag` 로 덮어쓰는 걸 몰랐다(`stats.js:267`) | 눌렸는데 «관문 0개» |

⭐⭐ **셋 다 «오류를 삼켜서» 몰랐다.** §0 의 레꾸자랑 버그와 **뿌리가 같다.**
　 ✅ 그래서 판에 **자기 점검**을 박았다 — 가로채기가 안 깔렸거나 화면이 안 뜨면 **스스로 죽는다.**
　 ⛔ 그전엔 `catch {}` 로 삼켰다. **조용히 실패하는 판은 없는 판이다.**
