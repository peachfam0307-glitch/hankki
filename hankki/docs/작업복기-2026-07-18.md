## 1. 🐻🐧 캐릭터 IP · 카톡 이모티콘 시즌1

- **캐릭터 확정**: 꼬르곰(순둥이 먹보 곰) × 펭펭이(시크 패셔니스타 펭귄) = **F × 쌉T 밈 콤비**.
  - 펭펭이 최종: **트렌치코트 + 일자 단발 + 베레모**, 선글라스는 필요한 컷만. (가죽자켓·은목걸이 폐기 — "건달 느낌")
  - 크기: 펭펭이 = 꼬르곰의 **2/3**(콤비컷 개그 포인트).
- **곰 시각장치 3종 채택**(GPT 제안 검토 후): ① 셰프모자 = 감정 안테나(붕뜸/처짐/삐뚤) ② 나무 숟가락 시그니처 ③ 욕망 입(먹는 컷만). 원칙 = **"기본값 + 상황별 해제"**("항상"의 함정 회피).
- **그림체 확정**: 얇고 끊기지 않는 연속선(손맛 삐뚤 OK, 끊김 금지) · 은은하고 따뜻한 톤(저채도 아님) · 플랫·음영 없음 · 흰 배경 · 글자 없음(후반 합성).
- **시즌1 구성**: 멈춤 32종 = 생활공감 18 + 먹는 상황 8 + 콤비 케미 6. (범용 컷에도 캐릭터 배게, 대표/썸네일엔 개성컷 앞세우기.)
- **📄 지피티 발주서 완성**: `docs/이모티콘-시즌1-발주서.md` — 곰/펭/콤비 프롬프트 3종 + 32컷 포즈 리스트 + 사용법. (창업자가 ChatGPT로 시안 생성 → 클로드 판정·세트구성·자막. 최종은 작가 외주 — 카카오 AI 입점 불허.)

## 2. ⚖️ 상표 전면 재조사 — 결론: **이름 안 바꿔도 됨**

KIPRIS 실검(창업자 직접) + 웹 재검증으로 오늘 확정.

| 이름 | 상태 | 판정 |
|---|---|---|
| **한끼** | 09류에 순수 "한끼" 임자 없음(다 로고·딴말 붙여 공존). 오팬하우스 "한끼"=**전자책(G5206)** → 우리 앱(G390802)과 유사군 다름 | 🟢 **앱 이름 유지 안전** |
| **끼록** | 황태영 등록(09류, **글자만**). 지정상품에 **"핸드폰용 응용소프트웨어(G390802)"** = 우리 앱 칸 직격 | ❌ 사용 불가 |
| **꼬르곰** | KIPRIS 검색결과 **0(완전 비어있음)** | ⭐ **문자+도형 상표로 통째 확보 가능** |
| **한끼유** | 비어있음(조어) | 😆 비상카드(구수 뉴트로 톤) |

- **핵심 배움**: 같은 09류여도 **"지정상품/유사군"이 겹쳐야** 충돌. 한끼(전자책)≠우리(앱SW)라 안전, 끼록(앱SW 동일)이라 막힘.
- **확정 전략**: **앱 이름 "한끼" 유지 + "꼬르곰"(문자) + 곰 그림(도형) 09류 출원** = 얼굴은 한끼, 방패는 꼬르곰 캐릭터. (단어는 원래 방패 못 됨 — 캐릭터가 진짜 해자.)
- **남은 액션(급하지 않음)**: 출시 즈음 무료 변리사 상담 1회로 도장. 선출원주의라 꼬르곰은 원할 때 출원.
- 원본: `docs/상표-확인.md`(재검증·실검 결과 반영), `docs/법적리스크-조사-2026-07-18.md`.
