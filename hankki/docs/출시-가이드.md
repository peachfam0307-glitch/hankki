## 1단계 — PWABuilder로 안드로이드 파일 만들기 (무료)

1. 브라우저에서 **https://www.pwabuilder.com** 접속
2. 가운데 칸에 우리 주소 붙여넣기:
   `https://peachfam0307-glitch.github.io/hankki/`
   → **Start** 클릭
3. 점수 화면이 뜸. 아래 **Package For Stores** 클릭
4. **Android** 카드에서 **Generate Package** 클릭
5. 옵션 창이 뜨면:
   - **App name:** `한끼`
   - **Package ID:** 자동으로 채워진 값 그대로 둬 (⚠️ 한 번 정하면 **영원히 못 바꿈** — 오타만 확인)
   - 나머지는 기본값
   - **Signing key:** "Create new" (새로 만들기) 선택
   - **Download** 클릭
6. zip 파일이 다운로드됨. 압축 풀면 안에:
   - `*.aab` ← Play 스토어에 올릴 **앱 파일**
   - `signing.keystore` + `signing-key-info.txt` ← ⚠️ **절대 잃어버리면 안 됨.**
     앞으로 앱 업데이트할 때마다 필요해. 카톡 내게쓰기·구글드라이브 등 안전한 곳에 백업!
   - `assetlinks.json` ← 2단계에서 쓸 인증 파일

> 💡 여기서 나온 `assetlinks.json` 파일 내용을 나(클로드)한테 붙여넣어 주면, 2단계를 같이 처리해줄게.

## 2단계 — 도메인 인증 (assetlinks.json 올리기)

안드로이드 앱이 "이 웹사이트가 내 앱 맞다"를 증명하는 단계.
이 파일은 주소의 **맨 뿌리**(`peachfam0307-glitch.github.io/.well-known/`)에 있어야 해서,
저장소를 하나 새로 만들어.

1. GitHub에서 **New repository**
2. 이름을 정확히 **`peachfam0307-glitch.github.io`** 로 (본인 아이디 그대로)
   - Public, "Add a README" 체크 → Create
3. 그 저장소에 **`.well-known`** 폴더를 만들고 그 안에 **`assetlinks.json`** 파일 추가
   (PWABuilder zip 안의 그 파일 내용 그대로 붙여넣기)
   - GitHub 웹에서: **Add file → Create new file** → 파일명에 `.well-known/assetlinks.json` 입력하면 폴더가 자동 생성됨
4. Settings → Pages → Branch를 `main`으로 두고 저장 (몇 분 뒤 활성화)
5. 확인: `https://peachfam0307-glitch.github.io/.well-known/assetlinks.json` 열어서 내용이 보이면 성공 ✅

> ⚠️ 이 단계를 안 하면 앱 위에 주소 막대가 뜨는 등 "진짜 앱" 느낌이 안 나. 꼭 하자.

## 3단계 — Google Play Console 등록

1. **https://play.google.com/console** 접속 → 구글 계정 로그인
2. **개발자 등록비 $25** 1회 결제 (평생 1번)
   - 개인/사업자 선택 → 이름·주소·전화 입력
3. **앱 만들기(Create app)**
   - 앱 이름: `한끼`
   - 기본 언어: 한국어
   - 앱/게임: 앱 / 무료
   - 정책 동의 체크
4. 왼쪽 메뉴를 따라 채우기:
   - **앱 콘텐츠(App content):** 개인정보처리방침 URL 입력, 콘텐츠 등급 설문, 데이터 보안(아래 참고), 타겟 연령
   - **스토어 등록정보(Main store listing):** 아래 소개글·그래픽·스크린샷 넣기
   - **프로덕션(Production) → 새 버전 만들기:** 1단계의 `*.aab` 업로드
5. 검토 후 **출시 제출** → 보통 며칠 내 승인

### 데이터 보안(Data safety) 답변 — 우리는 심플해!
- **데이터를 수집/공유하나요? → 아니요 (No)**
- 이유: 한끼는 **모든 데이터를 사용자 폰 안에만 저장**해. 서버 없음, 계정 없음, 수집 없음.
- (백업 파일도 사용자가 직접 저장/공유하는 거라 우리가 가져가는 게 아님)
