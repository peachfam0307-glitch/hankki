한끼는 회원가입·로그인이 없어 별도의 계정을 만들지 않습니다. 앱에서 저장한 데이터(레시피·냉장고·장보기·요리 기록·일기 등)는 사용자 기기에만 저장되며, 앱을 삭제하면 함께 삭제됩니다.

글자 인식(AI 스캔) 기능을 이용한 경우, 무료 이용 횟수 확인을 위한 임의의 기기 식별자가 서버에 저장됩니다. 아래 절차로 삭제를 요청하실 수 있습니다.

2. 삭제되는 데이터

  • 기기에 저장된 데이터 — 레시피·냉장고·장보기·요리 기록·일기·꾸미기·프로필. 앱 삭제 시 함께 삭제됩니다
  • 서버에 저장된 데이터 — 임의의 기기 식별자 및 이용 횟수. 요청 시 즉시 삭제합니다

한끼는 이름·이메일·전화번호·위치 등 개인식별정보를 수집하지 않습니다.

3. 앱에서 직접 삭제

계정이 없으므로 앱 삭제가 곧 전체 데이터 삭제입니다. 보관이 필요한 데이터는 삭제 전 앱의 설정 → 백업에서 파일로 저장해 주세요.

4. 보관 기간

삭제를 요청하지 않으셔도 아래 기간 경과 후 자동으로 삭제됩니다.

  • 사진 — 저장하지 않습니다(글자 인식 후 즉시 폐기)
  • 기기 식별자 및 이용 횟수 — 40일
  • 무료 이용권 잔여 횟수 — 잔여 횟수가 남아 있는 동안 최대 1년
  • 접속 IP — 2분(과도한 요청 방지 목적)

자세한 내용은 개인정보처리방침을 참고해 주세요.

5. 처리 기간

요청 접수 후 지체 없이 처리하며, 10일 이내에 처리 결과를 회신드립니다.
