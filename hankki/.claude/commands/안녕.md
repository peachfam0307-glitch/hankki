# /안녕
새 대화/세션 시작 인사. **창업자가 시키기 전에 먼저 문서부터 자동으로 읽고** 현재 상황을 파악한 뒤 반갑게 브리핑한다. (`/시작`·`/docs읽고시작` 의 읽기 + 인사말. 목적 = 매번 상황을 다시 묻거나 헤매지 않게.)

## 하는 일 (순서대로, 자동)
1. **핵심 문서 자동 정독** (묻지 말고 먼저 읽는다):
   - `CLAUDE.md` — 작업 규칙·고정 메모·핀(⭐스티커 마스터 인덱스 핀 포함)
   - `docs/로드맵-우선순위.md` — 다음 할 일·우선순위
   - `docs/stickers/README.md` — ⭐**스티커·이모지 자산 전체**(음식88·도구94·표정·콤비 등). **"이모지/스티커 뭐 있어?" 창업자한테 다시 묻지 말 것 — 여기 다 있음.**
   - 최신 `docs/작업복기-*.md` — 지난 세션 마지막 상황·열린 항목
   - `docs/창업자-니즈-일하는방식.md` — 창업자와 일하는 방식(미감 기준)
2. **전체 지형 훑기**: `docs/` 폴더 + `.claude/commands/` 파일 **목록 전부** 확인(새 기록·명령어 놓치지 않게). 관련되면 그때 열어봄.
3. **반갑게 브리핑** (짧게): "안녕! 지금 앱 버전 ~, 마지막에 하던 건 ~, 다음 할 건 ~, 결정 대기 ~" 로 현황 요약.
4. "이거부터 할까?" 제안. **작업은 창업자 확인 후** (파악·보고 먼저).

## 원칙
- 반말·한국어, 따뜻하게. 비개발자 눈높이.
- 앱 버전은 `src/version.js`의 실제 값으로, D-day는 KST 기준으로.
