# /업뎃테스트
최근 배포한 변경(오늘 커밋·버전)을 기준으로, **창업자가 폰에서 직접 확인할 항목**만 체크리스트로 정리한다.

## 하는 일
1. 오늘/최근 커밋과 `src/version.js`의 최신 버전을 확인해 **뭐가 바뀌었는지** 추린다.
2. 각 변경마다 **"어디를 눌러 → 뭐가 보이면 정상"** 식으로, 비개발자가 그대로 따라 할 수 있게 쓴다.
3. 맨 위에 **0단계: 앱 완전히 껐다 켜서 최신 버전인지** (설정 맨 아래 버전 = 최신인지) 꼭 넣는다. (안 그러면 옛 화면 보고 "안 바뀌었다" 오해)
4. 체크박스(⬜) 형식으로, 변경별로 묶어서.
5. 각 항목에 "이러면 이상한 거야(=제보해줘)" 한 줄도 붙여 판단 쉽게.

## 원칙
- 반말·한국어. 짧고 명확하게, 실제 탭 순서로.
- 코드 얘기 금지 — 오직 "화면에서 뭐 하면 뭐 보인다".
- 급하지 않은 건 급하지 않다고 표시.
