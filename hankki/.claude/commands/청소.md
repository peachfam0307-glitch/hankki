# /청소
저장소를 깔끔하게 정리한다. **삭제가 아니라 "정리·보관"** (창업자 보존원칙 — 전부 `git mv`로 히스토리 유지).

## 하는 일 (순서대로)
1. **죽은 코드·미사용 import·찌꺼기 파일** 정리 (참조 없는지 확인 후 안전하게).
2. **구버전 문서 보관 (= 최신순으로 쌓이게)** — 같은 계열의 날짜/버전 문서는 **최신 1개만 `docs/` 최상단에 두고**, 지난 것은 `docs/_archive/`(계열별 하위폴더)로 이동.
   - `할일-전체정리-*` → 최신만 위에, 나머지 → `docs/_archive/할일-정리/`
   - `작업복기-*` → 최근 2~3개만 위에, 오래된 것 → `docs/_archive/작업복기/`
   - 기타 `-v8.xx`·날짜 붙은 스냅샷 계열도 동일.
3. **타프로젝트·빌드 잔재 격리** — 한끼와 무관한 파일(다른 앱 코드·엉뚱한 README 등)은 루트 `_archive/타프로젝트-*/`로 이동. (앱을 오염시키는 잔재 제거)
4. **빌드 확인** → 통과하면 **커밋·푸시.**

## 원칙
- 🛟 **삭제 금지 = 보존.** 전부 이동(git mv). 애매하면 창업자에게 확인.
- **최신은 항상 `docs/` 최상단, 구버전은 `docs/_archive/`.** (그래야 "최신순으로 쌓임")
- `/잘자`가 이 청소를 포함 → **매일 밤 `/잘자` 한 번이면 자동으로 최신 유지 + 구버전 보관.**
- 규칙 전문 = `docs/_archive/README.md`.
- 반말·한국어.
