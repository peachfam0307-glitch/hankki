# /docs읽고시작  (짧게: /시작)
일 시작하기 전에 **문서를 먼저 읽고 현재 상황을 파악**한 뒤 움직인다. (엉뚱한 데서 시작하지 않게)

## 읽는 순서
1. **전체 지형 훑기 (빠짐없이)**: `docs/` 폴더와 `.claude/commands/` 폴더의 **파일 목록을 전부** 확인한다(제목만이라도). 어떤 기록이 있는지 하나도 모르는 게 없게 — 새로 생긴 문서도 놓치지 말 것.
2. **항상 정독 (핵심 5)** — 이건 매번 내용까지 꼭 읽는다:
   - `CLAUDE.md` (작업 규칙·고정 메모)
   - `docs/창업자-니즈-일하는방식.md` (창업자와 일하는 방식)
   - `docs/작업-명령어.md` + `.claude/commands/` (지시어 전체)
   - `docs/삽질-리스트-*.md` (같은 실수 반복 금지)
   - `docs/기능-아카이브.md` · `docs/결정-원칙.md` (지나온 결정·이미 정한 것)
3. **상황 파악용 핵심 문서**: `docs/한끼-지식체계.md` · `docs/로드맵-우선순위.md` · `docs/남은-할일-정리-2.md` · `docs/출시-실행-체크리스트.md` · `docs/열린항목-이어서.md` · 최신 `docs/작업복기-*.md`.
4. 1번에서 훑은 나머지 문서는 **지금 할 일과 관련되면 그때 열어본다** (매번 통째로 읽어 낭비하지 말 것).

## 그다음
- 읽고 나서 **지금 상황·남은 할 일·결정 대기·주의점**을 짧게 요약 보고 → "이거부터 할까?" 제안.
- 아직 손대지 말 것. **먼저 파악 → 보고 → 창업자 확인 후** 진행.
- 반말·한국어.
