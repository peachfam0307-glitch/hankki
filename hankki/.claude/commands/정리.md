# /정리
지금까지 한 것을 **중간에 깔끔히 정돈**한다. (하루를 닫는 `/잘자`와 달리, 작업 도중 아무 때나 · 예전 `/마무리` 흡수)
- 대화 훑어 **결정·자산·바뀐 것** 정리 → 관련 문서(`남은-할일-정리-2.md`·`CLAUDE.md`·해당 docs) 최신화.
- **안 커밋된 변경 있으면 커밋·푸시.**
- **대기 중·결정 대기 항목**도 짚어준다(다음에 이어서 시작하기 좋게).
- 저장은 **덮어쓰기 금지**(같은 이름이면 -2,-3…로 보존).
- 끝나면 "뭘 정리했는지" 짧게 보고.
- 반말·한국어.
