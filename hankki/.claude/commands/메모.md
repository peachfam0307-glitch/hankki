# /메모
**📌 고정 메모(핀)** 를 읽어서, 창업자에게 그대로 보기 좋게 보여준다.

## 📄 어디 있나 (2026-09-03 에 자리가 바뀌었다)
```
hankki/docs/고정메모-핀.md      ← 전문(핀 107개). 여기를 읽는다.
hankki/CLAUDE.md 맨 위          ← 색인만(제목 한 줄씩). 뭐가 있는지 훑을 때.
```
⛔ **CLAUDE.md 에서 핀 «본문»을 찾지 말 것** — 거기엔 색인만 있다.
📮 왜 갈랐나 = 창업자 *"도대체 프롬프트창은 왜저렇게 빨리차는거야."*
   핀 절 하나가 **357KB(파일의 77%)** 라 세션이 파일 하나만 열어도 대화 창이 찼다.

## ⛔⛔ 통째로 읽지 말 것 — `고정메모-핀.md` 는 **270KB** 다
`.claude/hooks/bigread-guard.sh` 가 통째로 여는 것을 **막는다**(상한 60KB). 막다른 길이 아니라 **이렇게** 한다:
```
sed -n '1,60p' hankki/CLAUDE.md            # ⭐먼저 색인(핀 107개 제목)을 본다
grep -n "<창업자가 물은 말>" hankki/docs/고정메모-핀.md   # 그 핀이 몇 행인지
sed -n 'A,Bp' hankki/docs/고정메모-핀.md    # 그 핀만 읽는다
```
📌 창업자가 「메모 보여줘」라고만 하면 **색인 ＋ 지금 걸리는 핀 몇 개**를 보여준다.
   107개를 다 펼치면 그것만으로 대화 창이 찬다 — 2026-09-03 에 고친 게 바로 그거다.

## 하는 일
- 대화가 길어져 위로 사라져도, 이 명령어 하나로 언제든 소환하는 용도.
- 최신값 반영: **현재 버전**은 `src/version.js`의 `APP_VERSION`을 확인해 실제 값으로 보여준다.
- 출시 일정은 **오늘 날짜 기준 D-day**(예: "7/31까지 D-13")도 같이 계산해 붙인다.
- 반말·한국어. 스캔 잘 되게 짧게.
- 창업자가 "메모에 ~ 추가/수정해"라고 하면 → **`hankki/docs/고정메모-핀.md`** 를 고쳐서 저장한다.
  ⛔ **CLAUDE.md 로 되돌려 붙이지 말 것.** 핀을 새로 하나 넣으면 CLAUDE.md 의 색인에도 **한 줄만** 더한다.
  🔒 어기면 `scripts/check-docsize.mjs` 가 배포를 막는다(CLAUDE.md 상한 150KB 경고 · 200KB 차단).
