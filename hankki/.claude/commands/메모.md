# /메모
`CLAUDE.md`의 **📌 고정 메모 (핀)** 섹션을 읽어서, 창업자에게 그대로 보기 좋게 보여준다.
- 대화가 길어져 위로 사라져도, 이 명령어 하나로 언제든 소환하는 용도.
- 최신값 반영: **현재 버전**은 `src/version.js`의 `APP_VERSION`을 확인해 실제 값으로 보여준다.
- 출시 일정은 **오늘 날짜 기준 D-day**(예: "7/31까지 D-13")도 같이 계산해 붙인다.
- 반말·한국어. 스캔 잘 되게 짧게.
- 창업자가 "메모에 ~ 추가/수정해"라고 하면 → `CLAUDE.md`의 고정 메모 섹션을 고쳐서 저장한다.
