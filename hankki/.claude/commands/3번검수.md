# /3번검수
이미지(스티커·프레임·마테)를 자를 때 **3단계 검수 시스템을 가동**한다.
창업자 2026-07-31: *"이렇게 2번 검수하는거 코드에 박아둬"* → *"또 다른방법으로 한번더 검수해 총 3번"*

## ⚠️ 왜 3단계인가 — 하나만 믿었다가 세 번 다 놓쳤다
| 어떻게 봤나 | 놓친 것 |
|---|---|
| **숫자만** | 재료 스티커가 **0%로 나왔는데 화면은 지저분했다.** 찌꺼기가 어둡고 무채색이 아니라 **회갈색**이라 필터에 안 걸림 |
| **눈만** | 프레임 6컷만 고치고 끝낸 줄 알았는데 **앱 전체 853컷에 퍼져 있었다.** 눈으로 다 볼 수 없다 |
| **숫자로 판정** | 의심 71컷에 **꼬르곰의 흰 다이컷 테두리**·**뚝배기의 검은 몸통**이 섞여 있었다. 둘 다 "어둡다" |

📌 **숫자는 「어디를 볼지」만 정하고, 「맞나 틀리나」는 눈이 정한다.**

## 하는 일 (순서대로, 하나도 건너뛰지 말 것)
1. **자른다** — ⛔`tools/cut.py` 만 쓴다(다른 컷 도구 8개는 잠겨 있음)
   ```bash
   python3 tools/cut.py <시트> <낼폴더> <접두어> [--frame] [--min 12000]
   ```
   → 자르면 **아래 3단계가 자동으로 돈다**(`--no-check` 로만 끌 수 있음)
2. **1단계 · 숫자** — 바깥 3px 띠에서 ⒜격자 찌꺼기(어둡고 무채색) ⒝회갈색 잔재(**상대적으로** 어두움) ⒞가장자리 닿음 을 재서 **의심 순위**를 매긴다
3. **2단계 · 눈** — 판 **두 장**을 만들어 클로드가 **직접 열어 본다**
   - ⒜ **진한 판**(`#22263A`) 전체 → **흰 잔재·투명 실패**가 드러난다
   - ⒝ **밝은 판** 의심 컷 확대 → **어두운 잔재·점점이**가 드러난다
   - ⚠️ **한 판만 보면 반은 놓친다.** 둘 다 볼 것
4. **3단계 · 실제 크기** — **앱에 보일 크기(스티커 238px·프레임 626px)로 다시 그려서** 본다 ＋ 알파 품질(반투명 픽셀 %)
   - ⭐ 1·2단계는 **원본 픽셀**을 본다. **유저는 원본을 안 본다.**
   - 알파가 0/255뿐이면(반투명 <2%) 키울 때 **계단**이 진다
5. **판정해서 창업자에게 보고** — 통과/문제 컷을 말로 정리하고, 판 이미지를 **보내준다**
6. 문제 있으면 **고치고 다시 1번부터.** 못 고치는 것(해상도 부족)은 **다시 뽑을 목록**에 올린다

## 판정 원칙
- ⚠️ **어두운 선이 있다고 다 잘못된 게 아니다** — 우리 진갈색 마감·검은 뚝배기·수박 껍질·홍합 껍데기는 **그림 자체**다. 그대로 둔다
- 🩹 **모양이 단순하면 살릴 수 있다**(마테 = 알파는 두고 띠 색만 속살 색으로) · **모양이 복잡하고 해상도까지 모자라면 다시 뽑는다**(프레임). **증상이 같아도 처방이 다르다**
- ⛔ **원본은 절대 안 지운다** — `_원본-*` 폴더에 보관하고 고친다

## 따로 돌리기

```bash
python3 tools/cut-check.py <폴더>              # 이미 자른 것 검수만
python3 tools/cut-check.py <폴더> <낼곳> --top 24
```
