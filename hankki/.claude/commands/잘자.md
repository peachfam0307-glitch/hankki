# /잘자   (창업자가 **「세션 종료할게. 핸드오버해줘.」** 라고 해도 이것이다)
하루를 닫는 **굿나잇 풀 시퀀스.** 아래를 순서대로 다 하고, 끝나면 따뜻하게 인사하고 마친다. (`/안녕`의 짝 — 시작:`/안녕`, 끝:`/잘자`)

## ⛔⛔⛔ 0. **[절대원칙 · 제일 먼저] 「내일 저절로 열리는 것」을 확인한다** (창업자 2026-08-17)

```
node hankki/scripts/release-calendar.mjs --tomorrow
```

> 📮 창업자 원문: *"**전날 검수 못한거는 어떻게잡아? 절대원칙도 무시됐는데?
> 심지어 어제 자기전에 확인하라했는데 네가 안 읽었잖아. 이걸어떻게 강제해?**"*

⛔ **2026-08-16 밤에 정확히 이걸 안 해서 사고가 났다.** 창업자가 *"내일 여름시원한 것 열리네? 확인만해줘"* 라고
   **말로 알려줬는데도** `/잘자` 순서에 그 칸이 없어서 그냥 지나갔다. 다음 날 검수 안 된 레시피 5편이 열렸다.

⭐ **이 명령은 검수 안 받은 레시피가 내일 열리면 `exit 1` 로 죽는다** — **하루를 닫을 수가 없다.**
   그때는 `/잘자` 를 멈추고 **먼저 검수판을 뽑아 창업자에게 보여준다.**
⛔ 「내일은 아무것도 안 열린다」를 **기억으로 말하지 말 것.** 명령이 답한다.

✅✅ **[창업자 확정 2026-08-17] 「한 달치 미리 ＋ 전날 한 번 더」 — 둘 다 한다.**
> 📮 *"**앞으로 한달치씩 미리 검수해두자. 전날도 무조건 한번 확인하고 나가고**"*

⭐ 미리 받은 검수는 **그때의 판**에 대한 것이다. 그 뒤 한 글자라도 고치면 **전날 확인이 그걸 잡는다.**
⛔ **「미리 받았으니 전날은 건너뛴다」 금지.** 창업자가 «무조건»이라고 했다.
📅 한 달치 = `node hankki/scripts/release-calendar.mjs --month <YYYY-MM>` → 판을 뽑아 창업자에게.

## 순서 (하나도 건너뛰지 말 것 · 마지막 7번 = HANDOVER 갱신)
1. **전체복기 (빠진 것 포함)** — 오늘 대화를 **하나도 안 빠뜨리고** 훑어서: 한 것·결정·자산·**빠뜨린 것**까지 찾아 정리. (빠진 항목을 적극적으로 탐색 — 대화에만 있고 문서엔 없는 것 잡아내기.)
2. **정리** — 결정·자산·바뀐 것을 관련 문서(`로드맵-우선순위.md`·`CLAUDE.md`·`docs/stickers/README.md`·해당 docs)에 반영·최신화.
3. **점검** — ①안 커밋된 변경 0인지 ②로컬=원격(전부 푸시)인지 ③앱 버전 ④(앱코드 바뀐 게 있으면) 빌드 통과 — 실제로 확인해서 보고.
4. **청소** — 저장소 찌꺼기·임시파일·죽은 코드/미사용 import 있으면 정리(참조 없는지 확인 후 안전하게). 빌드 통과 확인.
   🧹🧹 **＋ 그날의 찌꺼기를 «싹» 버리고 나간다** (창업자 확정 2026-09-05 — *"**그날의 필요없는 파일, 찌꺼기 싹 다 정리해서 버리고, 컨텍스트 정리까지 하고 마친다.**"*)
   ```
   node hankki/scripts/sweep.mjs --치움
   ```
   ⛔ **2026-09-05 아침에 세션이 «아무것도 못 돌고» 열렸다** — 디스크 8.9MB 남음(100%), `echo` 조차 실패.
      뿌리 = 끊긴 `git fetch` 가 남긴 `.git/objects/pack/tmp_pack_*` **35개 · 25GB**. 하루에 그만큼 쌓인다.
   ⭐ **그래서 밤에 버리고 나간다.** 안 버리면 «다음 세션이 부팅을 못 한다» — 남한테 넘기는 빚이다.
   ✅ 재생성 가능한 것만 지운다(git 찌꺼기·`dist`·캐시·**끝난 세션의** 스크래치패드).
      ⛔ git 이 추적하는 파일이 후보에 들어오면 도구가 스스로 죽는다 — 문서·자산은 안 지운다.
      ⛔ **지금 세션의 scratchpad 는 도구가 알아서 뺀다**(`CLAUDE_SCRATCHPAD_DIR`).
5. **아카이브저장** — 오늘 완료된 기능·결정을 `docs/기능-아카이브.md`에 **이어붙여** 보존(덮어쓰기 X).
6. **doc저장** — 오늘 세션 복기를 `docs/작업복기-YYYY-MM-DD-*.md`로 저장(같은 이름이면 `-2`,`-3`…). **커밋·푸시까지.**
7. 🤝 **HANDOVER.md 갱신 — «맨 마지막»** (창업자 확정 2026-08-23 · 「세션 종료할게. 핸드오버해줘.」)
   ⛔ **적기 «전»에** 실제 파일과 이번 세션 결과를 확인한다 — 버전 · git 상태 · 「현행」 세대 · hold 브랜치.
      **기억으로 적지 않는다. 확인하지 않은 일을 「끝났다」로 적지 않는다.**
   ✅ 갱신할 것 = **「마지막 정리: YYYY-MM-DD HH:MM」(KST)** ＋ 절 여섯을 지금 상태로
      (`## 왜 하는 작업인지` / `## 전에 무슨 작업을 했는지` / `## 앞으로 뭘 해야 하는지` /
       `## 하면 안 되는 작업` / `## 바로 다음 행동` / `## 아직 확인이 필요한 것`)
   ⛔ **끝난 것과 남은 것을 섞지 않는다** — 끝났으면 「전에 무슨 작업을 했는지」로 «옮긴다»(규칙 12ⓑ).
   ⭐ **「하면 안 되는 작업」과 「바로 다음 행동」을 분명히** 적는다 — 다음 세션이 그것부터 이어서 한다.
   ⭐ 확인 못 한 것은 **「아직 확인이 필요한 것」**에 남긴다(없으면 「없음」).

8. 🧹🧹 **[절대원칙 · 창업자 2026-09-03] 적었으면 «덜어내고» 나간다 — ⛔이걸 빼먹으면 안 나간 것이다**

   📮 창업자 원문 = *"**지울 것과 남길 것을 분류해야할 것 같아. 다 집어넣으니까 이지경이 된 듯.**"*
      ＋ *"본질적으로 파서 이런일이 다시는 안생기게."*

   ⛔⛔ **뿌리 = 여기 7번에 「무엇을 «안» 적는지」가 한 줄도 없었다.** 그래서 세션마다 다 집어넣었다.
      🔢 실측 = HANDOVER.md 가 8/23 에 **9,492 B** 로 태어나 11일 만에 **301,307 B(32배)**.
         손댄 커밋 79개 중 **늘어난 게 76회, 줄어든 게 3회.** 늘리는 사람만 있고 줄이는 사람이 없었다.
      ⭐ 게다가 **규칙이 「덧붙이기」를 «명령»하고 있었다** — 핀 「세션 영역 분담」②(*"남의 절을 지우지
         않는다ㆍ맨 아래로 얹는다"*) ＋ `check-current.mjs`(*"현행은 맨 아래"* · 어기면 배포 차단).
         **규칙을 잘 지킬수록 파일이 커지는 구조**였다. 안 지킨 게 아니다.

   ⭐⭐ **분류 기준 — 「내일 이걸 모르면 틀린 일을 하나?」**

   | 🟢 HANDOVER.md 에 «남긴다» (＝기억) | 🗄 세션기록·보관소로 «보낸다» (＝기록) |
   |---|---|
   | ⏳ 안 끝난 것 · 담아만 뒀다 · 배포 전 | ✅ 실물로 닫힌 것 · 배포 완료 |
   | ❓ 창업자 판정을 기다리는 것 | 🚨 사고 경위 · 복기 |
   | ⛔ 하면 안 되는 것 | 📚 옛 버전 목록 |
   | 📌 지금 상태 실측(버전·브랜치) · ▶️ 바로 다음 | 🎨🏛 그 세션이 «한 일» 전부 |

   ⭐ **기계가 가르는 기준 = 제목에 «날짜»가 있나.**
      `## 🎨 [2026-09-03 …] v12.29 …` → 날짜 있음 = 「그날 무슨 일이 있었다」 = 🗄기록
      `## 하면 안 되는 작업`            → 날짜 없음 = 「지금 상태가 이렇다」 = 🟢기억
      📌 **날짜가 붙었다는 건 이미 「지나간 일」이라는 뜻**이다.

   👉 **그래서 이렇게 한다 (읽고 판단할 필요 없다 — 도구가 한다)**
   ```
   node hankki/scripts/doc-trim.mjs           # 👀 뭘 옮길지 보여준다
   node hankki/scripts/doc-trim.mjs --옮김     # ✂️ 실제로 옮긴다
   node hankki/scripts/check-docsize.mjs      # 📏 문턱 아래인지 확인 (이게 초록불이어야 나간다)
   ```
   ⛔ **한 글자도 «지우지» 않는다 — 옮길 뿐이다.** 도구가 「뺀 줄 == 넣은 줄」을 스스로 세서 확인하고,
      안 맞으면 아무것도 안 한다. 나중에 근거를 찾을 수 있어야 하기 때문이다.
   ⭐ 끝난 절에는 제목에 **「✅」를 붙여 둔다** — 그래야 다음번에 도구가 자동으로 집어간다.
      (도구는 «저장소가 스스로 끝났다고 적어 둔 것»만 옮긴다. ⛔날짜만 오래된 것은 안 건드린다 —
       *"[2026-08-29 · 여기서 멈췄다]"* 같은 건 오래됐어도 **살아 있는** 일이다.)

   🔒 **안 해도 결국 걸린다 (세 겹)** — ① `/안녕` 이 다음 세션에 알린다 ② `check-docsize` 가 배포를 막는다
      ③ 이 7·8번. **셋 중 하나만 살아 있어도 파일이 안 커진다.**
