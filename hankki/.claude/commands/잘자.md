# /잘자   (창업자가 **「세션 종료할게. 핸드오버해줘.」** 라고 해도 이것이다)
하루를 닫는 **굿나잇 풀 시퀀스.** 아래를 순서대로 다 하고, 끝나면 따뜻하게 인사하고 마친다. (`/안녕`의 짝 — 시작:`/안녕`, 끝:`/잘자`)

## ⛔⛔⛔ 0. **[절대원칙 · 제일 먼저] 「내일 저절로 열리는 것」을 확인한다** (창업자 2026-08-17)

```
node hankki/scripts/release-calendar.mjs --tomorrow
```

> 📮 창업자 원문: *"**전날 검수 못한거는 어떻게잡아? 절대원칙도 무시됐는데?
> 심지어 어제 자기전에 확인하라했는데 네가 안 읽었잖아. 이걸어떻게 강제해?**"*

⛔ **2026-08-16 밤에 정확히 이걸 안 해서 사고가 났다.** 창업자가 *"내일 여름시원한 것 열리네? 확인만해줘"* 라고
   **말로 알려줬는데도** `/잘자` 순서에 그 칸이 없어서 그냥 지나갔다. 다음 날 검수 안 된 레시피 5편이 열렸다.

⭐ **이 명령은 검수 안 받은 레시피가 내일 열리면 `exit 1` 로 죽는다** — **하루를 닫을 수가 없다.**
   그때는 `/잘자` 를 멈추고 **먼저 검수판을 뽑아 창업자에게 보여준다.**
⛔ 「내일은 아무것도 안 열린다」를 **기억으로 말하지 말 것.** 명령이 답한다.

✅✅ **[창업자 확정 2026-08-17] 「한 달치 미리 ＋ 전날 한 번 더」 — 둘 다 한다.**
> 📮 *"**앞으로 한달치씩 미리 검수해두자. 전날도 무조건 한번 확인하고 나가고**"*

⭐ 미리 받은 검수는 **그때의 판**에 대한 것이다. 그 뒤 한 글자라도 고치면 **전날 확인이 그걸 잡는다.**
⛔ **「미리 받았으니 전날은 건너뛴다」 금지.** 창업자가 «무조건»이라고 했다.
📅 한 달치 = `node hankki/scripts/release-calendar.mjs --month <YYYY-MM>` → 판을 뽑아 창업자에게.

## 순서 (하나도 건너뛰지 말 것 · 마지막 7번 = HANDOVER 갱신)
1. **전체복기 (빠진 것 포함)** — 오늘 대화를 **하나도 안 빠뜨리고** 훑어서: 한 것·결정·자산·**빠뜨린 것**까지 찾아 정리. (빠진 항목을 적극적으로 탐색 — 대화에만 있고 문서엔 없는 것 잡아내기.)
2. **정리** — 결정·자산·바뀐 것을 관련 문서(`로드맵-우선순위.md`·`CLAUDE.md`·`docs/stickers/README.md`·해당 docs)에 반영·최신화.
3. **점검** — ①안 커밋된 변경 0인지 ②로컬=원격(전부 푸시)인지 ③앱 버전 ④(앱코드 바뀐 게 있으면) 빌드 통과 — 실제로 확인해서 보고.
4. **청소** — 저장소 찌꺼기·임시파일·죽은 코드/미사용 import 있으면 정리(참조 없는지 확인 후 안전하게). 빌드 통과 확인. (scratchpad 임시파일은 세션용이라 건드리지 않음.)
5. **아카이브저장** — 오늘 완료된 기능·결정을 `docs/기능-아카이브.md`에 **이어붙여** 보존(덮어쓰기 X).
6. **doc저장** — 오늘 세션 복기를 `docs/작업복기-YYYY-MM-DD-*.md`로 저장(같은 이름이면 `-2`,`-3`…). **커밋·푸시까지.**
7. 🤝 **HANDOVER.md 갱신 — «맨 마지막»** (창업자 확정 2026-08-23 · 「세션 종료할게. 핸드오버해줘.」)
   ⛔ **적기 «전»에** 실제 파일과 이번 세션 결과를 확인한다 — 버전 · git 상태 · 「현행」 세대 · hold 브랜치.
      **기억으로 적지 않는다. 확인하지 않은 일을 「끝났다」로 적지 않는다.**
   ✅ 갱신할 것 = **「마지막 정리: YYYY-MM-DD HH:MM」(KST)** ＋ 절 여섯을 지금 상태로
      (`## 왜 하는 작업인지` / `## 전에 무슨 작업을 했는지` / `## 앞으로 뭘 해야 하는지` /
       `## 하면 안 되는 작업` / `## 바로 다음 행동` / `## 아직 확인이 필요한 것`)
   ⛔ **끝난 것과 남은 것을 섞지 않는다** — 끝났으면 「전에 무슨 작업을 했는지」로 «옮긴다»(규칙 12ⓑ).
   ⭐ **「하면 안 되는 작업」과 「바로 다음 행동」을 분명히** 적는다 — 다음 세션이 그것부터 이어서 한다.
   ⭐ 확인 못 한 것은 **「아직 확인이 필요한 것」**에 남긴다(없으면 「없음」).
   ⛔ 비밀번호·인증키·개인정보·대화 전문은 **적지 않는다.**
   📌 전문 = `hankki/CLAUDE.md` 맨 아래 「🤝🤝 새 세션 인수인계」 절

## 원칙
- **덮어쓰기 금지** — 문서는 새 이름 or 이어붙이기.
- **모든 저장은 커밋·푸시까지** (세션 날아가도 안 잃게). 배포와 무관(규칙 9 예외).
- 끝나면 **"오늘 한 것 요약 + 내일 이거부터"** 짧게 + 굿나잇 인사.
- 날짜는 KST. 반말·한국어, 따뜻하게.
