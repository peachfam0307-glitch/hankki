# /최신
지금 **주제별로 뭐가 최신인지** 뽑아 본다. 「옛 문서 보고 판단하는 사고」를 막는 자리.

## 하는 일
1. `node scripts/latest-map.mjs` — 주제별 최신 문서 + 옛 문서 목록
2. `node scripts/latest-map.mjs --check` — 게이트(핀 낡음·옛 세대 되살아남 검사)
3. 결과를 창업자에게 짧게 보고. 특히 **「저장소 밖」 항목**은 파일로 확인할 수 없으니 **물어본다.**

## 원칙
- ⭐ **날짜 붙은 문서는 코드가 알아서 최신을 고른다.** 손으로 목록 관리하지 말 것 — 낡는다.
- 자동으로 못 고르는 것만 `docs/최신-지도.md` 에 **핀**으로 박는다.
- ⚠️ **「저장소에 있는 것」 ≠ 「실제로 올라가 있는 것」.**
  스토어 스크린샷·Play Console versionCode·구글폼 문항은 **저장소가 모른다.** 반드시 창업자 확인.
- 옛 것을 꼭 봐야 하면 **최신을 먼저 읽으면** 훅이 열어준다(`.claude/hooks/latest-guard.sh`).
