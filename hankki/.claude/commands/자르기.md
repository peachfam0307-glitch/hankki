# /자르기
이미지(스티커 시트) 자르기를 **시작하기 전에 무조건** 이걸 먼저 돈다.

> 창업자 2026-07-31: *"이미지 자르기전에는 무조건 그 문서를 읽고 시작하는 걸로"*
> 규칙은 있었는데 **지킬 장치가 없어서** 옛 격자 시트로 자르는 사고가 났다.

## 하는 일 (순서대로, 자동)

1. **`docs/자르기-먼저읽기.md` 정독** — 규칙·최우선 고려사항·도구·검수 포인트 전부 여기 있다.
2. **원본 우선순위 표 갱신** → `python3 tools/sheet-index.py`
   → `docs/stickers/_원본-우선순위.md` 를 열어 **가장 최근 팩**을 확인한다.
   ⛔ **옛날 시트 뒤져 쓰지 말 것.** 같은 그림이면 위(최신)에 있는 팩이 무조건 우선.
   ⚠️ **폴더 이름을 믿지 말 것** — `신규-2607-재료도구` 안에 프레임이 있었다.
3. **쓸 시트를 검사** → `python3 tools/sheet-index.py --check <시트.png>`
   격자 / 컷 크기 / 흰 다이컷 세 가지를 한 줄로 알려준다.
   🔒 이걸 돌려야 **훅이 열려** `cut.py`·`recut.py` 가 실행된다.
4. **창업자에게 한 줄로 확인** — 「이 시트(팩·컷 크기)로 이 옵션으로 자를게」.
   ⚠️ 크게 쓰는 것(프레임·표지)인데 컷이 400px 미만이면 **자르지 말고 다시 뽑자고 말한다.**
5. 자른 뒤 **눈으로 4판** — 진한 · 🟥빨간 · 밝은 · 실제 크기 (`cut.py` 가 자동으로 만든다).
6. 앱에 넣을 땐 **`recut.py --panel` 로 짝을 눈으로 본 뒤** `--apply`.
7. 마지막에 **`npm run smoke`**.

## 원칙
- 📌 **숫자는 「어디를 볼지」만 정하고, 「맞나 틀리나」는 눈이 정한다.**
- ⛔ 컷 도구는 **`tools/cut.py` 하나만.** 옛 도구는 실행하면 멈춘다.
- ⛔ **`--apply` 전에 `--panel`** — 숫자 「2」가 「오늘도 해냄」 자리를 차지한 적이 있다.
- 🔒 이 절차를 건너뛰면 `.claude/hooks/cut-guard.sh` 가 **명령 자체를 막는다.**
