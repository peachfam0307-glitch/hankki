# /명령어 — 명령어 목록

`.claude/commands/` 폴더의 모든 `*.md` 파일을 읽어서, 창업자에게 **명령어 목록**을 반말·한국어로 보여줘라.

## 하는 일
1. `.claude/commands/*.md` 를 전부 확인한다.
2. 각 파일의 이름(`/파일명`)과 맨 위 `description:` 을 뽑아 목록으로 정리한다.
3. 아래 형식처럼 보여준다:

   ```
   지금 쓸 수 있는 명령어:
   ▸ /복기   — 오늘 작업 대화 싹 읽고 복기 정리
   ▸ /명령어 — 명령어 목록 보여주기
   ...
   ```
4. "새 명령어 만들까?" 하고 물어본다.

## 원칙
- 반말·한국어로. 창업자는 비개발자니까 각 명령어가 "뭘 하는지" 한 줄로 쉽게.
