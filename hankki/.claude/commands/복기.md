# /복기 — 오늘 작업 복기

오늘 창업자와 나눈 **작업 대화 전체를 하나도 빠뜨리지 않고** 읽고, 검토해서 복기 문서로 정리한다.

## 절차 (반드시 순서대로)

1. **전체 대화 읽기.** 요약본이 아니라 실제 대화를 처음부터 끝까지 훑는다.
   - 현재 세션 트랜스크립트: `/root/.claude/projects/-home-user--/*.jsonl` 중 최신 파일을 읽는다.
   - 컨텍스트가 압축(summary)돼 있으면, summary + 이후 실제 메시지를 합쳐 **빠진 구간 없이** 재구성한다.
   - 창업자의 모든 요청·불만·결정, 내가 한 수정·커밋, 막혔던 지점과 해결을 빠짐없이 수집한다.

2. **검토.** 수집한 내용을 시간순/주제별로 교차 확인한다.
   - 미해결로 남은 것, 결정 대기, 다음에 이어서 할 것을 분리해 표시한다.
   - 헤맸던 원인과 교훈(다음에 반복 안 하려면)을 뽑는다.

3. **문서로 정리.** `docs/작업복기-YYYY-MM-DD.md` 에 저장(오늘 날짜, 이미 있으면 이어붙이기).
   - 형식: 기존 `docs/작업복기-2026-07-17.md` 스타일 따르기.
   - 섹션 예: `1) 오늘 한 일(주제별)`, `막혔던 점·교훈`, `미해결/결정 대기`, `다음 이어서 할 것`.
   - `docs/남은-할일-정리-2.md` 와 `CLAUDE.md` 의 상태도 필요하면 함께 갱신.

4. **커밋·푸시.** 정리 문서를 커밋하고 `claude/chatgpt-conversation-link-kvn5ph` 브랜치에 푸시.

## 원칙
- **하나도 빠뜨리지 말 것.** 사소해 보여도 창업자가 언급한 건 다 기록.
- 반말·한국어로 (창업자 규칙). 추측 금지 — 대화에 근거해서만 정리.
- 오늘 날짜는 시스템 컨텍스트의 currentDate 기준.
