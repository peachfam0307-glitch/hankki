# /할일
지금 상황 기준으로 **오늘 해야 할 일**을 우선순위로 정리해서 보고한다.

## ⭐⭐ 소스 = 전체 다 봐라 (창업자 명시 2026-07-24: "앞으로 전체에서 다 보고 뽑아줘")
**한 문서만 보고 좁게 뽑지 말 것.** 아래를 전부 훑어 최신 스냅샷으로 취합한다:
- **1순위 소스 = 가장 최근 `docs/할일-전체정리-YYYY-MM-DD.md`** (로드맵·태스크·컨셉·세션결과 취합한 마스터 스냅샷)
- `docs/로드맵-우선순위.md` · `docs/아이디어-로드맵.md` · `docs/출시-로드맵.md`
- `docs/남은-할일-정리-2.md` · `docs/할일-*.md`(공유카드 운영 등)
- **TaskList**(진행중·대기 태스크) + 스냅샷 이후 `작업복기-*.md`(완료·신규분) + **대화 흐름** + **코드 현재 상태(버전)**
- 스냅샷 이후 완료된 것/새로 생긴 것 반영해 **최신화**.
- ⚠️ **백로그를 숨기지 말 것.** 배경테마·온보딩·영상·스샷·템플릿 등 디자인/프로덕트 할일도 다 포함. (안 보이면 창업자가 "할일 많은데 다 어디갔어" 함 — 2026-07-24 실제 지적.)

## 형식 (스캔 잘 되게, 반말·한국어)
- 🔴 **지금 게임/착수** (막는 것 · 이번 포커스 묶음)
- 🎨 **폴리싱·병행** (창업자 결정 대기는 표시)
- 🔴 **출시 게이트** (7/31)
- 🟢 **지금 하면 유리** (선점)
- ✅ **최근 끝낸 것** (짧게)
- 🔵 **나중(수익 후)** — 한 줄로 묶어 "안 날아갔다"만 확인시켜줌
- 맨 아래 **"오늘 딱 하나만"** 골라 짚기.
- **창업자가 직접 할 일 vs 클로드가 도울 일** 구분 (대부분 제작=클로드, 창업자=판단·스토어 업로드·상표).
- 장황 금지, 스캔 잘 되게.
