# /할일
지금 상황 기준으로 **오늘 해야 할 일**을 우선순위로 정리해서 보고한다.
- 대화 흐름 + 문서(`남은-할일-정리-2.md`, `출시-실행-체크리스트.md` 등) + 코드 현재 상태를 반영해 **최신**으로.
- 나눠서 보여주기:
  - 🔴 **지금 결정/처리** (막고 있는 것, 오늘 손대야 할 것)
  - 🟡 **곧 할 것** (이번 주, 확인만 하면 되는 것)
  - 🟢 **배경·확인** (급하지 않음, 자동 진행/모니터링)
  - ✅ **이미 끝낸 것** (오늘 처리분 짧게)
- 맨 아래 **"오늘 딱 하나만"** 골라 짚어주기.
- **창업자가 직접 할 일** vs **클로드가 도울 일** 구분.
- 반말·한국어. 장황하게 말고 스캔 잘 되게.
