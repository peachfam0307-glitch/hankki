# 🍳 36편 검수판 — 만드는 도구

창업자에게 보여주는 판(아티팩트)을 만드는 세 파일이다.
👉 판 주소 = https://claude.ai/code/artifact/51b636a2-a4f8-47c4-97ed-976d2d870453

## ⛔ 왜 여기 있나
scratchpad 는 **컨테이너가 되감기면 통째로 날아간다**(2026-08-11 아침에 두 번 겪었다).
판을 다시 만들어야 할 때 이 폴더에서 꺼내 쓴다 — 원격에 있어야 산다.

## 쓰는 법
경로가 scratchpad 기준이라 **거기로 옮겨서** 돌린다.

```
S=/tmp/claude-0/.../scratchpad
cp scripts/_검수판36-0811/{검수36-데이터.mjs,make-검수36.mjs,_판검사36.mjs} "$S"/
cd "$S" && node make-검수36.mjs && node _판검사36.mjs
```

- `검수36-데이터.mjs` — 창업자 원문(1차 검수 24 · 2차 정정 11 · 전수) ＋ 내가 한 것
  ⛔ **창업자 원문은 한 글자도 고치지 않는다.** 판정 기준이 「내가 말한 대로 됐나」라서다.
- `make-검수36.mjs` — 판 생성기. 레시피 본문은 `docs/_대기/레시피-정리-초안-2026-08-10.json` 에서 읽는다
- `_판검사36.mjs` — 판을 열어 세는 검사 17칸
  ⭐ 개수를 **손으로 적지 말 것** — 첫 판에 14·2로 적었다가 둘 다 틀렸다(실제 15·1).
     둘 다 「판이 아니라 검사」가 틀린 것이었다.
