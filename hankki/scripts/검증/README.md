# 🔬 검증 스크립트 — 「진짜 그렇게 보이나」를 눈으로 확인하는 것들

**스티커·화면을 앱에 넣기 전 검수 원칙 ⑤(실제 앱 렌더)** 를 실행하는 도구들이다
(→ `docs/스티커-검수-절대원칙.md`).

`npm run smoke` 는 **배포를 막는 게이트**라 자동으로 돌지만, 여기 있는 건
**사람이 눈으로 볼 그림을 만드는 도구**라 필요할 때 손으로 돌린다.

> 📌 **2026-08-01 청소 전엔 이 파일들이 `hankki/` 루트에 `_xx.mjs` 로 흩어져 있었다.**
> 이름만 봐선 뭔지 알 수 없어서 매번 다시 열어봐야 했다 → 폴더로 모으고 이 표를 붙였다.
> 옛 문서가 `hankki/_aut.mjs` 처럼 부르고 있으면 **여기(`scripts/검증/`)를 보면 된다.**

## 돌리는 법

```bash
cd hankki
export SMOKE_CHROMIUM=/opt/pw-browsers/chromium-1194/chrome-linux/chrome
npm run build                 # ⚠️ preview 는 «빌드된 dist» 를 띄운다 — 안 하면 옛 화면을 본다
node scripts/검증/_ob5.mjs
```

⚠️ **`SMOKE_CHROMIUM` 을 `export` 안 하면 스크립트가 조용히 죽는다.**
그러면 **옛 스크린샷이 그대로 남아 「고쳤다」고 착각한다** — 실제로 겪은 사고다.

## ⛔ 새로 만든 일회용 스크립트는 저장소에 안 남긴다

한 번 쓰고 말 검증 스크립트는 **`hankki/` 루트에 `_이름.mjs`** 로 만든다 —
`.gitignore` 가 막아서 **커밋에 안 딸려 간다**(그래서 여기가 다시 안 지저분해진다).

**여러 번 다시 돌릴 것만** 이 폴더로 옮기고 위 표에 한 줄 적는다.
