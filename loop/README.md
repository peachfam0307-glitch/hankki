# loop — 주기 · 회차 캘린더 (1단계 앱)

내 학원 시간·회차, 네일/염색/커트 주기, 납부일 등을 한 곳에서 관리하는 캘린더 앱.
지금은 **실제로 동작하는 웹 앱(오프라인)** 이고, 다음 단계에서 Capacitor로 감싸 갤럭시 APK로 만든다.

## 지금 되는 것 (Stage 1 — 동작하는 앱)
- **월간 달력** — 라벨형(칸 크게, 색 라벨에 글자, 줄바꿈), 오늘 표시, 이전/다음 달 이동
- **목록 보기** — 날짜별로 일정·시간·회차 정리
- **하루 보기** — 날짜 탭 → 시트가 열리고 그날 일정이 시간순, 스티커 태그
- **일정 추가/편집** — 이름·날짜·하루종일·시간·알림·알림음·반복(매일/매주/매달)·색상·스티커·메모·삭제
- **회차 세기** — 반복 일정에 "N회차" 자동 표시 (예: 화·목 학원 → 4회차)
- **스티커** — 하루 태그 + 개별 일정 아이콘 (20종, 카테고리별 라이브러리)
- **글씨체 5종** — 주아 · 동글 · 프리텐다드 · 고운돋움 · 도현 (설정에서 전환)
- **다크 모드**, **로컬 저장(localStorage)**, **백업 내보내기(JSON)**
- **알림음 미리듣기**(합성음) — 실제 소리 파일은 네이티브 단계에서 탑재

## 실행 (미리보기)
정적 파일이라 로컬 서버로 열면 됨:
```
cd loop
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```
(폰트가 `./fonts/`에서 로드되므로 file:// 직접 열기보다 서버 권장)
