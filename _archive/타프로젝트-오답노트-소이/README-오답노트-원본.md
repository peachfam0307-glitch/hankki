# 오답 끝 ✗ — 오답노트 트래커

소이(Soi) 전용 오답노트 앱. 틀린 문제를 사진과 함께 기록하고, 플래시카드로
다시 풀고, AI가 변형문제를 출제·채점해 주는 Claude 아티팩트용 React 앱입니다.

컨셉은 **모눈 연습장 + 빨간펜 첨삭**. `WrongNoteTracker.jsx` 하나에 UI·로직·스타일이
모두 들어 있습니다.

## 탭 구성

- **기록** — 과목·단원·출처·틀린 이유(과목별 태그)·메모·문제 사진(최대 5장)·푼 시간·별표. 카드마다 풀이 기록, AI 풀이 도우미(소크라테스식/전체 풀이), 발상 카드, 즉석 변형문제를 붙일 수 있어요.
- **플래시카드** — 사진 오답을 과목별·랜덤으로. 스톱워치 또는 3분 타이머(+1분 최대 2회), 펜슬 풀이 패드(모눈·색펜·직선자·포스트잇)와 AI 채점, '다시 풀기'/'중요만' 필터.
- **변형문제** — 포항제철고 20년차 극악 출제 교사 페르소나가 특정 오답 또는 실수 패턴 종합을 기준으로 상/최상 문제를 출제. 기준 교재 반영, 3분 타이머, 풀이 패드+AI 채점.
- **실수 패턴** — 누적 오답·정복률, 틀린 이유별/과목별 분포 막대그래프, 가장 자주 걸리는 함정 안내.
- **설정** — AI 연결 점검, 과목·기준 교재·실수 태그 직접 관리, 선별/전체 삭제.

## 저장 방식

- 기록·사진·발상 카드는 `window.storage`(Claude 아티팩트 저장소)에 자동 저장됩니다.
- 작성 중이던 기록은 자동 임시저장되어 새로고침돼도 복구됩니다.
- **인쇄용 저장**으로 필터된 오답을 `.html` 파일로 내보내 인쇄할 수 있습니다.

## AI 기능

- Claude 안 실행판은 API 키 없이 AI(도우미·발상카드·변형문제·필기 채점)가 작동합니다.
- 파일 미리보기 등 외부 연결이 막힌 환경에서는 각 AI 버튼이 질문을 클립보드에 복사해, 새 채팅에 붙여넣어 답을 받을 수 있게 폴백합니다.

## 실행

이 앱은 Claude 아티팩트 런타임(`window.storage`, API 키 없는 `fetch`)에 의존하는
React 컴포넌트입니다. Claude 아티팩트로 열면 그대로 동작합니다.
