# 오답노트 트래커

틀린 문제를 기록하고, 간격 반복(1일 → 3일 → 7일 → 14일)으로 복습을 관리하는 웹 앱입니다.
`index.html` 파일 하나로 동작하며, 서버 없이 브라우저에서 바로 열면 됩니다.

## 기능

- 오답 기록: 과목, 출처·문제 번호, 문제 내용, 내가 쓴 답 / 정답, 틀린 이유, 해설·메모
- 간격 반복 복습: 4회 복습(1·3·7·14일 간격)을 마치면 완료 처리, "오늘 복습" 필터로 확인
- 필터·검색: 과목별, 상태별(오늘 복습 / 복습 전 / 완료), 텍스트 검색
- 요약: 총 오답 수, 오늘 복습할 문제 수, 완료 수
- 데이터: 브라우저 localStorage에 자동 저장, JSON 내보내기/가져오기 지원
- 라이트/다크 테마 자동 대응

## 사용법

`index.html`을 브라우저로 열기만 하면 됩니다. 데이터는 그 브라우저에 저장되므로,
기기를 옮길 때는 **내보내기**로 JSON을 저장한 뒤 다른 기기에서 **가져오기** 하세요.
