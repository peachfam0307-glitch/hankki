# 🍽️ 한끼 (HANKKI)

**흩어진 레시피를, 한곳에. — 그리고 예쁘게 꾸며서 자랑까지.**

인스타·유튜브·블로그·사진에 흩어진 레시피를 모으고 정리하는 **나만의 레시피 아카이브**.
한끼는 레시피를 *찾는* 앱이 아니라 **모으는** 앱입니다. "인스타에 저장은 해놨는데 못 찾겠다" — 이 문제를 해결합니다.

설치형 웹앱(**PWA**)이라 휴대폰 홈 화면에 설치하면 독립 앱처럼 전체화면으로 실행되고, 오프라인에서도 동작합니다.

> 📦 앱 소스는 [`hankki/`](./hankki) 폴더에 있습니다. · 🐻🐧 마스코트 = **꼬르곰·펭펭** · 현재 버전 **v8.69**

---

## ✨ 주요 기능

**모으기**
- **가져오기(Import)** — Instagram · YouTube · 링크 · **사진(OCR 자동 인식)** · 직접 작성
- **Inbox** — 가져온 레시피는 바로 저장 안 되고 임시 보관 → 나중에 제목·태그·폴더로 정리
- **검색** — 음식명 · 재료 · 태그로 찾기 · 즐겨찾기 · **자주 해먹는 요리**("만들었어요!" 누를수록 자동 수집)

**꾸미기 (레꾸) — 한끼의 시그니처**
- **레시피 꾸미기(레꾸)** — 레시피 표지를 **꼬르곰·펭펭 스티커·프레임·배경·손글씨·반짝임 효과**로 꾸미기 (다꾸 감성). 꾸미던 중 앱이 꺼져도 **자동저장 복구**.
- **레꾸자랑** — 내가 꾸민 표지나 랜덤 카드를 **카톡·인스타로 공유**(바이럴 진입점).

**살림**
- **장보기 · 냉장고** — 장보기 체크리스트("샀어요" → 냉장고 자동 입고), 유통기한 관리, **냉장고 파먹기**(있는 재료로 요리 추천), 레시피에서 재료 한 번에 담기
- **주부의 장바구니** — 18년차 주부가 엄선한 건강 식재료 큐레이션 · 쇼핑몰 바로가기
- **요리모드** — 큰 글씨 · 화면 안 꺼짐 · 단계별 타이머
- **요리 기록(다이어리)** — 만든 요리 아카이브 · 요리 달력

모든 데이터는 기기의 `localStorage`에 저장됩니다. *(V2에서 클라우드 백업·AI 자동 정리·가족 공유 예정)*

## 🛠️ 기술 스택

- **React 18 + Vite** · **PWA**(`vite-plugin-pwa`, 오프라인·공유받기 `share_target`)
- **tesseract.js** — 사진 레시피 OCR · **html-to-image** — 공유 카드 생성
- **GitHub Pages** 배포 (GitHub Actions) — 배포 전 **스모크 테스트 자동 실행**(저장 등 핵심 흐름 런타임 크래시 시 배포 차단)

## 📁 저장소 구조

```
hankki/                  ← 앱 소스 (React PWA)
  src/                   ← 화면·컴포넌트·스티커 자산
  docs/                  ← 기획·복기·로드맵 문서
  docs/stickers/         ← 스티커·이모지 마스터 라이브러리(README = 단일 진실원)
  .claude/commands/      ← 작업 명령어(/안녕·/잘자·/점검·/청소 등)
_archive/                ← 구버전·타프로젝트 잔재 보관(삭제 대신 격리)
```
